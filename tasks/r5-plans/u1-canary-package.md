**风险陈述(如实)**:按 axis1 主轴口径,基线结论对「以上述 5 轴为主干故事」的文本**无直接佐证力**——金丝雀集中不存在以它们为主轴的篇章,若这些轴的行文节奏/句式分布与样内 8 轴系统性不同,误报率结论不可外推。缓解事实:5 轴在 22 篇内**全部以次标签出现**(≥2 次),其语言特征(标签 keyword_patterns 所指的文本现象)有载体,故不是全盲区;但「主干 vs 配菜」的密度差异无法由次标签样本担保。若用户要求闭合该缺口,扩样方向为各轴 A 级最高分 1-2 篇(重逢修罗场/现实反差/身份反差各 1 篇 A 级;仙侠/修仙、危机压身仅 B 级,将触发 §1.3 同型偏离),代价是突破 22 篇规模并稀释 S 级权重——**默认不扩,如实声明缺口**。

## 3. 正文来源结论(全文级,未降级)

- `kb_corpus_articles` **无正文列**(仅 summary/char_count/source_url);`kb_corpus_excerpts` 436 段共约 2.5 万字(全文 265 万字),摘录级不满足基线口径;`kb_imported_files` 为方法论参考件登记,与语料无关;本地磁盘无原始抓取留存。
- 正文实际位置:source_url(123 篇均指向 `www.yanxuan.org`)页面内 `<script type="text/plain" id="compressed-story">`,内容为 **base64 + zlib deflate** 密文(站点前端以 pako.inflate 解压挂载)。已用 Node `zlib.inflateSync` 程序化复现该解压链,导出 22 篇全文至 `data/canary/g{1,2,3}/<article_id>_<title短>.md`。
- 清洗:HTML 转段落 + 实体反转义 + 整行剔除站点框架残留(备案验证码行/【已完结】标记)。导出字符合计 **329,300** vs 库 char_count 合计 **347,436**(ratio 0.948;逐篇 0.934-0.962 稳定,差值=站点框架字符,同量级达标)。
- 注释头二选一裁决:**正文文件保持纯净**,映射登记 `selection.json`——理由:①article_id 已入文件名可追溯;②D2 装载器契约尚未落地,纯净正文不依赖装载器对首行注释的处理;③字数/fingerprint 统计无需特判首行。
- 版权口径:抓取源为转载站,原始版权属原作者/原平台;语料仅落 `data/canary/`(gitignore),不进 git 不进 docs;与 **U12(版权数据通道)** 一并呈报,B 级语料授权另属 **U7**(R5 前)。

## 4. U13(用户裁决点):男频叙事语料缺失

- 金丝雀 123 篇全部为女频短篇,无一男频叙事样本。盲测对照组若用金丝雀叙事选段,判源结论带「频道泄漏折扣」(裁-9);D1 §3.5/锚点表的「男频项目折扣口径」也因无男频人类基线而只能维持单向(过紧检测)。
- 按 R5 总计划 §5,U13(R0 批):**男频叙事语料授权补采**由用户裁决——本包只登记缺失事实,不自行补采、不预设来源与规模。
