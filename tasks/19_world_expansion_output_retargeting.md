# Task 19：四个 World Expansion 输出收编为 World Contract 切片

## 状态

`CANCELLED`（经训练数据多题材对照评估，原方向不成立）

## 背景

世界观设计重构讨论稿（`documentation/worldbuilding-redesign.md`）第 22.2 条建议把四个 world expansion 的独立 `*_contract` 输出收编为 `world_contract` 的 state 切片。

## 评估结论：原方向不成立，问题本身是伪问题

经训练数据多题材对照（无需实跑 NovelOS），**"一份大契约 vs 四切片"不是普适问题，而是题材相关的**。三个结构差异大的题材呈现三种不同形态：

| 题材类型 | 代表 | 四维关系 | 适合形态 |
|---|---|---|---|
| 单一法则贯穿型 | 修仙（《凡人修仙传》）、西幻（西幻项目） | 规则→资源→势力是一条因果链，高度耦合 | **一份大契约**（西幻已实证质量高，守恒律贯穿八章） |
| 元规则+独立副本型 | 无限流（《无限恐怖》《轮回乐园》） | 主神空间规则稳定，每个副本世界资源/势力独立 | **元规则稳定 + 副本切片** |
| 规则为根的树型 | 序列流（《诡秘之主》） | 规则体系为核心，资源/势力挂载其上 | **规则为根的树形结构** |

### 为什么 22.2 原判断是错的

22.2 假设所有题材都适合"收编为切片"。但训练数据显示：
- 对单一法则贯穿型（修仙/西幻），收编**有害**——会切断"法则→资源→势力"的因果链。西幻实证已证明"一份大契约"对自洽有利。
- 只对元规则+独立副本型（无限流），切片才可能更好。

强制统一收编会让 NovelOS 适配某一类题材而伤害其他类。**正确的不是"要不要收编"，而是"按题材选形态"**——这超出 22.2 的原范围。

## 决定：取消本 Task

22.2 的"强制收编"方向不成立。四个 expansion 维持现状（各产独立 `*_contract`）是合理的——它保留了"按题材组合"的灵活性，而 world Agent 在生成 world_contract 时已能自由组织形态（西幻就组织成了一份连贯大契约）。

### 记入文档的修正

`documentation/worldbuilding-redesign.md` 第 22.2 条应补充评估结论：
- 22.2 原"强制收编"经多题材对照证伪。
- world_contract 的组织形态应由 world Agent 按题材自选（一份大契约 / 切片 / 树形），不应在 expansion 输出层强制。
- 四个 expansion 维持独立 `*_contract` 输出，作为 world Agent 的输入素材，而非强制拼装件。

## 改动文件

本 Task 取消，无代码改动。仅更新 `documentation/worldbuilding-redesign.md` 第 22.2 条的评估结论。

## 教训

22.2 是从单一题材（西幻）推论出的通用建议，但世界契约的组织形态是题材相关的。**单题材实证不足以支撑跨题材的架构级改动判断**——这类判断必须用训练数据做多题材对照，或跑多个实样本。
