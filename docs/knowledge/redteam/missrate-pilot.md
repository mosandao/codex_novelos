## 1. 实验设计

- **试点组**：标准 chapter-draft 管线产出——/tmp 夹具库（生产库副本 + 现成 style_seed persona 绑定 + locked 章纲），组装器产出完整注入（68,622B / 70,668B，含语态槽 prev_chapter_tail 取上章结尾 800 字），交写作 sub agent（fresh context ×2）各生成一章 ≥4000 汉字。即：**在被完整防指纹注入约束下的真实管线输出**，量其漏过 screen 层的 AI 味残留。

- **测量**：`novelos-prose-fingerprint.mjs --text-file <f> --json --stable`（screen 层 12 规则；measure 层不计入候选）。
- **初标**：对 screen 未命中段落逐段判「残留 AI 味」二元（阳性/阴性 + 边缘三档），标注焦点 = **规则表之外的变体**（抒情点题收束、跨章工整回环、格言式收束、抒情升华——即金丝雀基线揭示的「特征规则抓不住新变种」盲区类）。

逐段标注（阳性=残留 AI 味；边缘=两可，列理由不判死）：

| 章·段 | 判 | 理由 |
|---|---|---|
| ch1「冬天，天井里那台水泵响了一夜。……那年冬天特别长。」 | **阳性** | 「那年冬天特别长」=抒情点题收束句——记忆段以抒情升华格言收尾，规则表无此特征（FP 卡精神覆盖、fpr 表无条目） |
| ch1「两拨人，都挑了后半夜。一拨……一拨……连脸都没给。」 | 边缘 | 工整对照排比解说收束；信息密度高，网文语境可读为正常笔力 |
| ch1 末段「风铃没有再响。」 | 边缘 | 首尾风铃呼应闭环——呼应式收束工整度偏高 |
| ch2「昨晚凳腿……那道白印子还在。她蹲下去看了一眼，还是擦不掉，就算了。」 | **阳性** | 跨章**逐字级**细节复用（ch1 已有几乎同句的擦白印子节拍）——工整回环/母题复用未覆盖 |
| ch2「车过桥的时候……水泵响了一夜的那种冬天，水管上的手套搭了很多天。」 | 边缘 | ch1 记忆母题（水泵/手套）跨章呼应，回环密度偏高但非逐字 |
| ch2「她拍了一张……名单不会开口。」 | 边缘 | 「名单不会开口」格言式收束 |
| ch2「顺手把一包被捏扁的薯片扶正了。手比脑子先动。」 | **阳性** | 母题跨**场景**复用（ch1 自己店里扶薯片 → ch2 陌生超市同动作）+「手比脑子先动」格言句——工整回环 |
| ch2 末三段「评书停了。／满堂的说话声，一齐停了。／只有炉子上的水壶，还在响。」 | 边缘 | 三拍电影化收束 + 反差静音格——工整度高 |

**残留形态定性**（本轮唯一可靠结论）：漏过 screen 层的 AI 味不是表内特征复发，而是**三类表外变体**——①抒情点题/格言式收束句；②跨章/跨场景工整回环（母题复用与逐字级节拍重复）；③呼应式工整收尾。与金丝雀基线的预判一致：特征规则抓不住规则表外的新变种，结果侧检验（读者冷读）才是补位方向。
