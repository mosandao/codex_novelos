# 真实地名合规拦截（compliance-place-guard）

本包提供一份**真实地名拦截表**，供写作/审查 Agent 在现实题材、架空历史、都市题材中机械扫描命中，提示作者用虚构名替代真实地名。

## 定位（必读）

本包是合规的**第一道提醒，不是"通过即安全"**。

| 能力 | 可靠性 | 说明 |
|---|---|---|
| 真实地名机械拦截 | **较高** | 封闭数据集（国名/省名/城市），可用程序正则校验 |
| 语义违规识别 | **不做** | 影射/谐音/上下文敏感无法靠词表穷举，是人工终审职责 |

## 使用方式

### 1. 写作前（预防）
开书时若涉及现实世界背景（架空历史/都市/现实题材），先把本书的虚构地名词典建立好（京城叫什么、省叫什么、邻国叫什么）。参照 `真实地名.txt` 确认你的虚构名没有与真实地名撞名。

### 2. 写作中（提示）
写作智能体生成正文时，若上下文含现实地名风险，应优先使用本书的虚构地名词典，避免直接出现真实国名/省名/城市名。

### 3. 写作后（扫描）
章节/长场景草稿完成后，对正文做一次机械扫描：用 `真实地名.txt` 的词逐条匹配正文，命中点标记出来供人工复核。命中 = 用了真实地名，需替换为虚构名（除非有明确的艺术/纪实理由）。

### 4. 终审永远是人
扫描通过 ≠ 平台通过。本包只查已知真实地名，不查影射、谐音、敏感机构、在世人物、政治宗教议题。这些是人工终审的职责。

## 资源

- `真实地名.txt`：每行一个词，`#` 开头为注释。三类：国家名 / 中国省级行政区 / 中国主要城市。覆盖 51 国名 + 34 省级 + 81 城市。不覆盖乡镇/街道/谐音地名/外国城市（外国城市按需扩展）。

## 不收录什么

以下本包**不收录**，因为靠词表无法穷举或可靠性不足：

- 谐音/拆字规避词
- 上下文敏感词（同一词在不同语境风险不同）
- 违禁词/敏感词（草稿级不可靠，已按用户决定移除）
- 真实机构名/在世人物名（数量无限且变动）
- 外国城市名（除少量大国名外）

## 与其他包的配合

- 与 `universe-atlas` 的 `alternate-history` / `wuxia` / `supernatural` 簇配合：这些宇宙簇天然涉及现实世界的虚构替代，开书时必须调用本包做地名合规。
- framework 的 §1.3 把合规安全底座列为**最高优先级约束**，凌驾于任何宇宙法则之上。本包是这条约束的落地工具。
