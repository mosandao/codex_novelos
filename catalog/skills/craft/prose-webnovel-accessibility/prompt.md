# 商业网文通俗度、开头吸引力与钩子强度

面向商业网文的正文可读性检查规则。核心基准：**默认面向文学素养不高的多数读者（约 90%）**，不追求面向高素养少数读者的文学性。基准按免费算法平台（番茄/七猫）标定；付费订阅平台（起点）按下节「平台适配」放宽。

## §0 平台适配（判级前先读 `setup.platform_traits.model`）

- **免费算法**：全量从严执行本卡所有条款——前三章定生死，不设豁免。
- **付费订阅**：读者养书容忍更高，允许前期慢热铺体系——
  - §2 中「前 3 段无任何处境信息」的 **blocking 降为 warning**，但第 1 章结束前必须建立人物+冲突处境；
  - §3 钩子分级与「开篇章/卷末章必须强钩子」不变；普通章连续中钩子的评估阈值从 2 章放宽到 3 章；
  - §1 通俗度条款全量适用，不因付费放松。

## §1 通俗度与抽象修辞节制

商业网文的语言基准是"读得顺、看得懂、不用回头重读"。以下规则确保正文不因过度文学化而流失多数读者。

### 抽象修辞链控制

正文中的情绪、判断应以**具体动作、身体反应、口语化短句**呈现，不以概念性修辞链替代。

- **抽象修辞链**定义：连续 2 层以上概念性比喻构成的表达（如"归档→填栏→盖戳→定住"式递进比喻）。全章 ≤1 处。
- **修正方向**：把抽象修辞链替换为一个身体反应或具体动作。如"被填进一栏，盖个戳"→"衣领蹭上晒脱的皮，疼了一下，他下意识扯了扯领口"。
- **判级**：抽象修辞链 >1 → **warning**；导致段落含义需重读才能理解 → **blocking**。

### 书面化抽象动词节制

避免连续使用"归类""界定""锚定""解构""沉淀"等抽象动词替代具体行为。

- 这类词单章合计 ≤3 次。
- **判级**：>3 → **warning**。

### 通俗尺度

正文不需要牺牲智识深度（计谋、挖坑、算计、明线暗线照常），但表达方式应让文学素养不高的读者也能跟上。

- 允许的复杂：情节复杂、人物多面、信息密度高——但用直白的语言表达。
- 禁止的复杂：用抽象修辞、文学典故或概念化语言表达本可以直说的事情。
- **判级**：全章超过 3 处需要文学素养才能理解的修辞 → **warning**。

## §2 开头吸引力

商业网文第一章的前 3 段决定读者是否继续。

### 第一原则

前 3 段必须用**具体物、动作或对话**切入，建立处境、人物或冲突。

### 禁止模式

- 用比喻链开头（"命运像一张网，将他裹在其中"式）
- 用感官堆叠开头（"风带着腥味，雾色灰青，远处传来低沉的回响"式纯氛围）
- 用环境抒情开头（"这片大陆已经沉默了千年"式宏大叙事）
- 前三段读完不知道主角是谁、在什么处境

### 判级

- 前 3 段以纯意象/意境开头 → **warning**
- 前 3 段无任何处境信息（人物/冲突/动作）→ **blocking**

## §3 钩子强度

章末钩子不只是判"有无"，须判**强度等级**。

### 钩子分级

| 等级 | 定义 | 示例 |
|---|---|---|
| **强钩子** | 具体威胁/异常征兆/信息揭示，指向明确的下一章悬念，读者"必须"翻页 | 死树朝光扭 + 光向队伍移动 + 全队凝滞 |
| **中钩子** | 有信息钩子但威胁感或追读拉力较弱，读者"可能"翻页 | 远处亮起一点光 + "走。" |
| **弱钩子** | 纯情绪收尾、纯状态描述，读者"不一定"翻页 | 他深吸一口气，继续前行。 |

### 钩子设计原则

- **开篇章（第 1 章）和卷末章必须为强钩子**。
- 普通 pushing 章可用中钩子，但连续 2 章中钩子须评估是否插入一个强钩子提拉节奏。
- **禁止弱钩子**。若执行卡退出状态只能支撑弱钩子，应调整卷纲节奏。

### 判级

- 中钩子 → **note**（记录待改进）
- 弱钩子 / 纯情绪收尾 → **warning**
- 完全无钩子 → **blocking**

## 知识模块（kg-opening，R3 蒸馏）

以下为知识参照，非 Canon、无对账义务，示例表述不构成成稿标准。

1. 入题即事件：第一句写事件、动作或冲突，不写状态与环境；自检=删掉前三行故事仍成立则砍掉或前移；环境信息嵌进动作带出，每章环境描写不超过两句。
2. 危机前置：开篇数百字内给出明确危机或冲突，优先生死级并带时限；低谷开局第一句抛结果造悬念，用对比放大落差，第一页完成读者同情。
3. 视角锁定：开篇第一个名词是主角，信息全走主角五感与认知；配角在主角之后登场，配角心理不写；场景再小也要有冲突或信息量。
4. 信息节奏：世界观在行动与对话中穿插带出，三到五章渐次展开；当前不需要的信息不讲；悬念不超过三个，且各在十章内开始揭示。
5. 钩子纪律：每章结尾留钩，三章内每章一个小爆点——一章冲突、二章转机、三章反击见效；章首钩子类型轮换，防模式疲劳。
6. 信息差张力：让读者先于当事人知道关键信息，期待挂在何时会发现；每章开写前自问：读者此刻在期待什么，下一章该兑现还是加码。
7. 反差与反讽：用低微表面身份与隐藏实力的落差制造期待；书名或首句可在读者熟知处制造反转定调，颠覆预期的同时立起新规则。
