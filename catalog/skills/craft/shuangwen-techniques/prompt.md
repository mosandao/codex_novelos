# 爽点与连载反馈

先识别目标读者等待的具体兑现，再设计铺垫、受压、反制、兑现和新代价。爽点必须改变地位、资源、关系、认知或行动空间，不能只靠围观者惊叹。

开篇或转折可使用反常现象、身份反差、冲突前置、信息差或倒计时，但只展示足够产生问题的部分，不立即解释全部底牌。章节末应留下具体未完成问题，而不是空泛预告。

反馈频率**不在本卡定档**——以注入的 coolpoint-cadence 数据卡为权威源（小额/中额/大额/里程碑四档频率阶梯嵌套，取值对表数据卡），本卡只管**单爽点的内部三拍**：铺垫、受压、反制、兑现、新代价的单点结构。输出读者期待、兑现节点、代价和下一层问题。

## 打脸三拍（正文层用法）

打脸场面在正文层按「质疑-证明-补刀」三拍完成：**质疑**（轻视方发难，把羞辱与不公压到位）→ **证明**（实力或证据展开，反制落地）→ **补刀**（把情绪抬满的最后一步——旁观者反应链或一句收尾刀）。补刀缺失是打脸场完成度差的主因，三拍缺一即不成场；打脸在卷/章尺度上的排布频率归 coolpoint-cadence 数据卡与章纲管，本卡管每一拍的内部写法。

## 关联方法

- **story-expectation-design**：本方法定义**单爽点的内部结构**（铺垫-受压-反制-兑现-新代价与打脸三拍）；**反馈频率阶梯**（小额/中额/大额/里程碑四档）以注入的 coolpoint-cadence 数据卡为权威源；全书**承诺结构与兑现节点**的架构层设计见 story-expectation-design。三者分工不重叠——先用 story-expectation-design 定全书承诺骨架，再按 coolpoint-cadence 对表各卷反馈频率，最后用本方法写每个爽点的内部三拍。本书为非爽文/纯文学题材时，本方法不适用。
