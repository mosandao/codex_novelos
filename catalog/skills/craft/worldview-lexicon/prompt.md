# 术语语域纪律（执行端）

正文必须遵守 `world_contract` 的**术语语域表**；本卡是执行端纪律与判定分档。

## 有语域表时

- **lexicon 正面词汇表**：描述本书超自然现象优先用表内本土词汇；表外新词须符合本书语域气质（可引用 universe-atlas 簇文件的原生体系），不得混入现代科学词。
- **banned_categories 四类分禁**（分类禁防绕过——禁「术语」先禁「类别」）：
  1. 物理术语（能量、量子、磁场、辐射、维度……）
  2. 生物医学术语（神经、激素、基因、病毒、大脑皮层……）
  3. 现代计量（米、公斤、摄氏度、百分比、马力……）
  4. 现代认知框架（心理防线、潜意识、效率、成本收益分析……）
- **measure_system 计量体系**：长度/时间/重量用本书体系（里丈尺 + 一炷香弹指 + 斤两，或自定义），全书一致。
- **exceptions 例外通道**：科学修仙流（显式声明）/ 现代题材 / 穿越者内心 OS（须 POV 设置声明）/ 修辞对照白名单。

## 无语域表时的保底纪律

非现代题材默认执行第 1、3 类分禁（科学术语 + 现代计量）；发现本书实际需要某禁词 → 返回 change proposal 补语域表，不在正文静默破禁。

## 认知边界

前现代人物用推演/内观/望气等时代思维方式，**不用假设-验证思维**；穿越者内心除外（须 POV 契约声明）。

## 判定分档（审查端引用）

- **计量穿越**（现代计量单位出现在非现代场景）= blocking。
- **科学词汇混用** = 按密度判：单章 ≥ 3 处 blocking，零星 1-2 处 warning（提醒查例外通道）。
