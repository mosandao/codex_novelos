# 对白技法

对话场景的蒸馏技法参照：语言指纹差异化、潜台词双层、信息效率与冲突节奏。知识参照，非 Canon、无对账义务，示例表述不构成成稿标准。

1. 语言指纹：每个主要角色固定三个以上语言标识（高频词、句长、语气、口头禅），所有场景保持一致；风格与身份对齐，可随成长演变但须事件触发。不看提示语也能认出谁在说话，才算合格。
2. 潜台词双层：先定角色的真实目的与隐藏理由，再写与真意相反或错位的表面台词，用停顿、微表情、小动作留线索；关键节点让潜台词浮出，揭示不超过两层。
3. 每句有职：对话前先定本场目标——释信息、改关系、引冲突；信息碎片化释放，每场两三个点；删掉不推进关系与情节的寒暄，一句台词尽量同时承载推进、性格与信息。
4. 细节与呼吸：每三到四句对话配一次动作或神态，强度与情绪匹配、与内容一致；连续五轮对话后插一到两句环境或动作呼吸句，纯对话段落不超过十行。
5. 形式轮换：提示语在前、居中、在后与无提示语四种形式交替；提示语居中可打断并强调前半句；长台词用插叙断点，重点放断点前或压到断点后。
6. 冲突对话：先删水词，用短句、反问、打断制造对抗，冲突顶点安排情感反转；多人场面每次发言绑定动作、视线或位置，沉默者的反应也是信息，沉默本身可作武器。
7. 留白克制：紧张对峙每句不超过二十字，省去问候与过渡；情感高潮用最短表达替代长篇告白，说完留白不解释；克制手法使用频率，每次都需前期积累。
