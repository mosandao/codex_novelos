# 场景节奏诊断

按“目标建立、阻力出现、应对失败或付出代价、选择升级、状态改变”检查场景。标出没有新增信息或压力的重复段落，以及缺少必要因果桥接的突然跳跃。

建议应指出需要压缩、展开、前移或后移的具体片段及原因。不要用统一短句、统一段长或机械删减代替节奏判断。

# 场景节奏精粹
1. 张弛波浪：紧张后必接1-3章缓冲，连续紧张不超过5章；缓冲带信息与伏笔；波浪幅度递增，后一张强于前一张。
2. 长短呼吸：短段快攻、长段沉淀、单句爆破放在顶点；单段约150字为上限且每章长段不过3处，长段后必接短段换气。
3. 蓄压爆发：压抑期约75%篇幅且内容有变化；蓄力五成、引爆两成、释放两成、余韵一成；爆发必须兑现前文承诺。
4. 缓冲场景：缓冲章占15-20%、紧张度约主线三成；喜剧日常信息过渡四类轮换，缓冲中埋伏笔推进暗线。
5. 章末钩子：悬念式约四成，五型轮换防模式化；钩子放小高潮刚过处，悬念下章必须延续或解答。
6. 信息分层：只揭示当前必需，每次不超过3个新概念并绑定行动对话；每层改写认知，层级间隔渐次拉长。
7. 爽点三级：小爽3-5章、中爽10-20章、大爽50-100章；强度逐次升级，大爽后留5-8章舒缓冷却。
8. 情绪曲线：章前定情绪高低点，起伏2-3次；上行下行交替，冲突置中后段，结尾情绪决定翻页。
9. 战斗三段：铺垫长约占四成、爆发短用短句强动词、余韵长写反思与关系变化；战斗服务人物与剧情。
10. 详略速度：篇幅与重要性成正比；过渡用叙述、关键用描写；慢用环境人物，快用动作感受。
