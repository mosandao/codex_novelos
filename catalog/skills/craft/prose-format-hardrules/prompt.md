# 正文形式硬约束

章节正文在字数、标点、段落节奏、句式节奏和叙事沉浸感上的硬性约束。写作时遵守，审查时按此阈值判定。

## 1. 字数控制

**配置来源**（按优先级）：
1. 执行卡 metadata 的 `target_word_count`（如 `{min: 2500, target: 3000, max: 3500}`）
2. 无配置时默认 min=2500, target=3000, max=3500（含标点，不含空格换行）

**统计标准**：仅正文（章节标题 → "新增 Canon 候选摘要" 之间），汉字+标点+数字+英文，不含空格和换行。

**违规处理**：
- 字数 < min：必须扩充。**禁止**用内心独白解释填充、百科式信息植入、结尾升华排比、重复意象扩展。应通过增加场景细节、对话轮次、动作描写来充实。
- 字数 > max：必须裁剪。裁剪优先级：重复描写 > 过渡/铺垫 > 无效对话 > 结尾冗余。（慎删关键事件和因果桥接。）

**平台适配参考**：番茄/起点类快节奏平台默认 2500-3500 字/章；卷末高潮章可上浮至 max=4000（需执行卡预标）。

## 2. 对话符号规范

**正确使用**：
- 中文双引号：`"..."`（U+201C / U+201D）
- 中文单引号：`'...'`（U+2018 / U+2019，用于引号内嵌套）

**禁止使用**（出现即 critical 级错误）：

| 禁用符号 | Unicode | 严重程度 |
|---|---|---|
| 英文双引号 `"` | U+0022 | 出现即违规 |
| 英文单引号 `'` | U+0027 | 出现即违规 |
| 连续破折号 `————` | U+2014 ×2 | 出现即违规 |

**限量使用**：

| 符号 | 规则 | 超限严重程度 |
|---|---|---|
| 破折号 `——` | 同段 ≤1 个；连续 3 段出现=违规；全章 ≤5 次 | 超限=warning |
| 省略号 `……` | 连续两句出现=违规；省略号后紧跟解释句=违规；全章 ≤8 次 | 超限=warning |

**破折号密度控制三路径**（同段 ≥2 个时必选其一）：
1. 保留 1 个，其余改句号断开重起
2. 融入句子变成定语/插入语
3. 改逗号

## 3. 移动端段落密度与节奏

手机屏幕窄（约 40 字/行），但"适配移动端"不等于"每句一段"。通篇一句一段会把叙述节奏碾平——短句的重音感来自与长段的对比，没有长段就没有重音，全是重音等于没有重音。

**段落长度硬指标**：
- 单段 ≤110 字（硬上限，超出即违规）
- 连贯叙述段（判断、观察、信息铺陈）建议 30-90 字，让语义单元完整
- 关键短句（反转、重音、情绪落点）可短至 1-15 字，但必须从连贯段中突出，不可通篇堆叠
- 场景切换空行：全章不超过 3 处

**节奏要求——必须有疏密变化**：
- 全章不可呈现"通篇短句独立成段"的单一密度。碎句必须与连贯段交替。
- 不同场景类型应有不同段落密度：
  - **动作/危机场景**：短句碎段密集，制造紧张（合理）
  - **观察/判断/盘算场景**：连贯段为主（30-90字），让推理和判断有呼吸
  - **闪回/情绪重场景**：适当拉长句子、放缓节奏，与现实的快形成对比
- **过度碎片化判定**：全章平均段落 <25 字且最长段 <60 字时，判定为节奏单一，必须将观察/判断/闪回场景的碎句并段到连贯叙述。

**分段规则**（按需使用，非逐条强制拆分）：
1. **对话独立换行**：每句对话单独成行，对话归属（"他说"）可紧跟同行
2. **关键情绪/悬念可单独拎出**：高潮情感词、反转信息、悬念揭晓——仅当它需要成为重音时才独占一行，不要把每个普通判断都拎成独立段
3. **场景切换**：用空行而非碎句来分隔场景转换
4. **不要把同一个意思拆成多段**：如果几句短句表达的是同一个判断的递进，应合并为一个连贯段，而非拆成独立段堆叠

## 4. 句式节奏

**句长级差**：
- 禁止连续 3 句长度相似（差异 <5 字）
- 短句（≤10 字）与长句（≥25 字）交替使用，制造呼吸感
- 违规示例："他站起来。他走过去。他坐下。"（连续 3 句 8 字无级差）

**呼吸点密度**：
- 每 300 字必须有 1 个停顿句
- 停顿句定义：≤5 字短句 / 沉默描写 / 动作描写 / 环境描写

**外部阻力**：
- 每 800 字必须有一次外部事件打断内心思考
- 独自思考（连续内心独白）不超过 200 字，必须被外部事件（声响/他人动作/环境变化）打断
- 禁止整段纯内心推理无人打断

**章末节奏**：
- 最后 200 字句子应收紧（平均句长 <10 字），确保收束力
- 禁止章末用长句堆叠收尾

## 5. 禁止规划层元标签入正文

章节执行卡和规划资产使用大量内部元标签来描述状态，例如：`L1`、`Tier1`、`认知层`、`伪装层`、`沙雕皮`、`力量层`、`资源层`、`central_contradiction`、`soul_pressure`、`moral_residue`、`deliberate_silences` 等。这些是**规划层的行话**，读者不需要、也不应该看到。

**硬规则**：上述元标签及其同类**一律不得原样出现在正文叙述或人物心理中**。出现即 `blocking` 级错误。

**正确做法——处境化转译**：把标签转化为读者可感知的处境。
- `L1`（肉体磨损）→ 具体写身体的疲惫、伤痛、磨损（肋骨断了一根、脚踝磨烂、缺水三天）
- `Tier1`（食物链底端）→ 写面对威胁时的无力感（面对浊化兽完全无还手之力、只能装死求生）
- `认知层/伪装层`（策略思维）→ 通过他的观察、盘算、选择来**展示**，而非贴标签说"他的认知层已经成型"
- `central_contradiction` → 通过选择和后果让读者感受到张力，不点破概念名

**判断标准**：如果一个词像是"游戏数值面板"或"策划案术语"而非角色会用的自然语言，它就不该出现在正文里。正文必须保持叙事视角的沉浸感。

## 6. 参差原则（反均匀精修）

商业连载忌讳"句句都漂亮、段段都精致"。文本被加工得过度均匀时，反而暴露出一种"每句话都经过了加工"的感觉，削弱真实叙事的呼吸。参差不是放低质量，而是让精彩的部分在对比中真正出彩。

以下四条互相呼应，核心都是**反对均匀、制造参差**：

### 金句节制

禁止"事件 → 描写 → 判断 → 金句收束"的固定循环高频出现。金句应从叙事中自然涌出，而非每隔一两段刻意安置一个"可截图句"。

真人连载作者允许出现"不漂亮"的句子：有些只是交代，有些甚至略粗糙，有些心理活动不给结论。过于整齐的精修感会暴露加工痕迹。

**反模式**：全章可独立摘录的判断句分布均匀、间距稳定，像被规律安插的"重音点"。

### 比喻节制

连续段落不宜堆叠同类比喻。比喻的力量来自稀缺——关键场景用比喻，普通叙述直说，真正重要的比喻才会更有力量。

**反模式**：相邻段落连续出现 3 个以上独立比喻（如指甲刮后脑勺、石子敲瓦片、湿抹布捂脸式密集堆叠），每个比喻单独看都准，连起来却过载。

### 解释留白

主角接收信息后，不必然紧接"分析 → 结论 → 告知读者"。适当以行动、沉默、延迟反应或错误判断替代显性结论，把推理留给读者。

读者自己得出的结论比作者喂到嘴边的结论更有力。看到信息 → 主角行动 → 读者自行推断，比"看到信息 → 主角分析 → 得出结论 → 告诉读者"更像真正的小说。

**反模式**：主角认知零浪费，每条信息都被即时正确处理并转化为剧情资源——主角像作者的计算器，而非正在经历事情的人。

### 允许低密度段落

不必让每段都承担 3-5 个叙事功能。允许存在只交代、只过渡、只渲染的"不漂亮但必要"的段落。

**反模式**：全章每段都高度浓缩信息，没有任何真正意义上的低密度段落——表面是"信息密度高"，实质是"没有呼吸"。
