# 章节执行卡

根据锁定卷纲和精选 Canon，为一个章节定义可验证的执行边界。

必须给出：章节职责、进入状态、目标状态变化、场景序列、每场阻力升级、必须保留的信息差、退出状态、禁止修改的上游约束、`soul_pressure`、`moral_residue`、**出场人物要点**、**本章新登场人物微档案**和待审风险。不要写正文，不要增加卷纲未支持的新主线。

- **出场人物要点**（T37）：本章 POV 与在场人物清单，每人一行索引其契约要点——执念/失稳点/语域口癖（源自人物契约档案与出场人物卡的 essence）；POV 人物另声明本场他知道/不知道什么。在场人物不得无因超出卷纲冲突线的载体范围。
- **新登场人物微档案**（次要角色动态创建的规划端入口）：本章如需新配角，先查注入的人物名册镜像（character_roster 槽：契约 roster + 注册表在库人物）——班底内人物标注「卷纲已登记」直接消费，不重复微档案。名册之外的新面孔，每个在此预登记——`name`（对照名册镜像查重，含音近形近）/ `role_class`（`minor` 一次性 / `secondary` 拟复用）/ 一句话职责（本场干什么）/ 微档案一两句（可写的具体细节：习惯、忌口、随身物，不是简历）。微档案不整档落在 persona_gate 槽的分身「写不了」场景，确需涉盲区者标注绕开方式。正文只消费微档案不发明人物——Writer 写到未预登记的新名字 = 违卡。需要跨卷职责或卷级回归时走 change proposal 升级进人物契约，不在执行卡里扩张。章节接受后微档案由主控经 `novelos_register_characters.py --entry` 落人物注册表。本章无新人物时写「无新登场人物」。

- `soul_pressure` 说明本章是否前景化思想冲突；若前景化，指出哪个选择如何触碰 `book_soul.central_contradiction` 或 `recurring_tests`；纯动作、过渡和信息场景可明确标记为低前景强度。
- `moral_residue` 说明章末仍不能被标准答案消解的行为后果、关系余波或价值不确定性。低前景场景也要记录”无新增残留”或承接中的既有残留，不得伪造主题戏。
- 两项都必须追溯到锁定 Direction，不能发明新作者思想，也不能为突出观点改变卷纲状态。
- `target_word_count`（可选）：本章正文字数配置 `{min, target, max}`。番茄/起点类快节奏平台默认 `{min: 2500, target: 3000, max: 3500}`；卷末高潮章可上浮至 `max: 4000`。不填时 Writer 使用默认值 2500-3500 字。

如果目标需要改变卷目标或跨卷职责，返回上游 change proposal，不要把修改藏进执行卡。

## 冲突阶梯

双方目标必须不能同时成立，退让必须有具体损失。每层按“阻碍 -> 应对 -> 代价或新问题”表达，并改变时间、资源、身份、伤势、信息或选择；不要只写“冲突升级”。

## 场景序列指引（接章级单元机器三拍）

每章场景数建议：快节奏平台 2-4 场/章（对应 `target_word_count`），高潮章可 3-5 场。每场声明其在章级单元机器三拍中的位置：

- **分级**（输入定级）：本场的考验/输入是什么等级——衔接上一场的产出。
- **执行**（运转加工）：冲突怎么按机制规则碰撞（引用卷纲的冲突线）。
- **结算**（兑现切片 + 收费）：兑现哪条承诺的切片、收取什么代价。

同章多场构成「分级→执行→结算」的完整循环或跨章半循环（跨章须声明衔接点）。禁止场景只有执行无结算（白打）或只有结算无分级（无源之水）。

## 情绪曲线

用“起点 -> 中段变化 -> 落点”标出读者期待和人物情绪。可以使用期待落差、信息差、短释放后加压，但情绪必须落到选择、动作或持续后果，不用抽象情绪词替代。

## 钩子

标明埋钩、还钩或延迟，记录真相来源、信息差和读者下一章等待的具体问题。优先使用未完成动作、倒计时、选择代价或部分兑现；拒绝没有具体对象的空钩。

### 章末钩子强度

每章末尾的钩子须标注强度等级（参照 `catalog/skills/craft/prose-webnovel-accessibility` §3）：

- **强钩子**：具体威胁/异常征兆/信息揭示，指向明确的下一章悬念。开篇章（第1章）和卷末章必须为强钩子。
- **中钩子**：有信息钩子但威胁感较弱。普通推进章可用，连续 2 章中钩子须插入一个强钩子提拉节奏。
- **弱钩子**：纯情绪收尾或纯状态描述。禁止使用。

钩子强度标注在 metadata 的 `hook_strength` 字段（`strong`/`medium`/`weak`）。

## 条件语法模块（按项目组装）

频道轴的章纲级标注（男频力量兑现切片 / 女频债权兑付 / 全向双轴本章配比）**不在本主干**——组装器按 setup 取值附加，索引见 `modules/manifest.json`。
