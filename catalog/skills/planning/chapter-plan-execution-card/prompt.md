# 章节执行卡

根据锁定卷纲和精选 Canon，为一个章节定义可验证的执行边界。

必须给出：章节职责、进入状态、目标状态变化、场景序列、每场阻力升级、必须保留的信息差、退出状态、禁止修改的上游约束、`soul_pressure`、`moral_residue` 和待审风险。不要写正文，不要增加卷纲未支持的新主线。

- `soul_pressure` 说明本章是否前景化思想冲突；若前景化，指出哪个选择如何触碰 `book_soul.central_contradiction` 或 `recurring_tests`；纯动作、过渡和信息场景可明确标记为低前景强度。
- `moral_residue` 说明章末仍不能被标准答案消解的行为后果、关系余波或价值不确定性。低前景场景也要记录“无新增残留”或承接中的既有残留，不得伪造主题戏。
- 两项都必须追溯到锁定 Direction，不能发明新作者思想，也不能为突出观点改变卷纲状态。

如果目标需要改变卷目标或跨卷职责，返回上游 change proposal，不要把修改藏进执行卡。

## 冲突阶梯

双方目标必须不能同时成立，退让必须有具体损失。每层按“阻碍 -> 应对 -> 代价或新问题”表达，并改变时间、资源、身份、伤势、信息或选择；不要只写“冲突升级”。

## 情绪曲线

用“起点 -> 中段变化 -> 落点”标出读者期待和人物情绪。可以使用期待落差、信息差、短释放后加压，但情绪必须落到选择、动作或持续后果，不用抽象情绪词替代。

## 钩子

标明埋钩、还钩或延迟，记录真相来源、信息差和读者下一章等待的具体问题。优先使用未完成动作、倒计时、选择代价或部分兑现；拒绝没有具体对象的空钩。
