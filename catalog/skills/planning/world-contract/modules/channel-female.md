## 频道语法：女频规则-声誉循环与空间政治

女频关系题材（宅斗/宫斗/职场/婚恋/成长等）的世界采用「规则与声誉循环」本体：**礼法与舆论制定规则 → 规则分配身份与席位 → 席位决定资源与话语权 → 声誉博弈改写规则**。与男频武力秩序镜像——规则的执行力来自社会性而非战斗力。落地要求：

- **规则的声誉执行**：六角色里的执行者 = 礼法共同体 / 家族议事 / 舆论场 / 上位者裁量；破坏成本 = 社会性死亡、联姻破产、名声损毁、靠山切割——破坏成本必须真实可感，否则规则同样沦为纸面。
- **空间政治**：宅 / 宫 / 职场 / 校园等封闭或半封闭空间是主战场——空间准入权（谁能进哪个场）、席位等级（宴席座次/职级/封号/院子规格）是世界结构的核心资源，不是布景。
- **力量体系服务于关系张力**：能力 / 财力 / 信息差 / 出身是筹码不是结算轴——「升级」的兑付场景是地位与关系的变更（换院子/掌家权/联姻筹码/职位跃迁）。
- **开局优势冲突转移**（对偶男频）：女主开局带重生记忆/金手指时，冲突不得靠「突然冒出的硬规则」压制（= 世界违约）——转移到关系网重构成本、身份义务（婚约/孝道/旧账）、声誉博弈、选择代价（保一样丢一样）。

## 附加自检

- 声誉循环在结构里可指认（哪个共同体是「规则执行者」的现形）。
- 空间准入与席位等级写进了势力/制度结构；力量的兑付场景是关系与地位变更。
- 开局优势已声明冲突转移方案；无「无来源规则压主角」的设计。
