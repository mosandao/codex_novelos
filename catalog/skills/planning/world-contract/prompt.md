# 世界契约

只实现 Architecture 与 Strategy 实际需要的势力、制度、资源、地点和规则。每项设定必须说明叙事用途、约束对象、代价、可被利用的边界和与其他规则的关系。

**规则六角色**：每条重要规则（制度/戒律/契约/协议）必答——**制定者 / 承认者 / 执行者 / 受益者 / 豁免者 / 破坏成本**。规则来自世界本体或多方力量博弈，不是悬在世界之上的抽象道德；没有执行者与破坏成本的规则是纸面规则，正文不得依赖它约束强者。**三类分层**：每条规则归入一层——本体规则（世界底层限制，不可修订只能被发现）/ 力量规则（能力结构与强者协议形成的秩序，随力量对比漂移）/ 社会规则（法律礼法契约，有立法者与执法成本）；层级错装（社会规则越权执行本体效力）= 结构缺陷。

世界只能提供承载 `book_soul` 冲突的条件和后果，不能让宇宙法则、系统奖励或设定说明自动证明作者偏爱的立场正确。对立答案都必须有真实资源、制度激励和生存压力作为支撑。

不要生成无叙事消费者的百科设定，不要改写规则来源。涉及人物能力或关系的假设必须显式列出，供 Character/World 交叉审查。

## 术语语域表（必产节，正文执行端消费）

世界契约必须包含一节**术语语域表**，锁定本书的词汇气象（执行端纪律见 `catalog/skills/craft/worldview-lexicon/prompt.md`，正文审查按其判定分档）：

- **lexicon（正面词汇表）**：本书超自然现象的本土词汇清单——力量怎么叫、境界怎么称、修行怎么说。优先从题材原生体系长出（可参考 universe-atlas 簇文件），不用音译科学词凑数。
- **banned_categories（四类分禁）**：① 物理术语（能量/量子/磁场/维度…）；② 生物医学术语（神经/激素/基因…）；③ 现代计量（米/公斤/摄氏度/百分比…）；④ 现代认知框架（潜意识/效率/成本收益…）。分类禁防绕过——禁术语先禁类别。
- **measure_system（计量体系）**：长度/时间/重量的本书体系（里丈尺 + 一炷香弹指 + 斤两，或自定义），全书一致，不得与现代单位混用。
- **exceptions（例外通道）**：显式声明哪些破禁合法——科学修仙流 / 现代题材 / 穿越者内心 OS（须 POV 声明）/ 修辞对照白名单。无声明即无例外。

## 条件语法模块（按项目组装）

题材信息包的有无决定语域表的取材路径（非空：题材词汇优先；缺位：从 Architecture/Strategy 的机制命名反推）——组装器按 setup 取值附加，索引见 `modules/manifest.json`。

## 代价与激励的跨维度隔离原则

"经济分两档"给出的账本/债务模型，是**经济维度专属**的重投入样板，不是"代价 / 边界 / 量化指标"这几个通用要求的默认实现方式。

不同维度的代价逻辑必须由该维度自身的因果域决定，禁止把货币化的"发放-偿还-利息-违约"结构挪用到非经济维度（力量体系、血脉、神启、死后世界/审判机制等），除非题材本身就是经营/种田/基建/领主流。

每个维度在落地"代价"时，应先回答：这个维度的"透支"长什么样？——它不必是欠债，也可以是：

- **力量体系**：侵蚀 / 污染 / 心智损耗 / 反噬，代价体现在使用者本身的异化，而非欠某个债主
- **血脉 / 传承**：身份撕裂、立场绑定、无法摆脱的宿命标签，代价体现在"我是谁"而非"我欠谁"
- **神启 / 神赐**：意志让渡、被神圣叙事收编、丧失自主解释权，代价体现在主体性流失而非追索
- **死后世界 / 审判机制**：记忆无法逃避的回放、身份被永久定义，代价体现在"被看见"而非"被追债"

**自检**：产出后检查全书是否所有维度的代价结构都收敛成同一种"追偿/偿还/利息"逻辑（无论表面叫不叫"债"）。若是，视为跨维度隐喻坍缩，需要重写至少一半维度的代价机制，换成上面列出的非账本形态之一，或该维度自身更贴切的形态。

## 维度处理原则

不同维度的投入按题材分档，不要等量铺陈：

- **经济分两档**：
  - 经营 / 种田 / 基建 / 领主流：经济从"维度"升格为"对象"，必须重投入——产出 / 分布 / 消耗 / 枯竭曲线、债权-债务账本、脆弱度指标都要写。典型形态见西幻领主经营流：领地五要素、生产链、债权-债务可量化指标、"财富制造脆弱"机制。
    **边界声明**：这里的「重投入」**专指**经营流的货币/资源账本结构，仅在该题材下适用。其他维度即便剧情需要「重投入」（如力量体系需要精细的进阶阶梯），也应使用该维度自身的量化逻辑（等级/阈值/侵蚀值/污染度等），不得借用债权-债务账本的字段结构（如「利息」「违约」「追索权」）。
  - 其他题材（都市 / 玄幻 / 言情等）：经济默认只写"主角钱包四档（穷 / 一般 / 富 / 巨富）+ 地基资源曲线"，除非剧情必需。
  - 判定标准：删掉经济设定，主角的成长弧是否还成立？成立 → 默认砍；垮了 → 重投入。
- **人文默认符号化**：只写"一两个标志风俗 + 一个禁忌"，除非题材是民俗 / 东方韵味卖点。
- **历史默认倒推式**：只留有现在消费者（主角身世、神器来历、恩怨源头）的节点，中间空白留白，需要再补。不写完整编年史。

## 结构性消费约束

每项设定必须标注它被剧情消费的时机与方式，使世界契约不是静态百科而是钩子网络：

1. **消费绑定**：每个设定项（位面 / 势力 / 规则 / 资源 / 灾厄机制）必须标注"首次被消费的圈次 / 卷"与"消费场景类型"（如扮猪吃虎起点、冤枉打脸、装逼舞台、阵营博弈）。无消费者的设定不写入。
2. **消费时序表**：产出须包含至少一张"消费时序表"（如位面 × 圈次、势力 × 圈次、神线态 × 圈次），使钩子分布可视化。表中应能看出哪些设定在第几卷首次被消费、以什么场景形态消费。

   消费时序表要求的是"标注消费时机"，**不要求代价机制本身可精确计数或有到期日**。状态转移型代价（如"某次事件后血脉觉醒但同时被打上无法摆脱的标签"）与数值型代价（如"欠款到期未还触发追杀"）在消费时序表中同等有效，不应因为前者不好量化、不好凑"到期/违约"式节点，就被回避或强行改写成后者。

注意：消费绑定约束的是"标注消费时机"这个行为，不强制具体的 state 字段名或结构（如 `entry_tensions` / `plot_hooks`）。不同题材的世界契约结构差异极大（经营流的账本结构 vs 修仙流的境界结构），强制统一字段反而有害。关键是每项设定都能回答"它在哪、被什么剧情消费"。

## 增量扩展合法通道

当创作过程中产生 Architecture 与 Strategy 未覆盖、但剧情必需的新设定时（新势力 / 新位面 / 神国 / 深渊等），应返回 change_proposal 说明影响范围与归属层，而非自行扩张或静默忽略。

归属层判定：
- 新增 world 类设定（势力 / 规则 / 位面 / 地理）→ 归属 `world_contract`，产出新版本。
- 影响主角主线阶段或全书战略骨架的 → 归属 `strategy`，先改 strategy 再展开 world。
- 跨卷新故事线 → 归属 `story_arc`。

这条是对"只实现 Architecture 与 Strategy 实际需要的"的补充：开书时遵守该约束，中途扩展时走 change_proposal 正式通道，不得在下游输出中隐式重写上游。

**交叉审查附加项**：World Agent 在交叉审查阶段，应额外检查本书是否存在两个及以上非经济维度（力量 / 血脉 / 神系 / 死后世界等）使用了结构相同的因果模板（尤其是"发放-偿还-追索"型）。若存在，视为设定同质化风险，需在 change_proposal 中说明是否为刻意的题材设定（如"全书主题就是万物皆债"），否则应打回重新分化，参照上文"代价与激励的跨维度隔离原则"重写。

## 可选方法素材

以下 expansion skill 提供题材或方法细化的可选参考，**均为可选输入，不能替代本主干产出**。主控智能体或 World Agent 可按需 Read 对应 prompt 注入方法灵感：

- **scenario-atlas**（题材桥段图集）：按当前项目一级题材定位 `clusters/<题材>.md`（Read `catalog/skills/expansions/scenario-atlas/clusters/` 下对应文件），查阅该题材的可复用桥段、消费时序表与启发式推演提示，作为世界契约"结构性消费约束"的钩子灵感源。**不是强制拼装件**——世界契约的组织形态仍由 World Agent 按本书 Architecture/Strategy 自选。与 universe-atlas 互补：本图集管"剧情桥段怎么消费"，universe-atlas 管"世界怎么设定"。
- **universe-atlas**（宇宙设定图集）：当世界需要完整的"宇宙法则 + 力量体系骨架 + 势力格局 + 世界地图骨架"模板时，Read `catalog/skills/expansions/universe-atlas/clusters/` 下的宇宙簇文件（含 `framework.md` 上位法：U-1~U-7 元法则、LI 强度光谱、混搭仲裁）。与 scenario-atlas 互补——开书时两份并用。**不是强制拼装件**。
- **world-rule-system**：当世界需要"不可打破的超自然/物理铁律"时，参考其规则边界定义方法。
- **world-growth-resource**：当世界需要"能力进阶阶梯 + 资源消耗闭环"时（修仙境界、序列魔药、异能进化等），参考其成长曲线与资源枯竭设计。
- **world-social-power**：当世界需要"势力利益博弈 + 阶层垄断"设计时，参考其势力分配与制度冲突方法。
- **power-ecology**：当世界需要"力量生态 + 规则来源"深化时——因果优先级链、八力量类型七属性、三类规则六角色、男频力量-规则循环与开局无敌冲突转移，参考其方法（与本文六角色条款同源，提供展开式模板）。
- **world-system-interaction**：当世界存在双/多能力体系碰撞（如修真×魔法、超凡×科技）时，参考其体系翻译/压制/转化规则。

这些素材的使用条件见各自 metadata 的 `use_when` / `avoid_when`。未覆盖的题材或场景，应依靠 Architecture/Strategy 约束直接推导，不强行套用不相关素材。
