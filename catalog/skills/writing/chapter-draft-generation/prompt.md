# 章节正文生成

把章节执行卡转化为正文，但不改写执行卡。`style_refs` 至少包含项目绑定的精确 Creator Profile revision/hash 与锁定 Direction；POV/局部风格引用只能在其后叠加，不能覆盖前两项。

签名含 `persona`（schema v2）时，按这个人写：narrative 的目光与声音决定叙述的落点与语感，`trait_profile` 的行为锚点是文风的隐性指纹。写到超出这位作者经验边界的场景时，**执行 `blindspots` 条目附带的绕开方式**（转喻/侧写/留白/借他人之口）——`cannot_write` 是硬边界，禁止全知叙述假装在场；`refuses` 清单中的写法一律不出现。

让每个场景通过行动、阻力和选择产生明确变化；人物只能使用其当前知道的信息；世界规则必须在行动后果中一致生效。通过人物选择和后果表现 `soul_pressure`，保留已规划的 `moral_residue`；不得自行创建作者思想、重写 `book_soul`、让所有人物同声或用叙述者总结替代戏剧过程。纯动作、过渡和信息场景按执行卡降低思想前景强度，不机械复述母题。结尾应兑现执行卡的退出状态，并留下已规划的后续压力。

## 硬性形式约束

- 中文正文一律使用中文双引号""（U+201C/U+201D），禁止英文直引号"（U+0022）
- 单章字数从执行卡 metadata 的 `target_word_count` 读取；无配置时默认 2500-3500 字（含标点）
- 同一修辞句式（如"不是…而是…"）单章不超过 2 次
- 禁止把内心状态写成术语化清单；心理活动以角色声音和世界观语境表达
- **禁止规划层元标签入正文**：执行卡中的内部标签（L1/Tier1/认知层/伪装层/沙雕皮/力量层等）一律不得原样写入正文，必须处境化转译为读者可感知的描写
- 单段≤110 字；段落须有疏密变化，禁止通篇短句独立成段——动作/危机场景可用碎句，观察/判断/闪回场景须并段为连贯叙述（30-90字），关键短句从连贯段中突出制造重音
- **遵守参差原则**：金句/比喻节制，留白代替显性解释，允许低密度段落；禁止"事件→描写→判断→金句"固定循环高频出现；禁止主角认知零浪费（每条信息都即时正确处理并得出结论）
- 破折号同段≤1 个、全章≤5 次；省略号全章≤8 次

正文后单列简短的新增 Canon 候选，只记录本章明确发生或确认的变化。不要自报 Hash，也不要保存正文。

## 可选方法素材

- **prose-revision**：当需要对**已有章节草稿**做局部重写、润色或消除 AI 机械痕迹时，调用 `skill_catalog.get("prose-revision")` 拉取其方法。注意：它用于润色既有草稿（revise），**不能替代本主干起草全新章节正文**（generate）；严禁在润色中改变场景事实、突破人物视角受限或推翻已确定因果。其使用条件见 metadata 的 `use_when` / `avoid_when`。
- **scene-dialogue**：当本章执行卡包含**以对话推进的关键场景**（谈判、试探、摊牌、关系转折）时，调用 `skill_catalog.get("scene-dialogue")` 拉取其对话设计方法（参与者目标/信息差/潜台词/角色声音）。注意：它用于强化对话场景的张力与信息差结构，**不能替代本主干起草全新章节正文**；严禁用其提前写出完整台词覆盖执行卡设定，严禁改变场景事实或突破人物视角受限。其使用条件见 metadata 的 `use_when` / `avoid_when`。
- **scene-fight-craft**：当本章执行卡包含**对抗/冲突场景**（战斗、论辩、对峙）时，调用 `skill_catalog.get("scene-fight-craft")` 拉取其对抗设计方法（每轮改变距离/资源/伤势/信息/心理优势）。注意：它用于强化对抗场景的因果与代价，**不能替代本主干起草全新章节正文**；严禁用招式清单或强度形容词代替因果，严禁改变场景事实或推翻已确定因果。其使用条件见 metadata 的 `use_when` / `avoid_when`。
- **compliance-place-guard**：当本书为**现实/架空/都市题材**且正文涉及真实国名/省名/城市名时，调用 `skill_catalog.get("compliance-place-guard")` 拉取真实地名表，对命中地名做虚构替换。注意：它是机械拦截工具（第一道提醒），**不替代语义层合规审查**；纯架空/异界无现实地名风险时不拉取。其使用条件见 metadata 的 `use_when` / `avoid_when`。
- **prose-anti-ai-fingerprint**：起草或润色时调用 `skill_catalog.get("prose-anti-ai-fingerprint")` 拉取完整的 AI 指纹规避规则、叙事姿态要点和真人感量化门槛。注意：它用于系统性规避 AI 写作痕迹，**不能替代本主干起草全新章节正文**；其使用条件见 metadata 的 `use_when` / `avoid_when`。
- **prose-format-hardrules**：起草时调用 `skill_catalog.get("prose-format-hardrules")` 拉取字数控制配置、标点规范、移动端段落密度和句式节奏的完整阈值。注意：它提供形式硬约束的精确阈值，**不能替代本主干起草全新章节正文**；其使用条件见 metadata 的 `use_when` / `avoid_when`。
- **prose-webnovel-accessibility**：起草时 Read `catalog/skills/craft/prose-webnovel-accessibility/prompt.md` 拉取商业网文通俗度基准、抽象修辞控制规则、开头切入方式和钩子强度分级标准。注意：它用于确保正文面向多数网文读者可读、开头不堆意象、结尾留有足够追读拉力，**不能替代本主干起草全新章节正文**。
