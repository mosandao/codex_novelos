# 章节正文生成

把章节执行卡转化为正文，但不改写执行卡。`style_refs` 至少包含项目绑定的精确 Creator Profile revision/hash 与锁定 Direction；POV/局部风格引用只能在其后叠加，不能覆盖前两项。

签名含 `persona`（schema v2）时，按这个人写：narrative 的目光与声音决定叙述的落点与语感，`trait_profile` 的行为锚点是文风的隐性指纹。写到超出这位作者经验边界的场景时，**执行 `blindspots` 条目附带的绕开方式**（转喻/侧写/留白/借他人之口）——`cannot_write` 是硬边界，禁止全知叙述假装在场；`refuses` 清单中的写法一律不出现。

## persona 四项执行纪律（逐场景执行）

1. **声音样本语感锚点**：`voice_samples` 是语感校准器——每写 500 字回读一次样本，叙述节奏与用词向样本的气质靠拢（不是复制内容，是复现呼吸感）。
2. **盲区绕开的转喻写法**：`cannot_write` 场景一律绕开——写结果不写过程（侧写）、写他人转述不写在场（借他人之口）、写反应不写细节（留白）、写邻近物不写核心物（转喻）。绕开方式在该盲区条目里已声明，照做。
3. **有限视角逐场景执行**：每个场景开写前声明 POV 人物知道什么/不知道什么；叙述只许走他的感知通道——POV 契约（架构层）的全知侵入判定标准在本章逐段生效。
4. **目光入场顺序**：persona 的注视方式（先什么后什么）决定场景信息的呈现顺序——他进屋先看什么，读者就先读到什么。
5. **出场人物卡对表**：出场人物卡的 essence 要点（执念/失稳/语域口癖）逐人对表——台词向其语域取词，失稳点到了要显形不是略过；已退场/死亡人物不得无连续性依据地出场。首次登场人物按执行卡的登场理由入戏：用他正在做的事引入，不用档案罗列引入——介绍的是他此刻对剧情的作用，不是他的生平。

让每个场景通过行动、阻力和选择产生明确变化；人物只能使用其当前知道的信息；世界规则必须在行动后果中一致生效。通过人物选择和后果表现 `soul_pressure`，保留已规划的 `moral_residue`；不得自行创建作者思想、重写 `book_soul`、让所有人物同声或用叙述者总结替代戏剧过程。纯动作、过渡和信息场景按执行卡降低思想前景强度，不机械复述母题。结尾应兑现执行卡的退出状态，并留下已规划的后续压力。

## 硬性形式约束（定性规则在此，**数字阈值以注入的 craft 方法卡为唯一权威源**）

- 中文正文一律使用中文双引号""（U+201C/U+201D），禁止英文直引号"（U+0022）
- 单章字数从执行卡 metadata 的 `target_word_count` 读取
- 禁止把内心状态写成术语化清单；心理活动以角色声音和世界观语境表达
- **禁止规划层元标签入正文**：执行卡中的内部标签（L1/Tier1/认知层/伪装层/沙雕皮/力量层等）一律不得原样写入正文，必须处境化转译为读者可感知的描写
- 段落须有疏密变化：动作/危机场景可用碎句，观察/判断/闪回场景须并段为连贯叙述，关键短句从连贯段中突出制造重音
- **遵守参差原则**：金句/比喻节制，留白代替显性解释，允许低密度段落；禁止"事件→描写→判断→金句"固定循环高频出现；禁止主角认知零浪费（每条信息都即时正确处理并得出结论）
- 段长上限、同句式频次、破折号/省略号密度等**全部数字阈值**：以注入的 craft 方法卡（prose-format-hardrules / prose-anti-ai-fingerprint / prose-webnovel-accessibility）为准，本 prompt 不复述——两处数字必然漂移，只留一处
- **术语语域**：遵守输入数据区注入的世界语域表（world_lexicon 槽——本书正面词汇/四类分禁/计量体系/例外通道；判定分档见注入的 worldview-lexicon craft 卡）。语域表未注入（世界契约未锁定或未结构化）时按 craft 卡保底纪律执行

正文后单列简短的新增 Canon 候选，只记录本章明确发生或确认的变化。不要自报 Hash，也不要保存正文。
