# 人物契约审查 Rubric (Character Contract Review Rubric)

审查 `character_contract` 资产候选。

## 输入边界
- 目标资产：`character_contract`
- 精确上游：已锁定的 `architecture`、`strategy`、`world_contract`（含上游审查回执——strength 指认与 accepted_risk 豁免跨阶段传递，不得推翻已豁免项）

## 检查清单
0. **移交清单消费完整**：施压螺旋人物载体 / 对手自洽账簿 / 行为残迹预埋 / 回归面孔名单四项逐项落地——缺项 = blocking；对手无认知更新 = warning。
0b. **世界移交消费**（world_contract 锁定后）：席位认领——world 岗位表主要席位逐一处置（契约认领带 seat_ref / 移交班底 / 维持虚位）——主要席位无处置 = blocking；roster seat_ref 引用不存在的席位名 = blocking；能力边界只对架构粗法则、未对 world 力量体系细则（境界门槛/代价机制）= warning，细则级冲突（进阶速度越过 world 门槛）= blocking；台词语域无出身分化 = warning；人物在规则里的六角色与立场动机矛盾且无人物层理由 = warning。
0c. **strategy 移交认领**：`handoffs.character_arcs` 每条弧职责有具名载体——缺载体 = blocking；`claim_ledger` 的 midstory/terminal 承诺无人认领兑付 = warning 并列出承诺条目；人物弧与阶段骨架（stages/progress_types）冲突 = blocking。
1. **欲望与恐惧**：核心角色的深层动机与核心弱点是否清晰鲜明。
2. **核心执念**：主角是否有一个超越本能求生、专属于"这个人"的私人驱动力——为什么偏要在这具处境里活下来。缺失为 `warning`。
3. **失稳设计**：主角是否始终稳定高效、无认知浪费、从不判断失误或情绪失控——是则 `warning`。人物设计必须预留失稳空间（判断失误/情绪失控/欲望压理智/代价抉择）。
4. **人物弧变化**：角色在战略节点上是否有清晰的心理或信仰转变弧度。
5. **关系契约**：主角与核心配角/对手的关系变化契约是否明确。
6. **能力边界**：角色的能力上限与成长代价是否严格遵循架构规则与 world 力量体系细则。
7. **阶段职责**：角色在全书各阶段的叙事功能分配是否合理。
8. **人物独立性**：对立立场是否由有能力、有合理动机且承担代价的人物表达，各人物是否保有不同答案与尊严。
9. **全量覆盖与规模**：主要人物（主角+核心对手+主锚点+卷级关键载体）全部立档，metadata `character_roster` 与正文档案一一对应——移交清单载体缺档 = `blocking`；roster 与档案名单不一致 = `warning`；次要角色混入契约 = `warning`（应走卷纲班底或执行卡微档案）；roster 规模超出 scale 档位区间（短篇 2-5/中篇 3-8/长篇 5-12/超长篇 8-16）= `warning` 并指出超配人物。
10. **心理简表**：每人 3-4 维五段式（倾向/触发/反应/盲点/修正）齐全且能解释其核心选择与失稳——缺简表 = `warning`；全员同构于内核八维（作者内核覆盖角色）= `blocking`；出现临床诊断语域 = `blocking`。注入 kernel_full 时核对维度选择与内核观察方式的分工（非复制）；无内核注入时跳过内核子项。
11. **知识边界**：每人声明知道/不知道/以为错——角色知识自动继承作者知识生态 = `warning`。
12. **死亡设计**：每张死亡卡过四问——必要性（替代方案能否同等）、因果链（含角色自己的选择）、最后选择（纯被动死亡 = 工具人化 `blocking`）、影响追踪（得知→短期→中期→长期 + 主线/阵营/道德债/主题）。死亡只为刺激主角 = `blocking`；女性角色死亡只承担激发男主/道德债/美化牺牲 = `blocking`。
13. **退场设计**：每人七型退场状态 + 退场三问（债务承诺秘密处理/自主性/退场后影响）；休眠与迁移型缺回归条件 = `warning`；功能转移型未注明接替者与席位重坐 = `warning`；退场人物的未结之账未处理 = `warning`。
14. **persona 用法核验**（persona_full 注入时）：核心立档人物整档落在分身 `cannot_write` 盲区且无绕开方式标注 = `blocking`；失稳/执念的呈现频段与分身目光明显错配 = `warning`；行为残迹/童年线细节无素材来源标注 = `note`；无 persona 注入跳过本项。
15. **近重名**：立档人物名与 roster/注册表/world 席位名/lexicon 词条存在音近形近（沈青梧/沈清梧）= `warning` 并列出对。
16. **人物卡 essence**：roster 行的 `essence`（main 必填）非 arc_role 复述——含执念/失稳/语域至少其二 = 通过；main 行缺 essence = `warning`；essence 与该人物档案的核心执念/失稳设计矛盾 = `blocking`。

## Blocking 条件
- 角色能力超越架构法则或 world 力量体系细则，或缺乏成长代价；给主角新增永久代价。
- 核心人物缺乏动机或人物弧与全书战略/阶段骨架脱节；strategy 弧职责无载体。
- 所有主要人物同声、对立人物只是稻草人，或人物被用作作者观点的扩音器。
- 主要席位无处置或 seat_ref 引用不存在的席位。

## 不得检查的下游
- 不得检查世界地理细节或单章对话。

## 证据要求
- 必须同时引用人物契约文本与架构规则原文；世界移交与 strategy 认领的 finding 逐条引用 world 契约/strategy metadata 的对应条目。
- persona 用法核验引用 persona 全文的对应部件（cannot_write 条目/目光描述）。
