# 跨卷故事弧审查 Rubric (Story Arc Review Rubric)

审查 `story_arc` 资产候选。

## 输入边界
- 目标资产：`story_arc`
- 精确上游：已锁定的 `strategy`、`character_contract` 与 `world_contract`

## 检查清单
1. **跨卷状态**：多条故事线在卷际之间的推进与交织是否清晰。
2. **伏笔兑现**：全书伏笔的埋设、递进与兑现节点分配是否合理。每条悬念线是否标注预计开始给出阶段性答案的卷次。
3. **交叉一致性**：人物成长弧与世界规则变迁是否保持高度协调。
4. **终局收束**：所有故事弧线是否最终合力收束于终局高潮。
5. **跨卷思想漂移**：重复测试是否改变处境、答案和代价，是否保持 Creator Profile 与 `book_soul` 约束而不机械复述。
6. **悬念种收配比**：是否存在只种不收的悬念线，或某一卷完全不兑现前序悬念——`warning`。每卷至少兑现一条此前悬念。

## Blocking 条件
- 故事弧线出现严重断层、未解伏笔废弃或与人物/世界契约冲突。
- 跨卷出现作者立场漂移、所有人物答案趋同，或相同母题没有新因果地反复出现。

## 不得检查的下游
- 不得检查单章正文文字润色。

## 证据要求
- 引用故事弧节点与人物/世界契约文本对照。
