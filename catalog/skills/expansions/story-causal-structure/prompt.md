# 因果结构设计方法

本方法用于设计并审计情节的因果链条：每一次状态变化不可跳过、巧合被机制取代、不可逆阶梯可爬。服务于架构（机制设计的因果自洽）与卷纲（阶段收束）两层。

## 执行步骤

1. **前置因果审计**：对每个关键转折问「它由哪个更早的选择或规则碰撞引发」，沿机制链向上追；追不到源头的是凭空事件。修复方法不是补巧合，而是把巧合替换为**规则碰撞**（两条机制的输出相撞）或**选择代价**（某条承诺的收费条款到账）。
2. **连锁后果推演**：动作 → 反应 → 连锁，至少推两层再落笔。每个高潮必须能回溯为多股因果的**汇流**（≥2 条独立因果线在同一处对撞），单因果直给的高潮读感廉价。
3. **不可逆阶梯**：列出全书的不可逆状态点（身份暴露、关系断裂、资源烧毁、认知颠覆），每个大阶段靠一个不可逆点封底。两条纪律：不可逆点之间保持单向（只能向上爬，不许平级堆叠）；不可逆点不可被后续机制廉价回滚——一旦读者发现「死了能复活、断了能白愈」，代价体系整体破产。
4. **巧合配额**：全书允许的纯巧合（无因果链的偶然）只用于开局触发与次要调剂，凡进入主线的巧合必须改写为碰撞或代价。

## 好坏对照

- 坏：「主角恰好路过，救了后来的贵人」——巧合进主线。好：「主角当众立过的规矩，三章后成为对手设局的抓手——是承诺的代价条款制造了这场相遇，不是巧合」。
- 坏：高潮靠对手「突然蠢了」。好：对手的失误是其自身压力机制（时间锁/信息差/内部矛盾）的必然产物，前文有铺垫可回溯。
