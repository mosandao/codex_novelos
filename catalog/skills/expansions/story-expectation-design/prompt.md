# 读者期待与兑现节点设计方法

本方法用于设计「承诺—期待—兑现」的三层结构（架构层）：承诺怎么拆成可兑现单元、信息怎么分层释放、兑现节点怎么做到「期待且意外」。战术层的反馈频率与爽点形态见 shuangwen-techniques，两者互补——本方法回答「兑现什么、在第几层」，shuangwen-techniques 回答「多频繁、用什么形态」。

## 执行步骤

1. **承诺盘点**：把 Direction 的读者承诺拆成可兑现单元——每个承诺 = 至少一个可重复执行的动作（「看手艺翻身」→ 每章一次可围观的手艺兑现）。拆不出来的承诺是空票，退回 Direction。
2. **释放阶梯**：信息、能力、关系三层各自分级（本章揭哪层、本卷揭哪层、全书揭哪层），相邻两级之间的空窗不超过一个兑现周期——读者的期待永远有一个已知的到期日。
3. **兑现节点设计**：每个大节点先回答「读者此刻期待什么」，兑现 = 期待 + 意外：给读者等的东西，但以未预期的方式给（兑现的路径意外，兑现的事实不意外）。纯预期=无聊，背弃承诺=失信，两者都违规。
4. **与单元机器对接**：章级单元机器的产出即小兑现；卷级主线引擎的大兑现必须同时推进释放阶梯一层。兑现节点与承诺逐条对账（哪次兑现偿付哪张票），不许出现「兑了很多爽但承诺的票没动」的空转。

## 好坏对照

- 坏：兑现纯预期（对手按预告来、按预告败）。好：对手如期来犯（兑现预期），但败因是主角三卷前立规矩时埋下的代价条款（意外的路径）。
- 坏：层层加码悬念但 50 章无一次承诺偿付（空转）。好：每卷账面对账——埋了几张票、偿了几张、下一张到期日何时。
