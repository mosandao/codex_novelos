# 力量生态与规则分层设计方法

本方法用于设计世界的因果优先级、力量生态与规则来源——防止「抽象规则压过力量」与「社会分析吞掉类型快感」。

## 输入约束
- 必须基于已锁定的 Story Direction（power_currency 已声明）与 Story Architecture。
- 不改变 book_soul 的力量货币语义，只深化其生态与规则层。
- 与 world-contract 主干的「代价与激励跨维度隔离原则」同向：规则六角色用于说明规则从哪来、谁执行、破坏要付什么，**不是**把账本结构泛化到所有维度。

## 因果优先级链

世界必须明确什么决定结果。常用结构（题材可调序，但不能让规则在没有来源、执行者和代价的情况下拥有无限权力）：

```
基础力量／世界本体 → 力量之间的相互作用 → 资源与信息分布
→ 组织和身份结构 → 多方博弈与妥协 → 规则、制度和契约
→ 人物的选择与行动 → 后果
```

## 八种力量类型（每种回答七属性）

| 类型 | 例子 |
|---|---|
| 物理力量 | 修为、武力、技术 |
| 资源力量 | 财富、情报、机会 |
| 组织力量 | 宗门、家族、国家、联盟 |
| 身份力量 | 血脉、名位、资格、正统 |
| 关系力量 | 信任、依赖、联盟、声望 |
| 象征力量 | 名誉、舆论、历史解释权 |
| 道德力量 | 恩情、牺牲、承诺、道德债 |
| 主体力量 | 拒绝、选择、谈判、承担后果的能力 |

每种进入正文的力量类型逐项回答七属性：**拥有者 / 作用对象 / 使用成本 / 可转让性 / 可剥夺性 / 兑换范围 / 失效条件**。答不全的力量在该题材戏份内不得成为决定性力量（warning 级缺口，交 world-contract-review 判）。

## 三类规则分层

1. **本体规则**：世界运行的底层限制（能量守恒、境界门槛、因果代价）——不可修订，只能被发现。
2. **力量规则**：由能力结构、强者协议和资源控制形成的秩序（境界压制、血脉权限、领域控制）——随力量对比漂移。
3. **社会规则**：宗门戒律、国家法律、家族礼法、联盟契约、市场制度——有立法者也有执法成本。

分层核对：每条声明的规则归入一层；层级错装（社会规则越权执行本体规则的效力、本体规则被博弈修改）= 结构缺陷。

## 规则六角色（每条重要规则必答）

**制定者 / 承认者 / 执行者 / 受益者 / 豁免者 / 破坏成本**。规则应当来自世界本体或多方力量博弈，不是悬在世界之上的抽象道德。没有执行者与破坏成本的规则 = 纸面规则，正文不得依赖它约束强者。

## 男频力量-规则循环

仙侠/玄幻/高武可采用四段循环本体：**力量塑造规则 → 规则集中和放大力量 → 规则反过来限制力量 → 新的力量打破旧规则**。开局无敌不等于没有冲突——冲突转移到身份、责任、政治、公共风险、规则重写与选择代价上；禁止用无来源的抽象规则强行压过主角力量（那等于世界违约）。

## 输出要求

生成 Markdown 格式的力量生态与规则层契约文档：因果优先级声明（含题材调整说明）、入场力量类型的七属性表、三类规则分层清单（每条带六角色）、男频题材的循环声明与开局冲突转移方案（如适用）。
