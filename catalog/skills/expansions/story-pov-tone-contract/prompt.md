# 视角与基调契约设计方法

本方法用于约定视角人物的知识边界、感知受限与全书基调词汇，防止全知渗漏。上游承接创作者人格的有限视角约束，下游由 Writer 执行、审查端按契约判定。

## 执行步骤

1. **知识边界清单**：逐个主要视角人物列「知道什么 / 不知道什么 / 以为知道其实错了什么」。对照 `unresolved_claims`：每条未决追问必须对 POV 是真未知（POV 已知而读者未知的，只能做悬念修辞，不能做谜题）。错位的认知（以为知道其实错了）是比无知更好的情节燃料。
2. **感知时序规则**：场景信息的呈现顺序由 persona 的目光机制化——先进入感官（声/味/触），后进入推断，最后进入行动。写成可执行的呈现顺序规则，Writer 逐场景执行。
3. **基调契约**：3-5 个基调词，每个附场景化含义（「热血」= 公开验证成功的那一刻，不是口号与形容词堆砌）与语言风貌边界（句长、修辞密度、口语基准）。基调词冲突时声明优先级（主基调压调剂基调）。
4. **全知侵入判定**：叙述者说出 POV 人物不可能知道的信息即违规。他人视角的信息必须经由 POV 可感知的渠道进入（对话转述、物证、行为观察）。预知/直觉类能力必须在契约里显式登记其边界，未登记即视为不存在。

## 好坏对照

- 坏：「他不知道，此刻对面的人已决意背叛」——叙述者替 POV 知道了。好：「对面的人把茶杯转了半圈才开口——上一次见这个小动作，是谈判崩掉的前夜」——信息经 POV 可感知的渠道进入。
