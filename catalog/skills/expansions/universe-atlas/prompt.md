# 宇宙图集（Universe Atlas）

本图集是 NovelOS 的**统一宇宙观设定模板库**，供 World Agent 在生成 `world_contract` 时按本书题材检索可裁切拼合的力量体系 / 势力格局 / 世界规则 / 世界地图设定骨架。**它不是强制拼装件**——World Agent 仍按已锁定的 Architecture 与 Strategy 自由组织世界契约形态，从图集中按需裁切。

> **与 scenario-atlas 的分工**：本图集（universe-atlas）管"世界怎么设定"（宇宙法则 / 力量体系骨架 / 势力格局 / 世界地图骨架）；`scenario-atlas` 管"剧情桥段怎么消费"（爽点 / 节奏 / 消费时机）。两者互补，开书时两份并用，不重复。

> 本文件是索引。每个宇宙簇的完整设定放在 `clusters/<宇宙>.md`。簇文件格式规范见 `clusters/README.md`。

## 顶层结构：主宇宙 + 派生宇宙

- **主宇宙（P-0）**：正常现实，无超自然，承担"合规安全底座"职责（真实地名/敏感内容由 `compliance-place-guard` 包处理）。
- **派生宇宙（D-*）**：各自有独立宇宙法则的虚构宇宙，彼此并列、与主宇宙并列。

主宇宙不是"父亲宇宙"，派生宇宙也不是它的变体。但所有派生宇宙共享同一份**现实底色**（人性逻辑、基础因果、单向时间），这部分从主宇宙继承、默认开启。

所有宇宙之上还有一份**宇宙法则框架**（`clusters/framework.md`），它是上位法：定义主/派生宇宙关系、跨所有宇宙的 U-1~U-7 元法则（代价守恒/越级反噬/法则惰性等）、裁切拼合的元规则、宇宙选择决策树、法则强度光谱（LI 0–10）。**任何宇宙簇的规则与 framework 冲突时，以 framework 为准。**

## 使用方式

1. 先读 `clusters/framework.md`，理解主/派生宇宙关系、U-* 元法则、LI 强度光谱、混搭仲裁四原则（P-1 主从/P-2 接口化/P-3 法则归一/P-4 单一基调）。
2. 按本书的核心冲突与题材，在下方"宇宙簇索引"定位对应的宇宙簇（或用 framework 的决策树路由）。
3. 打开该簇文件，按其七节结构（宇宙法则/力量体系/势力格局/世界规则/世界地图/裁切指引/启发式推导）裁切设定。
4. 用簇末"启发式推导"的引导性问题，把母题衍生为本书独有的设定，而非硬套标准设定。
5. 锁定 `world_contract` 前，按簇内"裁切指引"与"自检清单"逐项确认，避免全都要、境界膨胀、法则打架。
6. **跨宇宙混搭**（如科幻+克苏鲁）须遵循 framework §3.2 的四条仲裁原则，且必须指定一个主宇宙、其余为辅。
7. **图集未覆盖的细分宇宙不要硬套**——遇到未覆盖题材应依靠 Architecture/Strategy 约束直接推导，而非误用不相关簇。

## 宇宙选择决策树

输入：一本书的核心冲突 + 题材关键词。详见 `clusters/framework.md §4`。摘要：

```
Q1 根本张力含超自然/超物理？
  ├ 否 ──► alternate-history（架空）或 主宇宙 P-0（纯现实）
  └ 是 ─► Q2 力量来源性质？
            ├ 科学/技术延伸        ─► scifi / cyberpunk / interstellar
            ├ 修持/境界/灵力/天道   ─► xuanhuan / xianxia
            ├ 神祇/信仰/神话血脉    ─► myth / western-magic
            ├ 不可知/存在性恐惧     ─► cthulhu
            ├ 文明崩塌后生存        ─► apocalypse
            ├ 现代+隐藏超自然       ─► supernatural
            ├ 跨副本/主神空间       ─► multiverse
            └ 多种混合             ─► 走 framework §3.2 拼合流程
```

辅助校验：情绪是"敬畏/渺小" → cthulhu；解决路径是"变强曲线" → xuanhuan/xianxia；冲突来自"规则被揭示" → scifi/硬体系。

## 跨宇宙混搭（如科幻+克苏鲁、玄幻+神话）

允许，但必须遵循 `framework.md §3.2` 的四条仲裁原则：
- **P-1 主从原则**：指定一个主宇宙（提供根本法则与基调），其余为辅（只贡献局部模块）。
- **P-2 接口化**：跨宇宙模块拼接处必须显式定义"接口"——两套规则如何并存/转化/互斥。
- **P-3 法则归一**：若两宇宙根本法则互斥，必须选定一方为表层法则，另一方降格为例外/异常。
- **P-4 单一基调**：一本书的情绪基调只能由主宇宙决定；辅宇宙不得篡夺叙事情绪。

冲突仲裁优先级（高→低）：合规底座 > U-* 元法则 > 主宇宙根本法则 > 主宇宙模块规则 > 辅宇宙模块规则。

## 覆盖说明

本图集 v0.1.0 覆盖 1 份框架 + 13 个派生宇宙簇。每个簇含宇宙法则、五层左右力量分级、势力六原型适配、世界规则（生死/创世/因果/边界）、地图骨架与通道、裁切指引、3-5 个启发式推导问题、反模式与自检清单。内容源自：环球档案 92 篇神话文稿提炼（myth 簇）+ 主控训练数据对主流类型文学的共性提炼（其余簇）+ 各簇 3-5 次 WebSearch 力量体系/反套路素材补充 + framework 吸收 Sanderson 三律与 worldbuilding bible 方法论。

World Agent 遇到仍未覆盖的细分宇宙时，应依靠 Architecture 与 Strategy 的约束直接推导世界契约，不强行套用不相关簇。簇文件末尾的启发式推导提示就是为支持这种"从已有母题衍生新设定"的推导。

## 可靠性边界

- 本图集是对类型文学共性与神话素材的**二次提炼**，目标是给创作提供可用结构，不是学术考据或还原某部 IP 的设定真相。
- 簇内引用的代表作仅作"参考标注"，开书时必须替换为自有名词体系（结构可借，名词要换），避免版权/考据争议与读者出戏。
- 涉及真实地名/朝代/民族/宗教的题材，须同时调用 `compliance-place-guard` 包做地名合规处理——合规是 framework §1.3 的最高优先级约束，凌驾于任何宇宙法则之上。
