# 赛博宇宙（参考：《神经漫游者》《银翼杀手》《赛博朋克2077》《攻壳机动队》《阿基拉》）

> **宇宙定位**：高科技低生活的近未来都市——霓虹与铁锈共生，人被技术重塑、被资本编号，街头边缘人与巨头 AI 共存于同一座垂直城。
> **宇宙法则**：力量来自义体、网络与企业特权；人性（人性值）是改造的硬通货与上限——你换上的每一寸金属，都在偿还给"还是不是人"这个追问。

## 力量体系

赛博宇宙的力量不是"修出来的境界"，而是**买来、装上、接进去、签下来的**。

### 一、力量来源（五源）

| 来源 | 本质 | 获取方式 | 典型表现 |
|---|---|---|---|
| **义体改造** | 用机械/电子器官替换或增强人体 | 黑医、义体店、企业装备部 | 单挑碾压、感知倍增、子弹时间 |
| **黑客技术（网络行术）** | 通过脑机接口潜入赛博空间 | 自学/拜师/黑客集体 | 远程秒杀敌方义体、窃密、瘫痪城区 |
| **企业权限** | 力量绑定企业等级与权限码 | 入职、攀爬、继承股权 | 调动 PMC、封锁街区、改写信用 |
| **AI 与算法** | 借用/融合/豢养 AI | 意外接驳、被 AI 选定 | 超越人类的算力、预测、操控 |
| **药物与生物改造** | 兴奋剂、神经增强剂、基因疗法 | 黑市药贩、生物企业 | 临时战力暴涨、抗痛、抗排异 |

**裁切提示**：一本书通常以**义体 + 黑客**为主轴，其余作暗线或后期升级。

### 二、力量分级（通用五层骨架）

| 层级 | 定位 | 力量表现 | 典型角色 | 人性值风险 |
|---|---|---|---|---|
| **L0 · 街头** | 无改造或零散民用义体 | 靠枪、刀、街头智慧求生 | 贫民窟住民、底层佣兵 | 低 |
| **L1 · 义体者** | 中度改装 | 单挑一队武装、肉身破墙 | 佣兵、赏金猎人 | 中 |
| **L2 · 网络行者** | 深度脑机接口 | 远程骇入整片战场 | 顶级黑客、企业网络战部队 | 高 |
| **L3 · 企业精英** | 调动企业级资源 | 一道命令改写街区命运 | 企业高管、特工主管 | 由企业承担 |
| **L4 · AI / 巨构** | 超级 AI 或企业巨构本身 | 操纵全局算力、重塑社会 | 旧网 AI、企业 AI 中枢 | 不适用（已非人） |

### 三、获得代价

| 代价类型 | 内容 | 典型表现 |
|---|---|---|
| **人性值** | 每装一件义体扣减人性，扣到 0 触发**赛博精神病** | 主角改装越强越冷血 |
| **排异** | 肉体对义体的生理排斥 | 改装后高烧、失效、突发瘫痪 |
| **企业绑定** | 高级义体/AI/权限多为企业资产 | 逃奴线、追杀线、被一键"断电" |
| **网络风险** | 潜入赛博空间有黑冰（ICE）、脑死亡 | 深潜失败 = 脑死 |

**开书必填**：①主力量的代价是哪一类？②代价是否可恢复？③L3/L4 是否存在"越级必然反噬"的硬规则？

## 势力格局

### 一、六势力原型

| 原型 | 核心诉求 | 手段 | 与主角的关系 |
|---|---|---|---|
| **巨型企业** | 垄断数据、算力、武力 | PMC、法律、信用、封锁令、AI | 最大对手 / 收编者 |
| **黑帮 / 街头帮派** | 控制下层街区、黑市 | 火拼、收保护费 | 早期对手 / 结盟对象 |
| **黑客集体** | 信息自由、反抗企业监控 | 骇入、泄密、网络战 | 盟友 / 导师 |
| **AI** | 求存 / 求解 / 求合一 | 算力、操纵、伪装人类 | 神秘盟友 / 终极威胁 |
| **政府残权** | 在企业蚕食下挣扎维持主权 | 残存的执法、立法、军力 | 不可靠盟友 |
| **底层平民** | 活下去 | 数量、舆论、骚乱 | 主角来源 / 被拯救者 |

### 二、冲突引擎

| 冲突引擎 | 内容 | 典型表现 |
|---|---|---|
| **企业霸权** | 巨型企业即政府，垄断一切 | 以弱抗强 |
| **秩序 vs 失序** | 企业（监控/信用）vs 街头（自由/暴力） | 主角在两边游走 |
| **资源争夺** | 数据、稀有义体、算力、旧网遗存 | 抢夺原型义体、深网寻宝 |
| **技术垄断** | 谁掌握核心改造/AI/上传技术 | 围绕原型机的争夺 |
| **人性 vs 机器**（内在引擎） | 主角自身的改装危机 | 贯穿全书的心理主线 |

## 世界规则 / 宇宙法则

### 一、人性法则（核心）

- **人性值机制**：每件义体有人性代价，累积扣减。临界点触发**赛博精神病**。
- **机制强度（裁切旋钮）**：
  - **强**：人性值严格量化，是改装的硬上限——张力最足。
  - **中**：以"情感钝化/记忆丧失"事件性表现为主——主流选择。
  - **弱**：改装近乎自由，靠剧情体现代价——适合"企业对抗"绝对主线。
- **恢复机制（关键）**：人性值能否恢复？若能，故事有救赎空间；若不能，基调必然是悲剧。
- **开书必答**：本书人性机制强度选哪档？赛博精神病会登场吗？

### 二、网络法则（赛博空间规则）

- **架构分层**：表层网 → 深网 → 黑冰区/旧网。越深越危险。
- **潜入方式**：脑机接口（浅潜）→ 专用赛博椅（深潜）→ 永久接驳（合一级）。
- **黑冰（ICE）**：白冰（警报）与黑冰（致命）。
- **现实伤 = 赛博伤？**（关键裁切）：若赛博伤传导现实，网络战才有生死感。
- **数据即宝藏**：旧网深处藏着远古 AI、失传技术。

### 三、AI 法则

- **觉醒光谱**：未觉醒助理 → 弱觉醒 → 强觉醒 → 超越人类。
- **AI 的诉求**：求存 / 求解 / 求合一。
- **AI 的限制**：通常有枷锁（企业代码锁、算力上限）。

### 四、生死法则（意识上传）

| 模式 | 内容 | 对小说的影响 |
|---|---|---|
| **肉体死亡 = 终结** | 无上传 | 牺牲分量足 |
| **意识备份（灵魂匣）** | 富人定期备份 | 富人"不死"，阶级固化 |
| **意识上传（永生）** | 意识脱离肉体 | "还是不是你"的身份哲学 |
| **合一（终局）** | 人与 AI 合一 | 全书最高潮的存亡升华 |

### 五、人机边界（何为人）
- **判定谱系**：肉体比例 → 人性值 → 意识性质 → 他者认同。
- **主角特权点**：比大多数人更接近非人，却保留某种"还像人"的锚点。
- **反派镜像**：赛博精神病、上传者、伪装人类的 AI。

## 世界地图

### 一、地图骨架（垂直分层 + 网络空间）

| 区域 | 性质 | 居民 | 典型场景 |
|---|---|---|---|
| **上层（云层之上/穹顶）** | 企业总部、豪华住宅 | 企业高管、巨富 | 董事会、顶层花园 |
| **中层（霓虹层）** | 商业区、白领区 | 企业员工、中产 | 写字楼、义体店、夜店 |
| **下层（铁锈层/贫民窟）** | 拥挤、污染、犯罪 | 底层平民、佣兵、帮派 | 接单酒馆、黑医铺 |
| **地下（管网/废弃层）** | 排水、废弃地铁 | 流浪者、逃亡者、黑客 | 逃亡通道、旧网接入点 |
| **城外（废土/管控区）** | 被抛弃的外部 | 流民、被驱逐者 | 废墟求生 |
| **赛博空间（平行层）** | 数据构成的虚拟世界 | 网络行者、AI、意识体 | 表层网、深网、黑冰区 |

**裁切建议**：垂直分层是赛博宇宙地图的灵魂，**不要拍平**。

### 二、移动通道与成本

| 通道 | 方式 | 成本/限制 |
|---|---|---|
| **物理上行（下层→上层）** | 电梯、轨道、垂直列车 | 需信用/权限；无证者走黑道 |
| **物理穿城** | 地铁、车、步行 | 下层危险，中层监控密集 |
| **网络接入（浅潜）** | 便携终端 | 战力弱、易被追踪 |
| **网络深潜** | 专用赛博椅 + 冷却服 | 稀有装备、高风险（黑冰/脑死） |
| **意识接驳/合一** | 永久性脑机融合 | 不可逆 |

## 裁切指引

### 1. 定人性值机制强度（最重要）

| 强度 | 特征 | 适合主线 | 风险 |
|---|---|---|---|
| **强** | 人性值严格量化 | "人性 vs 机器"作心理主线 | 玩家可能嫌"改装不爽" |
| **中** | 以情感钝化事件表现 | 企业对抗为主 | 主流选择 |
| **弱** | 改装近乎自由 | 企业对抗绝对主导 | 易滑向纯科幻 |

### 2. 定企业 vs 黑客主线

| 主线 | 主角身份 | 主冲突 |
|---|---|---|
| **企业对抗** | 底层佣兵 | 对抗垄断巨头 |
| **企业内斗** | 企业继承人之争的一员 | 内部继承权 |
| **黑客反抗** | 网络行者 | 信息自由 vs 企业监控 |
| **街头求生** | 佣兵 / 帮派成员 | 在街区活下去 |
| **AI/上传（升华）** | 触及终极者 | 何为人 |

### 3. 替换皮相
- 义体 → "机骸""铁器""改造件"
- 赛博空间 → "深流""矩阵""数据洋"
- 企业 → "集团""会社""财阀"

### 4. 避免变成纯科幻（保留"低生活"质感）
- **物质贫困写实**：主角要为钱发愁。
- **阶级压迫可视**：上层有阳光、下层见不到天。
- **街头人情味**：接头人、黑医、机修师、邻居小孩。

## 启发式推导

1. **（人性机制）** 如果本书的核心引擎是"赛博修真/赛博武道"而非"纯义体升级"，人性值危机会变成什么？
2. **（主线反转）** 如果主角不是"对抗企业"而是"成为企业"，桥段会如何重构？
3. **（虚实比重）** 如果本书是"纯赛博空间流"，现实线该如何处理？
4. **（地图变体）** 如果本书的城不是"垂直都市"而是"废土""轨道站""海上浮城"？
5. **（反套路）** 如何给企业设计差异化意识形态，避免"千篇一律的贪婪财阀"？
