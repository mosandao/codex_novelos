# 架空历史/穿越宇宙（参考：《回到明朝当王爷》《唐砖》《赘婿》《临高启明》《大宋的智慧》）

> **宇宙定位**：所有派生宇宙里最接近主宇宙的一支——物理与社会运行就是"正常现实的历史古代"，唯一的外生变量是穿越者带来的现代知识差与架空朝代皮相，几乎无超自然。
> **宇宙法则**：力量来自跨时代的知识差与权谋手腕，受当时代生产力水平、生产关系与政治结构的硬约束，无超自然降维。

## 力量体系

这个宇宙的"力量"不是武力值，而是**改变历史走向的社会杠杆**。来源是知识差，但兑现成权力要穿过一整条古代社会结构。

### 一、力量的五大来源

| 来源 | 本质 | 兑现路径 | 典型表现 |
|---|---|---|---|
| **现代知识** | 工业/科学/制度/历史走向的先知信息 | 造物、改革、预判 | 玻璃肥皂火药起家；预知某场战役走向 |
| **攀科技树** | 把现代工艺链条在古代复刻 | 建作坊→规模化→军火/民用品垄断 | 炼铁→火药→蒸汽机的逐级解锁 |
| **政治手腕** | 权谋、制衡、站队、借势 | 在皇权/官僚/世家的缝隙里爬升 | 夺嫡站队、党争平衡 |
| **人脉网络** | 名臣/名将/世家/基层的关系资本 | 收服、联姻、师徒、同窗 | 收服虚构名将 |
| **财富** | 现代产业/商业垄断积累的财力 | 财力反哺军政 | 工业品倾销换白银，再换军权 |

### 二、力量分级（通用五层骨架——权力而非武力）

| 层级 | 定位 | 权力标志 | 典型约束 |
|---|---|---|---|
| **L0 · 寒门/布衣** | 白身，无官无爵 | 一技之长、少量产业 | 任何官吏可拿捏；知识难以变现 |
| **L1 · 乡绅/吏目/豪商** | 地方富户或基层胥吏 | 田产、作坊、地方人脉 | 出不了地方；受知县/知府节制 |
| **L2 · 权臣/封疆/一方诸侯** | 进入朝廷视野 | 知府以上、掌控一省或一军 | 站错队即贬谪抄家 |
| **L3 · 重臣/顾命/摄政** | 皇帝之下、百官之上 | 入阁、大将军、辅政 | 功高震主，皇权猜忌是常态 |
| **L4 · 帝王/开国之君** | 制定规则、改写历史格局 | 称帝、立国、改元 | 孤家寡人；守成比打天下更难 |

**裁切建议**：
- 种田流：L0→L2 为主战场。
- 夺嫡/朝堂流：L1→L3。
- 称帝流：L2→L4。

### 三、获得权力的代价

| 代价类型 | 内容 | 典型 |
|---|---|---|
| **政治风险** | 每升一级都押上性命前程 | 夺嫡站队失败、党争被贬 |
| **背叛** | 收服的人脉会反水 | 名将倒戈、家臣通敌 |
| **历史惯性** | 改变历史遭旧秩序修正 | 改革触动既得利益，守旧派反扑 |
| **守旧势力反扑** | 世家/勋贵/官僚联合反制"奇技淫巧" | 火药配方被觊觎；产业被课重税 |
| **猜忌** | 功越高，皇权越忌惮 | 功高震主被赐死或逼反 |

## 势力格局

### 一、势力的六种原型

| 原型 | 核心特征 | 在故事里的功能 |
|---|---|---|
| **皇室/皇权** | 掌握最高合法性 | 夺嫡/赐死/禅让的源头 |
| **世家门阀** | 累世簪缨，垄断田产、人脉 | 守旧势力主力；联姻对象 |
| **军头/藩镇/边将** | 握兵权的实权派 | 军事变量 |
| **改革派** | 试图变法/改制（含主角阵营） | 推动历史前进 |
| **守旧派** | 维护旧制、旧产、旧礼 | 主线最大摩擦源 |
| **平民/商贾/流民** | 无权但有数量、劳动力、民情 | 被争夺的资源 |

### 二、冲突引擎

| 冲突引擎 | 内容 | 代表场景 |
|---|---|---|
| **权力更替（夺嫡）** | 皇位继承的合法性之争 | 虚构王朝的"诸子夺嫡" |
| **秩序（旧制）vs 失序（改革）** | 守旧派维护祖制 vs 改革派推动变法 | 税制/军制/科举改革 |
| **资源（土地/财权）争夺** | 田产、盐铁、商税、军饷的分配 | 土地兼并、盐课之争 |
| **传承** | 世家/门阀的延续、家主更迭 | 门阀内斗、过继、立嫡 |

## 世界规则 / 宇宙法则

### 1. 生产力法则（科技不能凭空跃迁）
- **资源前置**：蒸汽机需要煤铁；火药需要硝石硫磺木炭。
- **配套工业**：造蒸汽机要先有精密加工、耐压材料、密封技术。
- **劳动力束缚**：奴婢/部曲/匠籍制度下，劳动力无技术创新激励。
- **行会/官营垄断**：技术扩散极慢。

**开书必答**：本书的"科技节点解锁表"是否每项都标注了前置资源与配套工业？

### 2. 政治法则（皇权/官僚/制衡）
- **皇权的双重性**：皇帝至高无上但精力有限，必须依赖官僚代理。
- **制衡结构**：皇权靠平衡派系维系。
- **合法性来源**：功业、血统、禅让、民心。

### 3. 历史惯性法则（改变历史的阻力）
- **蝴蝶效应**：主角干预历史后，连锁反应会催生原本不存在的敌人。
- **历史修正力**：重大走向难靠个人扭转。
- **知识差递减**：主角的先知优势会随干预累积而失效。

### 4. 生死规则（政治死亡 vs 真死亡）

| 模式 | 内容 | 对小说的影响 |
|---|---|---|
| **真死亡** | 物理死亡，不可复活 | 牺牲才有分量 |
| **政治死亡** | 贬谪/抄家/流放/废为庶人 | 不死但"社死"，可作转场与东山再起 |

### 5. 知识与权力边界
- **知识 ≠ 权力**：现代知识要兑现成权力，必须穿过社会结构。
- **知识会外泄**：配方、技术一旦展示就可能被逆向。
- **知识有时效**：先知信息随蝴蝶效应失效。

## 世界地图

### 一、地图骨架：中心辐射型

```
                 [北疆 · 军事压力源]
                        ↑ 边军/外族
   [西陲/蜀]  ←  [京城 · 皇权中枢]  →  [漕运/江南 · 财赋]
        ↘                              ↙
          [南方/流民/商路/海贸]
```

### 二、移动通道与成本

| 通道类型 | 通行内容 | 成本/延迟 |
|---|---|---|
| **官道/驿站** | 人员、政令、军报 | 快马日行数百里；常人日数十里 |
| **漕运/水路** | 粮草、大宗货物 | 比陆运廉价，受季节/水情制约 |
| **海路/海贸** | 远洋货物、外来情报 | 风险高（海盗/风浪），利润极大 |
| **信息传递** | 奏折、密信、战报 | 边疆军报到京常需旬日至月余 |

**开书必答**：主要区域靠什么连接？信息延迟多久？"京城决策滞后于边疆战况"这类延迟应写成冲突来源。

## 裁切指引

### 1. 选主线引擎（夺嫡 / 种田 / 军功 / 称帝）

| 主线 | 力量来源侧重 | 核心冲突引擎 |
|---|---|---|
| **夺嫡/朝堂流** | 政治手腕 + 人脉 | 权力更替 |
| **种田/基建流** | 攀科技 + 财富 | 资源争夺 |
| **军功/征战流** | 攀科技（军火）+ 军事 | 资源（地盘）争夺 |
| **称帝/立国流** | 全来源累积 | 传承（开国之君） |

### 2. 定攀科技深度（写实 vs 夸张）
- **写实硬核流**（《临高启明》向）：严格遵循生产力法则，改生产关系比造机器更难。
- **半硬核流**：科技节点给方向不包办，阻力主要来自政治觊觎。
- **爽文夸张流**：科技树为权谋/种田服务，需用"本地变量"掩盖跳变。

**关键约束**：避免 WebSearch 高频批评的**"老三样填空题"**（玻璃肥皂火药已成公式）。规避方法：选冷门高附加值产业，或把攀科技与权谋深度绑定。

### 3. 替换皮相（虚构朝代替代真实朝代 —— 合规核心）

**这是本宇宙最特殊的裁切项，直接呼应合规安全层。** 真实朝代名（唐/宋/明/清）、真实地名（长安/洛阳/北京）、真实帝王将相姓名均可能触发合规风险与读者考据争议。

裁切做法：
- **完全架空**（合规风险最低，《琅琊榜》向）：虚构国号、都城、年号、帝王谱系。建议本宇宙**默认采用完全架空**。
- **半架空**（基于真实朝代改编）：审核风险较高。
- **地名映射**：京城用虚构都名（如"上京""神都"）；行省用虚构路名；边疆用虚构族名。
- **朝代生命周期**：按"初期—前期—中期—后期—末年"设计虚构王朝所处阶段。

**合规联动提示**：具体禁用名见 `compliance-place-guard` 包（含国名/省名/主要城市，可程序校验）。裁切时把命中词全部替换为虚构名；但词表是第一道提醒，非"通过即安全"，终审须人工。调用方式：写作/审查 agent 通过 `skill_catalog.get` 读取该包的 `真实地名.txt` 资源。

### 4. 避免科技树跳变与开挂感
- 每个科技节点标注前置资源与配套工业。
- 让古人会逆向学习——主角的碾压优势应有递减曲线。
- 给攀科技配政治代价。

## 启发式推导

1. **如果你的主角穿越到的不是"盛世"而是"王朝末年/乱世"**，力量分级与冲突引擎会如何重排？
2. **如果本书核心引擎是"思想启蒙/制度变革"而非"科技碾压"**，攀科技会退化为背景板吗？
3. **你的虚构王朝处于生命周期的哪个阶段？** 初期（百废待兴）、中期（盛世，夺嫡最烈）、还是末年（礼崩乐坏）？
4. **主角的先知优势什么时候失效？** 蝴蝶效应累积到哪个节点，"未来"就不再是 ta 记得的样子？
5. **你的"攀科技"是否回避了生产关系这一层？** 如果主角只造机器不解放劳动力，严肃读者会出戏。
