# 簇文件格式规范（clusters/README.md）

本目录下每个 `.md` 文件是一个宇宙（或框架）的完整设定簇。World Agent 通过父级 `prompt.md` 的索引定位到对应簇文件后，读本文件获取该宇宙的全部可裁切设定骨架。

> **与 scenario-atlas 的分工**：本图集（universe-atlas）管"世界怎么设定"（宇宙法则/力量体系骨架/势力格局/世界地图骨架）；`scenario-atlas` 管"剧情桥段怎么消费"（爽点/节奏/消费时机）。两者互补，开书时两份并用，不重复。

## 文件命名

`<宇宙英文短名>.md`，全小写，连字符分隔。当前 14 个文件：

```
framework.md            宇宙法则框架（上位法，非具体宇宙）
alternate-history.md    架空历史/穿越
wuxia.md                武侠/江湖
supernatural.md         超自然/都市灵异
scifi.md                科幻
cyberpunk.md            赛博
apocalypse.md           末世/废土
western-magic.md        西幻/魔法
xuanhuan.md             玄幻
xianxia.md              修真/仙侠
myth.md                 神话
cthulhu.md              克苏鲁/宇宙恐怖
interstellar.md         星际
multiverse.md           无限流/多元宇宙
```

## 簇文件结构（强制）

每个宇宙簇文件必须按以下结构编写（framework.md 是上位法，结构略有不同，见其文件头说明）：

```markdown
# <宇宙中文名>（参考：<代表作 1><代表作 2>）

> **宇宙定位**：<一句话概括该宇宙在世界谱系中的位置>
> **宇宙法则**：<底层根本法则，定义该宇宙与主宇宙的本质差异>

## 力量体系
### 力量来源（表格：来源/本质/代表/表现）
### 力量分级（5 层左右骨架，标注各传统/代表作对应）
### 获得代价（代价类型表格，至少一类）

## 势力格局
### 势力原型（六原型适配该宇宙）
### 冲突引擎（3-5 种）

## 世界规则 / 宇宙法则
### 生死规则
### 创世法则/底层物理
### 因果宿命
### 神凡/人异/仙凡边界

## 世界地图
### 地图骨架（四种之一或组合：垂直分层/横向并置/中心辐射/单一平面）
### 通道与成本

## 裁切指引
### 开书怎么挑（选 1-2 主线、定层级深度、替换皮相）
### 自检清单
### 反模式（照搬会踩的坑）

## 启发式推导
（3-5 个引导性问题，从已有母题衍生本书特有设定）
```

## 编写原则

1. **宇宙法则是灵魂**：每个簇的 `> **宇宙法则**` 一行定义该宇宙与主宇宙的本质差异，是力量/势力/规则的地基。开书裁切时，宇宙法则一旦选定就应贯穿全书。
2. **结构可借，名词要换**：簇内用通用术语或引用传统/代表作作参考标注，但开书时必须替换为自有名词体系。
3. **裁切指引不是补充说明**：它是开书必读的操作指南，明确"怎么挑、定多深、换什么皮、避什么坑"。
4. **启发式推导不是预设答案**：它是一组问题，引导 LLM 在本书差异下自行推导设定，而非硬套或穷举。
5. **服从 framework**：任何簇的规则与 `framework.md` 的 U-* 元法则或 LI 光谱冲突时，以 framework 为准；簇内如需例外，须在文件头 `overrides` 列出。
