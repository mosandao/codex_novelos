# 宇宙法则框架（上位法）

framework_version: 1.0

> 本文件是「宇宙设定模板库」的**上位法 / 顶层总纲**。所有具体宇宙簇（科幻、玄幻、克苏鲁、神话、末世……）文件均须服从本文。当簇内规则与本文冲突时，以本文为准；本文未覆盖处，由各簇自行补全并在头部声明 `derives: framework.md`。
>
> 本文只回答"宇宙之间如何相处、开书如何选宇宙、法则如何标定"三件元层级问题，**不**规定任何具体宇宙的设定细节。

## 0. 术语约定（全文沿用）

| 术语 | 定义 |
|---|---|
| **主宇宙（Prime / P-0）** | 现实题材小说运行的默认宇宙。零超自然、遵循现实物理、承担"合规安全底座"职责。 |
| **派生宇宙（Derived / D-*）** | 与主宇宙并列、各自有独立根本法则的虚构宇宙。编号如 D-SF、D-XH（玄幻）、D-CT（克苏鲁）。 |
| **宇宙法则（Cosmic Law）** | 某宇宙区别于主宇宙的**底层根本命题**，是该宇宙一切力量/势力/规则的公理地基。 |
| **模块（Module）** | 可被"裁切"复用的设定单元：力量体系、势力、地理、种族、科技层级、形而上规则等。 |
| **裁切（Slice）** | 从某派生宇宙中选取若干模块组成一本书的世界设定。 |
| **拼合（Splice）** | 把来自多个宇宙的模块合并进同一本书的设定。 |
| **法则强度（Law Intensity, LI）** | 0–10 的标量，量化一本书偏离主宇宙的程度（见 §5）。 |

## 1. 主宇宙与派生宇宙的关系

### 1.1 拓扑模型：共享现实底色，法则各自为政

- 主宇宙 **不是**"父亲宇宙"，派生宇宙也不是它的"变体"。它们是**并列**的。
- 但所有派生宇宙共享同一份**现实底色**：人性逻辑、基础因果、时间单向流逝、社会运作常识。这部分从主宇宙继承，**默认开启、不可关闭**——除非某宇宙的"宇宙法则"明确否决某条（例如克苏鲁宇宙否决"人类可知论"）。
- 关系可记作：`D-x = 共享现实底色 ∪ 宇宙法则(x) ∪ 模块集(x)`。

### 1.2 是否可交汇 / 穿越

设三档开放度，每本派生宇宙簇须在头部声明其一：

- **封闭（CLOSED）**：与主宇宙及其他派生宇宙零交集。绝大多数单题材书。
- **半透（SEMI）**：允许**单向渗透**——例如主宇宙角色"穿越"进入 D-x，或 D-x 的事件以隐喻/梦境渗回主宇宙，但不发生双向自由贸易。
- **可穿越（OPEN）**：允许双向角色/物质/信息流动。仅用于明确的多元宇宙、位面、轮回流作品。

**默认值 = CLOSED**。改 OPEN 必须在宇宙法则中显式给出"通道机制 + 通行代价"，否则判定设定越界。

### 1.3 合规安全底座的强制职责

无论进入哪个派生宇宙，凡涉及**现实地名、真实机构、在世人物、敏感政治宗教议题**，一律回退到主宇宙的合规层处理（化名 / 虚构替代 / 模糊化）。这是**最高优先级约束**，凌驾于任何宇宙法则之上。具体地名拦截由 `compliance-place-guard` 包提供。

## 2. 通用宇宙法则（跨所有派生宇宙的硬约束）

下列七条为**不可协商**的元规则。任何宇宙簇、任何模块、任何剧情都不能违反；如剧情需要违反，必须先修改本文件并升级版本号。

| 编号 | 法则 | 一句话释义 | 违反时的症状 |
|---|---|---|---|
| **U-1 代价守恒** | 力量必有代价 | 任何超自然/超规力量的获取与使用，必须伴随等价或更高代价（消耗、损耗、风险、道德、不可逆后果）。 | 主角无脑变强、爽点贬值。 |
| **U-2 越级反噬** | 越级必有反噬 | 以弱胜强、跨阶使用力量、违反本宇宙层级秩序，必须付出代价或埋下反噬伏笔。 | 战力崩坏、读者失去张力。 |
| **U-3 法则惰性** | 规则不可临时改动 | 已确立的宇宙法则与模块规则不得为解当前剧情而临时变更；新设定必须向前兼容已发布正文。 | 机械降神、设定吃书。 |
| **U-4 信息对称** | 作者→读者→角色 | 角色"用法则解决冲突"的能力，正比于"该法则被读者理解的清晰度"（Sanderson 第一律的元化）。读者看不懂的法则不得用于破局。 | 突兀翻盘、作弊感。 |
| **U-5 限制优于能力** | 弱点 > 强项 | 一个模块的力量上限远不如它的**限制、代价、副作用**有叙事价值；每引入一种新能力，必须同步定义至少一条硬限制。 | 角色万能、无冲突空间。 |
| **U-6 扩展先于新增** | 先挖深再加宽 | 新需求优先通过"深挖已有模块"满足，确认无法满足后才允许引入新模块（Sanderson 第三律的元化）。 | 设定膨胀、互不咬合。 |
| **U-7 法则后果一致性** | 设定反推世界 | 一旦确立某宇宙法则，该宇宙的社会、经济、军事、文化、两性关系必须据此被合理改造，不得与现实社会无差别共存。 | 法则是装饰、世界不真实。 |

### 2.1 各宇宙"自定"的部分

U-* 之外，下列维度由各派生宇宙**自行立法**，但必须在簇文件中显式声明：

1. 力量来源（神授 / 血脉 / 科技 / 知识 / 契约 / 不可知）。
2. 力量的"硬/软"程度（见 §5，是否向读者全公开规则）。
3. 时间 / 空间 / 因果在本宇宙是否被改写。
4. 死亡是否可逆、灵魂是否存在。
5. 该宇宙特有的层级秩序（境界、阶级、维度、位格）。
6. 与主宇宙的开放度档位（CLOSED / SEMI / OPEN）。

## 3. "裁切拼合"的元规则

开书时按下列流程从宇宙库中取设定。

### 3.1 单宇宙裁切（默认路径）

1. 由核心冲突路由到唯一派生宇宙 D-x（见 §4 决策树）。
2. 从 D-x 的模块清单中按"剧情必要集"裁切：只取推动主线所必需的模块，其余留库不引。
3. 裁切结果写入该书的《世界契约》文件，标注 `source: D-x`、`modules: [...]`、`intensity: LI=?`。

### 3.2 跨宇宙拼合（混搭，如 科幻+克苏鲁）

允许，但须遵守四条仲裁原则：

- **P-1 主从原则**：必须指定一个**主宇宙**（提供根本法则与基调），其余为**辅宇宙**（仅贡献局部模块）。辅宇宙模块不得与主宇宙的根本法则直接冲突。
- **P-2 接口化**：跨宇宙模块拼接处必须显式定义"接口"——两个体系如何并存、如何转化、是否互斥。禁止"两套规则各自运行却假装对方不存在"。
- **P-3 法则归一**：若两宇宙的根本法则互斥（如"科学可解释一切" vs "不可知古神"），必须选定一方为**表层法则**，另一方降格为**例外/异常**被解释，不得并存为同等公理。
- **P-4 单一基调**：一本书的**情绪基调**只能由主宇宙决定；辅宇宙模块不得篡夺叙事情绪（克苏鲁做辅，就只能贡献"局部异质感"，不能让全书滑向绝望宇宙恐怖）。

### 3.3 混搭冲突仲裁顺序

当两个模块在同一场景里给出矛盾结论时，按此优先级裁决：

1. 合规安全底座（§1.3，最高）
2. 通用宇宙法则 U-1 ~ U-7
3. 主宇宙的根本法则
4. 主宇宙模块的具体规则
5. 辅宇宙模块的具体规则（最低，遇冲突则改写辅模块以适配上层）

任何层级不得反向覆盖其上层。

## 4. 宇宙选择决策树

输入：一本书的**核心冲突**（一句话）与**题材关键词**。按下表自上而下匹配，命中最深叶子即路由结果。

```
Q1  本书的根本张力是否包含"超自然 / 超现实 / 超物理"？
    │
    ├─ 否 ───────────────────────► 主宇宙 P-0（现实题材，合规层全权）
    │                                  或 alternate-history（架空穿越，无超自然但有权谋知识差）
    │
    └─ 是 ─► Q2  超常力量的"来源性质"是哪一种？
              │
              ├─ 科学/技术的延伸（哪怕虚构）  ─► D-SF   科幻簇 / cyberpunk / interstellar
              ├─ 修持/境界/灵力/天道          ─► D-XH   玄幻/仙侠簇
              ├─ 神祇/信仰/神话血脉           ─► D-MY   神话簇 / western-magic
              ├─ 不可知/存在性恐惧/宇宙冷漠   ─► D-CT   克苏鲁簇
              ├─ 文明崩塌后的生存秩序         ─► D-PA   末世簇
              ├─ 现代+隐藏超自然              ─► D-SN   超自然/都市灵异簇
              ├─ 武学/江湖恩怨（低魔）        ─► D-WX   武侠簇
              ├─ 跨副本/主神空间              ─► D-MV   无限流簇
              └─ 上述多种混合                 ─► 走 §3.2 拼合流程
```

辅助校验（任一命中即重新评估路由）：

- 若核心冲突的**情绪**是"敬畏/渺小/未知" → 倾向 D-CT。
- 若核心冲突的**解决路径**是"角色变强曲线" → 倾向 D-XH。
- 若核心冲突的**张力**来自"规则被一点点揭示" → 倾向硬体系（D-SF / 硬魔法 D-XH 子类）。
- 若冲突可完全用现实社会逻辑解释 → 退回 P-0 或 alternate-history。

## 5. 宇宙法则强度光谱（Law Intensity, LI 0–10）

用单一标量标定一本书"偏离主宇宙"的程度，便于卡边界、防越界。每本书在《世界契约》中必须填写 `intensity: LI=?`。

| LI | 档位 | 含义 | 典型 | 法则约束 |
|----|------|------|------|----------|
| **0** | 现实 | 主宇宙本体。零超自然。 | 现实主义、都市情感、行业文 | 合规层全权；U-* 仅 U-3/U-4/U-6 生效 |
| **1–2** | 微光 | 现实为主，可有民俗/传说/巧合的暧昧暗示，不坐实。 | 民俗悬疑、氛围文学 | 超自然不可被证实；不得给出明确法则 |
| **3–4** | 低魔/低科 | 单一、受限的异常存在，世界整体仍是现实逻辑。 | 都市异能、低魔历史、武侠 | 力量代价高昂、影响局部；U-7 弱生效 |
| **5–6** | 中魔/中科 | 力量体系公开存在，社会部分被改造，但日常生活仍可辨认。 | 经典奇幻、近未来科幻、赛博、西幻 | 全部 U-* 生效；U-7 必须显著体现 |
| **7–8** | 高魔/高科 | 力量/科技重塑文明基底，现实逻辑退居二线。 | 史诗奇幻、太空歌剧、修真大世界、玄幻 | U-7 强约束：每一处社会细节都须据此改写 |
| **9** | 高神秘 | 人类认知框架本身被动摇，因果/时间/自我可能不稳。 | 克苏鲁、新怪谭、元叙事 | U-4 信息对称可定向**放松**（详见簇文件） |
| **10** | 超法则 | 法则本身是叙事对象/被角色改写。 | 神修、创世流、元小说 | 必须显式声明"法则可变性机制"，否则视为越界 |

### 5.1 强度边界守则

- **上行越界**：一本书声明 LI=3，却写出 LI=6 的力量效果 → 判定设定越界，必须或上调 LI 并补写 U-7 后果，或削弱情节。
- **下行漂移**：声明 LI=7 却仍按现实社会描写日常 → 违反 U-7，须回填世界改造细节。
- **U-4 放松许可**：仅 LI≥9 的宇宙允许"用读者尚未理解的法则破局"作为**有意的惊奇手段**，且须在事后补足理解。低于 LI=9 一律禁止。

### 5.2 强度与硬/软的解耦

LI 衡量"偏离现实多少"，**不**衡量"规则是否向读者公开"。后者是独立维度：

- **硬（Hard）**：规则全公开，可被读者用来推理解题（适配 U-4 上限）。
- **软（Soft）**：规则留白，制造惊奇/氛围；不得用于破局。

二者可正交组合：高 LI 可软（高魔史诗但魔法神秘），低 LI 也可硬（低科但技术规则严密）。每书须在《世界契约》同时声明 `intensity` 与 `hardness`。

## 6. 文件引用与版本契约

- 本文件版本号记于顶部元数据（建议 `framework_version: 1.0`）。
- 每个派生宇宙簇文件须在头部写明：
  ```
  derives: framework.md@1.0
  universe: D-SF
  openness: CLOSED
  intensity_range: 5-10
  overrides: []   # 对 U-* 或本框架的任何例外，逐条列出并给理由
  ```
- `overrides` 列表为空时，默认完全接受本框架。任何非空 override 都视为对上位法的修订申请，须在 review 时单独审查。
- 本框架一旦升版，各簇须做一次兼容性核对：被新版本否决的 override 必须下线或迁移。
