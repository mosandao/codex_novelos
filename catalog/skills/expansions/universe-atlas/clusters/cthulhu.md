# 克苏鲁/宇宙恐怖宇宙（参考：H.P.洛夫克拉夫特《克苏鲁的呼唤》《疯狂山脉》；《诡秘之主》(爱潜水的乌贼)；《血源诅咒》(FromSoftware)；《克苏鲁的呼唤》TRPG (Chaosium)；奥古斯特·德雷斯神话扩展）

> **宇宙定位**：现实表层之下叠加一层"不可知"的宇宙恐怖——人类渺小如蝼蚁，超凡力量以理智、人性乃至存在本身为代价，知识本身即是危险。
> **宇宙法则**：宇宙对人类漠不关心；越界知晓（禁忌知识）必然侵蚀理智；超凡来自被外神/旧日"注视"或主动承接其力量，而"被注视"本身即等同于异变与疯狂。

## 力量体系

### 1. 力量来源

| 来源 | 本质 | 典型表现 | 代价基调 |
|---|---|---|---|
| **禁忌知识** | 研读古卷/咒文/真实形态，知道得越多越强也越疯 | 调查员学《死灵之书》、解读符文获得仪式能力 | 理智不可逆流失 |
| **外神/旧日赐予** | 被更高存在选中或献祭，借其权柄行事 | 教徒获神迹、眷族获异能、预言者获真视 | 被注视、人格被侵蚀 |
| **仪式** | 通过特定仪轨临时调用或召唤超自然力量 | 召唤、束缚、献祭、占卜 | 失败即疯/死，成功欠下因果 |
| **序列魔药（序列流变体）** | 服用按"途径"配制的魔药逐级晋升，序列4起需仪式 | 22 条途径、序列9→0、神位（真神） | 失控、异变、被聚合定律追猎 |
| **血脉/眷属污染** | 被外神血脉或眷族血统沾染，先天带部分力量 | 深潜者混血、旧日后裔 | 缓慢非人化、终被族群召回 |

### 裁切建议
- **纯克苏鲁（绝望流）**：以"禁忌知识 + 仪式"为主，天花板是"接触者"。
- **序列流（升级流）**：以"序列魔药 + 外神赐予"为主，有成长希望但代价是失控风险。理性化了恐怖，适合长篇网文。
- **混合要小心**：若知识本身致疯，为何序列者越知越强？必须设定"序列是对知识的可控封装"。

### 2. 力量分级（六层骨架，强调渺小）

| 层级 | 定位 | 典型对应 | 与凡人差距 |
|---|---|---|---|
| **L0 · 凡人** | 普通人类，对真相一无所知，无知是唯一保护 | 大众、初级调查员 | 基准 |
| **L1 · 接触者** | 接触过禁忌知识或仪式，获得零碎超自然感知/能力，理智已受损 | 资深调查员、低阶教徒、序列7-9 | 能做超凡之事，但仍会死、会疯 |
| **L2 · 序列者** | 系统化掌握某途径力量（序列流）或精通多条仪式链 | 序列4-6 非凡者、高阶祭司 | 单体碾压凡人，但受途径与理智约束 |
| **L3 · 眷族** | 被旧日/外神深度沾染或晋升至高序列，身体与心智已半非人 | 深潜者长老、序列1-3、眷族化强者 | 凡人几乎无法正面抗衡 |
| **L4 · 旧日支配者** | 远古沉睡的强大存在，"群星归位"时苏醒 | 克苏鲁、哈斯塔 | 不可战胜，只能逃避或延缓 |
| **L5 · 外神** | 宇宙级混沌原核，超越理解，一切存在之源 | 阿撒托斯、奈亚拉托提普、犹格·索托斯 | 接触即灭，理解即疯 |

### 裁切建议
- 纯恐怖短篇/中篇：L4/L5 作为背景压顶，主角挣扎在 L0~L1。
- 序列流长篇：主角从 L1（序列9）爬到 L2~L3（序列3-1）。

### 3. 获得代价

| 代价类型 | 内容 | 典型表现 |
|---|---|---|
| **理智（SAN）** | 每次接触真相/使用力量扣减，永久性流失，归零即疯 | 看见旧日真容、研读禁书、施展高阶仪式 |
| **人性/人格** | 越强越失去共情、记忆、自我认同 | 序列者逐步"非人化"、眷族遗忘前世 |
| **变异（肉体）** | 力量扭曲肉身，向非人形态靠拢 | 深潜者化、触手/复眼/鳞片、血源诅咒的兽化 |
| **被注视** | 一旦动用力量即被外神"看见"，从此被追踪 | 奈亚拉托提普的关注、聚合定律的吸引 |
| **失控（序列流）** | 魔药失败或消化不良，直接异变成怪物 | 序列者"失控"成无理智眷族 |

**开书必填**：①主力量的代价是哪一类？②理智/代价是否可恢复？③L4/L5 会不会登场？④凡人能否越级？

## 势力格局

### 势力原型（六原型适配）

| 原型 | 在本宇宙的形态 | 核心诉求 | 与主角关系 |
|---|---|---|---|
| **隐秘教团** | 崇拜外神/旧日的秘密教派 | 唤醒沉睡的旧日 | 直接反派 / 信息源 |
| **调查员组织** | 结社对抗或记录超自然的研究者、侦探、守秘人 | 守护无知大众，封印禁忌知识 | 主角阵营（纯克苏鲁） |
| **旧日眷族** | 旧日支配者的仆从种族（深潜者、米·戈、食尸鬼） | 服侍旧主、繁衍、扩张 | 中立威胁 / 战斗对手 |
| **外神/旧日本体** | 沉睡或游荡的宇宙级存在 | 多数漠不关心，少数主动搅动 | 终极背景压顶 |
| **政府秘密机构** | 知情并试图管控的官方组织 | 掩盖真相、控制/利用超凡力量 | 亦敌亦友 / 灰色盟友 |
| **无知大众** | 对真相一无所知的普通社会 | 维持正常生活（无知即保护） | 主角要守护的对象 / 拖累 |

### 冲突引擎

| 冲突引擎 | 内容 | 驱动的故事 |
|---|---|---|
| **秩序 vs 混沌（不可知）** | 调查员/机构试图维系现实秩序，教团/眷族/外神不断撕裂现实 | 调查、封印、阻止仪式 |
| **禁忌知识争夺** | 不同势力争夺古卷、神器、真名 | 寻宝、解谜、背叛 |

## 世界规则 / 宇宙法则

### 1. 理智法则（SAN）
- **理智是有限资源**：扣减基本不可逆恢复。
- **理智归零即疯**：临时疯狂 → 永久疯狂。
- **知识与理智负相关**：禁忌学识越高，理智上限越低。

### 2. 知识法则
- **知道越多越危险**：真相本身就是污染。
- **不可名状**：旧日/外神的真实形态无法被人类认知系统处理，直视即疯。
- **真名有力量**：掌握真名可召唤/束缚，但念出即被对方"听见"。

### 3. 注视法则
- **被外神注视即异变**：动用力量、念诵名、踏入领域都引来注视。
- 注视是单向不可逆的。
- 序列流的"聚合定律"是注视法则的变体。

### 4. 生死法则
- **变异代替死亡**：坏结局常是变成怪物/疯子/眷族，比死更绝望。
- **复活/不死的代价**：续命者逐步非人化。
- **死亡不是解脱**：被标记的灵魂死后仍可能被召回。

### 5. 凡人边界（核心基调约束）
- **凡人绝对渺小**：面对 L4/L5 几乎没有胜算，只能逃避、延缓、封印。
- **越级几乎不可能**：主角的"胜利"应是"暂时阻止仪式/逃出生天"，而非"打败神"。
- 序列流可放宽：允许主角晋升至能与眷族抗衡，但仍不应正面击败外神。
- **这条规则是本宇宙的灵魂：破坏它，故事就退化成普通奇幻。**

## 世界地图

### 1. 地图骨架（单一现实平面 + 叠加的隐层）

| 层 | 性质 | 典型表现 |
|---|---|---|
| **表层（现实）** | 现代或近代人类社会，秩序井然，大众无知 | 都市、港口、大学、图书馆 |
| **暗层（隐世界）** | 现实之下的另一面，物理/时间/空间规则扭曲 | 拉莱耶、幻梦境、海底古城、镜中世界 |
| **梦境地** | 意识共享的梦境层面 | 幻梦境（Dreamlands）、集体噩梦 |

### 2. 区域原型
- **沉睡之地**：旧日沉睡的远古遗迹。
- **禁书与知识中心**：大学、私人图书馆。
- **教团据点**：偏僻村落、废弃港口、地下神庙。
- **机构总部**：城市中的秘密办事处。
- **扭曲地带**：现实与暗层交叠的区域。

### 3. 移动通道与成本

| 通道 | 方式 | 成本/风险 |
|---|---|---|
| **仪式** | 召唤/打开传送门 | 失败即引怪/疯；欠下因果 |
| **梦境** | 入梦进入幻梦境 | 肉身留于现实，梦死即真死 |
| **古老遗迹** | 物理进入沉睡之地 | 一路怪物与理智检定 |
| **真名/符文** | 念诵特定真名 | 被对应存在"听见"并注视 |

## 裁切指引

### 1. 纯克苏鲁 vs 序列流：先做这个选择

| 维度 | 纯克苏鲁（洛夫克拉夫特式） | 序列流（诡秘流变体） |
|---|---|---|
| **基调** | 绝望、渺小、不可知 | 有希望、可成长、理性化 |
| **力量体系** | 禁忌知识 + 仪式 | 序列魔药途径 |
| **主角弧** | 调查员，越查越疯 | 序列者，从底层爬升 |
| **恐怖浓度** | 高，真相即毁灭 | 中低，恐怖作氛围 |
| **凡人边界** | 极严，不可越级 | 放宽 |
| **适合篇幅** | 短/中篇 | 长篇网文 |

### 2. 恐怖浓度调节
- **高浓度**：理智不可逆、结局必疯/死、外神登场。
- **中浓度**：理智可部分恢复、主角能险胜眷族。
- **低浓度（不推荐）**：理智可随意恢复、主角正面击败旧日——已不是克苏鲁宇宙。

### 3. 替换皮相
- "外神/旧日" → 自创神名（如"渊主""群星之母"）
- "序列/途径" → 自创体系名（如"阶梯""道途""刻印"）
- "理智/SAN" → 自创度量（如"清明""神志""锚定值"）
- "拉莱耶/幻梦境" → 自创地名

### 4. 避免去恐怖化（守住宇宙灵魂）
- [ ] 主角正面击败外神/旧日（应改为阻止、封印、逃避）
- [ ] 理智可廉价恢复
- [ ] 禁忌知识只增力不致疯
- [ ] 外神被拟人化成有计划、可谈判的反派
- [ ] 变异可逆
- [ ] 凡人凭借意志/友情越级战胜眷族

守住其中至少 4 条，宇宙恐怖的灵魂才在。

## 启发式推导

1. **主角的"无知保护"何时被打破？** 第一次接触禁忌知识后，他还能回到正常生活吗？
2. **本书的"绝望天花板"在哪一层？** L3 眷族 / L4 旧日 / L5 外神？决定结局是"险胜""逃亡"还是"疯狂"。
3. **理智代价如何兑现？** 永久 debuff / 可控风险 / 会被克服（去恐怖化警告）？
4. **禁忌知识在本书是"奖励"还是"诅咒"？** 若主角越知越强且无代价，需重新审视宇宙归属。
5. **"被注视"的后果如何贯穿全书？** 一次性事件还是持续追猎暗线？

## 附：与本模板库其他宇宙的边界
- 与**神话宇宙**的区别：神话宇宙力量来自血脉/神职/修炼，有秩序与善恶；本宇宙力量来自污染与认知，无善恶只有冷漠。混用会把克苏鲁"拟人化"。
- 序列流变体可视为本宇宙与"修真/升级流"的杂交，但**晋升代价必须是失控/异变**，否则失去本宇宙归属。
