# 武侠/江湖宇宙（参考：《天龙八部》《雪中悍刀行》《笑傲江湖》《射雕三部曲》《鹿鼎记》）

> **宇宙定位**：力量源于武学修炼与内力、人有肉身上限、以江湖恩怨信义为运行法则的低魔武侠宇宙。
> **宇宙法则**：力量来自武学修炼与内力，人不可能真飞天遁地（夸张武学有度），江湖以「恩怨、信义、报复」为底层运行法则，强者为尊但侠义制衡暴力；死亡有分量、不可轻易复活。

## 力量体系

### 力量来源

| 来源 | 性质 | 获得方式 | 典型表现 | 代价/风险 |
|------|------|----------|----------|-----------|
| **内功（内力/真气）** | 由内而外，修炼经脉真气 | 打坐吐纳、心法秘籍、机缘贯通任督 | 内力深厚者掌风可碎碑 | 走火入魔、经脉寸断 |
| **外功（外家/招式）** | 由外而内，打熬筋骨 | 师传招式、苦练拳脚兵器 | 拳可裂石、刀剑精绝 | 身负暗伤、寿元损耗 |
| **神兵利器** | 外物加持 | 传承、寻得、铸造、夺取 | 削铁如泥、自带煞气 | 引祸招夺、依赖成瘾 |
| **秘籍/绝学** | 体系性的高阶武学 | 偷学、师传、藏经阁、崖洞遗刻 | 同境界下压制普通武学 | 残缺致歧路、强练致伤 |
| **丹药/外物** | 速成或突破的辅助 | 名医炼制、深山奇草 | 短时暴涨内力、续命疗伤 | 药力反噬、依赖成瘾 |

> 设计原则：内功决定上限与续航，外功决定招式杀力，神兵提供越级筹码，秘籍/丹药是稀有加速器。

### 力量分级（5 层，强调肉身上限）

| 分层 | 江湖位阶 | 描述 | 上限锚点（写实武侠） |
|------|----------|------|----------------------|
| **第一层 · 三流** | 三流好手 | 会基本拳脚兵器 | 能敌数名兵卒，破砖裂木 |
| **第二层 · 二流** | 二流高手 | 一门武学小成 | 可护一方、敌数十人 |
| **第三层 · 一流** | 一流高手 | 武学精湛、江湖有名 | 飞檐走壁、内力外放伤人于数丈 |
| **第四层 · 绝顶** | 绝顶高手 | 开宗立派级 | 摘叶飞花可伤人、百人难近 |
| **第五层 · 宗师 / 陆地神仙** | 宗师 / 陆地神仙 | 武学化境，凡人之巅 | 接近"人"之极限——但仍不能真飞、不能长生 |

> 高武向（如《雪中》式）可把第五层细分为「金刚 / 指玄 / 天象 / 陆地神仙」四境，但务必守住「仍属人身极限」这一边界，否则滑入仙侠。

### 获得代价（力量的暗面）
- **苦修**：数十年寒暑不辍。
- **走火入魔**：强练高阶内功、心境不配境界，轻则疯癫残废。
- **寿元/伤势**：外家硬功透支肉身，年老即衰是铁律。
- **心魔/执念**：杀孽过重、恩怨缠身会反噬修为。
- **恩怨牵扯**：怀璧其罪——神兵、秘籍、盟主之位都自带仇恨值。

## 势力格局

### 势力原型（六原型适配）

| 原型 | 江湖定位 | 武学特征 | 与他方关系 |
|------|----------|----------|------------|
| **名门正派** | 自居武林正统 | 体系完备、传承久远 | 倡「正邪之分」，与魔教死斗 |
| **魔教 / 邪派** | 行事不拘常理 | 武学阴狠奇诡、速成易强 | 与正派结构性对立 |
| **朝廷 / 官府** | 王法与军力 | 军阵、人数、火器/弓弩 | 与江湖若即若离；碾压性兵力是终极制衡 |
| **帮会** | 以行业/地域为纽带 | 实用、群战 | 控制水陆商路与情报 |
| **世家 / 望族** | 以血脉传承武学 | 家传绝学、底蕴深厚 | 与门派联姻或争霸 |
| **散人 / 平民** | 无门无派的个体 | 杂学、机缘 | 江湖的底色与奇遇主角的出身 |

### 冲突引擎

1. **正魔秩序之争**：名门正派与魔教的结构性对立。
2. **恩怨传承**：「有恩报恩，有仇报仇」，且恩怨可跨代。
3. **资源争夺**：秘籍、神兵、名药、灵脉、传承之地。
4. **盟主之位 / 武林秩序**：武林盟主象征号召力与合法性。

## 世界规则 / 宇宙法则

### 肉身法则（人有上限，不能真飞）
- 人始终是人：会饿、会累、会老、会病、会死。
- 「轻功」是借力、提气、缩地的夸张化人体机能，不是飞行。
- 重伤会留根：年老体衰是铁律。

### 内力法则（走火入魔）
- 内力修为与心境、经脉、体质绑定，强练高阶心法会走火入魔。
- 内力有属性相克（阴/阳、寒/热、刚/柔）。
- 内力耗尽后需打坐恢复。

### 江湖法则（信义 / 恩怨 / 报复）
- **信义第一**：一诺千金。
- **恩怨分明**：有恩必报、有仇必雪。
- **江湖规矩高于王法（在江湖内部）**。
- **强者为尊，但以德服人**。
- **拜师如父、同门如手足**。

### 生死（难复活，武侠死亡有分量）
- 武侠宇宙**不可复活**。
- 死亡带来连锁：仇恨、传承断裂、势力洗牌、遗孤复仇。

### 武凡边界（凡人能否学武）
- 凡人**可以**学武，门槛在外家基本功与资质，不需要超自然天赋。这是武侠与仙侠的根本分野。
- 但能登顶者极少：需资质 + 名师 + 秘籍 + 苦修 + 机缘 + 心境六者兼备。
- 上限守恒：无论多努力，绝大多数人止步二三流。

## 世界地图

### 地图骨架（江湖大地 · 单一平面）

- **中原 / 腹地**：名门正派、世家、朝廷中枢所在。
- **边陲 / 塞外 / 南疆**：异域武学、魔教老巢、隐世高人。
- **名山 / 古洞 / 藏经地**：门派祖庭与遗刻秘籍。
- **水陆要冲 / 城镇 / 镖路**：帮会与商旅网络。
- **庙堂（京师 / 边镇）**：朝廷势力节点。

### 移动通道与成本

| 通道 | 方式 | 速度 | 成本/限制 |
|------|------|------|-----------|
| **轻功** | 个人武学提气纵跃 | 极快（短途） | 耗内力、不可长途持续 |
| **驿道 / 官道** | 车马步行 | 中等 | 易被官府/仇家设伏 |
| **水路** | 舟船、漕运 | 中等 | 受帮会控制、有渡口关卡 |
| **商路 / 暗道** | 私路、地道 | 不定 | 需人脉/银两 |

## 裁切指引

### 法则强度：写实武侠 vs 高武

| 维度 | 写实武侠 | 高武（如《雪中》） |
|------|----------|----------------------------|
| 力量上限 | 绝顶为顶，宗师罕见 | 可有「陆地神仙」级，细分四境 |
| 飞行 | 绝不飞，轻功只是纵跃 | 可「踏空借力」短时滞空 |
| 内力表现 | 内力外放数丈为极 | 罡气护体、剑气及远 |
| 复活 | 严格禁止 | 仍禁止，但可放宽「假死/神医续命」 |

> **建议默认写实偏中**，保证武侠味道不滑入仙侠。

> **红线**：无论写实或高武，**不可真飞、不可长生、不可复活、不可无代价速成**。越线即变宇宙类型。

### 主线轴：庙堂 vs 江湖
- **江湖主线**：恩怨、夺宝、盟主、正魔之争。
- **庙堂主线**：朝廷收编/利用江湖、世子涉足武林。
- 两者可并存。

### 替换皮相（避免真实朝代名）
- 用架空王朝（虚构国号、都城、年号、帝王谱系）。
- 涉及真实地名时调用 `compliance-place-guard` 包。
- 允许「少林式」「武当式」「丐帮式」的通用原型，但建议重命名门派。

### 避免武学通货膨胀（设定保值）
1. **天花板锁死**：明确全书最高境界，设定"全天下不超过 N 人"。
2. **代价对等**：每一次越级都要付代价。
3. **克制链成立**：毒、暗算、群殴、地形都能让弱胜强。
4. **秘籍/神兵稀缺**：高阶资源数量恒定、不可量产。
5. **衰老与传承**：老一辈会老会退。
6. **分阶段揭示**：前期一流即天花板，后期才显绝顶。

## 启发式推导

1. **力量上限定在哪？** 全天下最高境界是什么、全天下有几个人到？
2. **谁是结构性对立的两极？** 正派 vs 魔教、江湖 vs 朝廷、世家 vs 门派？
3. **主角的"力量—代价"契约是什么？** 他靠什么登顶？每一份力量付什么代价？
4. **江湖与庙堂的距离有多远？** 朝廷是背景板、终极 boss、还是博弈棋手？
5. **哪一条"江湖法则"会被主角挑战或捍卫？** 信义、恩怨、还是「强者为尊」？主角的态度往往就是全书主题轴。
