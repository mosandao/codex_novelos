# 无限流/多元宇宙（参考：《无限恐怖》《轮回乐园》《惊悚乐园》《王牌进化》《诸天尽头》）

> **宇宙定位**：一个跨宇宙的"元枢纽"——主神空间/轮回乐园/系统把来自主宇宙（正常现实）的轮回者投放到多个规则各异的副本世界（副本本身可以是科幻/玄幻/恐怖等任意派生宇宙），以"副本生死—积分兑换—权限攀升"的闭环驱动成长，主神/系统是终极仲裁者。
> **宇宙法则**：力量来自跨副本的积分兑换与主神/系统权限；每个副本内部运行各自派生宇宙的法则，但**副本法则不可违，主神/系统法则凌驾一切**；副本死亡即真死亡（除非付出极高代价复活）。它是"包含"其他宇宙的元设定。

> **嵌套说明（与 framework 及其他 clusters 的关系）**：本宇宙是 NovelOS 宇宙库中的**唯一"容器型"派生宇宙**——它的副本世界直接复用其他设定簇作为内容。
> - **framework 引用**：主宇宙（轮回者的原乡，无超自然）是回归休整锚点；副本来自**派生宇宙**，每个副本继承该派生宇宙的"宇宙法则"。本宇宙的元法则（兑换/抹杀/传送）凌驾于单个副本法则之上。
> - **clusters 引用**：开副本时调用 `cthulhu.md`（恐怖副本）、`xianxia.md`/`xuanhuan.md`（玄幻副本）、`interstellar.md`/`cyberpunk.md`（科幻副本）、`scifi.md`、`apocalypse.md`、`myth.md` 等。本文件管"世界怎么设定"，`scenario-atlas` 的 `infinite.md` 管"剧情桥段怎么消费"。

## 力量体系

无限流的力量体系是**跨体系嫁接型**：力量来自"在副本里赚到积分 → 在主神空间兑换任意体系的能力 → 带回下一个副本使用"。

### 一、力量的六大来源

| 来源 | 本质 | 典型表现 |
|---|---|---|
| **积分兑换（属性/技能）** | 用奖励点数直接买六维属性和技能 | 最稳定的成长底座 |
| **血统强化** | 兑换某体系血脉（血族/基因/神族/魔族） | 高投入高回报 |
| **副本自取（硬核模式）** | 主神**不**提供兑换，能力只能从副本内抢/学/偷 | 自由度最高、最"硬" |
| **装备/道具** | 带出副本的神兵、科技造物、一次性道具 | 可跨副本携带，但有耐久/次数限制 |
| **伙伴/召唤物** | 收服副本 BOSS、原著角色当队友 | 战力叠加 + 情感羁绊 |
| **主神/系统权限** | 主神或系统赋予的"开挂级"权能 | 终极力量，要对抗或继承主神才能获得 |

> **可兑换 vs 不可兑换（关键分流）**：主神是否提供兑换大厅是根本分叉。

### 二、力量分级（通用五层骨架）

| 层级 | 定位 | 典型表现 |
|---|---|---|
| **L0 · 新人** | 刚被拉入、无强化 | 副本里的炮灰，存活率极低 |
| **L1 · 老手/正式轮回者** | 活过 2~3 场，有初级血统/技能 | 单人通关 D~C 级副本 |
| **L2 · 队长/精英** | 拥有团队权限与中级血统 | 带 7~20 人团队进团本 |
| **L3 · 轮回王/强者** | 跨副本积累极深 | 排行榜常客 |
| **L4 · 主神/系统级** | 接触或继承主神/系统终极权限 | 反抗/取代主神 |

> **L4 不要第一卷登场**，否则压扁所有中层力量。

### 三、获得代价

| 代价类型 | 内容 | 典型 |
|---|---|---|
| **副本生死** | 力量的每一次进阶都要拿命换 | 主线任务失败 = 抹杀 |
| **积分/资源** | 高级血统吃天量积分 | 兑换通货膨胀 |
| **精神/人性** | 血统强化侵蚀心智 | 基因锁/精神污染 |
| **被主神操控** | 力量本质是主神"借"给你的 | 主神空间的"养蛊" |

## 势力格局

无限流的势力格局是**"枢纽—轮回者—副本原生"三层嵌套**。

### 一、势力的六种原型（适配）

| 原型 | 核心特征 | 在故事里的功能 |
|---|---|---|
| **主神/系统**（当权者） | 终极仲裁者 | 秩序代表，常是被推翻/逃离的对象 |
| **轮回者团队**（半神/英雄） | 多人协作的常驻战斗单位 | 主角最常见的归属阵营 |
| **反派轮回者/敌队**（被放逐者） | 以猎杀队友/敌队为手段 | 反派主力、打脸爽点来源 |
| **副本原生势力** | 单个副本世界内的原著阵营 | 单副本内的对手/盟友，副本结束即退场 |
| **新人**（凡人社群） | 刚被拉入、被当炮灰 | 筛选/淘汰对象、人性试金石 |
| **高维存在/主神背后的存在**（创世遗族） | 比主神更高层的存在 | 终极威胁/背景板，第三卷后才登场 |

### 二、势力间的冲突引擎

| 冲突引擎 | 内容 | 代表 |
|---|---|---|
| **积分/资源争夺** | 零和博弈下队友/敌队都是资源竞争者 | 坑杀新人夺积分 |
| **秩序（主神规则）vs 失序** | 主神维持轮回秩序 vs 轮回者觉醒反抗 | 反主神流 |
| **团队背叛/人性博弈** | 信任在生死压力下崩塌 | 团队内斗 |
| **流派之争（独行 vs 组队）** | 制度性对立 | 独行狩猎者 vs 团队 |

## 世界规则 / 宇宙法则

### 一、副本法则（副本规则不可违）
每个副本是一个独立派生宇宙，轮回者进入后**必须服从副本法则**。副本里没有灵气，你兑换的修真功法就用不出来；副本禁止超凡，你的血统会被压制。

### 二、兑换法则（等价交换）
- 能力价值 = 积分 + 支线剧情等级（D/C/B/A/S 级）。
- **通货膨胀风险**：必须设定平衡机制（难度等级与收益严格挂钩 / 权限壁垒）。
- **带出限制**：从副本带出的物品/能力有限制。

### 三、主神/系统法则（终极权限）
主神/系统拥有**终极权限**：传送、兑换、抹杀、评级。
- **主神的真实身份**是核心长线悬念。
- **反抗可行性**：可推翻 / 不可推翻只能逃离 / 反抗本身就是主神的剧本。

### 四、生死（副本死亡 = 真死亡）
- **副本内死亡即真死亡**。
- **复活机制**（谨慎使用）：必须设极高代价。

### 五、跨宇宙仲裁（不同副本宇宙法则冲突时谁说了算）

| 仲裁层级 | 优先级 | 说明 |
|---|---|---|
| **副本法则**（局部最高） | 单副本内绝对优先 | 该派生宇宙的法则说了算 |
| **主神/系统法则**（全局最高） | 跨副本最高 | 传送/兑换/抹杀/评级凌驾于任何副本法则 |
| **framework 宇宙法则**（元最高） | 主宇宙 + 派生宇宙的总框架 | 主神被掀桌时，仲裁权上交 framework |

> **裁定口诀**：副本内看副本法则，副本间看主神法则，主神被掀桌了看 framework。

### 二、移动通道与成本

| 通道类型 | 通行成本 | 代表 |
|---|---|---|
| **主神传送（强制任务）** | 不可拒绝 + 时限 + 抹杀惩罚 | 所有无限流通用 |
| **主神传送（自愿/休整）** | 消耗积分/次数 | 主动挑战高难副本 |
| **回归现实** | 限定次数/时长 | 回归休整桥段 |
| **副本内移动** | 服从副本法则 | 副本剧情内 |

## 裁切指引

### 一、副本类型选择（可调用其他宇宙簇做副本）

| 副本调性 | 调用 clusters | 适合全书基调 |
|---|---|---|
| 恐怖无限 | `cthulhu.md` | 暗黑、压抑、硬核生存 |
| 综漫/影视无限 | IP 知识差 | 猎奇、截胡原著机缘 |
| 玄幻/修仙副本为主 | `xianxia.md` / `xuanhuan.md` | 战力膨胀快、升级爽 |
| 科幻副本为主 | `interstellar.md` / `cyberpunk.md` | 理性、智斗、科技碾压 |
| 基建/经营副本 | `isekai-build` (scenario-atlas) | 经营向、慢热 |
| 混合（推荐长篇） | 每 2~3 个副本轮换一种簇 | 保持新鲜感 |

### 二、团队 vs 单人
- **组队流**：以队为单位，强调协作与背叛。
- **单人/独行流**：主角独行，靠个人战力碾压。
- **混合**：第二卷中段让主角做一次重大选择。

### 三、替换皮相
- "主神空间" → 你的枢纽名（轮回乐园 / 万界系统 / 深渊试炼场 / 一本书 / 一个 APP / 一群投票的观众）。
- "积分" → 你的货币。
- "副本" → 你的副本名。

### 四、避免兑换通货膨胀
1. **难度—收益严格挂钩**。
2. **权限壁垒**。
3. **不可兑换流（硬核模式）**。

### 五、跨宇宙法则冲突的仲裁原则
写副本时若出现法则冲突，按 framework §3.3 的优先级裁定。

## 启发式推导

1. **主神是什么？** 如果主神是"主角的未来自我"、"一群投票的观众"、"一个 APP"，全书会怎么变？
2. **副本来源是什么？** 如果副本全是原创（非知名 IP），"原著知识差"金手指失效，需要什么替代金手指？
3. **经济闭环怎么闭？** 如果是"不可兑换"硬核模式，轮回者怎么变强？
4. **死亡分量够不够重？** 副本死亡是否可逆？复活代价大到什么程度？
5. **嵌套边界在哪？** 本书与快穿流的边界？与纯"诸天流"的边界？副本里能不能再嵌套副本？

> **使用提示**：本文件管"世界怎么设定"。剧情桥段怎么消费请配套查阅 `scenario-atlas` 的 `infinite.md`（桥段图集）。两者互补。
