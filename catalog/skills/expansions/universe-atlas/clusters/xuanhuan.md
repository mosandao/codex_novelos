# 玄幻宇宙（参考：《斗破苍穹》《遮天》《武动乾坤》《大主宰》）

> **宇宙定位**：东方玄幻大陆，力量源于血脉觉醒、功法武技与天地异宝，主角自废柴/被弃者沿境界攀升至大陆巅峰。
> **宇宙法则**：力量源于血脉、功法与天地异宝，修炼突破伴随天材地宝消耗与境界反噬，越强越稀缺、越级必有代价。

## 力量体系

### 一、力量的四大来源

| 来源 | 本质 | 典型表现 | 在故事里的功能 |
|---|---|---|---|
| **血脉** | 力量来自出身，血脉越古老/越纯越强 | 神兽血脉、上古家族血脉、异族血脉；觉醒分阶段 | 身世之谜主线、命运改写引擎、越级反杀的合理化 |
| **功法/武技** | 通过修炼功法与武技锤炼力量，可越级发挥 | 斗技、玄阶/地阶/天阶功法、自创武学、武意/斗意 | 成长曲线主轴、独门底牌、悟道高潮 |
| **天地异宝** | 天地孕育的稀有力量实体，数量有限、不可再生 | 异火、神雷、玄冰、灵物、神兵；有排名榜 | 收集养成暗线、实力质变节点、争夺冲突源 |
| **天地灵气** | 弥漫天地的能量，修炼者吸收、积蓄、外放 | 斗气/元力/灵力/真元；浓度随地而异 | 修炼门槛、地域强弱逻辑、资源稀缺性基底 |

### 裁切建议
- **血脉流**：境界按"血脉纯度/觉醒程度"分，主角往往是末代/混血，越级靠血脉压制。
- **功法武技流**：境界按"修炼进度"分，主角靠独门功法/武意越级。
- **异宝流**：境界与异宝收服挂钩，主角收集异火/神物逐级质变。
- **混合要小心**：血脉+功法混用最常见，但必须设"凭什么血脉差的能越级"。

### 二、力量分级（通用九层骨架）

| 层级 | 定位 | 斗气链参考 | 元力链参考 | 故事功能 |
|---|---|---|---|---|
| **L0 · 凡** | 普通人 | 斗之气 | 锻体境 | 背景板，主角起点 |
| **L1 · 入门** | 初窥门径 | 斗者 | 元动境 | 家族/小镇级强者 |
| **L2 · 初成** | 力量成型 | 斗师 | 聚气境 | 城池级高手 |
| **L3 · 化形** | 力量可凝形 | 斗灵 | 灵动境 | 一方小势力骨干 |
| **L4 · 凌空** | 斗气化翼 | 斗王 | 元丹境 | 区域级强者，换地图门槛 |
| **L5 · 称雄** | 一方霸主 | 斗皇 | 造化境 | 帝国/学院级顶尖 |
| **L6 · 宗师** | 触及法则 | 斗宗 | 造气境 | 大陆一流势力之主 |
| **L7 · 巅峰** | 借法则之力 | 斗尊/半圣 | 转轮境 | 中州/核心域顶尖 |
| **L8 · 极道** | 言出法随 | 斗圣/斗帝 | 转生境/圣境 | 终极存在，结局级 |

**裁切建议**：
- 轻量/校园玄幻：只用 L0~L5。
- 标准升级流：L0~L7，L8 只作传说。
- 史诗/群像：L0~L8 全开，但 L8 数量严格受限（个位数）。
- **务必预留空间**：前期最高设定不要超过 L5~L6，否则后期"圣阶多如狗"。

### 三、获得代价（关键约束）

| 代价类型 | 内容 | 典型表现 |
|---|---|---|
| **资源消耗** | 突破需海量天材地宝、灵石、丹药 | 嗑药突破、夺宝、拍卖会 |
| **境界反噬/天劫** | 越级或突破触发天地反噬 | 渡雷劫、异火焚身、法则反噬 |
| **心魔** | 修炼越深心魔越重 | 走火入魔、心境滞涩、心魔劫 |
| **血脉纯度/诅咒** | 血脉越强代价越大 | 血脉觉醒引来追杀、血脉吞噬神智 |

## 势力格局

### 一、势力的六种原型

| 原型 | 核心特征 | 在故事里的功能 |
|---|---|---|
| **超级世家** | 以血脉传承立族，底蕴深厚，嫡庶内斗激烈 | 主角出身地或宿敌，家族倾轧主线 |
| **学院** | 培养同辈精英的舞台，有排名与赛事机制 | 中段舞台，比武打脸与同辈登顶 |
| **宗门** | 师徒传承、功法垄断的修炼组织 | 主角成长平台或敌对势力 |
| **帝国/王朝** | 世俗权力，统辖城池与军队 | 政治博弈背景、征兵与战乱引擎 |
| **远古遗族** | 隐藏的顶级势力，存世极久 | 主角身世伏笔、终极威胁或盟友 |
| **散修/平民** | 无背景的修炼者与凡人 | 被争夺的资源、主角起点或同情锚点 |

### 二、势力间的冲突引擎

| 冲突引擎 | 内容 | 代表倾向 |
|---|---|---|
| **血脉/纯度之争** | 谁的血统更纯、谁有资格继位或掌族 | 家族嫡庶内斗、古族排座次 |
| **资源/异宝争夺** | 天材地宝、异火、传承稀缺 | 拍卖会、遗迹争夺、杀人夺宝 |
| **家族/势力更替** | 新势力崛起挑战旧秩序 | 散修崛起、宗门颠覆、帝国兴亡 |
| **秩序 vs 远古混沌** | 当下大陆秩序 vs 远古遗族/封印凶物回归 | 远古封印松动、异族入侵、禁区现世 |

## 世界规则 / 宇宙法则

### 一、修炼法则
- **境界不可越**：必须逐级突破；越级必赖异宝/顿悟/血脉爆发，且付出代价。
- **突破必历劫/反噬**：L6 以上突破触发天地感应。
- **功法分阶**：功法/武技分等级，高阶需高境界或特殊资质才能修。

### 二、天地法则
- **灵气/异宝稀缺**：核心区浓、边缘区淡；异宝不可再生。
- **强者寿元更长**：境界越高寿命越长，远古强者可能尚存。
- **天材地宝有主**：灵脉、异火多被势力占据。

### 三、因果/心魔规则
- **业力清算**：杀戮/夺宝积累业，终将招致反噬或仇家。
- **心魔**：修炼越深，执念/恐惧/欲念凝聚成心魔。
- **血脉诅咒**：强大血脉往往伴随代价。

### 四、凡修边界
| 模式 | 说明 | 影响 |
|---|---|---|
| **凡可证道** | 凡人靠修炼/异宝/顿悟一路登顶，无血脉天花板 | 经典网文升级流 |
| **血脉天花板** | 无血脉者终有上限 | 主角需靠血脉觉醒/异宝打破天花板 |
| **越级需代价** | 凡人伤神级存在必须付出惨重代价 | 悲壮色彩，提升牺牲分量 |

## 世界地图

### 一、两种地图骨架

#### 1. 中心辐射型（最常见）

```
              [远古禁区 / 封印之地]
        [北域][东玄][西域][南荒]      ← 偏远地域，主角起步点
            [ 中 州 / 中央 ]           ← 核心，强者云集，主角终点
        [乱魔海][妖域][百朝]
              [凡人城邦 / 散修地]
```

- **优点**：天然有"换地图=升级"的推进逻辑。

#### 2. 横向并置型（多大陆/多位面）

```
[大陆 A]      [大陆 B]      [大陆 C]      [上位面/万界]
主角出身       同级大陆       敌对大陆       续篇/飞升地
```

- **注意**：大陆数控制在 3~5 个；每大陆必须有**独有资源或规则**。

### 二、移动通道与成本

| 通道类型 | 通行成本 | 典型表现 |
|---|---|---|
| **步行/骑兽** | 时间 + 沿途魔兽/强盗 | 低阶主角的主要移动方式 |
| **飞行** | 需达 L4 境界，耗力 | 中阶主角的移动方式 |
| **传送阵** | 灵石/费用 + 固定节点 + 可被封锁 | 高效但受势力控制 |
| **空间挪移** | 需 L6 以上境界 | 顶级强者的机动手段 |

## 裁切指引

### 1. 境界层数选择（轻量 vs 史诗）
- 轻量（100~300 万字）：L0~L5（6 层）。
- 标准（300~500 万字）：L0~L7（8 层）。
- 史诗（500 万字+）：L0~L8 全开，但严格控制 L8 数量。

**铁律**：前期登场的最高设定不要超过目标层数的 60%~70%。

### 2. 血脉主线 vs 功法主线
| 主线 | 主角越级靠什么 | 风险 |
|---|---|---|
| **血脉** | 血脉觉醒/压制 | 易陷"血统决定论" |
| **功法** | 独门功法/武意 | 易陷"功法万能" |
| **异宝** | 收服异火/神物 | 易陷"吞噬单一化" |

### 3. 替换皮相
- 地名/力量/异宝/境界名全部替换为自创名，但保留九层结构。

### 4. 避免境界通货膨胀
- **质变节点**：每境界设质的差异（飞行/凝形/御法/挪移）。
- **数量约束**：L6 以上势力数量有限。
- **资源稀缺**：突破资源不可再生。
- **代价递增**：越级代价随境界递增。

### 自检清单
- [ ] 境界层数已定，前期上限 ≤ 目标 70%
- [ ] 主线（血脉/功法/异宝）已选 1 种为主
- [ ] 越级条件与代价已定义
- [ ] 势力 2~4 个，至少一对结构性冲突
- [ ] 地图骨架选定一种，区域 ≤ 5
- [ ] 名词已替换

## 启发式推导

1. **如果本书的核心引擎是"智谋博弈"而非"血脉碾压"**，力量体系会怎么变？境界差距该被放大还是淡化？
2. **如果本书要把"血脉觉醒"从第一卷挪到第三卷**，前期靠什么支撑读者耐心？开篇钩子该是什么？
3. **如果本书的世界规则是"天道即反派"（天劫/法则是有意的筛选）**，修炼会从"自我提升"变成什么？突破高潮的情绪色彩会如何变化？
4. **如果本书核心引擎是"共生而非吞噬"**（异宝/血脉/灵兽有自主意识），收服会从"吞噬强化"变成什么？
5. **如果本书的势力格局重心是"散修/平民 vs 世家垄断"**，学院/宗门会从"主角成长舞台"变成什么？

### 反套路与"烂大街"风险
- **"废柴+退婚+血脉觉醒"**：已成梗。规避：让退婚方有合理苦衷，或主角的"废柴"是主动伪装。
- **境界通货膨胀**：前期上限开到 60%~70%、用质变节点替代数字碾压。
- **天才群像脸谱化**：给宿敌独立成长线与理念冲突。
- **吞噬流单一化**：让奇物有自主意识或使用代价。
- **越级反杀同质化**：让越级付出不可逆代价。
