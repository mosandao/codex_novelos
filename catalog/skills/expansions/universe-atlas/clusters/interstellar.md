# 星际宇宙（参考：《银河英雄传说》《沙丘》《星球大战》《基地》《质量效应》）

> **宇宙定位**：跨星系文明以跃迁技术与星舰舰队串联、以疆域、资源星域与远古传承为角力场的太空歌剧舞台——区别于硬科幻，这里技术服从于史诗与人物，而非物理考据。
> **宇宙法则**：力量来自文明等级（能量与疆域尺度）与星舰 / 跃迁技术，文明冲突以资源星域争夺、文明霸权与传承为核心；个人是文明的细胞，但少数个体（异能者、舰长、遗族）能撬动星系级棋盘。

## 力量体系

### 一、力量的四大来源

| 来源 | 本质 | 代表作 | 典型表现 |
|---|---|---|---|
| **文明科技** | 力量来自文明整体的技术树与产能，个体只是齿轮 | 《基地》（帝国工业力）、《银英传》（舰队产能） | 星舰量产、武器代差、后勤碾压；越级靠技术而非个人 |
| **星舰 / 舰队** | 力量物化为可量化的战争机器，舰队是流动的疆域 | 《银英传》（要塞舰队）、《星战》（死星） | 舰长 / 提督是力量的人格化；一艘旗舰可扭转战役 |
| **异能 / 精神力** | 个体觉醒超常规精神或生理能力，与科技并存或超越科技 | 《星战》（原力）、《沙丘》（姐妹会预知） | 主角金手指来源；可单兵撬动舰队级战局 |
| **远古遗产** | 上一代文明遗留的科技 / 遗迹 / 神器，数量有限、不可再生 | 《质量效应》（质量中继器 / 收割者）、《星战》（古代圣殿） | 战略级资源，谁掌握谁改变规则；常带"代价/诅咒" |

**裁切建议**：
- **文明科技流**：主角是体制内的棋手（提督、总督、科学家），适合权谋与战争史诗。
- **异能流**：主角靠个人崛起对抗舰队，最像网文升级，但需解释"凭什么异能者不怕星舰主炮"。
- **远古遗产流**：主角是考古者 / 被选中者，适合悬疑 + 史诗。
- **混合要小心**：异能与星舰混在一起容易逻辑打架（一个原力使用者凭什么毁灭一支舰队？必须有"代价 / 限制 / 稀缺"设定兜底）。

### 二、力量分级（通用五层骨架）

| 层级 | 定位 | 作用尺度 | 典型对应 |
|---|---|---|---|
| **L1 · 个人级** | 单兵 / 驾驶员 / 异能者 | 一个舱段、一个突击队 | 银英传的单舰王牌、星战的绝地武士、机甲驾驶员 |
| **L2 · 星舰级** | 一艘主力舰或一支分舰队 | 一片星域的局部战区 | 要塞级旗舰、航母战斗群、死星单发 |
| **L3 · 文明级** | 一个完整的星际国家 | 数十至数百星系 | 银河帝国、自由行星同盟、星际联邦 |
| **L4 · 星系级** | 控制整个星区或星系的霸主，卡尔达肖夫 III 型 | 一整个星系 / 星区 | 古代先行者、收割者级文明、戴森云文明 |
| **L5 · 宇宙级** | 能改写物理法则或跨宇宙的存在 | 整个可观测宇宙 | 远古创世文明、收割者的造物主、原力之本 |

**裁切建议**：
- **轻量 / 升级流**（个人向）：只用 L1~L3，主角天花板是"以一舰 / 一异能扭转文明级战局"，L4/L5 是背景传说。
- **战争史诗 / 群像**：L2~L4 为主，主角是舰长或提督。
- **文明兴衰 / 黑暗向**：L3~L5，主角对抗的是收割循环或宇宙级宿命。

### 三、获得代价（关键约束）

| 代价类型 | 内容 | 典型 |
|---|---|---|
| **资源 / 燃料** | 跃迁、星舰、武器都依赖稀缺资源（反物质、香料、跃迁晶体） | 《沙丘》（香料垄断跃迁）、《质量效应》（元素零） |
| **科技树 / 产能** | 力量需要整套工业链支撑，落后即挨打 | 《基地》（帝国工业衰退）、《银英传》（要塞维修周期） |
| **文明代价** | 越级使用遗产或异能，会透支文明寿命、引来收割、触发黑暗森林 | 《质量效应》（解锁遗产引来收割者）、《三体》（暴露坐标） |

**开书必答**：①主力量的代价是哪一类？②代价是否可累积 / 可转嫁？③L4/L5 层是否存在"越级必遭反噬"的硬规则？

## 势力格局

### 一、势力的六种原型

| 原型 | 核心特征 | 典型代表 | 在故事里的功能 |
|---|---|---|---|
| **星际帝国** | 中央集权的庞大疆域，常带贵族 / 皇权结构 | 《银英传》（银河帝国）、《沙丘》（帝国） | 秩序的代表，可正可邪；常是被推翻或被复兴的对象 |
| **自由联盟 / 共和国** | 多星系联合、议会制、多元但低效 | 《银英传》（自由行星同盟）、《质量效应》（神堡议会） | 主角的母邦或理想阵营 |
| **远古遗族 / 先行者** | 上一代文明的残存者或造物，技术远超当代 | 《质量效应》（收割者 / 普洛仙人） | 终极威胁 / 真相来源 / 压迫感；一醒就是结局级事件 |
| **异星种族** | 与人类生理、思维、价值观根本不同 | 《质量效应》（突锐 / 萨拉人） | 中立变量、合纵连横对象、文化冲突来源 |
| **星际海盗 / 雇佣兵** | 灰色地带的武装力量，逐利、机动 | 《星战》（汉·索罗早期） | 主角的灰色盟友 / 反派打手 / 边缘视角担当 |
| **殖民平民 / 边疆星域** | 文明边缘的开拓者、矿工、难民 | 《沙丘》（弗里曼人）、《基地》（端点星） | 被争夺的资源与人口、信仰 / 动员来源、主角的出身 |

### 二、势力间的冲突引擎

| 冲突引擎 | 内容 | 代表 |
|---|---|---|
| **文明霸权** | 谁主导银河秩序、谁制定跃迁与贸易规则 | 《沙丘》（宇航公会垄断） |
| **秩序 vs 混沌** | 帝国维持秩序 vs 边疆 / 海盗 / 异族试图瓦解 | 《银英传》（帝国平叛） |
| **资源星域争夺** | 香料、跃迁晶体、宜居星、矿星的归属 | 《沙丘》（厄拉科斯） |
| **血脉 / 传承** | 皇位继承、贵族世系、纯种 vs 混血的合法性 | 《沙丘》（厄崔迪 vs 哈克南） |
| **黑暗森林 / 收割循环** | 文明间因猜疑而先发制人，或被更高文明定期收割 | 《三体》、《质量效应》 |

**开书必选**：至少锁定**一种**主冲突引擎。文明向小说可选 2~3 种叠加。

## 世界规则 / 宇宙法则

### 1. 跃迁规则（FTL 机制与代价）

| 机制 | 速度 | 灵活性 | 是否需基建 | 代表作 |
|---|---|---|---|---|
| **曲速引擎（Warp）** | 较慢 | 高（途中可改航向） | 否（舰载） | 《星际迷航》 |
| **跳跃引擎（Jump）** | 快 | 低（一旦启动目的地固定） | 否（舰载） | 《银英传》 |
| **星门 / 跃迁点（Gate）** | 极快 / 瞬时 | 固定路线 | 是（门网） | 《质量效应》（质量中继器） |
| **超空间 / 折叠（Hyperspace）** | 可变 | 中 | 部分需 | 《星球大战》、《沙丘》 |

**跃迁的代价（必须设一种）**：燃料稀缺 / 导航垄断 / 跃迁风险 / 门网依赖。

**开书必答**：本书 FTL 是哪一种？它的代价是什么？这直接决定"为什么不能随便逃 / 随便支援 / 随便增援"。

### 2. 文明等级法则（卡尔达肖夫等）

| 等级 | 能量尺度 | 文明形态 |
|---|---|---|
| **I 型以下** | 行星级 | 母星文明、早期殖民 |
| **I 型** | 恒星-行星能量 | 多星系殖民文明 |
| **II 型** | 恒星级（戴森云） | 控制单星系能源 |
| **III 型** | 星系级 | 控制整个星系 |
| **IV 型+** | 宇宙 / 多宇宙级 | 改写法则的神级文明 |

**裁切要点**：当代文明通常在 I~II 型，III 型以上是"遗迹里的传说"。

### 3. 外星接触法则

| 模式 | 内容 | 影响 |
|---|---|---|
| **可沟通的异族** | 价值观不同但能谈判、贸易 | 外交线丰富，适合政治权谋 |
| **不可沟通的异族** | 思维根本不同，无法外交 | 灭绝战基调，无妥协余地 |
| **沉默的观测者** | 高等异族旁观不介入 | 提供压迫感与悬念 |
| **无外星 / 人为主** | 银河几乎只有人类 | 焦点回到人类内部斗争 |

### 4. 因果（星际战争因果）

| 模式 | 内容 | 代表 |
|---|---|---|
| **霸权周期** | 文明必经兴衰 | 《基地》（心理史学预言） |
| **收割循环** | 文明发展到阈值即被更高存在定期收割 | 《质量效应》 |
| **黑暗森林** | 暴露即被先发打击 | 《三体》 |

### 5. 个人与文明的边界

| 模式 | 说明 | 影响 |
|---|---|---|
| **个人无效论** | 个人只是历史尘埃 | 史诗苍凉感（基地式），主角是观察者 |
| **天才 / 英雄杠杆** | 极少数个体能扭转文明走向 | 主角金手指合法化（提督、异能者、预言者） |
| **继承 / 血脉特权** | 特定血脉拥有文明级影响力 | 适合王道升级（沙丘式弥赛亚） |

## 世界地图

### 一、两种地图骨架

#### 1. 横向并置型（多星系 / 星域并立）

```
[核心星域]  ──跃迁点──  [边疆星域]  ──星门──  [异族疆域]
   帝国首都               殖民前线               外星文明
```

- **代表**：《银英传》、《质量效应》。
- **适合**：群像、多势力战争、文化冲突。
- **注意**：星区数控制在 3~5 个；每区必须有**独有资源或规则**。

#### 2. 中心辐射型（首都星为核心）

```
            [禁地·先行者遗迹]
        [核心星域][核心星域]
     [首都星 · 帝国心脏]  ← 主角最终目标
        [边疆星域][边疆星域]
            [海盗 / 法外之地]
```

- **代表**：《沙丘》、《基地》。
- **适合**：夺权 / 朝圣 / 复兴叙事、王道升级。

### 二、移动通道与成本

| 通道类型 | 成本 / 限制 | 叙事功能 |
|---|---|---|
| **跃迁点** | 只能点对点，敌方可设伏 | 战略咽喉、伏击战场 |
| **星门** | 建造极贵、可被摧毁 | 控制星门 = 控制星区 |
| **自由跃迁** | 燃料 / 导航 / 风险限制 | 机动性高，适合冒险流与追逃戏 |
| **禁跃区** | 必须亚光速穿越 | 制造孤立与困局 |

## 裁切指引

### 1. 个人向 vs 文明向（最重要的分叉）

| 取向 | 主角定位 | 力量层级 | 代表 |
|---|---|---|---|
| **个人向** | 单兵 / 异能者 / 舰长 | L1~L3 | 《星球大战》、机甲流 |
| **文明向** | 提督 / 总督 / 文明本身 | L2~L4 | 《银英传》、《基地》 |

**判定**：主角是"靠个人崛起"还是"靠文明机器"？不要两头都想占。

### 2. 替换皮相

- "香料" → "跃迁晶体 / 灵能矿 / 反物质源"
- "收割者" → "静默者 / 净化者 / 第零文明"
- "星门" → "虫洞门 / 古道 / 折叠锚点"

### 3. 避免设定过载

- 势力不超过 4 个；地图不超过 5 个星区；FTL 机制只用一种；远古遗族最多登场一次。

## 启发式推导

1. **跃迁机制的核心代价**：如果本书的 FTL 是"人人可自由跃迁"，那么**为什么还有边疆与中心之分**？
2. **异能者与星舰的关系**：如果同时有"个人异能"和"星舰舰队"，**凭什么一个异能者能威胁一支舰队**？
3. **远古遗族的功能定位**：它是"沉睡的终极威胁"（结局级）、"分散的遗产来源"（升级道具）、还是"沉默的观测者"？
4. **文明的"天花板"在哪里**：本书的文明最高能到卡尔达肖夫几型？天花板决定终极张力来源。
5. **个人能否撬动文明**：本书信奉"个人无效论"还是"天才杠杆"？必须给主角一个"合法撬动点"并标明其代价。

### 反套路与"烂大街"风险
- **模板化帝国 vs 反抗军**：让"帝国"并非纯恶（如《银英传》帝国有开明派）。
- **"天选之子 + 远古遗产"**：主角主动争夺遗产而非被动接受，或遗产本身是陷阱。
- **黑暗森林滥用**：需"无法沟通 + 先发优势"两个前提，缺一不可。
- **FTL 自相矛盾**：开书就锁死 FTL 代价，全程不破例。
