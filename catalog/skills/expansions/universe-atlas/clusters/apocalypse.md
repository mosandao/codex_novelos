# 末世/废土宇宙（参考：《末日乐园》《全球进化》《小蘑菇》《辐射》Fallout、《地铁2033》Metro 2033、《疯狂的麦克斯》Mad Max）

> **宇宙定位**：现代文明被灾变（病毒 / 核战 / 陨石 / 异界入侵 / AI 觉醒 / 灵气异变）瞬间摧毁后的派生宇宙，幸存者在废土、变异体、极端环境与人性博弈中求生并重建秩序。
> **宇宙法则**：资源极度稀缺且持续递减，力量来自变异 / 异能 / 旧科技 / 组织 / 基因改造；生存与人性底线是核心张力——力量越强越接近"非人"，保留人性即封顶力量，突破封顶即承担失控风险。

## 力量体系

### 力量来源

| 来源 | 触发条件 | 强度上限 | 核心代价 | 典型承载者 |
|---|---|---|---|---|
| **变异 / 灾变因子** | 感染 / 高剂量暴露于病毒、辐射、异能因子 | 极高 | 失控、丧失人性、被追猎 | 丧尸王、变异兽王、失控进化者 |
| **异能觉醒** | 灾变激活隐性基因 / 灵能潜力 | 中高 | 进化瓶颈、精神负荷 | 异能者（主角常见起点） |
| **旧科技 / 末日遗物** | 挖掘末日前的军火、能源、机械、药品 | 中 | 依赖弹药 / 燃油 / 备件 | 军阀、拾荒者 |
| **组织 / 建制** | 纪律、人数、工事、分工 | 中（集群可极高） | 内耗、官僚、易被斩首 | 大型基地、旧政权残余 |
| **基因改造 / 进化药剂** | 注射药剂 / 植入物 | 中高 | 药剂依赖、排异、不可逆 | 进化者、科技派精英 |
| **系统 / 面板**（可选金手指） | 灾变同步激活系统 | 高（视设定） | 削弱稀缺感，需克制设计 | 主角专用 |

> 设计要点：纯废土倾向"旧科技 + 组织"，异能末世倾向"变异 + 异能"，科幻末世倾向"基因改造 + 旧科技"。

### 力量分级（5 层）

| 层级 | 定位 | 典型表现 | 与人性的关系 |
|---|---|---|---|
| **幸存者** | 普通人 | 靠工具、警惕、组织活下去 | 完全人类 |
| **异能者** | 觉醒初期 | 单体战力超凡 | 基本人类，异能有副作用 |
| **进化者** | 多次升华 | 指挥变异兽群、对抗中型尸潮 | 力量与人性的拉扯期 |
| **变异体** | 脱离人形 | 丧尸王 / 异兽王 | 大多非人，少数保留残识 |
| **灾变源** | 末世本源 | 零号感染体 / 异界裂隙核心 | 全书终极目标与最终反派 |

> 升级路径不是单向：进化者可能"退化"回幸存者（人性回归封顶战力），也可能"越界"成为变异体。

### 获得代价（力量守恒）
- **变异失控**：越强的变异越可能失控。
- **人性侵蚀**：每次进化都消耗一部分"人"。
- **被追猎**：强者引来更高阶威胁、组织征用。
- **资源依赖**：药剂 / 晶核 / 弹药持续消耗，断供即战力断崖。
- **代价可见化原则**：任何力量提升都必须让读者看到代价。

## 势力格局

### 六原型（适配本宇宙）

| 原型 | 核心特征 | 内在矛盾 | 典型剧情功能 |
|---|---|---|---|
| **大型基地** | 秩序重建派 | 官僚 vs 创新、安全 vs 扩张 | 主角的归宿 / 目标 / 对手 |
| **军阀** | 暴力割据 | 暴政激起反抗、继承人内斗 | 中期主反派 |
| **流民帮派** | 失序掠夺派 | 信任脆弱、道德真空 | 开篇冲突源、人性试金石 |
| **变异体群落** | 非人势力 | 进化本能 vs 对人类的本能敌意 | 持续威胁 |
| **旧政权残余** | 握有末日前的科技与情报 | "为了人类"旗号 vs 牺牲少数的冷酷 | 真相持有者、亦敌亦友 |
| **孤立幸存者** | 独行侠 / 小团体 | 信任缺失、孤独 | 主角开局身份 |

### 冲突引擎
- **资源争夺**：水、食物、药品、弹药——稀缺即冲突。
- **秩序 vs 失序**：重建文明规则 vs 弱肉强食。
- **进化 vs 守人**：进化派 vs 守人派，本宇宙独有的意识形态战。
- **领地 / 商路**：据点扩张、商路控制。
- **净化 vs 利用灾变源**：是终结末世，还是驾驭灾变源？

## 世界规则 / 宇宙法则

### 稀缺法则（宇宙第一法则）
- **资源极度稀缺且持续递减**：罐头有保质期、弹药打一发少一发。
- **不可再生性**：末日前工业产能归零，一切工业品都是"吃存量"。
- **货币演变**：旧货币 → 物物交换 → 弹药 / 食盐 / 药品 → 异能晶核 / 能源电池。
- **稀缺递进设计**：早期缺食物水，中期缺弹药药品，后期缺进化资源。

### 变异法则
- **变异条件**：暴露于灾变因子是前提。
- **成功率与失控率**：变异非必然。
- **越强越易失控**：力量与失控概率正相关。

### 辐射 / 污染法则
- **危险带分级**：爆心/疫区（禁地）→ 重污染带 → 缓冲带 → 相对洁净区。
- **防护成本**：防化服、盖革计数器、抗辐射药剂皆为稀缺消耗品。

### 生死（变异 / 感染）
- **感染不可逆阈值**：被咬伤后存在"逆转窗口"，过后不可逆转化。
- **死亡不等于退场**：死者可能迅速转化为新威胁。
- **变异体等级 = 威胁等级**。

### 人异边界（核心张力）
- **保留人性 = 力量封顶**：拒绝越界的进化者战力有上限，但保留共情、记忆。
- **突破封顶 = 承担失控**：追求极致力量必须跨过边界。
- **"锚"机制**：用牵挂稳住人性，锚点失守即失控。
- **全书终极命题**：主角最终是"带着人性封顶"地拯救残存文明，还是"越界换取力量"地成为新的灾变源？

## 世界地图

### 地图骨架（两种模式，可混用）

- **中心辐射（推荐）**：基地（安全核心）→ 缓冲带 → 探索带 → 高危带 → 禁地（灾变源所在）。
  - 优点：难度与地图同步升级。
- **单一平面（废土）**：广袤均质的废土，据点散布；适合公路片式流浪主线。

### 移动通道与成本
- **车队 / 商队**：连接据点，本身是高风险高回报的移动场景。
- **据点跳跃**：途中是无人区 / 危险区。
- **出行成本**：燃油 / 载具损耗；路途威胁；时间与信息差；人员伤亡概率。

## 裁切指引

### 变异浓度（决定力量体系走向）
- **纯废土（低 / 无超自然变异）**：力量来源 = 旧科技 + 组织。代表作《疯狂的麦克斯》。
- **半变异（中等）**：存在丧尸 / 变异兽 / 局部异能。最常见的商业浓度。
- **异能末世（高）**：异能 / 进化体系成熟。爽感最强，但需严控代价。

### 基地经营 vs 流浪主线
- **基地经营**：爽点在养成、扩张、降维打击。
- **流浪主线**：爽点在未知、遭遇、人性试炼。
- **混合**：前期流浪 → 中期经营 → 后期再出发。

### 替换皮相（底层法则不变）
- 灾变形式可替换：病毒 / 核战 / 陨石 / 异界入侵 / AI 觉醒 / 灵气复苏。
- 换皮要点：换"灾变成因"与"变异形态"，保留"资源稀缺、力量有代价、人性有边界"。

### 避免物资通货膨胀（破坏稀缺感的头号杀手）
- **金手指限规模**：空间 / 系统仓库必须有容量、损耗、冷却。
- **物资持续消耗**：防守战、人口扩张、设备维护持续烧资源。
- **新威胁逼投入**：每次基地升级后引入更高烈度威胁。
- **稀缺升级而非消失**。

## 启发式推导

1. **结局导向**：你的末世是"可净化拯救"还是"只能适应"？这决定主角终极目标与最终反派形态。
2. **人异边界划在哪**：主角会在哪一次进化后第一次"踩线"？全书最重的悲剧或高潮是否就押在这条线上？
3. **稀缺校准**：主角的金手指是否大到足以架空稀缺感？如果是，用什么代价把它拉回来？
4. **灾变源人格化**：它是病毒（无意志）、外星文明（有意志的清洗）、AI（逻辑冷酷），还是某种存在（神意 / 实验者）？
5. **主线抉择**：基地经营与流浪公路片，哪条是全书脊柱？
6. **势力差异化**：主角势力填补六原型中的哪个空缺？
