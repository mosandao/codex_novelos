# 官场重生（参考：《侯卫东官场笔记》《二号首长》《沧浪之水》《重生之衙内》）

> **世界观支柱**：以派系、政绩、升迁、民心为核心的体制内博弈世界，靠"官职序列 + 派系网络 + 政策窗口 + 群众基础"支撑主角爬升合理性。
> **典型消费节奏**：开篇用重生卡位与历史事件预判钩住读者，中段以"政绩工程 + 派系站队"高频供给博弈爽点，后段以"升迁调令 + 改变历史"做长线收束。

## 桥段清单

### 重生卡位
- **资源需求**：一个清晰的"前世时间线"（主角知道未来哪些事件会发生）；一个可卡位的起点位置（基层科员、衙内、落魄干部）；一份前世记忆的关键节点清单。
- **爽点类型**：先知碾压 + 改命爽感 + "我比所有人都早一步"的优越感。
- **消费时机**：第一卷开篇钩子，前 20 章密集消费。
- **变体**：①卡位到一个关键岗位；②卡位到一个关键人物身边；③反套路"重生回去发现自己卡错位了"；④极端"重生回去发现历史已经因为重生而改变"。
- **消费绑定提示**：开篇钩子。第一章必消费；前 20 章的每个"先知预判"都应作为开篇阶段的密集钩子。

### 政绩工程
- **资源需求**：一项可量化、可归功、可上级可见的政绩项目（招商、基建、扶贫、改革）；一个政策窗口（上级导向、时代风口）；执行所需的人财物资源。
- **爽点类型**：经营成功 + 上级赏识 + 同僚嫉妒。
- **消费时机**：每个任职岗位的中段，作为升迁跳板。
- **变体**：①正统经济政绩（GDP、招商）；②民生政绩（脱贫、教育）；③反套路"政绩工程反而捅了娄子，主角靠危机公关翻盘"；④极端"政绩工程其实是更大的阴谋的掩护"。
- **消费绑定提示**：高频爽点 + 阶段转折。每个岗位任期中段必消费；政绩完成章应作为升迁调令的阶段转折点。

### 站队与倒台
- **资源需求**：一个清晰的派系图谱（改革派/保守派、本土派/空降派、家族派/草根派）；主角所属或可选择的上位者；一个派系斗争的爆发节点（会议、人事调整、案件）。
- **爽点类型**：博弈胜利 + 站队正确 + 看着对手倒台的爽感。
- **消费时机**：第二卷起高频出现，每卷至少一次派系冲突。
- **变体**：①主角坚定站队一派；②主角两面逢源；③反套路"主角表面站队 A 实则暗中扶植 B"；④极端"主角自己成为新派系的祖师爷"。
- **消费绑定提示**：高频爽点 + 阶段转折。每次派系倒台都应作为本卷阶段转折；主角的站队选择应作为长线伏笔影响后续多卷。

### 升迁调令
- **资源需求**：一个清晰的官职序列（科员→副科→正科→副处→正处→副厅→正厅→副部）；一份调动逻辑（政绩、背景、平衡、流放）；调动带来的资源与人脉变化。
- **爽点类型**：阶位跃迁 + 地位碾压 + 新舞台的新鲜感。
- **消费时机**：每卷尾或重大政绩之后。
- **变体**：①正常升迁；②破格提拔；③反套路"明升暗降，调到边远地区"；④极端"升迁是陷阱，新岗位是派系绞肉机"。
- **消费绑定提示**：阶段转折。每次升迁调令章作为本卷阶段转折，开启下一卷新舞台。

### 民心工程与群众基础
- **资源需求**：一群有具体诉求的群众（拆迁户、上访户、受灾群众、小微企业主）；一项能解决实际问题的政策或项目；主角与基层的连接渠道。
- **爽点类型**：被爱戴 + 政治资本积累 + "为人民服务"的道德优越感。
- **消费时机**：每个任职岗位的中后段，作为政绩工程的深化。
- **变体**：①正统为民办事；②利用民心反制上级；③反套路"民心工程被对手利用制造群体事件"；④极端"群众基础最终成为主角问鼎最高位的真正筹码"。
- **消费绑定提示**：高频爽点 + 长线伏笔。每岗位至少一次民心工程章节；积累的群众基础应作为终卷问鼎时的长线伏笔回收。

### 历史事件提前布局
- **资源需求**：一系列主角知道会发生的历史/时代事件（金融危机、政策转向、重大灾害、人事变动）；主角在每个事件前的布局手段；布局带来的红利。
- **爽点类型**：先知碾压 + "我早就准备好了"的装逼感 + 改变历史的成就感。
- **消费时机**：第一卷起的每个重大事件节点，贯穿全书。
- **变体**：①经济事件布局（抄底、做空）；②政治事件布局（押宝、避祸）；③反套路"提前布局反而引发了原不会发生的事件"；④极端"主角发现历史有自己的修正力，越布局越偏离"。
- **消费绑定提示**：开篇钩子 + 长线伏笔 + 阶段转折。第一卷首次预判作为开篇钩子；每个事件布局在前卷埋伏笔、当卷消费为阶段转折。

### 老领导提携与师徒线（新增）
- **资源需求**：一位位高权重、识才爱才的老领导（即将退居二线或正攀升）；主角与老领导的识遇节点；老领导的人脉与政治遗产。
- **爽点类型**：贵人相助 + 伯乐识马 + "我是 X 书记的人"的归属感。
- **消费时机**：第一卷中段引入老领导，贯穿全书作为主线靠山。
- **变体**：①老领导一路提拔到底；②老领导中途倒台主角独立；③反套路"老领导其实是利用主角的棋子"；④极端"老领导是重生的另一个玩家"。
- **消费绑定提示**：开篇钩子 + 长线伏笔。老领导的识遇章作为第一卷阶段转折；老领导的政治遗产应在终卷作为长线伏笔回收。

### 经济布局与资本积累（新增）
- **资源需求**：一项主角在体制外可控制的经济资源（家族企业、白手套、产业基金、地产）；经济资源与政治资本的相互转化通道。
- **爽点类型**：经营成功 + 财力碾压 + "政商双线"的爽感。
- **消费时机**：第二卷起作为暗线，与政绩工程交织。
- **变体**：①家族产业支撑政治；②主角自己暗中经商；③反套路"经济布局被反腐盯上，险些翻船"；④极端"经济布局最终成为主角问鼎最高位后推行改革的核心筹码"。
- **消费绑定提示**：长线伏笔 + 阶段转折。经济资源的积累应作为跨卷长线伏笔；当经济资源与政治事件交汇时作为阶段转折。

### 反腐风暴与政治洗牌（新增）
- **资源需求**：一场自上而下或自外而内的反腐/整顿运动；一批被牵连的派系与人物；主角的应对策略（自保、顺势清洗对手、被冤枉）。
- **爽点类型**：危机求生 + 顺势扩张 + 看着贪官落马的爽感。
- **消费时机**：第三卷或终卷作为长线大事件。
- **变体**：①主角借反腐清洗对手；②主角被反腐调查需自证清白；③反套路"反腐的推动者本身才是最大的贪官"；④极端"反腐最终指向主角的老师/家族，主角被迫反体制"。
- **消费绑定提示**：长线伏笔 + 终卷阶段转折。反腐伏笔应在前期派系戏中埋下；风暴爆发章作为全书阶段转折。

### 改革试点与时代风口（新增）
- **资源需求**：一项可被主角主导或参与的改革试点（特区、国企改制、乡村振兴、数字经济）；改革所需的政策授权与试错空间；改革遇到的既得利益阻力。
- **爽点类型**：开创历史 + 时代弄潮儿 + "我改变了这片土地"的成就感。
- **消费时机**：第二卷或第三卷作为主角的标志性政绩。
- **变体**：①经济改革试点；②治理机制改革；③反套路"改革试点失败，主角靠承认失败并调整翻盘"；④极端"改革试点最终被中央复制推广，主角成为路线代表"。
- **消费绑定提示**：阶段转折 + 长线伏笔。改革试点的授权章作为本卷阶段转折；试点的成效应作为终卷主角问鼎的长线伏笔。

### 问鼎与历史改写（新增）
- **资源需求**：一个全书累积的资本总和（政绩、人脉、民心、经济、派系）；一个可问鼎的最高位置或历史事件；一个终极对手或终极抉择。
- **爽点类型**：登顶 + 改写历史 + "我做到了前世没做到的"的圆满感。
- **消费时机**：终卷高潮。
- **变体**：①问鼎最高位；②不问鼎高位但改变一项国策；③反套路"主角主动放弃问鼎，回归为民"；④极端"主角问鼎后发现，重生只是一场梦/另一个玩家设计的局"。
- **消费绑定提示**：长线伏笔全回收 + 终卷阶段转折。前文所有政绩、民心、布局在此桥段集中回收。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：阶位跃迁
- **标准形态**：科员→副科→正科→副处→正处→副厅→正厅→副部，每卷跃迁 1~2 级。
- **可变维度**：跃迁的速度、跃迁的路径（党务/政务/国企/人大）、跃迁的代价、是否破格。
- **衍生问题**：如果本书的 Architecture 核心引擎是"经营"而不是"博弈"，阶位跃迁要不要让位于经济布局？如果 Strategy 是"短篇单元"，要不要砍掉副厅以上的阶位戏？

### 母题 2：派系博弈
- **标准形态**：改革派 vs 保守派 / 本土派 vs 空降派 / 家族派 vs 草根派，主角选边站队。
- **可变维度**：派系的数量、派系的意识形态色彩（80 年代有思想路线斗争，当代多为权力斗争）、主角的站队自由度、派系斗争的烈度。
- **衍生问题**：如果本书是"国企流"，派系要不要改组为"技术派 vs 财务派 vs 党务派"？如果核心引擎是"博弈"，派系戏是否可以超过升迁戏成为主线？

### 母题 3：先知红利
- **标准形态**：主角靠重生记忆提前布局历史事件，收割红利。
- **可变维度**：先知的准确度（精确 vs 模糊）、先知的失效节点（历史因重生而改变）、先知的来源（重生 vs 系统 vs 异能）。
- **衍生问题**：如果本书是"非重生官场"，先知红利要不要替换为"主角的敏锐判断"？如果核心引擎是"博弈"，先知红利是否要被削弱以增加博弈难度？

### 母题 4：政商双线
- **标准形态**：体制内升迁 + 体制外经济布局相互支撑。
- **可变维度**：经济线的比重、经济线的合法性（白手套/家族/自身）、政商转化通道的畅通度。
- **衍生问题**：如果本书定位是"纯体制内"，经济线要不要砍掉？如果核心引擎是"反腐"，经济线是否要反过来成为主角的风险源？

### 反套路与"烂大街"风险
（综合 WebSearch 读者批评素材提炼，来源包括人民网、中国作家网、光明日报等）
- **派系斗争取代思想路线斗争**：中国作家网指出，80 年代官场小说有"改革派 vs 保守派"的思想路线斗争，当代官场小说中思想路线斗争消失，纯粹权力斗争成为焦点，导致作品思想深度下降。World Agent 应至少为派系冲突注入一点路线/理念分歧。
- **政治神秘感作为卖点**：人民网批评官场小说的流行依赖"政治不透明"，一旦政治透明化，小说吸引力下降。建议把博弈重点从"政治黑箱"转向"政策博弈与人性"。
- **升迁流水账**：从科员到省委书记的"岗位流水账"被批评为套路化，每个岗位的政绩工程模板雷同。建议每个岗位设计独有的政绩母题。
- **重生先知碾压**：先知红利用滥后失去紧张感，读者批评"主角太顺没意思"。建议引入"历史修正力"或"重生副作用"增加难度。
- **女性角色工具化**：官场小说女性角色多为"贤内助/红颜知己/政治筹码"。建议加入有独立政治诉求的女性角色。
- **反腐戏套路化**：反腐戏被批为"清官斗贪官"的现代版，正邪分明缺乏灰色地带。建议增加"灰色主角"或"被迫腐败"的复杂性。

### 未覆盖子流派的推导路径
- **国企改革流**：从"政府岗位"替换为"国企岗位"，派系戏改组为"技术/财务/党务"，政绩工程改为"扭亏为盈/上市/混改"。
- **基层乡镇流**：把阶位戏压缩在"村→乡→县"，强化"民心工程"与"地方势力博弈"，弱化高层派系。
- **衙内流 / 红色后代流**：主角出身政治家族，从"重生卡位"推导为"家族资源继承 + 自身证明"，博弈重点是家族内部与同辈竞争。
- **反腐调查流**：主角身份改为纪委/监察委，从"升迁"推导为"办案"，桥段重点是"反腐风暴"与"心理博弈"。
- **古代官场流**：穿越到古代，官职序列替换为"品阶制"，可嫁接 `isekai-build.md` 的基建母题。
- **官场 + 系统流**：叠加系统签到/任务/商城（参考 `system.md`），把"政绩"升级为"系统任务奖励"。
- **女性官场流**：把硬汉博弈替换为女性视角的"柔术政治"，增加性别阻力作为博弈维度。
