# 基建 / 穿越（参考：《临高启明》《放开那个女巫》《战国野心家》《唐砖》）

> **世界观支柱**：穿越者携带现代知识或基建系统，在古代/异界从零攀登科技树并重塑社会制度。
> **典型消费节奏**：前期慢热种田积累（资源解锁爽点），中期技术节点突破（信息差碾压），后期军事/工业碾压推图。爽点密度随科技等级递增。

## 桥段清单

### 攀科技树（纯种田主线）
- **资源需求**：原材料产地（铁矿/硝石/硫磺/煤）、可培训劳动力、实验场所、可被复刻的工艺链条。世界契约需标注"科技节点解锁表"作为长线资源。
- **爽点类型**：节点解锁的"原来如此"感 + 信息差碾压冷兵器的降维爽点。
- **消费时机**：贯穿全书，每个科技节点（烧砖→炼铁→火药→蒸汽→电力）是一个独立小高潮；首卷首节点常作开篇钩子。
- **变体**：①系统面板直接发放科技蓝图；②纯靠现代记忆+实验试错（硬核流）；③金手指只给"方向提示"不包办（半硬核）；④科技被原住民逆向破解（反转流）；⑤科技路线被本地魔法/灵气干扰产生变异（混血流）。
- **消费绑定提示**：长线伏笔 + 高频爽点。具体场景：第一卷以"主角烧出第一块合格耐火砖/炼出第一炉钢"作为开篇钩子节点；之后每个科技节点（火药、蒸汽机、电报）作为卷尾转折锚点，并在 world_contract 的"科技节点解锁表"中绑定消费卷数。
- **跨簇说明**：本桥段以"纯种田"为消费主线（科技节点本身即爽点高潮）。若攀科技服务于朝堂权谋（如"火药配方被皇子觊觎"驱动党争），则属于架空历史簇 `alternate-history.md` 的"攀科技树与产业奠基"（权谋镶嵌式），请按本书核心引擎选用对应母题。

### 种田经营
- **资源需求**：可开垦土地、可招募流民/农奴、水利设施、种子与牲畜、仓储与账房体系。
- **爽点类型**：从无到有的"家业积累"感 + 数字化增长（粮仓储量/人口/产值）的养成爽点。
- **消费时机**：第一卷至第二卷为主战场，后期转为战略后方支撑线。
- **变体**：①单人手搓起步；②带流民/灾民集体开荒；③接管破败庄园/封地整顿；④异界物种农作物（如魔芋、地精薯）带来意外产量；⑤与本地领主合作分成经营。
- **消费绑定提示**：开篇钩子 + 高频爽点。具体场景：开篇 3-5 章内必须出现一次"荒地变良田/破屋变作坊"的对比镜头作为钩子；之后每 10-15 章安排一次"账面数字翻番/人口破万"的养成回报镜头。

### 土著外交
- **资源需求**：可接触的原住民势力（部落/领主/朝廷）、翻译/通译角色、可交易的高价值新奇货（玻璃珠/白糖/烈酒）、文化缓冲地带。
- **爽点类型**：信息差谈判碾压 + 文化输出启蒙的优越感。
- **消费时机**：第一卷后半至中段，主角站稳脚跟后第一次走出根据地。
- **变体**：①用现代商品换矿产/人口；②用医术/技术换取土著信仰；③介入土著内战扶植傀儡；④被土著高层视为妖异打压（反转）；⑤与土著女性/贵族联姻建立联盟。
- **消费绑定提示**：阶段转折。具体场景：作为第一卷到第二卷的过渡转折——主角第一次以"外来文明"身份与本地最大势力正面交涉，结果决定下一阶段的地缘格局。

### 工业品倾销
- **资源需求**：成规模的手工工场或早期工厂、运输通道（车船/驿站）、销售网络/代理商、本地市场缺口（盐/铁/布/糖）。
- **爽点类型**：经济碾压 + 市场垄断的"降维打击"爽点。
- **消费时机**：中段（第二至三卷），生产规模化之后。
- **变体**：①白糖/精盐冲击本地盐商；②玻璃器皿/镜子换黄金；③烈酒开拓蛮族市场；④纺织品打垮本地织户引发反弹；⑤倾销引发本地行会/官府反扑（冲突型变体）。
- **消费绑定提示**：高频爽点。具体场景：每隔 1-2 卷安排一次"工业品上市即被抢空/本地同行破产"的市场碾压镜头，作为稳定爽点供给；并在 world_contract 中标注"垄断品类清单"。

### 现代军事碾压
- **资源需求**：火药武器生产线（火绳枪/燧发枪/火炮）、可训练的近代化军队、标准化后勤、可被碾压的冷兵器对手。
- **爽点类型**：跨代军事碾压的极致反差爽点（排队枪毙vs骑兵冲锋）。
- **消费时机**：第三卷后段至高潮卷，科技与工业积累兑现为军事胜利。
- **变体**：①燧发枪线列步兵平推冷兵器军团；②火炮轰城结束围城战；③机枪/野战炮屠杀骑兵冲锋（经典爽点）；④对手也获得部分火器（势均力敌型）；⑤现代军事碾压被本地超凡力量（修仙/魔法）部分抵消（反转流）。
- **消费绑定提示**：阶段转折 + 长线伏笔兑现。具体场景：作为全书第一次"军事碾压"大高潮，应安排在第一卷末或第二卷中——主角的第一支火器部队首战屠戮十倍冷兵器敌军；后续每卷至少一次递进式军事胜利。

### 跨时空贸易垄断
- **资源需求**：稳定的时空通道或穿越门、双时空价差商品（古代黄金→现代 / 现代工业品→古代）、现代销赃渠道、古代采购网络。
- **爽点类型**：无限套利的"空手套白狼"爽点 + 双时空信息差的认知优越。
- **消费时机**：贯穿全书，作为稳定资源线，中段集中爆发。
- **变体**：①单向穿越带现代货回古代；②双向门户两界倒爷；③垄断古董/文物回流现代；④用古代资源（人口/矿产）反哺现代产业；⑤通道关闭/受限带来的资源危机（转折型）。
- **消费绑定提示**：高频爽点 + 长线伏笔。具体场景：开篇用一次"两界价差"作为钩子（古代一担粮换现代一个打火机）；中段安排"垄断品类"事件作为阶段转折；通道稳定性作为长线伏笔贯穿。

### 根据地启蒙与基层改制（新增）
- **资源需求**：可被改造的基层政权（村庄/封地/殖民地）、识字阶层、印刷术或等价传播手段、可援引的理论体系（墨家/法家/共和/科学方法）。
- **爽点类型**：观念碾压 + 历史进程加速的"加速主义"爽点。
- **消费时机**：第二卷起持续渗透，第三卷与争霸线交织。
- **变体**：①推广简字+印刷办扫盲班；②以墨家/科学方法改造本地学派；③推行均田/废奴/科举等制度；④思想启蒙引发守旧势力反扑（冲突）；⑤启蒙成果被反派利用（反转）。
- **消费绑定提示**：长线伏笔。具体场景：第二卷埋下"扫盲班第一批学生/第一部印刷小册子"作为长线伏笔，第四卷兑现为"这批学生成为新政权骨干"的回扣镜头。
- **跨簇说明**：本桥段聚焦"根据地/殖民地基层"的自下而上改制（无既定朝廷约束）。若改制发生在真实/半真实朝代、需对抗既定朝廷与党争（自上而下或朝堂博弈驱动），则属于架空历史簇 `alternate-history.md` 的"制度改革与思想启蒙"，请按本书有无历史背景约束选用对应母题。

### 流民/人口吸纳与城邦建立（新增）
- **资源需求**：乱世灾民/战俘来源、可扩张的定居点、户籍与分配制度、防御工事。
- **爽点类型**：从无到有建立"乌托邦小社会"的建国爽点。
- **消费时机**：第一卷后半至第二卷，根据地成型期。
- **变体**：①收容战乱流民建新城；②赎买/解救奴隶建自由城；③宗教式聚众建圣地；④流民来源被敌对势力截断（危机）；⑤城邦人口过载引发内部矛盾（反转）。
- **消费绑定提示**：阶段转折。具体场景：第一卷尾或第二卷头安排"主角的城邦人口破千/破万"作为阶段转折节点，标志着从"求生"转入"建国"阶段。

### 海外殖民与远洋开拓（新增）
- **资源需求**：远洋船只、航海术/星图、海外未知大陆或岛屿、殖民拓荒队、远洋补给站。
- **爽点类型**：地理大发现 + 新世界建立的探险爽点。
- **消费时机**：第三卷及以后，本土根基稳固后的扩张线。
- **变体**：①大航海时代式发现新大陆；②殖民海岛建立第二根据地；③与海外土著文明接触；④海外发现超凡资源/远古遗迹（混血流）；⑤殖民引发宗主国/本土势力反扑（冲突）。
- **消费绑定提示**：长线伏笔。具体场景：第二卷末埋下"远洋船队首航/海图绘制"伏笔，第三卷兑现为"发现新大陆/建立海外殖民地"的大转折。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：科技节点解锁
- **标准形态**：主角按"烧砖→炼铁→火药→蒸汽→电力"的固定顺序逐级解锁，每节点产出一次碾压爽点。
- **可变维度**：解锁顺序、解锁动机（自发需求 vs 外部威胁）、节点之间的间隔节奏、节点的可视化形式（系统面板 vs 实验日志）。
- **衍生问题**：如果本书的 Architecture 核心引擎是"魔法工业化"而不是"纯科技"，攀科技树会变成"魔药量产化→魔导机械→符文工业化"的什么形态？如果 Strategy 把火药节点从第一卷挪到第三卷，第一卷需要前置哪些非军事爽点替代？

### 母题 2：信息差碾压
- **标准形态**：主角凭现代知识碾压本地人的认知盲区（谈判、医疗、军事、制度）。
- **可变维度**：信息差的领域、本地人逆向学习的速度、信息差被打破的临界点。
- **衍生问题**：如果本书的本地文明也拥有"另一套高知识体系"（如修真/魔法），信息差碾压会双向化——主角的哪些现代优势反而会被视为"低维"？这种双向信息差如何转化为新桥段？

### 母题 3：根据地从小到大
- **标准形态**：一个破败落脚点（村庄/庄园/荒岛）逐步膨胀为城邦、国家、帝国。
- **可变维度**：膨胀的动力（流民/征服/殖民）、内部治理结构的复杂度、外部威胁的升级节奏。
- **衍生问题**：如果本书的核心引擎是"个人武力"而非"集体组织"，根据地扩张会变成"主角打下一地→委派人治理"的什么形态？集体组织桥段（户籍/军制/官僚）该如何缩减或重构？

### 反套路与"烂大街"风险
来自 WebSearch 读者批评的提炼：
- **科技路线完全可预测**：烧砖→炼铁→火药三件套已成公式，读者审美疲劳。建议跳过已烂大街的节点，或给节点加"本地变量"（如异界矿物改变冶炼路径）。
- **情绪驱动同质化**：套路化为满足爽感重复使用"碾压打脸"桥段，缺乏具体精准的场景展示，描写流于大词堆砌。建议每个碾压节点配一个具体到"某个原住民的反应镜头"的细节。
- **后期争霸套路灌水**：前期种田扎实，后期陷入"打一城下一地"的重复推图模板。建议在推图线之外开辟制度/思想/文化输出线作为差异化。
- **穿越方式雷同**：理工男/工程师穿越明末已成标配。可尝试女性视角、非技术背景、群体穿越、反向穿越（古代人穿越到现代再回去）等变体。

### 未覆盖子流派的推导路径
- **明穿/宋穿/战国穿/架空建国**：从"攀科技树"母题反推，把节点表替换为对应朝代可获取的资源（宋代有煤有铁可前置蒸汽机；战国缺铁需先点冶铁）。"根据地启蒙与基层改制"母题按朝代调整（宋穿可前置科举改革，战国穿可前置郡县制）；若涉及真实朝堂党争，改用 `alternate-history.md` 的"制度改革与思想启蒙"。
- **群体穿越/元老院流**：从"流民吸纳与城邦建立"反推，主角团本身就是初始人口，内部派系博弈取代单人决策，需新增"穿越者内部路线之争"桥段。
- **异界基建（非历史）**：从"土著外交"反推，本地文明可能是精灵/兽人/魔族，工业品倾销变成"用现代糖盐换魔晶/精灵木材"，需混血进 xuanhuan.md 或 xianxia.md 母题。
- **反向穿越（古代人穿越现代）**：从"信息差碾压"反转，主角成为被碾压方，桥段变为"在现代社会求生+反向输出古代技艺（武艺/医术/谋略）"。
