# 都市灵气（参考：《大王饶命》《这里有妖气》《三寸人间》都市灵气复苏类）

> **世界观支柱**：现代都市表层秩序 + 灵气复苏 / 异能觉醒的隐秘超凡世界；隐世家族、古武世家、官方超凡机构、地下组织四方角力；主角在平凡身份下隐藏超凡实力，逐步揭开"灵气为何复苏"的真相。
> **典型消费节奏**：高频打脸装逼爽点（隐世家族少主被扮猪吃虎的主角打脸）+ 长线悬疑（灵气复苏的真相），读者期待"日常伪装 + 关键时刻爆发"的反差循环。

## 桥段清单

### 异能觉醒与金手指激活
- **资源需求**：灵气复苏或异能觉醒的触发事件（全球灵气潮 / 个体奇遇 / 系统绑定）；觉醒后的能力分类（异能 / 修为 / 血脉）；能力的隐藏与暴露机制；觉醒者的登记 / 监控制度。
- **爽点类型**：金手指激活 + 命运转折 + 逆袭起点。
- **消费时机**：第一卷开篇必消费（开篇钩子）。
- **变体**：①系统绑定式觉醒；②血脉觉醒式（隐藏的古老血脉）；③奇遇式（古墓 / 流星 / 异兽内丹）；④全家觉醒（家庭流）；⑤被动觉醒后被迫卷入超凡世界。
- **消费绑定提示**：标注为**开篇钩子**。具体场景：第一卷第一章用一次觉醒事件把主角从平凡人拉入超凡世界，3 章内完成第一次能力实战验证。

### 隐秘组织与地下势力
- **资源需求**：至少一个地下超凡组织（归墟会式）；组织的诉求（颠覆秩序 / 谋利 / 复古）；组织对主角的态度（拉拢 / 追杀 / 不知情）；组织内部的派系。
- **爽点类型**：阴谋 + 卧底 + 多方博弈 + 反杀。
- **消费时机**：第二卷起地下组织成为主要对手或合作方。
- **变体**：①主角被地下组织追杀；②主角潜入地下组织卧底；③主角被拉拢后反客为主；④地下组织其实是某位古神的傀儡；⑤地下组织与官方机构暗中合作（黑白共生）。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷中段让主角首次接触地下组织，被迫在"加入 / 对抗 / 利用"之间抉择，作为本卷从"个人觉醒"升级为"势力博弈"的转折。

### 灵气复苏与世界异变
- **资源需求**：灵气复苏的渐进过程（前兆 / 全面复苏 / 高潮）；异变的具体表现（动植物异化 / 灵脉开启 / 古代遗迹出世 / 妖兽重现）；世俗社会对异变的反应（掩盖 / 公开 / 适应）；复苏背后的真相。
- **爽点类型**：世界观扩张 + 探索 + 文明级变化的史诗感。
- **消费时机**：第一卷铺设前兆，第二卷全面爆发，第三卷揭真相。
- **变体**：①灵气复苏是周期性事件；②复苏是某位存在的阴谋；③复苏会带来灭世级灾难；④复苏开启通往异界的通道；⑤复苏让古代神话生物重现。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第一卷用一系列"小异变"（地铁里的妖兽 / 公园里的灵脉）铺设悬念，第三卷揭晓灵气复苏的真相，作为全书主线的引爆点。

### 扮猪吃虎与身份伪装
- **资源需求**：主角的平凡身份（学生 / 上班族 / 服务业）；主角隐藏实力的理由（怕麻烦 / 怕被实验 / 战略需要）；暴露身份的代价与场景；多次"被迫暴露"的递进。
- **爽点类型**：反差爽 + 装逼打脸 + 隐藏大佬揭晓。
- **消费时机**：贯穿全书的高频爽点，每 3~5 章一次。
- **变体**：①校园扮猪吃虎（学渣其实是修真大佬）；②职场扮猪吃虎（小员工其实是隐世强者）；③外卖员 / 网约车司机偶遇大佬被打脸；④直播 / 短视频无意暴露；⑤连续多次"最后一次暴露"的递进笑点。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每卷至少 3 次"主角被迫出手 + 周围人震惊"的小高潮，作为该题材的核心爽感节拍。

### 打脸装逼与隐世震惊
- **资源需求**：被打脸的对象（隐世家族少主 / 古武世家天才 / 富二代 / 官方机构精英）；打脸的场合（拍卖会 / 校园 / 商场 / 武道场）；围观震惊的群众（同学 / 同事 / 之前看不起主角的人）；打脸后的连锁反应。
- **爽点类型**：纯粹的打脸爽 + 数值碾压 + 围观震惊流的二次爽。
- **消费时机**：贯穿全书的高频爽点，每个长副本必有一次大打脸。
- **变体**：①拍卖会用财力打脸富二代；②武道场用武力打脸古武世家；③学术 / 商业场合用智商打脸精英；④饭局上用身份背景打脸势利眼；⑤连打多个档次的脸（小角色叫来大角色继续被打脸）。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每卷高潮安排一次"大型公开场合打脸 + 围观群众集体震惊"事件，作为本卷的情绪顶点。

### 隐世家族与古武世家
- **资源需求**：多个传承千年的隐世家族 / 古武世家；家族的实力阶梯（顶级 / 一流 / 二流）；家族与世俗政权的关系；家族之间的恩怨与联姻网络；家族对觉醒者的态度。
- **爽点类型**：势力碾压 + 家族秘辛 + 拉拢与打压的反复。
- **消费时机**：第二卷起家族势力登场；中后段主角与顶级家族博弈。
- **变体**：①主角是某隐世家族遗孤（隐藏血脉流）；②主角被多个家族拉拢；③主角与某家族联姻；④主角消灭敌对家族；⑤主角建立自己的新家族 / 势力。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷末让主角首次正面对抗一个一流家族并获胜，作为本卷从"个人战"升级为"势力战"的转折。

### 官方超凡机构
- **资源需求**：一个官方秘密机构（烛龙组式特勤局 / 国家安全部门）；机构的职能（监控觉醒者 / 处理异变 / 对抗地下组织）；机构与主角的关系（招募 / 监控 / 合作 / 对立）；机构内部的派系。
- **爽点类型**：组织归属感 + 任务驱动 + 官方背景的碾压。
- **消费时机**：第一卷末或第二卷初主角接触机构；贯穿中后段作为主角的官方后盾或对立面。
- **变体**：①主角被招募成正式成员；②主角是编外协查者；③主角与机构对立（被通缉）；④机构被地下组织渗透主角协助清洗；⑤多国机构的跨国合作 / 对抗。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第一卷末让主角通过一次"协助官方处理异变"获得官方认可（编制或协查身份），作为主角从"地下"转入"半合法"的转折。

### 都市秘境与灵脉争夺（新增）
- **资源需求**：现代都市中隐藏的秘境 / 灵脉 / 古代遗迹；秘境的开启条件（特定时间 / 钥匙 / 灵气浓度）；秘境的资源（灵药 / 功法 / 异兽内丹 / 古代法宝）；多方势力争夺。
- **爽点类型**：探险 + 截胡 + 多方博弈 + 资源积累。
- **消费时机**：第二卷起开始探索秘境；中后段灵脉争夺成为势力冲突焦点。
- **变体**：①都市地下的古代修真洞府；②高楼大厦里的隐形秘境；③地铁 / 商场下的灵脉；④秘境连通异界；⑤灵脉争夺引发都市级冲突。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每 1~2 卷安排一次"都市秘境开启 + 多方争夺 + 主角截胡"事件，作为主角资源跃迁的节点。

### 商业帝国与超凡经济（新增）
- **资源需求**：超凡资源的市场化（灵药 / 法器 / 异兽材料）；主角的商业化运作（公司 / 拍卖行 / 平台）；现代商业知识与超凡资源的结合；官方对超凡经济的监管。
- **爽点类型**：财富积累 + 商业碾压 + 用钱砸死对手。
- **消费时机**：第二卷起开始商业化；中后段主角的商业帝国成为势力支柱。
- **变体**：①主角开拍卖行垄断灵药流通；②主角做法器品牌碾压传统炼器世家；③主角建立超凡资源线上平台；④商业帝国被官方盯上；⑤用商业手段瓦解敌对家族的经济基础。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每卷至少一次"商业博弈胜利 + 敌对势力经济受损"事件，作为主角势力扩张的节点。

### 修真功法与境界体系（新增）
- **资源需求**：一套都市背景下的修真境界体系（练气 / 筑基 / 金丹等的现代化包装）；功法的来源（古修传承 / 自创 / 系统兑换）；功法与异能的差异；境界突破的瓶颈与契机。
- **爽点类型**：养成 + 境界突破 + 数值膨胀 + 跨境界碾压。
- **消费时机**：第一卷铺设境界体系；每卷必有一次境界突破作为卷末高潮。
- **变体**：①主角修炼古修真功法；②主角自创功法融合现代科学；③主角修炼的是上古妖修 / 魔修功法；④境界突破引发天象被官方监测；⑤多功法并行（修真 + 异能 + 古武三修）。
- **消费绑定提示**：标注为**阶段转折**。具体场景：每卷末安排一次境界突破 + 跨境界碾压战，作为本卷的能力跃迁节点。

### 妖兽潮与都市保卫战（新增）
- **资源需求**：灵气复苏引发的妖兽潮；妖兽的等级与类型；都市防御体系（官方 + 觉醒者 + 隐世家族）；保卫战的规模（街区级 / 城市级 / 全国级）。
- **爽点类型**：史诗战争 + 守护 + 主角力挽狂澜 + 民众认知翻转。
- **消费时机**：第二卷末或第三卷高潮，全书最大规模的正面战场。
- **变体**：①街区级小妖兽潮主角独立解决；②城市级妖兽潮多方联合；③全国级妖兽潮主角成为关键战力；④妖兽潮其实是人为引发；⑤妖兽潮背后有妖王 / 妖神指挥。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第二卷高潮让主角在一次城市级妖兽潮中力挽狂澜，由此从"隐秘超凡者"跃升为"公众英雄"或"官方顶级战力"，作为全书公开化的转折。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：扮猪吃虎的"伪装—暴露"循环
- **标准形态**：主角隐藏实力，关键时刻被迫暴露，围观群众震惊，然后换一个新身份继续伪装。
- **可变维度**：伪装的层数（一层 vs 多层马甲）；暴露的代价（麻烦 / 被实验 / 被通缉）；暴露是否可逆（换马甲 vs 永久公开）；暴露的戏剧性（无意 vs 蓄意威慑）。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"主角无法隐藏实力、一觉醒就全场瞩目"而非"扮猪吃虎"，这个桥段会变成什么形态？爽点从反差转为碾压？如果 <Strategy 阶段目标> 在第二卷就让主角身份完全公开（不再伪装），第三卷的爽点结构如何重组？

### 母题 2：灵气复苏的"渐进—真相"曲线
- **标准形态**：灵气从前兆到全面复苏，最终揭开复苏真相（阴谋 / 周期 / 灾难前奏）。
- **可变维度**：复苏的速度（突然 vs 渐进）；复苏的可逆性；复苏对世俗社会的冲击程度（掩盖 vs 公开）；真相的性质（人为 / 自然 / 神意 / 外星）。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"灵气早已复苏千年、隐世家族一直存在"而非"当代复苏"，这个桥段会变成什么形态？真相从何而来？如果 <Strategy 阶段目标> 让灵气复苏在第二卷就公开化（政府承认超凡），都市日常的伪装结构如何维持？

### 母题 3：隐世家族与世俗政权的"双线权力"
- **标准形态**：隐世家族掌握超凡力量，世俗政权掌握现代武力与行政，两者既合作又对抗。
- **可变维度**：双方的力量对比（家族压制官方 vs 官方压制家族 vs 平衡）；双方的知情程度（互相知晓 vs 单向知情）；双方的代理人战争；普通人在双线权力下的处境。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"无隐世家族、超凡者全部新觉醒"而非"家族传承千年"，这个桥段会变成什么形态？权力格局如何重组？如果 <Strategy 阶段目标> 让主角的目标是"打破家族垄断、让超凡知识全民公开"，需要前置哪些势力与冲突？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评素材（知乎书评、番茄小说评论、知乎写作技巧帖）：

- **"风格陈旧，套路模板化，标准小白爽文"**：知乎书评直言多数灵气复苏作品"中规中矩，可以充饥"，缺乏惊喜。规避：核心设定（灵气来源 / 觉醒机制 / 势力格局）至少有一项反常规。
- **"对灵气复苏理解太狭隘"**：写作圈批评大量跟风作品扎堆模仿《大王饶命》《这里有妖气》，导致题材同质化。规避：跳出"学生觉醒 + 校园打脸 + 隐世家族少主"的标准模板，可尝试职场 / 工业 / 服务业视角的觉醒者。
- **"主角戾气太重、写得像黑暗文"**：番茄读者批评部分高武 + 剑道作品主角人设套路化（被欺凌 → 觉醒 → 暴戾反杀）。规避：打脸动机必须有合理性，而非为爽而爽，避免主角变成嗜杀反派。
- **扮猪吃虎被滥用**：每章都"被迫暴露"导致审美疲劳。规避：暴露必须有递进的代价与后果（每次暴露引来更强敌人），而不是无代价的循环。
- **隐世家族全是反派**：跟风作品把隐世家族一律写成打压主角的反派，缺乏复杂性。规避：家族内部必须有改革派，或某些家族是主角的盟友，避免脸谱化。
- **"灵气复苏引发房价波动"等设定新鲜但常被浪费**：好的现代细节常被一笔带过。规避：把现代社会的真实反应（房价 / 股市 / 就业 / 国际政治）做成持续的背景板而非一次性笑点。

### 未覆盖子流派的推导路径

- **都市修真**：去掉异能觉醒，纯修真体系搬到都市，从"修真功法"母题推导出"现代修真宗门"，从"隐世家族"推导出"千年修真世家"。
