# 玄幻（参考：《斗破苍穹》《遮天》《武动乾坤》《大主宰》）

> **世界观支柱**：以血脉、奇物（异火/天地奇物）、家族与学院为支柱，境界与血脉觉醒双轨并行，主角从废柴/被弃者攀升至大陆巅峰。
> **典型消费节奏**：开篇强冲突（退婚/废柴）立即拉满情绪，中段以学院、家族、遗迹交替输出打脸爽点，每卷一次"逆袭—碾压"循环。

## 桥段清单

### 学院比武排名
- **资源需求**：大陆级学院（招生、分级、强者导师）、同辈精英阵容、排名与奖品机制、宿敌学院。
- **爽点类型**：竞技打脸 + 同辈登顶 + 校园养成。
- **消费时机**：第二至第三卷，主角脱离家族进入更广阔舞台。
- **变体**：①标准——主角入学后一路排名登顶；②反转——主角扮猪吃虎藏实力；③极端——学院被外敌入侵，比武化为保卫战；④反套路——主角是导师不是学员，调教怪胎学生。
- **消费绑定提示**：标注为「高频爽点」。消费场景：中段每卷安排一次不同级别（班级→学院→跨院）的比武，作为稳定爽点输出节奏。

### 血脉觉醒
- **资源需求**：血脉体系（神兽/上古家族血脉）、觉醒契机（生死、机缘、情绪激荡）、血脉等级与隐藏形态。
- **爽点类型**：命运改写 + 实力跃升 + 身世之谜揭示。
- **消费时机**：第一卷中后段或第二卷初，主角第一次质变的转折点。
- **变体**：①标准——危机中觉醒上古血脉反杀；②反转——血脉是诅咒，觉醒即被追杀；③极端——主角拥有多种血脉逐步解锁；④反套路——血脉觉醒反而压低实力，需要重新修炼。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：作为开篇钩子的延伸——主角觉醒血脉翻盘退婚方，同时埋下"血脉来源家族"之谜作为长线伏笔。

### 远古遗迹探索
- **资源需求**：上古强者遗迹/洞府、传承机制、多方觊觎的势力、遗迹中的守护凶兽与机关。
- **爽点类型**：机缘 + 智斗 + 越级反杀。
- **消费时机**：第二至第四卷，作为秘境探索的玄幻变体。
- **变体**：①标准——获上古强者传承；②反转——遗迹是上古魔头封印；③极端——主角与同伴反目分赃；④反套路——传承是一段悔恨记忆，主角悟道而非得宝。
- **消费绑定提示**：标注为「阶段转折」。消费场景：每卷新地图开启时用遗迹探索作为"换地图 + 交付机缘"的双引擎。

### 天才对决
- **资源需求**：同代顶尖天才群像（每人有独门绝学与背景）、对决舞台（比武、论道、夺宝混战）、宿敌养成线。
- **爽点类型**：巅峰对决 + 同辈压制 + 越级斩天骄。
- **消费时机**：中后段，主角与同代最强者的正面碰撞。
- **变体**：①标准——主角碾压各路天才登顶；②反转——宿敌是主角失散同胞；③极端——主角与宿敌联手对抗更强外敌；④反套路——宿敌才是被命运选中的"主角"，主角是逆袭者。
- **消费绑定提示**：标注为「高频爽点」+「长线伏笔」。消费场景：中段每次天才对决既是爽点高潮，又为后续"宿敌联手/身世揭秘"埋伏笔。

### 家族倾轧
- **资源需求**：庞大家族（旁支/嫡系/长老会）、家族内部利益分配、继承人争夺、家族外部敌对势力。
- **爽点类型**：权谋打脸 + 内部崛起 + 嫡庶反转。
- **消费时机**：第一卷与贯穿全书，主角出身的第一道人情世故战场。
- **变体**：①标准——主角压制打压自己的旁系崛起；②反转——主角是被流放的嫡系回归夺位；③极端——主角直接分家自立门户；④反套路——主角是家族隐藏守护者，暗中扶持傀儡。
- **消费绑定提示**：标注为「开篇钩子」+「高频爽点」。消费场景：第一卷开篇用家族倾轧制造压抑，中段每隔一段安排一次"打脸家族长辈"作为稳定爽点。

### 异火天地奇物收服
- **资源需求**：天地奇物体系（异火、神雷、玄水等排名榜）、收服机制（吞噬、炼化、契约）、奇物产地与守护者。
- **爽点类型**：实力质变 + 收集养成 + 越级夺宝。
- **消费时机**：贯穿中段，主角收集奇物强化底牌的长线。
- **变体**：①标准——主角吞噬异火获得新能力；②反转——异火有意识，主角与其谈判共存；③极端——主角集齐所有异火引发天地异象；④反套路——主角放弃异火，自创替代之物。
- **消费绑定提示**：标注为「长线伏笔」。消费场景：作为贯穿 3~5 卷的收集暗线，每次收服即一次小高潮，奇物榜本身是长线钩子。

### 大陆级排位赛
- **资源需求**：跨大陆/跨域的大型赛事、各大陆强者阵容、丰厚奖品（神物、名额、封号）、赛事背后的势力博弈。
- **爽点类型**：巅峰对决 + 大陆闻名 + 跨域打脸。
- **消费时机**：中后段或末卷前，主角在大陆舞台正式登顶。
- **变体**：①标准——主角一路碾压夺魁封神；②反转——赛事是上位者设下的筛选陷阱；③极端——赛事中途异族入侵中断；④反套路——主角拒绝参赛，靠场外行动影响赛果。
- **消费绑定提示**：标注为「阶段转折」。消费场景：作为大陆篇的高潮收束，标志主角从"区域强者"晋升为"大陆级人物"。

### 退婚流开局（权威定义：由《斗破苍穹》开创）
- **资源需求**：与主角有婚约的强势家族/宗门、当众退婚羞辱场景、可触发翻盘的金手指（血脉、至宝、传承）。
- **爽点类型**：羞辱反噬 + 命运翻盘 + 经典打脸（"三十年河东三十年河西"）。
- **消费时机**：第一卷前 3~20 章，强冲突开局。
- **变体**：①标准——退婚后觉醒血脉逆袭；②反转——主角主动退婚，对方后悔倒追；③极端——退婚方是主角前世至亲；④反套路——主角是顶流重生，废柴是伪装。
- **消费绑定提示**：标注为「开篇钩子」。消费场景：开篇即抛出退婚冲突，作为"压抑—觉醒—反杀"循环起点，3 章内交付第一波打脸爽点。
- **跨簇说明**：退婚流是玄幻的标志性开局桥段，本桥段为全图集权威定义。修仙族（`xianxia.md`）借用此母题时，应改用"灵根/资质觉醒"作为翻盘机制（修仙专属），而非照搬玄幻的"血脉觉醒"，以避免两个题材开篇雷同。

### 洪荒圣人斩三尸
- **资源需求**：洪荒/圣人级世界观（鸿蒙、混沌、先天神祇）、斩三尸（善、恶、执念）的证道机制、圣人位阶与天道博弈。
- **爽点类型**：证道升维 + 大道领悟 + 与天道博弈。
- **消费时机**：末卷或番外篇，主角证道成圣的阶段。
- **变体**：①标准——主角斩三尸证道成圣；②反转——三尸反噬成独立人格；③极端——主角不斩三尸走肉身证道路线；④反套路——主角是他人三尸之一，反向追溯本体。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：作为全书境界顶点的证道高潮，同时埋下"三尸独立"或"天道本质"的续篇伏笔。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：废柴逆袭与金手指觉醒
- **标准形态**：主角开局被视为废柴（经脉尽废/印力尽失/血脉未醒），被退婚或欺凌后觉醒上古血脉/获得传承/系统，修为突飞猛进逐一打脸。
- **可变维度**：废柴原因（资质/封印/转世重修）、觉醒契机（生死/情绪/机缘）、觉醒代价（暴露身份/引来追杀/血脉诅咒）。
- **衍生问题**：如果本书核心引擎是"智谋博弈"而不是"血脉碾压"，废柴逆袭会从"觉醒神血"变成什么？如果 Strategy 把觉醒从第一卷挪到第三卷，前期靠什么支撑读者耐心？

### 母题 2：学院与同辈竞争
- **标准形态**：主角进入大陆学院，与各路天才同辈竞技，通过排名赛、考核、对抗赛逐步登顶。
- **可变维度**：学院性质（公立/家族/隐世）、竞争形态（个人/团队/跨院）、导师介入程度（庇护/放养/利用）。
- **衍生问题**：如果本书核心引擎是"团队作战"而不是"个人英雄"，学院比武会从"单挑登顶"变成什么？如果学院本身是反派试验场，主角该合作还是颠覆？

### 母题 3：奇物收集与证道
- **标准形态**：主角收集天地奇物（异火、神雷、玄冰），每收一样即实力跃升，集齐后证道成圣。
- **可变维度**：奇物形态（元素/神兽/法则碎片）、收服方式（吞噬/契约/炼化）、集齐后果（证道/反噬/被天道针对）。
- **衍生问题**：如果本书核心引擎是"共生而非吞噬"，奇物收集会从"吞噬强化"变成什么？主角是该收齐所有奇物，还是该让它们回归天地？

### 母题 4：血脉身世与家族宿命
- **标准形态**：主角觉醒上古血脉，揭开身世之谜，背负家族宿命（复兴/复仇/抵御外敌）。
- **可变维度**：血脉来源（神兽/上古家族/异族）、宿命性质（荣耀/诅咒/实验）、主角与宿命的关系（接受/反抗/超越）。
- **衍生问题**：如果本书核心引擎是"自我定义而非血脉决定"，血脉觉醒会从"宿命加冕"变成什么？主角是该继承家族，还是该斩断血脉重新定义自己？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评的集中意见：

- **"废柴+退婚+血脉觉醒"被列为典中典**：东方财富网对百部 AI 漫剧的分析指出该套路已成"填空题式"创作模式，"三十年河东三十年河西"被反复使用。规避方式：把退婚方写成有合理苦衷（家族压力/替主角挡灾），或让主角的"废柴"是主动伪装（顶流重生/转世重修）。
- **天才群像脸谱化**：每个天才都是"傲慢—被打脸—跪地求饶"的循环。规避方式：给宿敌加入独立成长线与价值观冲突，让对决有"理念之争"而非"意气之争"。
- **吞噬流单一化**：异火/奇物收服被反复套用，爽点趋同。规避方式：让奇物有自主意识或使用代价，把"吞噬"改成"契约/共生/谈判"。
- **学院篇拖沓**：校园日常与支线过多导致节奏涣散。规避方式：限定学院篇卷数，每卷必有阶段性高潮（考核/入侵/毕业战）推进。
- **后期境界膨胀**：金丹—元婴—化神—圣人的数字膨胀让早期积累失去意义。规避方式：用"质变节点"（每境界有质的差异）替代纯数字碾压。

> **力量代价的元法则**：本簇桥段涉及"血脉觉醒/异火吞噬/境界突破"时，题材层的口头建议不足以约束。强制性的元法则（U-1 法则惰性、U-2 代价不可消除、U-4 力量上限）见 `universe-atlas/clusters/framework.md`；玄幻世界的力量分级骨架（斗气/元力双参考的 L0~L8）与法则强度（LI）见 `universe-atlas/clusters/xuanhuan.md`。推导越级/血脉觉醒桥段时必须同时参照 framework 的 U-* 元法则，确保突破付出不可逆代价而非纯数字膨胀。

### 未覆盖子流派的推导路径

- **洪荒流**：从"洪荒圣人斩三尸"扩写——主角是先天神祇或洪荒大能，桥段改为"开天辟地""立教传道""封神大战""红云让座"等洪荒母题。
- **神话流/封神流**：从"血脉觉醒"反推——主角血脉源自上古神话人物（盘古/女娲/鸿钧），桥段改为"继承神位""重立封神榜""周天星斗大阵"。
- **御兽玄幻**：从"异火奇物收服"反推——收服对象从死物改为活物（神兽/灵宠），桥段改为"契约神兽""御兽进化""万兽图鉴"。
- **武道玄幻**：从"血脉觉醒"反推——主角不靠血脉而靠武道极致，桥段改为"武魂觉醒""武意领悟""一拳碎苍穹"。
- **位面/万界流**：从"大陆级排位赛"反推——排位跨位面进行，桥段改为"飞升万界""万界商会""位面之战"。
- **星际玄幻**：从"远古遗迹"反推——遗迹是星际文明遗产，桥段改为"觉醒星舰""星际古族""宇宙法则"。
