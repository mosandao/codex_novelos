# 诡异流 / 规则怪谈（参考：《动物园规则怪谈》《我有一座恐怖屋》《规则怪谈：国家队》）

> **世界观支柱**：以规则、异常、直播、组织串联为核心，靠"自相矛盾的规则文本 + 异常的因果律 + 围观直播机制 + 跨怪谈组织"支撑"细思恐极"的恐怖美学。
> **典型消费节奏**：开篇用一份矛盾规则钩住读者，中段以"规则推理 + 异常规避"高频供给智力恐怖，后段以"真相揭穿 + 跨怪谈串联"做长线收束。

## 桥段清单

### 规则守则降临
- **资源需求**：一份以"守则/须知/注意事项"形式出现的规则文本；规则与日常场景（动物园、医院、学校、小区）的违和搭配；规则中至少一处明显的自相矛盾。
- **爽点类型**：诡异氛围 + 好奇心驱动 + "哪里不对劲"的不安感。
- **消费时机**：每个新怪谈/副本的开篇钩子。
- **变体**：①纸质守则贴在场景入口；②APP/短信推送规则；③反套路"规则是日常的，违反规则的世界才是正常的"；④极端"规则会随主角的行为实时改写"。
- **消费绑定提示**：开篇钩子 + 高频爽点。每个新怪谈的第一章必消费；规则的矛盾点应作为本怪谈的高频推理素材。

### 矛盾规则推理
- **资源需求**：至少两条相互矛盾的规则（"遇到 X 必须做 A" vs "遇到 X 绝不能做 A"）；一套可推理的真假规则判断方法（场景细节、其他角色证词、试错）；主角的推理能力。
- **爽点类型**：解谜快感 + 智力优越感 + "细思恐极"的顿悟。
- **消费时机**：每个怪谈的中段，反复消费。
- **变体**：①靠物证推理真假规则；②靠人证推理（谁是"它"的化身）；③反套路"两条矛盾规则都是真的，只是条件不同"；④极端"规则本身没有真假，违反任何一条都触发不同后果"。
- **消费绑定提示**：高频爽点。每个怪谈的推理章节反复消费；推理结论应作为后续规避行为的依据。

### 异常规避与求生
- **资源需求**：一套违反规则会触发的异常后果（被替换、消失、变成"它"、时间循环）；一套可规避异常的手段（遵守真规则、识别"它"、特殊物品）；主角的求生本能。
- **爽点类型**：恐怖 + 求生 + 极限规避的爽感。
- **消费时机**：每个怪谈的高潮章节，伴随异常出现。
- **变体**：①物理规避（逃跑、躲藏）；②规则规避（遵守真规则）；③反套路"主动触发异常利用异常";④极端"异常其实是某种'升维'机制，触发后主角获得规则之外的能力"。
- **消费绑定提示**：高频爽点 + 阶段转折。每次异常规避作为本怪谈的高频爽点；当主角学会"利用异常"时应作为本卷阶段转折。

### 真相揭穿与"它"的真面目
- **资源需求**：一个被规则掩盖的真相（场景的真实性质、"它"的真实身份、规则制定者的目的）；主角揭穿真相的推理链；揭穿后的后果。
- **爽点类型**：世界观炸裂 + 智力碾压 + 宇宙级恐惧。
- **消费时机**：每卷尾或终卷，作为长线收束。
- **变体**：①"它"是上古存在；②"它"是规则制定者本身；③反套路"'它'其实是受害者，规则才是真正的恶"；④极端"'它'是读者/观众/更高维度的存在"。
- **消费绑定提示**：阶段转折 + 长线伏笔。每卷尾的真相揭穿作为本卷阶段转折；揭穿所需的线索应在前文怪谈中埋伏笔。

### 怪谈直播与围观机制
- **资源需求**：一套让怪谈被外部围观的机制（直播间、电视、监控、意识共享）；一群围观者（弹幕、观众、政府、组织）；围观者的反应与干预。
- **爽点类型**：群体围观 + 主角被注视的优越感 + "众人皆醉我独醒"的装逼感。
- **消费时机**：每个怪谈的中后段，作为爽点放大器。
- **变体**：①围观者只能看不能干预；②围观者可投票/打赏影响规则；③反套路"围观者其实也是怪谈的一部分"；④极端"围观者的注意力本身就是'它'的食物"。
- **消费绑定提示**：高频爽点。每个怪谈至少消费一次围观机制；围观者的弹幕/反应可作为推理线索的伏笔。

### 跨怪谈串联与背后组织
- **资源需求**：多个独立怪谈背后共享同一个秘密（"它"的网络、规则制定者、政府秘密机构）；一个串联多怪谈的组织（国家队、基金会、反抗军）；贯穿多卷的线索。
- **爽点类型**：世界观扩张 + 真相逼近 + 长线悬念。
- **消费时机**：第二卷末或第三卷正式展开，前期埋伏笔。
- **变体**：①政府秘密组织管理怪谈；②反抗组织对抗"它"；③反套路"组织本身就是'它'的延伸"；④极端"所有怪谈其实是同一个超大怪谈的不同入口"。
- **消费绑定提示**：长线伏笔 + 终卷阶段转折。第一卷起的每个怪谈细节都应被标注为此桥段的伏笔载体；组织真面目揭穿章作为终卷阶段转折。

### 规则制定者与因果律操控（新增）
- **资源需求**：一个有能力制定/修改规则的存在（神、AI、外星文明、人类集体潜意识）；一套规则制定的逻辑（实验、游戏、惩罚、保护）；主角与规则制定者的关系。
- **爽点类型**：终极真相 + 因果颠倒的震撼 + "我们都是被设计的"恐惧。
- **消费时机**：终卷高潮。
- **变体**：①规则制定者是善意的（规则是为了保护人类）；②规则制定者是恶意的（规则是屠宰场说明书）；③反套路"规则制定者已死，规则在自动运行"；④极端"主角自己就是规则制定者，只是失忆了"。
- **消费绑定提示**：长线伏笔全回收 + 终卷阶段转折。前文所有规则的"反常细节"应在此桥段集中解释。

### 国家队 / 官方应对怪谈（新增）
- **资源需求**：一个国家级的怪谈应对机构（特殊部门、军队、基金会式组织）；一套官方应对规则怪谈的流程与资源；主角与官方的关系（合作、对抗、被招募）。
- **爽点类型**：国家机器碾压 + 集体行动的爽感 + "原来国家早就知道"的安心感。
- **消费时机**：第二卷或第三卷引入官方，作为长线背景。
- **变体**：①官方高效应对；②官方束手无策需主角救场；③反套路"官方应对方式比怪谈本身更恐怖"；④极端"官方其实在与'它'合作"。
- **消费绑定提示**：阶段转折 + 长线伏笔。官方的介入章作为本卷阶段转折；官方的真实目的应作为长线伏笔至终卷揭穿。

### 异常物品与规则道具（新增）
- **资源需求**：一类可在规则之外发挥作用的特殊物品（护身符、识别镜、记录本、钥匙）；物品的来源与代价；物品的使用规则。
- **爽点类型**：装备升级 + 金手指 + "我有了对抗规则的筹码"的安全感。
- **消费时机**：每个怪谈中段获得新道具，后段使用。
- **变体**：①正统护身道具；②反常道具（道具本身有规则）；③反套路"道具其实是'它'的诱饵"；④极端"道具会用完，主角必须不断进入新怪谈补充"。
- **消费绑定提示**：高频爽点 + 长线伏笔。每怪谈至少获得一件道具作为高频爽点；其中关键道具应被标注为终卷串联大阴谋的伏笔。

### 多视角规则拼图（新增）
- **资源需求**：同一怪谈中多个角色各自看到不同版本规则；多视角的叙述差异；主角拼合多视角还原真相的能力。
- **爽点类型**：拼图快感 + "原来如此"的顿悟 + 叙述诡计的智力碾压。
- **消费时机**：复杂怪谈的中后段，作为推理高潮。
- **变体**：①多角色 POV；②同一角色不同时间的规则差异；③反套路"所有视角都是真的，因为怪谈本身在分裂"；④极端"主角自己的视角是假的，是被植入的"。
- **消费绑定提示**：阶段转折 + 长线伏笔。多视角拼合章作为本怪谈阶段转折；视角差异的伏笔应在前文埋下。

### 沙雕反套路与规则玩梗（新增）
- **资源需求**：一套可被主角"反向利用"或"钻空子"的规则漏洞；主角的非常规思维；规则的字面意义与精神的落差。
- **爽点类型**：解构恐怖 + 沙雕爽感 + "用怪谈的逻辑打败怪谈"的智力碾压。
- **消费时机**：作为部分章节的调剂，或定位为"沙雕流"全书基调。
- **变体**：①字面遵守规则钻空子；②反向触发异常利用；③反套路"主角把规则怪谈玩成经营游戏"；④极端"主角最终成为新规则的制定者"。
- **消费绑定提示**：高频爽点。作为恐怖章节的调剂反复消费；若全书定位沙雕流，则此桥段升格为主线消费点。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：规则文本设计
- **标准形态**：一份守则，10~20 条，其中 3~5 条相互矛盾，1~2 条是陷阱。
- **可变维度**：规则的格式（守则/短信/ signage）、矛盾的性质（直接矛盾/条件矛盾/视角矛盾）、陷阱的烈度、规则是否会变化。
- **衍生问题**：如果本书的 Architecture 核心引擎是"解谜"而不是"求生"，规则要不要更复杂、矛盾更密集？如果 Strategy 是"沙雕流"，规则要不要写得"看似恐怖实则漏洞百出"？

### 母题 2：异常的因果律
- **标准形态**：违反规则 → 触发异常 → 异常按自己的逻辑演化。
- **可变维度**：异常的可见度（只有当事人可见 vs 全场可见）、异常的可逆性、异常的"传染性"、异常是否带规则提示。
- **衍生问题**：如果本书定位"硬核恐怖"，异常要不要彻底不可逆、不可知？如果核心引擎是"博弈"，异常是否可以作为主角攻击对手的武器？

### 母题 3：围观机制的伦理
- **标准形态**：怪谈被直播/共享，围观者反应作为爽点放大器。
- **可变维度**：围观者的身份（普通观众/政府/组织/另一个"它"）、围观者的干预能力、围观者自身的风险。
- **衍生问题**：如果本书核心引擎是"求生"，围观者要不要彻底无能为力以增加绝望？如果 Strategy 是"国家队流"，围观者要不要反过来成为官方调度的资源？

### 母题 4：串联的方式
- **标准形态**：多个独立怪谈背后共享同一组织/真相。
- **可变维度**：串联的密度（每怪谈一线索 vs 几怪谈一汇总）、串联的性质（组织/存在/规则制定者）、串联揭穿后是否还能有独立怪谈。
- **衍生问题**：如果本书是"纯单元怪谈"，串联要不要砍掉？如果核心引擎是"博弈"，串联要不要改组为"主角与组织的长期对抗"？

### 反套路与"烂大街"风险
（综合用户提供的调研素材 + WebSearch 结果，来源包括中国作家网《动物园中的卡夫卡——规则怪谈与控制社会》、知乎与 B 站的多篇解析等）
- **网文爽点与"细思恐极"相悖**：规则怪谈原生的"卡夫卡式无解之解"魅力，与网文的"爽点密集供给"天然冲突——一旦主角太强、爽点太足，恐怖感就被稀释；一旦追求恐怖，爽点又被压制。World Agent 应在契约中明确本书的"恐怖/爽点"配比。
- **模板化严重**：《动物园规则怪谈》之后大量衍生（医院、学校、超市、小区）套用同一模板，读者批评"换个场景换个名字"。建议为每个怪谈设计独有的规则母题，而不是套用动物园模板。
- **为水字数而水字数的围观讨论**：直播/弹幕/围观者反应被批评为"水字数重灾区"，长篇围观讨论拖慢节奏。建议围观内容必须服务于推理或人物塑造，严格控制篇幅。
- **"一旦开启推理就会被一直推理"的魅力被消解**：中国作家网指出《动物园》的魅力在于"每一次推理都不带来真相，只拉入更深迷雾"，而网文为了爽点往往急于给出明确答案，消解了这种魅力。建议保留至少一个"无解之谜"至终卷。
- **国家队/官方介入后的套路化**：一旦官方强势介入，怪谈的恐怖感被"国家机器碾压"消解，沦为爽文。建议官方介入后保留"官方也无法完全掌控"的灰色地带。
- **规则文本堆砌**：为炫技而堆砌长篇规则，被批评"看不动"。建议规则文本精炼，矛盾点集中。
- **"它"的真面目套路化**：上古存在/外星/规则制定者已用滥。建议"它"的真面目有反预期设计。

### 未覆盖子流派的推导路径
- **本格规则推理流**：从"矛盾规则推理"加强推导，弱化恐怖与求生，每个怪谈是一份可解的逻辑谜题。
- **变格 / 纯恐怖流**：把"异常规避"权重压到最高，弱化推理，强调氛围与不可名状，可参考 `cthulhu.md`。
- **国家队 / 基金会流**：把"官方应对"与"跨怪谈组织"作为主线，主角是组织成员，每个怪谈是一次出勤任务，可参考 `infinite.md` 的副本结构。
- **无限怪谈流**：嫁接 `infinite.md`，主角在主神空间/规则空间中穿梭不同怪谈副本。
- **沙雕反套路流**：把"沙雕反套路"作为全书基调，主角钻规则空子、把恐怖场景玩成经营游戏。
- **怪谈 + 系统流**：叠加系统（参考 `system.md`），把"规则推理"升级为"系统提示"，把"异常物品"升级为"系统掉落"。
- **怪谈 + 都市灵气**：嫁接 `urban-qi.md`，主角是异能者，规则怪谈是异能世界的隐秘角落。
- **怪谈直播 / 网游流**：把"围观机制"作为主线，嫁接 `game-esports.md`，怪谈是直播平台的内容，主角是主播。
