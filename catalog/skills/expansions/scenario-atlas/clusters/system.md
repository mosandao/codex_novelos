# 系统流（参考：《神豪从签到开始》《百年签到系统》《我有一个属性板》等签到/任务/抽奖类系统文）

> **世界观支柱**：以"系统"为核心金手指，通过签到、任务、商城、抽奖等机制向主角持续输送资源与目标，系统本身可工具、可导师、可对手。
> **典型消费节奏**：高频低门槛爽点（每章签到/任务奖励），节奏明快，平均 5~10 章一个小爽点、30~50 章一个大转折。

## 桥段清单

### 系统觉醒绑定
- **资源需求**：可被绑定的系统（签到/任务/属性板/商城类）、觉醒契机（穿越、重生、生死、怨念）、系统与主角的接口（界面、语音、意念）。
- **爽点类型**：命运改写 + 金手指确立 + 独特性承诺。
- **消费时机**：第一卷开篇 1~5 章，全书爽点来源的奠基。
- **变体**：①标准——意外绑定系统获得金手指；②反转——系统是诅咒/契约，每用一次付代价；③极端——系统是上界大能的实验品；④反套路——主角反向"黑入"系统，自定规则。
- **消费绑定提示**：标注为「开篇钩子」+「长线伏笔」。消费场景：开篇即绑定系统，作为"爽点来源契约"向读者承诺；同时埋下"系统来源/真实目的"作为长线伏笔（如系统其实是反派）。

### 签到每日奖励
- **资源需求**：签到机制（地点签到/时间签到/特殊地点加倍）、奖励梯度（普通/稀有/神器）、签到地点地图（名山大川/隐世家族/禁地）。
- **爽点类型**：躺赢养成 + 收集惊喜 + 低门槛爽感。
- **消费时机**：贯穿全书的高频爽点，几乎每章可消费。
- **变体**：①标准——每日签到领奖稳定变强；②反转——签到奖励引来追杀（神器认主）；③极端——签到地点难度递增，需主角越级抵达；④反套路——签到奖励是"知识/记忆"而非实物，需主角自行转化。
- **消费绑定提示**：标注为「高频爽点」。消费场景：每章末尾或每卷开篇固定插入一次签到，作为稳定爽点节拍器，调节剧情节奏。

### 任务成就解锁
- **资源需求**：任务发布机制（主线/支线/隐藏/限时）、任务与剧情世界的接口、奖励与惩罚规则。
- **爽点类型**：目标驱动 + 成就感 + 意外惊喜（隐藏任务）。
- **消费时机**：贯穿中段，作为剧情推进的引擎。
- **变体**：①标准——完成任务获得奖励；②反转——任务实为系统设下的陷阱；③极端——任务目标与主角道德冲突；④反套路——主角反向给系统派任务（系统是打工仔）。
- **消费绑定提示**：标注为「高频爽点」+「阶段转折」。消费场景：每卷主线用一组任务串联，阶段性大任务（如"成就：宗师"）作为卷末高潮。

### 商城兑换体系
- **资源需求**：商城货币（积分/系统币）、商品梯度（功法/丹药/血脉/技能/召唤物）、稀缺商品解锁条件。
- **爽点类型**：资源选择 +养成路径分化 + 期待感。
- **消费时机**：第二卷起，主角积累货币后展示选择。
- **变体**：①标准——主角用积分兑换稀缺资源；②反转——商城有隐藏商品需特殊条件解锁；③极端——主角可以上架商品反向交易；④反套路——商城货币可兑换"概念"（如寿命、记忆、命运）。
- **消费绑定提示**：标注为「高频爽点」。消费场景：每隔 20~30 章安排一次商城消费（如兑换新功法/新血脉），作为实力跃升的固定节点。

### 抽卡抽奖扭蛋
- **资源需求**：抽奖机制（单抽/十连/保底）、奖池梯度（普通/稀有/SSR/隐藏）、抽奖券获取途径。
- **爽点类型**：赌博快感 + 惊喜爆表 + 非酋/欧皇反差。
- **消费时机**：贯穿中段，作为间歇性高潮。
- **变体**：①标准——主角十连出 SSR 惊艳全场；②反转——抽中"诅咒物品"引来麻烦；③极端——抽中的物品/人物有自己的剧情线；④反套路——主角是"非酋"，靠保底和拼凑取胜。
- **消费绑定提示**：标注为「高频爽点」。消费场景：每隔 15~25 章安排一次抽奖，作为节奏调剂与小高潮，可与签到/任务奖励联动。

### 系统真相升级
- **资源需求**：系统的多层身份（工具/导师/对手/反派/上界投影）、升级机制、真相揭示的伏笔链。
- **爽点类型**：世界观升维 + 反转震撼 + 长线伏笔回收。
- **消费时机**：中后段或末卷，全书最大反转之一。
- **变体**：①标准——系统升级揭示真实身份（如上界至宝）；②反转——系统是反派，主角一直被利用；③极端——系统是主角未来的自己；④反套路——主角反吞系统，自己成为新系统。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：中段埋伏笔（系统异常/隐藏界面），末卷揭示真相作为全书最大反转。

### 系统对决多系统博弈
- **资源需求**：多系统并存设定（其他宿主/系统阵营）、系统间博弈规则、宿主对决舞台。
- **爽点类型**：智斗 + 金手指碰撞 + 阵营对抗。
- **消费时机**：中后段，主角与同类的正面博弈。
- **变体**：①标准——主角系统碾压其他宿主；②反转——对方系统更高级，主角靠智谋取胜；③极端——多系统宿主联合对抗"系统之源"；④反套路——主角与对方宿主私下结盟对抗各自系统。
- **消费绑定提示**：标注为「阶段转折」+「高频爽点」。消费场景：中后段引入其他宿主作为新宿敌，每次对决即一次高潮，同时为"系统之源"主线埋伏笔。

### 神豪数值膨胀
- **资源需求**：可量化的资源体系（金钱/积分/属性点）、消费场景（豪车/豪宅/拍卖/投资）、数值膨胀的合理性（系统兜底）。
- **爽点类型**：财力碾压 + 装逼打脸 + 数字快感。
- **消费时机**：第二卷起，主角脱离初始窘境后的稳定爽点。
- **变体**：①标准——主角挥金如土打脸势利眼；②反转——主角隐藏财力装穷体验生活；③极端——主角用金钱撬动整个行业/城池；④反套路——主角把钱全捐出去靠"功德系统"变强。
- **消费绑定提示**：标注为「高频爽点」。消费场景：每卷安排 1~2 次大型消费场景（拍卖会/收购战/慈善），作为财力展示的固定节点。

### 听劝/选择系统
- **资源需求**：选择机制（多选一/网友建议/系统推荐）、选项的差异化后果、外部信息源（网友/观众/弹幕）。
- **爽点类型**：互动感 + 选择反差 + 意外喜剧效果。
- **消费时机**：贯穿中段，作为节奏调剂与剧情分支。
- **变体**：①标准——主角听从网友/系统建议获得奇效；②反转——选择看似最优实为陷阱；③极端——所有选项都是坑，主角自创第四选；④反套路——主角反向"听劝"系统，给系统出选择题。
- **消费绑定提示**：标注为「高频爽点」。消费场景：每隔 10~20 章安排一次重大选择，作为剧情分支点与读者代入感设计。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：系统与主角的关系定位
- **标准形态**：系统是主角的金手指工具，被动提供服务，主角是使用者。
- **可变维度**：系统主动性（工具/导师/对手/寄生者）、系统人格（无情/AI/有情感/反派）、系统与主角的权力关系（服务/合作/控制/敌对）。
- **衍生问题**：如果本书核心引擎是"系统即反派"，签到/任务会从"奖励"变成什么？如果 Strategy 把"系统觉醒人格"从末卷挪到第二卷，主角该如何应对一个有自我意志的金手指？

### 母题 2：任务/签到驱动与剧情自然性
- **标准形态**：系统发布任务，主角执行获得奖励，任务即剧情主线。
- **可变维度**：任务来源（系统/世界/主角自定）、任务与人物动机的契合度、任务失败后果（扣分/惩罚/系统反噬）。
- **衍生问题**：如果本书核心引擎是"人物驱动而非任务驱动"，系统任务会从"主线"退化成什么角色？主角是该追任务，还是该被自己的目标驱动而忽略任务？

### 母题 3：系统机制深度与可玩性
- **标准形态**：签到+任务+商城+抽奖四件套，机制清晰，爽点稳定。
- **可变维度**：机制复杂度（简单/嵌套/隐藏层）、机制与世界观的接口（系统是否融入世界法则）、机制的代价与限制。
- **衍生问题**：如果本书核心引擎是"机制博弈"而不是"躺赢"，系统机制该增加哪些约束（冷却/反噬/被发现风险）？什么样的约束会让"签到"从躺赢变成智斗？

### 母题 4：多系统世界的博弈结构
- **标准形态**：主角不是唯一宿主，存在其他系统/宿主，形成阵营对抗。
- **可变维度**：系统种类（同源/异源/敌对）、宿主关系（竞争/合作/亦敌亦友）、系统背后的上位者博弈。
- **衍生问题**：如果本书核心引擎是"阵营博弈"，多系统会从"单挑碾压"变成什么？主角是该消灭其他宿主，还是该联合对抗"系统之源"？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评的集中意见：

- **签到流"躺赢"丧失紧张感**：知乎与 QQ 阅读专栏指出，签到流"省去了做任务的步骤，躺赢即可"，导致"缺乏人性的各种转变""太直白"。规避方式：让签到奖励伴随代价（神器认主引来追杀、稀有物品暴露身份），或限定签到地点迫使主角越级冒险。
- **任务驱动逻辑断裂**：搜狐文章指出，作者围绕系统任务组织剧情"连逻辑也无需过多顾及"，导致剧情为任务服务而非为人物服务。规避方式：让任务目标与主角个人动机一致，或让主角主动"自定义任务"。
- **数值膨胀与爽点麻木**：商城/抽奖带来的资源堆叠使早期积累失去意义，读者对"又抽到 SSR"逐渐麻木。规避方式：用"质变节点"（新功能/新接口）替代纯数量增长，让每次大奖解锁新玩法而非只是数字+1。
- **系统真相同质化**：末卷"系统是反派/上界投影"已成标配。规避方式：让系统真相与主角个人成长深度绑定（如系统是主角未来的悔恨/至亲的馈赠），避免纯外部反转。
- **金手指过强导致无冲突**：系统兜底让主角几乎无失败可能。规避方式：给系统设明确限制（每日额度/冷却/不可干涉某类事件），让主角在限制内博弈。

### 未覆盖子流派的推导路径

- **反派系统**：从"系统真相升级"反推——主角绑定的系统要求他扮演反派，桥段改为"反派任务""气运之子对抗""反派洗白"。
- **无敌流/躺平流**：从"签到每日奖励"扩写——主角开局即无敌，桥段重心从"变强"转向"伪装弱者""日常装逼""带飞配角"。
- **种田/经营系统**：从"商城兑换体系"反推——主角用系统经营领地/宗门/公司，桥段改为"领地建设""资源调度""势力扩张"。
- **直播/弹幕系统**：从"听劝选择系统"反推——主角被直播/弹幕围观，桥段改为"观众打赏""弹幕互动""舆论博弈"。
- **亡语/死亡回归系统**：从"系统真相升级"反推——主角每次死亡回归重来，桥段改为"死亡循环""信息差利用""轮回破局"。
- **气运/气数系统**：从"任务成就解锁"反推——系统操控气运，桥段改为"夺人气运""气运之子""天道博弈"。
- **属性板/熟练度系统**：从"签到每日奖励"反推——主角靠属性板/熟练度面板变强，桥段改为"刷熟练度""技能组合""面板博弈"。
