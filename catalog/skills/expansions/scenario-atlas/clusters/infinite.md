# 无限流（参考：《无限恐怖》《轮回乐园》《王牌进化》）

> **世界观支柱**：以一个核心枢纽（主神空间 / 轮回乐园 / 系统）连接众多规则各异的副本世界，轮回者在副本中执行任务、赚取积分、强化兑换、最终对抗或逃离枢纽本身。
> **典型消费节奏**：副本内高频爽点（解谜 + 战斗 + 反杀）+ 副本间休整期长线伏笔（强化升级、组织阴谋），副本结束的"结算时刻"是公认最强爽点节点。

## 桥段清单

### 主神任务副本进入
- **资源需求**：一个能强制或诱导轮回者进入副本的枢纽（主神空间 / 轮回乐园 / 系统面板）；至少一种"进入契约"机制（生死绑定 / 抹杀威胁 / 利益诱惑）；副本世界库（动漫 / 电影 / 游戏 / 原创）。
- **爽点类型**：未知世界探险的猎奇爽 + 强制任务下的紧迫感，开篇钩子级爽点。
- **消费时机**：第一卷第一章 / 第一节必消费；后续每开启新副本时复用。
- **变体**：①经典球形主神点名传送；②网页广告 / 手机 APP 诱导签约；③死亡瞬间被拉入轮回空间；④签订轮回契约自由加入（轮回乐园式独行侠）；⑤被动卷入跨空间战争。
- **消费绑定提示**：标注为**开篇钩子**。具体场景：第一卷第一章用一次"被迫进入第一个副本"完成世界规则抛出与主角金手指激活，必须在 3 章内交付第一次副本生存危机。

### 副本生存（推进剧情 / 击杀目标 / 守护 NPC）
- **资源需求**：副本世界本身的世界观与剧情线；主角的能力面板与装备；副本主线任务与隐藏支线；副本原住民 NPC。
- **爽点类型**：解谜 + 战斗 + 逆袭，是无限流最高密度的复合爽点来源。
- **消费时机**：每个副本中段持续消费，全书 60% 以上的字数发生在此桥段。
- **变体**：①经典恐怖片生存（丧尸 / 异形 /咒怨）；②动漫世界改写剧情；③游戏副本通关；④原创奇幻世界冒险；⑤与原著角色的暧昧 / 收编 / 击杀。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每个副本的中段必须每 3~5 章交付一次"任务推进 + 危机反转"的小高潮，副本结尾交付一次大爽点（击杀 BOSS / 完成隐藏任务）。

### 团队内斗与背叛
- **资源需求**：以"队"为单位的轮回者组织（或反队制的独行设定）；轮回者之间的利益冲突来源（积分 / 道具 / 任务目标冲突）；新人的淘汰机制。
- **爽点类型**：人性博弈 + 反杀打脸，信任崩塌带来的戏剧张力。
- **消费时机**：第二卷起开始铺设，每个长副本的中后段集中爆发；新人副本必有一次。
- **变体**：①老队员坑杀新人夺积分；②队长背叛全队投靠主神；③不同队伍间空间战争；④独行侠被组队者围剿反杀；⑤队友被副本腐蚀黑化。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷末用一个"信任危机"事件把主角从团队模式转向独行 / 重组队伍，作为本卷的情绪转折点。

### 强化兑换与属性养成
- **资源需求**：主神空间的兑换大厅 / 属性强化系统 / 商城；可兑换的血统（血族 / 基因 / 神族）、技能、装备、道具；积分获取规则。
- **爽点类型**：养成 + 数值膨胀 + 跨体系组合（如把魔法血统塞进科幻副本）。
- **消费时机**：每个副本结束后的"休整期"必消费；中期开始出现跨血统组合爽点。
- **变体**：①经典六维属性 + 技能树兑换；②血统融合（多血统叠加）；③装备锻造 + 附魔；④召唤物 / 宠物养成；⑤禁止兑换、只能副本内自取的硬核模式。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每个副本结算后用一整章展示"兑换 + 强化 + 数值飞跃"，紧接下一副本开局让新能力立刻实战验证。

### 回归休整（现实世界锚点）
- **资源需求**：副本之间的"现实世界"或专属房间；现实世界的牵挂（家人 / 恋人 / 朋友）；现实世界与副本世界的力量落差。
- **爽点类型**：温情 + 反差爽（在现实用副本能力装逼 / 解决现实问题）。
- **消费时机**：每 2~3 个副本穿插一次；全书共 3~5 次重要休整。
- **变体**：①回现实陪家人隐藏身份；②现实中也出现怪物需轮回者清剿；③现实世界其实也是某个副本；④专属房间内独自休整独行侠流；⑤现实世界的平凡日常与副本的残酷形成强烈反差。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第一卷末安排一次"回现实却发现现实已被轮回空间渗透"的伏笔，为第三卷的"现实崩塌"主线埋线。

### 副本隐藏剧情与彩蛋
- **资源需求**：副本原著剧情线的隐藏分支；触发条件（特殊道具 / 特定选择 / 击杀隐藏 BOSS）；隐藏奖励（高序列道具 / 主神空间权限 / 剧情真相碎片）。
- **爽点类型**：智斗 + 信息差爽 + 截胡原著主角机缘。
- **消费时机**：每个副本的结尾高潮段消费；长线贯穿全书。
- **变体**：①取代原著主角获得机缘；②触发原著反派剧情线反杀主角团；③找到原著未解之谜的真相；④触发跨副本串联的隐藏剧情；⑤获得"主神空间起源"碎片信息。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷某个副本结尾让主角意外获得一条指向"主神空间真相"的隐藏线索，作为本卷升级为长线主线的钩子。

### 主神空间阴谋与反抗
- **资源需求**：主神 / 枢纽的真实身份与目的；轮回者觉醒真相的途径；反抗主神的组织或前人遗产；高维存在（主神背后的更大存在）。
- **爽点类型**：真相揭露 + 弱者反抗强权 + 史诗感。
- **消费时机**：第三卷起开始揭露，全书后 1/3 主线。
- **变体**：①主神是被困的高维存在，轮回者是它的电池；②主神是未来人类建的试炼场；③主角本身就是上一轮主神的转世；④轮回空间是多位主神的博弈棋盘；⑤打破轮回、回归现实的终极反杀。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第一卷某副本里埋一个"主神为何选中我"的疑点，第三卷揭晓，作为全书高潮的引爆点。

### 跨副本道具 / 伙伴 / 召唤物积累（新增）
- **资源需求**：副本世界间的物品流通规则；可带出的伙伴 / 召唤物 / 宠物契约系统；带出物在现实 / 主神空间的限制（如召唤次数、能量消耗）。
- **爽点类型**：收集养成 + 战力叠加 + 跨世界 CP / 兄弟羁绊。
- **消费时机**：第二卷起开始积累，每副本至少进账一项；中期形成"主角团"战力体系。
- **变体**：①收服副本 BOSS 当召唤兽；②带回原著主角当队友；③收集神兵拼图合成神器；④带回副本世界的科技 / 魔法体系反哺主神空间；⑤伙伴在后续副本中牺牲制造泪点。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每个副本结尾结算时必有一个"收获展示"环节，其中至少一个副本收获的是活体伙伴，为后续团队线服务。

### 主神任务评级与排行（新增）
- **资源需求**：主神空间的任务评级系统（S/A/B/C/D）；轮回者排行榜与积分榜；评级对应的额外奖励与惩罚；轮回者之间的名声传播机制。
- **爽点类型**：数值爽 + 排名逆袭 + 同行震惊流（"那个新人又拿 S 评级了"）。
- **消费时机**：第二卷起每个副本结算必消费；中期出现全空间排行震动。
- **变体**：①单人 S 级通关震惊全空间；②连续 S 级触发隐藏称号；③评级垫底被抹杀的危机；④排行榜第一的老牌强者关注主角；⑤评级系统本身有黑幕（某些任务被故意调低难度）。
- **消费绑定提示**：标注为**高频爽点**。具体场景：第二卷开局用一个"超难副本拿下 S 级"事件让主角在轮回空间一战成名，作为本卷的名声跃升节点。

### 独行侠 vs 组队流派冲突（新增）
- **资源需求**：主神空间对独行与组队的差异化奖励机制；独行流的特殊职业（狩猎者 / 清道夫 / 赏金猎人）；组队流的团队副本与团队战。
- **爽点类型**：流派之争 + 个体战力碾压团队 + 反套路爽。
- **消费时机**：第二卷中段开始体现流派分歧，第三卷升级为空间级冲突。
- **变体**：①独行侠被大型团队围剿反杀；②主角组建自己的精英小队融合两派优势；③独行流鼻祖收主角为徒；④组队流团队内部分裂出独行者；⑤空间战规则改变迫使两派合作。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷中段让主角在"加入老牌强队"与"坚持独行"之间做一次重大选择，该选择决定第三卷的剧情走向。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：副本世界的"原著知识差"
- **标准形态**：主角进入已知动漫 / 电影 / 游戏副本，凭借对原著剧情的了解截胡机缘、规避死亡点。
- **可变维度**：副本来源（知名 IP / 冷门 / 原创）；主角对原著的熟悉度（全知 / 半知 / 完全陌生）；副本是否会因主角行为偏离原著。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"原创副本"而非"知名 IP 副本"，这个桥段会变成什么形态？是否需要一个"副本预言 / 副本攻略库"作为替代金手指？如果 <Strategy 阶段目标> 把"原著知识差"从第一卷挪到第三卷才失效（主角终于遇到没看过的副本），需要前置哪些世界资源？

### 母题 2：主神空间的"被控制 vs 反控制"张力
- **标准形态**：主神以抹杀威胁控制轮回者，轮回者后期觉醒反抗主神。
- **可变维度**：主神的真实身份（神 / AI / 未来人 / 被困高维存在）；主神对轮回者的态度（工具 / 实验 / 养蛊 / 培养继承人）；反抗的可行性（可推翻 / 不可推翻只能逃离 / 反抗本身就是主神的剧本）。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"主神其实是主角的未来自我"而不是"外在高维存在"，这个桥段会变成什么形态？反抗主神是否变成自我和解？如果 <Strategy 阶段目标> 把"主神真相揭露"提前到第二卷而非第三卷，整个故事的爽点结构会如何重组？

### 母题 3：积分兑换系统的"经济闭环"
- **标准形态**：副本赚积分 → 主神空间兑换血统 / 技能 / 装备 → 强化后挑战更难副本赚更多积分。
- **可变维度**：积分的稀缺度（通胀 / 通缩）；兑换池的开放度（全开放 / 部分锁定 / 抽奖制）；是否允许轮回者之间交易；带出副本物的限制。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"禁止兑换、只能副本内自取"的硬核模式而非"自由兑换"，这个桥段会变成什么形态？经济闭环如何重建？如果 <Strategy 阶段目标> 在第二卷引入"轮回者间的黑市交易"，需要前置哪些势力与规则？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评素材（起点club、豆瓣读书、知乎专栏、write-on-paper.wikidot）：

- **模板化严重**：自《无限恐怖》确立"球形主神 + 积分任务 + 抹杀惩罚"框架后，大量作品照搬同一模板，被读者批评为"填空式写作"。规避：主神形态、契约机制、惩罚方式至少有一项反常规（如主神是一本书 / 一个 APP / 一群投票的观众）。
- **副本选材雷同**：丧尸、异形、咒怨、生化危机被反复使用，读者审美疲劳。规避：优先选冷门 IP 或大比例原创副本，或对经典副本做反转（如丧尸副本里丧尸才是原住民，轮回者是入侵者）。
- **"被主神控制"的老梗已被反套路消解**：读者已不满足于主角被动受控，"主角穿越逐渐成为自身金手指""反主神流"成为新趋势。规避：在第一卷就埋下"主角对主神有特殊性"的伏笔，而不是拖到第三卷才觉醒反抗。
- **同质化的套话分析**：连评论文章都用相同套话分析无限流，说明该流派的陈词滥调已渗透到元层面。规避：核心设定（枢纽性质 / 副本来源 / 强化方式）至少有一项是不可被"标准模板"覆盖的原创点。

### 未覆盖子流派的推导路径

- **综漫无限**：副本全部来自动漫 IP，可从"副本隐藏剧情彩蛋"母题推导出"跨 IP 联动彩蛋"变体（如在火影副本里发现海贼王的彩蛋）。
- **电影无限 / 恐怖无限**：副本全部来自恐怖电影，强化"副本生存"的恐怖解谜维度，弱化"强化兑换"的数值维度，从"主神任务评级"反推出"无评级、只看活下来的硬核排行"。
- **主神流变体（玩家为主神）**：主角自己就是主神或主神候选，从"主神空间阴谋"反推出"主神选秀 / 主神养蛊"桥段——多个候选主神各自培养轮回者军团对抗。
- **数据流 / 游戏化无限**：副本是游戏数据构成，从"强化兑换"推导出"代码修改 / 卡 BUG"作为强化途径，从"副本隐藏剧情"推导出"未公开测试内容的隐藏地图"。
- **反无限（逃离轮回）**：核心目标不是变强而是逃出轮回空间，从"主神空间阴谋"反推出"前人逃离者的遗产路线图"作为主线钩子。
