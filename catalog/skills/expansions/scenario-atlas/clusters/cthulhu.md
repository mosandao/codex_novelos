# 克苏鲁 / 序列流（参考：《诡秘之主》《黎明之剑》蒸汽朋克 + 克苏鲁衍生）

> **世界观支柱**：以"序列魔药 + 扮演消化 + 仪式晋升"为超凡力量核心，辅以"知识即污染、神性与人性的对立"作为克苏鲁式宇宙恐怖底色；秘密结社、教会、神位序列构成势力格局。
> **典型消费节奏**：低频高强度——日常调查铺设悬疑（长线伏笔）+ 关键仪式 / 晋升节点的爆发（阶段转折），读者期待"压抑—爆发—更深压抑"的螺旋节奏，而非高频爽点。

## 桥段清单

### 魔药晋升与扮演消化
- **资源需求**：序列魔药配方体系（主材料 = 非凡特性 + 辅助材料）；扮演法（按途径人设行动以消化魔药）；失控机制（不消化则疯狂变异）；魔药材料来源（异常生物 / 黑市 / 教会配给）。
- **爽点类型**：养成 + 能力解锁 + 扮演的戏剧感（主角被迫演一个与本性相反的人设）。
- **消费时机**：第一卷首次晋升（开篇钩子）；之后每个序列晋升节点（阶段转折），全书共 7~10 次晋升。
- **变体**：①经典单途径晋升；②双途径 / 多途径融合（高难度高回报）；③跳序列（用更高序列魔药强行压低途径）；④反向消化（先失控再回收）；⑤他人代为扮演协助消化。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第一卷末让主角第一次成功消化魔药 + 展现新能力，作为本卷的能力跃迁节点；每卷至少一次晋升作为卷末高潮。

### 教会任务与教会体系
- **资源需求**：至少一家主流教会（如蒸汽与机械之神、愚者、黑夜女神式教会）；教会的神位序列途径垄断；教会内部等级与异端审判机制；教会与世俗政权的关系。
- **爽点类型**：组织归属感 + 任务驱动冒险 + 教会内部权谋。
- **消费时机**：第一卷中段主角接入教会体系；第二卷起教会任务成为副本驱动器。
- **变体**：①主角是教会正式成员（正教士流）；②主角是教会编外协查者（半官方流）；③主角潜伏敌对教会卧底；④主角创立新教会 / 异端教派；⑤多教会平衡主角被多方拉拢。
- **消费绑定提示**：标注为**开篇钩子**。具体场景：第一卷前 10 章让主角通过一次教会任务获得第一个序列魔药配方，把"教会"作为主角接入超凡世界的入口。

### 异常调查与案件侦破
- **资源需求**：都市 / 港口 / 蒸汽朋克城市背景；连环异常事件（污染源 / 失控者 / 邪教仪式）；调查手段（占卜 / 灵视 / 物证 + 推理）；调查机构（警察 / 教会异端裁决 / 私人侦探）。
- **爽点类型**：悬疑推理 + 信息揭露 + 智斗，克苏鲁流的核心爽感来源。
- **消费时机**：贯穿全书每个卷的中段，作为卷主线推进的骨架。
- **变体**：①单元剧式独立案件；②连环案指向同一邪教；③案件真相牵扯教会高层；④主角就是案件元凶（反套路）；⑤案件是某位神明的"剧本"。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每卷中段安排一个 5~8 章的"调查单元"，结尾必有一次"真相揭露 + 战斗爆发"的双高潮。

### 仪式举行与仪式反制
- **资源需求**：仪式规则（特定时间 / 地点 / 材料 / 咒文 / 参与者）；仪式的目的（晋升 / 召唤 / 献祭 / 封印）；仪式被打断或被劫持的可能性；高序列仪式对环境的影响。
- **爽点类型**：宏大场面 + 紧张博弈 + 反转（仪式被截胡 / 反向利用）。
- **消费时机**：每卷高潮段消费；全书后段的神位争夺必经多次大型仪式。
- **变体**：①主角主导晋升仪式；②主角破坏敌对仪式；③主角冒名顶替完成他人仪式窃取成果；④仪式召唤出意外存在；⑤仪式其实是更大仪式的一部分（套娃反转）。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷高潮用一个"大型仪式被主角截胡"事件，让主角获得关键序列魔药材料，同时把反派势力推到台前。

### 知识污染与疯狂代价
- **资源需求**：知识 / 信息的污染属性（越深知的真相越疯狂）；神性与人性的拉扯；"锚"机制（维持人性的牵挂）；失控者的形态与危害。
- **爽点类型**：恐怖氛围 + 悲剧美学 + 力量代价的沉重感（区别于无代价爽文）。
- **消费时机**：第二卷起开始铺设代价感，全书后段集中爆发主角的失控危机。
- **变体**：①主角每次晋升都失去一段记忆；②主角必须定期回锚点（家人 / 恋人）稳人性；③同伴失控主角被迫亲手了结；④主角主动拥抱部分神性换取战力；⑤最终主角是否还算是"人"成为终极命题。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第一卷某次晋升后让主角短暂出现"失控幻觉"，为第三卷的"主角人性保卫战"主线埋线。

### 神位序列 0 争夺
- **资源需求**：序列 0 = 神位的设定；空缺或可夺取的神位；多位竞争者（其他途径的天使 / 教会 / 秘密组织）；成神仪式与代价。
- **爽点类型**：史诗感 + 弱者夺神 + 终极目标达成。
- **消费时机**：第三卷 / 全书后 1/4 主线，最终卷高潮。
- **变体**：①主角自己登神；②主角扶持他人登神；③主角阻止任何人登神（反套路）；④神位被瓜分多人共享；⑤登神其实是被旧神吞噬的陷阱。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第一卷某条支线暗示某个空缺神位的存在，第三卷揭晓该神位是全书争夺的核心，作为终极目标的引爆点。

### 秘密结社（塔罗会式组织）
- **资源需求**：一个跨途径 / 跨势力的秘密组织；成员之间的代号与信息差机制（互相不知真实身份）；组织的共同目标与内部博弈；集会仪式（如塔罗会的"塔罗会议"）。
- **爽点类型**：信息差爽 + 多重身份扮演 + 组织养成。
- **消费时机**：第一卷末或第二卷初主角加入 / 创建组织；贯穿全书作为长线。
- **变体**：①主角是组织成员（塔罗会式平等）；②主角是组织创建者与隐藏领袖；③组织其实是某位神明的棋子；④组织内部有卧底与清洗；⑤组织跨世界 / 跨时间运作。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷初让主角加入一个秘密结社，借此认识跨途径的同伴，作为本卷从"独行"转向"组织战"的转折点。

### 途径能力开发与组合技（新增）
- **资源需求**：单途径的能力树（序列 9 到序列 0 的能力演进）；多途径能力的组合可能性；能力的非战斗应用（占卜 / 伪装 / 操纵记忆 / 制作神奇物品）。
- **爽点类型**：智斗 + 能力妙用 + 数值之外的"创意爽"。
- **消费时机**：每个序列晋升后必消费一次"新能力开发"；中后期出现跨途径组合技。
- **变体**：①把占卜能力用到极致成侦探流；②把观众 / 读心者能力用于权谋操纵；③双途径能力组合出意料外的效果；④能力的副作用反而成为关键武器；⑤把能力封入物品做成神奇物品贩卖。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每次序列晋升后用一整章展示"主角对新能力的创意开发 + 实战验证"，确保晋升不止是数值提升而是质变。

### 锚与人性牵挂（新增）
- **资源需求**：主角在凡人世界的牵挂（家人 / 恋人 / 朋友 / 故乡）；神性侵蚀的具体表现；锚点失守的后果；主角为守护锚点与超凡世界的冲突。
- **爽点类型**：温情 + 悲剧张力 + 守护爽。
- **消费时机**：第二卷起反复消费锚点的危机，全书后段集中爆发"锚点崩塌"。
- **变体**：①家人不知主角身份，主角双重生活；②恋人被卷入超凡事件主角被迫暴露；③锚点是人造物 / 一个约定 / 一段记忆而非活人；④锚点本身是某位存在的化身；⑤主角主动放弃锚点换取神性（黑化分支）。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第一卷铺设一个温馨的家庭场景作为锚点，第三卷让该锚点面临崩塌危机，作为主角人性保卫战的情绪引爆点。

### 非凡物品与神奇物品交易（新增）
- **资源需求**：封印非凡特性制成的神奇物品体系；黑市 / 拍卖会 / 地下交易网络；神奇物品的封印级别与副作用；官方对神奇物品流通的管控。
- **爽点类型**：收集 + 装备爽 + 黑市博弈 + 信息差交易。
- **消费时机**：第二卷起开始接触神奇物品经济，贯穿中后段。
- **变体**：①主角是神奇物品制作者（工匠流）；②主角是神奇物品鉴定师 / 倒爷；③主角收集一套封印神奇物品拼图；④黑市交易被官方盯上引发追杀；⑤神奇物品的副作用成为主角的关键伏笔。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每 1~2 卷安排一次"黑市拍卖会 / 神奇物品交易"事件，作为主角获取关键道具或暴露身份的节点。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：扮演法的"人设强制"
- **标准形态**：晋升后必须按途径人设行动才能消化魔药，主角被迫演一个与自己本性冲突的角色。
- **可变维度**：人设与本性冲突的强度；扮演的可见性（私下扮演 / 公开扮演影响社交）；扮演失败的即时后果；多条途径扮演的互相干扰。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"无扮演法、靠战斗消化魔药"而非"扮演消化"，这个桥段会变成什么形态？戏剧感从何而来？如果 <Strategy 阶段目标> 把"扮演冲突"从主角个人挪到整个组织（组织被迫扮演一个虚假形象），需要前置哪些世界资源？

### 母题 2：知识即污染的"认知代价"
- **标准形态**：越接近真相越疯狂，主角每次获得关键信息都付出精神代价。
- **可变维度**：污染的形态（疯狂 / 失忆 / 身体异变 / 被旧神注视）；污染是否可逆；污染能否被利用（污染本身就是力量）；同伴分担污染的可能性。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"知识不污染、反而是战斗记忆污染"而非"知识本身污染"，这个桥段会变成什么形态？代价结构如何重组？如果 <Strategy 阶段目标> 让主角主动追求污染以换取战力（黑化流），需要前置哪些世界规则使该选择合理？

### 母题 3：途径垄断与教会权力结构
- **标准形态**：主流途径被各大教会垄断，民间非凡者只能获取残缺配方或投靠教会。
- **可变维度**：垄断的强度（完全垄断 / 部分流出 / 地下市场流通）；教会对异端途径的态度（抹杀 / 收编 / 默许）；多教会之间的势力平衡；新兴教会 / 异端教派的崛起空间。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"无教会垄断、途径配方全网公开"而非"教会垄断"，这个桥段会变成什么形态？权力冲突的来源是什么？如果 <Strategy 阶段目标> 让主角的目标是"打破教会垄断、解放途径知识"，需要前置哪些势力与角色？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评素材（飞书文档、搜狐书单点评、知乎）：

- **跟风作品"套路模板化、高开低走"**：搜狐推荐的 24 本诡秘流跟风作品中，多本被点评"存在套路模板化的内容、元素没有深入挖掘、后期高开低走"。规避：必须有一项核心设定（途径体系 / 教会结构 / 污染机制）与《诡秘之主》明显不同，而不是换皮。
- **扮演法被简化为"打卡"**：跟风作品常把扮演法写成"按剧本打卡完成任务"，丧失原作的戏剧张力。规避：扮演法的人设必须与主角本性形成真实冲突，且冲突要推动剧情而非只是数值条。
- **伪克苏鲁流于表面**：很多作品只借"克苏鲁"皮（触手 / 不可名状），却无"宇宙级冷漠与人类渺小"的精神内核。规避：至少安排一次"主角直面旧神 / 见证宇宙真相"的极限恐惧场景，而不只是把怪物换成触手系。
- **魔药配方罗列成设定集**：跟风作品常大段罗列途径配方，被读者批评为"设定集式灌水"。规避：配方只在晋升节点展示关键材料，把更多笔墨放在材料的获取过程（异常生物狩猎 / 黑市博弈）。

### 未覆盖子流派的推导路径

- **非诡秘的克苏鲁衍生（纯克苏鲁）**：去掉序列魔药体系，从"异常调查"母题推导出"调查员流派"，从"知识污染"推导出"禁忌典籍研读"作为力量来源，强化恐怖氛围弱化养成。
- **蒸汽朋克无超凡**：保留蒸汽朋克世界观但去掉超凡力量，从"教会任务"反推出"工业财阀任务"，从"仪式"反推出"机械仪式 / 科技仪式"（如大型机械启动仪式）。
- **东方序列流**：把序列体系嫁接到东方修真，从"魔药晋升"推导出"丹药晋升 + 走火入魔"，从"教会"推导出"宗门 / 仙门"，从"塔罗会"推导出"地下仙盟"。
- **现代都市克苏鲁**：把蒸汽朋克换成现代都市，从"异常调查"推导出"都市怪谈调查"，从"教会"推导出"官方异常管控机构"，保留污染机制。
- **科幻克苏鲁（星际 + 克苏鲁）**：把旧神换成宇宙级存在，从"神位争夺"推导出"文明级晋升"，从"仪式"推导出"文明级仪式（戴森球 / 维度裂隙开启）"。
