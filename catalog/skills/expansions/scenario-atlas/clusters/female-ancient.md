# 女频古言（参考：《知否知否应是绿肥红瘦》《庶女攻略》《嫡谋》《锦屏记》《花开锦绣》）

> **世界观支柱**：以古代（多为架空王朝或明清式社会）的嫡庶礼法、内宅后宫、联姻嫁娶、田庄产业为硬约束底本，女主凭借穿越/重生/清醒心性/算计手腕，在内宅—家族—朝堂—后宫的层层闺阁权力结构中谋取生存、地位与自主。
> **典型消费节奏**：开篇用"嫡庶身份落地 + 第一场宅斗反击"钩住读者，前中段以"打脸白莲花/手撕极品/智斗嫡母妾室"高频供给爽点，中段穿插"嫁娶联姻/产业经营/夫婿磨合"，后段以"母仪天下/家族翻盘/复仇清算"做长线收束，全书以 HE 与"清醒女主不恋爱脑"为承诺。

## 桥段清单

### 穿越/穿书落地与嫡庶身份确立
- **资源需求**：一段古代社会背景（架空王朝/明清式礼法）、女主的落地身份（嫡女/庶女/继室之女/旁支寄居/宫女/罪臣之女）、嫡母与庶母的关系、家族的礼法约束、落地后第一场生存危机（被欺负/被算计/被退婚/被发卖）。
- **爽点类型**：身份反差 + 现代视角碾压礼法 + 第一次反击打脸。
- **消费时机**：开篇第一卷。
- **变体**：①标准——现代女主穿越成被欺负的庶女，靠清醒头脑翻身；②反转——穿成高位嫡女，开局即富贵但危机四伏（家族将倒/被盯上婚事）；③极端——穿书成"注定被女主踩"的恶毒女配/炮灰，反向逆天改命；④反套路——穿成"嫡母/婆婆"这类中年掌权者，开局即内宅话事人。
- **消费绑定提示**：开篇钩子。第一卷开篇必消费，确立女主"现代视角 + 古代闺阁身份"的双重视角；嫡庶身份落差应作为前 20 万字的高频打脸来源。
- **跨簇说明**：本桥段聚焦"闺阁嫡庶身份"落地（女频古言专属）。若穿越落地服务于"朝堂夺嫡/攀科技/改历史"（男主或男频视角），则属于架空历史簇 `alternate-history.md` 的"穿越落地与身份确立"，请按本书核心引擎与主角性别选用对应母题。两者的关键分野：女频落地的第一战场是内宅礼法，男频落地的第一战场是朝堂或产业。

### 宅斗：嫡母、嫡姐妹与妾室博弈
- **资源需求**：内宅权力结构（嫡母掌家/妾室争宠/嫡庶姐妹等级）、可争夺的内宅资源（掌家权/嫁妆/婚事/陪嫁/田庄/铺子）、嫡母与妾室的矛盾、嫡姐妹对女主的排挤、可借势的男眷（父亲/兄长/夫婿）。
- **爽点类型**：智斗打脸 + 内宅权谋 + "看你怎么嚣张"的优越感。
- **消费时机**：贯穿第一二卷，作为前中段高频爽点主体。
- **变体**：①标准——庶女主反击嫡母与嫡姐妹的打压，逐步夺回掌家权；②反转——嫡母其实是被妾室构陷，女主与嫡母联手对付真正的祸源；③极端——女主自己就是嫡母/继室，与一屋子妾室庶子女斗智；④反套路——嫡姐妹并非反派，姐妹联手对抗父权与家族倾轧。
- **消费绑定提示**：高频爽点 + 镶嵌式消费。每隔 10~20 章安排一场宅斗回合（掌家权之争/嫁妆纠纷/妾室构陷/姐妹排挤），每回合必须推进女主的内宅地位跃迁，避免变成纯流水账。

### 宫斗：后宫妃嫔、圣宠与子嗣之争
- **资源需求**：后宫体系（皇后/贵妃/嫔妃等级、六宫制度）、圣宠机制（侍寝/晋位/赏赐）、子嗣资源（皇子/公主/过继/滑胎）、前朝与后宫的联动（母族势力决定后宫地位）、后宫的礼法与禁忌。
- **爽点类型**：智斗 + 圣宠争夺 + 母仪天下的地位跃迁。
- **消费时机**：女主入宫后，常作为中后段主线（若开篇即宫斗则为全书主线）。
- **变体**：①标准——低位妃嫔靠智谋与圣宠一步步晋位至后；②反转——女主不想争宠只想自保，却被卷入宫斗被迫反击；③极端——女主扶持皇子夺嫡，以太后之尊收束；④反套路——女主与皇后/敌对妃嫔惺惺相惜，联手对抗前朝对后宫的操控。
- **消费绑定提示**：阶段转折 + 高频爽点。每次晋位/保胎/破局作为阶段转折；圣宠的起伏应作为高频爽点的节奏调剂。
- **跨簇说明**：本桥段聚焦"后宫妃嫔视角"的闺阁博弈（女频古言专属）。若后宫戏服务于"皇子夺嫡/前朝党争"且主角是皇子或权臣（男频视角），则属于架空历史簇 `alternate-history.md` 的"夺嫡与皇位之争"，请按主角身份与战场（后宫 vs 朝堂）选用对应母题。中国作家网评论亦指出，清穿宫斗是架空历史"夺嫡"母题的女频镜像，二者共享皇权结构但视角迥异。

### 重生复仇与步步为营
- **资源需求**：前世被害的明确轨迹（被陷害/被休弃/家族覆灭/惨死）、前世的仇人矩阵（嫡母/姐妹/夫家/妾室/奸夫）、重生节点、女主掌握的前世信息、可被提前布局改写的悲剧节点。
- **爽点类型**：宿怨清算 + 步步为营的智斗 + 命运补偿。
- **消费时机**：贯穿全书，常作为情感与剧情主轴。
- **变体**：①标准——女主逐一报复前世仇人，步步为营翻盘；②反转——前世悲剧有女主自己的责任（恋爱脑/轻信），重生后先改自己；③极端——仇人这一世也是重生者，信息差博弈；④反套路——女主放弃复仇，专注今生新生活，却阴差阳错完成救赎。
- **消费绑定提示**：长线伏笔 + 高频爽点。前世遗憾清单作为贯穿全书的长线伏笔；每卷推进一条复仇/改写线作为高频爽点。

### 庶女逆袭：嫁姐夫、继室与婚事博弈
- **资源需求**：婚事决定权（父母之命/嫡母做主）、可被博弈的婚事对象（姐夫/继室/填房/续弦/老夫少妻/高门低就）、嫁妆与陪嫁、女方家族的筹码、被退婚/被抢婚的危机。
- **爽点类型**：身份反转 + 婚事翻盘 + "你高攀不起"的打脸。
- **消费时机**：第一卷末至第二卷，女主婚事落定的关键转折。
- **变体**：①标准——庶女被嫡母塞给糟老头/填房，女主运作嫁入更好的人家；②反转——女主主动选"看似差实际好"的婚事（继室/姐夫/落魄世家），婚后逆袭；③极端——女主拒婚不嫁，自立女户掌家；④反套路——嫁姐夫/继室本是悲剧开局，女主却把"继室/填房"过成正室待遇。
- **消费绑定提示**：阶段转折。婚事落定作为第一二卷的阶段转折；嫁妆与陪嫁的明细应作为后续产业经营线的伏笔。

### 种田经营与家长里短
- **资源需求**：田庄/铺子/产业的经营权、可经营的产业（田产/铺面/放印子钱/腌菜/织布/药铺/茶庄）、内宅日常（管家/管账/调度下人）、街坊亲族的家长里短、可雇佣的掌柜伙计。
- **爽点类型**：经营获得感 + 家长里短的烟火气 + 财力崛起的安稳爽。
- **消费时机**：贯穿中段，作为宅斗/宫斗线之间的节奏调剂与底气来源。
- **变体**：①标准——女主靠现代经营头脑把破败田庄铺子做大；②反转——产业经营反过来成为宅斗宫斗的武器（财力即话语权）；③极端——女主弃宅斗专心经商，成为一代女商人；④反套路——家长里短的"极品亲戚"其实并非反派，化解误会后变成助力。
- **消费绑定提示**：高频爽点（镶嵌式）。每经营成一个产业节点消费一次，必须与宅斗/婚事线交织（如"铺子被嫡母惦记"驱动剧情），避免变成纯种田流水账。

### 真恶女与清醒女主：不恋爱脑、攻心算计
- **资源需求**：女主的清醒人设（不圣母/不恋爱脑/利益优先）、可供算计的男眷与女眷、女主的底线（护短/重利/重权）、与"恋爱脑女配"的对照、HE 的达成路径（不是靠爱情而是靠布局）。
- **爽点类型**：反套路人设爽 + 攻心算计 + "我才不吃这套"的清醒优越。
- **消费时机**：贯穿全书，作为女主核心人设的高频输出。
- **变体**：①标准——女主对感情清醒，专攻权位产业；②反转——女主表面恶女内心重情，只在底线被触碰时翻脸；③极端——女主是真·恶女，心狠手辣不留后患；④反套路——女主"清醒"到最后学会接纳一段平等感情，完成人设软化。
- **消费绑定提示**：高频爽点。每隔一段安排一次女主"拒绝恋爱脑/反杀算计者"的人设输出章，作为读者粘性的核心来源。

### 联姻与婚姻博弈：嫁妆、妻妾与夫家内宅
- **资源需求**：夫家内宅结构（婆母/妯娌/妾室/通房/庶子女）、女主带入的嫁妆与陪嫁人手、妻妾博弈的资源（宠爱/子嗣/管家中馈）、夫婿的态度（冷淡/扶持/对立/日久生情）、妻族的支撑。
- **爽点类型**：内宅权谋 + 妻妾博弈 + 夫妇磨合的甜。
- **消费时机**：女主嫁人之后，中段主线之一。
- **变体**：①标准——女主嫁入复杂夫家，逐一收服婆母妯娌妾室；②反转——夫婿表面冷淡暗中扶持，夫妇联手整顿内宅；③极端——女主夫家是将倒之门，女主靠嫁妆与人脉撑起整个家族；④反套路——妾室通房并非反派，女主与她们各取所需甚至结盟。
- **消费绑定提示**：阶段转折 + 高频爽点。嫁入夫家作为阶段转折；妻妾/妯娌的每一次博弈作为高频爽点；夫妇感情的进展应作为节奏调剂（甜宠撒糖节点）。

### 内宅治理与产业经营进阶
- **资源需求**：中馈掌家权、家族产业版图（田庄/铺子/放贷/盐铁/漕运）、可调度的管事伙计、家族子嗣的教育与联姻布局、与官府/乡绅的外部关系。
- **爽点类型**：经营养成 + 家族崛起 + "女主撑起门楣"的成就感。
- **消费时机**：中后段，女主从"自保"升级为"撑起家族"。
- **变体**：①标准——女主掌家后把家族产业做大，子嗣教育联姻布局周全；②反转——家族内部有人拆台，女主边经营边肃清；③极端——女主把家族经营成一方豪族，甚至影响朝堂；④反套路——女主经营到顶峰后急流勇退，把家业交给后人自己归隐。
- **消费绑定提示**：阶段转折 + 长线伏笔。家族产业的每个里程碑作为阶段转折；子嗣联姻布局应作为终卷"母仪天下/家族翻盘"的长线伏笔回收。

### 宫廷政变与母仪天下
- **资源需求**：皇权更迭机制（夺嫡/禅让/政变/拥立）、女主或子嗣在其中的位置、前朝后宫的联动、政变的代价（株连/抄家/废后）、母仪天下的合法性（子嗣/圣宠/家族/功业）。
- **爽点类型**：地位跃迁 + 长线爽感兑现 + 时代洪流。
- **消费时机**：终卷或全书高潮。
- **变体**：①标准——女主或其子嗣在政变中胜出，女主以太后/皇后之尊收束；②反转——女主是政变的幕后推手而非受益者前台；③极端——女主自己称帝或垂帘听政，成为实际掌权者；④反套路——政变后女主拒绝高位，携家归藩/归隐。
- **消费绑定提示**：长线伏笔全回收 + 终卷阶段转折。前文所有的内宅经营、宫斗积累、子嗣布局都应在此回收；母仪天下的形态应作为全书"清醒女主"承诺的兑现。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：嫡庶身份的爽点边界
- **标准形态**：女主穿越/重生为被欺负的庶女，靠清醒头脑与算计在内宅翻身，嫡庶落差即爽点来源。
- **可变维度**：女主的落地身份（嫡女/庶女/继室之女/旁支/掌权嫡母）、嫡庶矛盾的烈度（刁难/谋害/发卖）、女主翻身的手段（智斗/嫁人/自立女户）。
- **衍生问题**：如果本书 Architecture 核心引擎是"真恶女攻心算计"而不是"庶女委屈翻身"，嫡庶身份会从"受气包"变成什么？如果 Strategy 把女主落地身份从庶女换成掌权嫡母，第一卷的开篇钩子该如何重写？如果本书是穿书且女主穿成"恶毒女配"，嫡庶博弈的敌我阵营会如何重组？

### 母题 2：宅斗宫斗的烈度与格局升级
- **标准形态**：女主从内宅宅斗（嫡母妾室姐妹）逐步升级到宫斗（后宫妃嫔圣宠子嗣），战场从一家一族扩大到一朝后宫。
- **可变维度**：战场的层级（内宅/家族/后宫/朝堂）、博弈工具（掌家权/嫁妆/圣宠/子嗣/母族）、烈度（智斗/谋害/政变）、女主的格局（自保/撑起家族/母仪天下）。
- **衍生问题**：如果本书 Strategy 让女主始终留在内宅（不入宫不嫁皇室），宫斗母题该如何被"家族内宅版宫斗"替代？如果核心引擎是"种田经营"而非"宅斗宫斗"，宅斗戏份该退化为背景板还是与经营深度绑定？如果女主的终局不是母仪天下而是"一代女商人/女户主"，长线伏笔该如何收束？

### 母题 3：婚事博弈的主动权
- **标准形态**：女主的婚事被嫡母/家族当作筹码，女主通过运作（嫁姐夫/继室/高门低就/自立女户）夺回婚事主动权。
- **可变维度**：婚事决定权归属（嫡母/父亲/女主自选）、婚事对象的好坏（明面差实际好/明面好实际差）、嫁妆与陪嫁的厚度、婚后夫家的复杂度。
- **衍生问题**：如果本书核心引擎是"先婚后爱"而不是"婚事翻盘打脸"，嫁姐夫/继室母题会从"打脸"变成什么？如果 Strategy 让女主拒婚不嫁自立女户，"婚事博弈"该如何被"事业经营"替代？如果女主嫁的是"明面差实际好"的夫婿，夫妇磨合线该占据多大比重？

### 母题 4：清醒女主的人设与 HE 路径
