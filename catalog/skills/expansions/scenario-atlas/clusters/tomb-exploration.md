# 盗墓 / 探险（参考：《鬼吹灯》《盗墓笔记》《寻龙诀》）

> **世界观支柱**：以古代陵墓、风水堪舆、陪葬明器、墓中异变（粽子/尸变）为核心的地下冒险世界，靠"门派传承 + 古卷残页 + 机关术"支撑合理性。
> **典型消费节奏**：开篇用家传残卷或怪事钩子拉人入墓，中段以"一墓一机关一粽子"的高频单元剧稳定供给爽点，后段串联跨墓大阴谋做长线收束。

## 桥段清单

### 古墓进入与机关破解
- **资源需求**：一座结构复杂、有明确建造年代与墓主身份的古墓；一套与墓主身份匹配的机关体系（流沙、机括、毒气、水银、悬魂梯）；盗墓门派的"入墓口诀"或残卷。
- **爽点类型**：解谜快感 + 智商碾压 + 危险逼近的紧张感。
- **消费时机**：第一卷每 3~5 章一次的高频单元，几乎每个新墓都要消费。
- **变体**：①摸金摸穴式正门破机关；②搬山道人式力破机关；③反套路"墓主故意留生门引君入瓮"；④极端"机关是活物/是阵法/是诅咒"。
- **消费绑定提示**：高频爽点。每个新墓的"入门章"必消费此桥段，作为单元剧的标准开胃菜，例如第一卷第二墓"西周积沙墓"开篇三章。

### 陪葬品与明器争夺
- **资源需求**：墓中有可识别、可估价、可编号的明器清单（夜明珠、青铜器、玉衣、甲骨）；一个"明器即诅咒"的传说体系；同行或外国探险队的觊觎。
- **爽点类型**：贪欲满足 + 稀有掉落 + 持有即危险的"代价感"。
- **消费时机**：每墓中段，机关破解之后、粽子出现之前。
- **变体**：①摸金规矩"只取一件"；②明器带诅咒反噬持有者；③明器是更大谜题的钥匙碎片；④反套路"明器是活的/会繁殖/会择主"。
- **消费绑定提示**：高频爽点 + 长线伏笔。明器在取得当下消费爽点，同时其中一件应被标注为后续串联大阴谋的伏笔道具（如"玉柄上刻的字对应第三卷的主墓墓主")。

### 风水寻龙定穴
- **资源需求**：一套可吟诵、可推演的风水口诀体系（寻龙诀、分金定穴）；一张祖传残图或罗盘；地理环境的龙脉走势描写。
- **爽点类型**：专业感 + 神秘感 + "一眼定穴"的装逼感。
- **消费时机**：每个新墓定位章节，通常位于单元剧开头。
- **变体**：①正统风水派靠山势水势；②反套路"龙脉已断/被改"；③极端"现代基建破坏龙脉致古墓现身"；④反套路"风水是假的，是前人留下的导航坐标"。
- **消费绑定提示**：开篇钩子 + 阶段转折。第一卷开篇用一次定穴钩住读者；每卷新区域开启时再用一次作为阶段转折。

### 超自然粽子与尸变对抗
- **资源需求**：一套尸变等级体系（白毛、黑毛、绿毛、肉尸、血尸）；克制手段（黑驴蹄子、糯米、墨线、桃木、童子血）；墓中阴气/尸气环境描写。
- **爽点类型**：恐怖 + 求生 + 碾压式反杀的爽感。
- **消费时机**：每墓高潮章节，通常位于明器争夺之后。
- **变体**：①传统物理搏杀；②口诀镇压式智斗；③反套路"粽子是墓主执念所化，需解开心结"；④极端"粽子会进化、会说话、记得生前"。
- **消费绑定提示**：高频爽点 + 阶段转折。每个墓的高潮章必消费；卷尾大墓的血尸战应作为本卷阶段转折点。

### 跨墓串联大阴谋
- **资源需求**：多个古墓背后共享同一个秘密（长生、龙脉、上古文明、家族宿命）；一个幕后组织或家族；贯穿多卷的线索物件。
- **爽点类型**：真相揭穿 + 世界观扩张 + 长线悬念。
- **消费时机**：第二卷末或第三卷正式展开，前期埋伏笔。
- **变体**：①家族三代人的跨墓布局；②反派组织跨墓盗掘求长生；③反套路"主角自己就是阴谋的一环"；④极端"所有古墓其实是同一个超大墓的入口"。
- **消费绑定提示**：长线伏笔 + 终卷阶段转折。第一卷起的每个明器、口诀残页都应被标注为此桥段的伏笔载体，第三卷揭穿章集中回收。

### 探险队内斗与同行博弈
- **资源需求**：一支临时拼凑、各怀鬼胎的探险队（队员身份有摸金、土夫子、洋人、军阀、官方考古）；一个分配权或背叛动机。
- **爽点类型**：人性博弈 + 背叛打脸 + 黑暗丛林。
- **消费时机**：每墓中后段，机关与粽子之外的人祸。
- **变体**：①土夫子黑吃黑；②洋人/军阀强夺明器；③反套路"内鬼其实是保护主角的卧底"；④极端"全队除主角外都已不是活人"。
- **消费绑定提示**：高频爽点。每墓至少消费一次队伍内部冲突，作为机关粽子的间奏。

### 门派传承与四派博弈（新增）
- **资源需求**：四大门派（摸金校尉、发丘天官、搬山道人、卸岭力士）的传承设定，每派有自己的规矩、口诀、克星；门派间的恩怨与分工。
- **爽点类型**：专业认同 + 派系归属 + 同行鄙视链的优越感。
- **消费时机**：第一卷用于建立主角身份，第二卷起引入其他门派制造博弈。
- **变体**：①正统摸金独走；②多派合作下墓各司其职；③反套路"主角是无门无派的野路子，靠现代知识碾压"；④极端"四派其实是一家分裂的，背后是同一祖师"。
- **消费绑定提示**：开篇钩子 + 长线伏笔。主角的门派身份在第一章消费为钩子；"四派同源"应在第二卷埋伏笔、终卷揭穿。

### 家族秘史与祖传残卷（新增）
- **资源需求**：一个跨越两到三代的盗墓家族；一本残缺的祖传手札或口诀；一段被刻意抹去或失忆的家族往事。
- **爽点类型**：身世悬念 + 父辈光环 + 寻根认同。
- **消费时机**：开篇钩子（爷爷/父亲留下的残卷）；第二卷中段揭穿父辈往事。
- **变体**：①爷爷的笔记指引下墓；②父亲死因成谜；③反套路"祖传残卷是伪造的，家族本身是阴谋制造者"；④极端"主角是墓主血脉，残卷是回家的路"。
- **消费绑定提示**：开篇钩子 + 长线伏笔。残卷在第一章消费为入坑钩子，残页的逐页解锁应贯穿全书，作为跨卷阶段转折点的标志。

### 明器回流与诅咒反噬（新增）
- **资源需求**：一件被卖出/流出/上交的明器；一个因持有明器而遭灾的受害者；主角的"善后"职责。
- **爽点类型**：因果报应 + 主角救场 + 道德优越感。
- **消费时机**：第二卷起的过渡章节，作为单元剧之间的串联。
- **变体**：①买家暴毙主角回收；②明器在国外博物馆闹鬼；③反套路"反噬是假的，是同行设局抢明器"；④极端"所有流出的明器正在被一种力量召唤回墓"。
- **消费绑定提示**：阶段转折。每两个大墓之间的过渡卷消费一次，串联单元剧并埋下一墓的钩子。

### 长生秘术与上古真相（新增）
- **资源需求**：一个被多个古墓共同指向的"长生"或"上古文明"母秘密；一份需要多件明器合体才能解读的总图；一个已经"长生"的存在（墓主、反派、祖师）。
- **爽点类型**：世界观炸裂 + 终极真相 + 宇宙级恐惧。
- **消费时机**：第三卷或终卷，全书高潮。
- **变体**：①长生是诅咒不是奖励；②上古文明是外星或史前人类；③反套路"主角破除长生，选择凡人归宿"；④极端"长生者已变成不可名状的怪物"。
- **消费绑定提示**：长线伏笔（前三卷埋）→ 终卷阶段转折。明器、残卷、门派、家族四条伏笔线在此桥段集中回收。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：下墓单元剧
- **标准形态**：定位 → 入墓 → 机关 → 明器 → 粽子 → 撤退/内斗，五章一循环。
- **可变维度**：墓的朝代与规模、机关是否超自然、粽子是否会说话、内斗的烈度、是否引入第二支队伍。
- **衍生问题**：如果本书的 Architecture 核心引擎是"经营"而不是"探险"，下墓桥段会变成"墓园承包开发"形态吗？如果 Strategy 把第一墓从第一卷挪到第二卷，开篇要用什么钩子替代？

### 母题 2：跨墓真相
- **标准形态**：多个独立单元剧的明器/线索最终指向同一宏大真相。
- **可变维度**：真相的性质（长生/外星/家族/诅咒）、揭穿的时机、主角与真相的关系、揭穿后是否还能继续下墓。
- **衍生问题**：如果本书的 Strategy 是"短篇单元剧为主、长线为辅"，跨墓真相要不要砍掉？如果核心引擎是"解谜"而不是"探险"，明器碎片要不要直接变成推理线索？

### 母题 3：门派与传承
- **标准形态**：四派分工 + 主角归属一派 + 跨派博弈。
- **可变维度**：派别的数量、是否引入官方考古/洋人/军阀作为第五派、传承是口诀还是血脉、主角是正统还是野路子。
- **衍生问题**：如果本书是都市背景的"现代盗墓"，门派要不要改组为事务所或直播公会？如果核心引擎是"博弈"，门派戏的比重应该超过下墓戏吗？

### 母题 4：恐怖与爽感的配比
- **标准形态**：前段靠粽子与机关营造恐怖，后段靠主角碾压反杀转爽。
- **可变维度**：恐怖的来源（物理粽子/诅咒/不可名状）、爽感的来源（武力/口诀/现代装备/智斗）、配比随卷次的变化。
- **衍生问题**：如果本书定位是"沙雕盗墓流"，恐怖母题要不要彻底反套路化？如果核心引擎是"求生"，爽感母题是否要让位于恐怖压迫？

### 反套路与"烂大街"风险
（综合 WebSearch 读者批评素材提炼）
- **机关同质化**：每个墓的机关套路雷同，流沙、毒气、悬魂梯反复出现，读者已审美疲劳。World Agent 应至少为每个墓设计一种"该墓独有"的机关母题。
- **粽子等级化套路**：白毛→黑毛→血尸的等级表被用滥，失去了初见的恐惧感。建议淡化等级、强化"每个粽子都有独立执念"。
- **风水口诀堆砌**："寻龙分金看缠山"等经典口诀被无脑复制，读者批评为"水字数"。风水描写应服务于剧情而不是炫技。
- **大阴谋强行串联**：为串联而串联，把所有明器都变成"长生碎片"，导致单元剧失去独立乐趣。建议保留至少 30% 的纯单元墓。
- **同行内斗模板化**：土夫子黑吃黑、洋人强夺的桥段被反复使用，人性博弈变成了套路化的"工具人背叛"。

### 未覆盖子流派的推导路径
- **考古正剧流**：从"门派传承"反推为"官方考古队"形态，桥段从"摸金"推导为"发掘规范 + 文物保护 + 学术争议"。
- **寻宝探险流（非墓葬）**：从"古墓"替换为"沉船、雪山、雨林遗迹"，把"粽子"替换为"自然环境异变或守护生物"。
- **灵异盗墓流**：把"机关"权重让给"鬼怪灵异"，门派戏让位给道士/法师/阴阳师体系，可借鉴 `horror-rules.md` 的规则母题。
- **盗墓系统流**：在传统盗墓上叠加系统签到/任务/商城（参考 `system.md`），把"明器"升级为"系统掉落"。
- **女频盗墓流**：把"硬汉摸金"替换为"女主探险 + 感情线"，下墓戏与感情线 5:5 配比，可参考言情快穿的反派救赎母题。
