# 重生都市（参考：《重生之娱乐圈巅峰》《重生之国民男神》《听劝的我成为了顶流巨星》《重生十七岁那年夏天》）

> **世界观支柱**：以"重生带来的信息差"为核心金手指，主角回到过去某个关键节点（成名前/被伤害前/事业起步前），靠先知布局在商业、文娱、金融、情感领域全面逆袭。
> **典型消费节奏**：开篇立即抛出重生节点与遗憾清单，中段以"打脸曾经看不起主角的人"高频循环，每卷一次大型逆袭高潮。

## 桥段清单

### 重生先知提前布局
- **资源需求**：明确的重生时间节点、主角掌握的未来信息（事件/人物/趋势）、可被提前布局的资源（房产、股票、IP、人脉）。
- **爽点类型**：信息差碾压 + 命运改写 + 先发制人。
- **消费时机**：第一卷开篇 1~10 章，全书金手指的奠基。
- **变体**：①标准——主角靠先知抢先布局财富与人脉；②反转——某些"未来记忆"已因蝴蝶效应失效；③极端——主角是平行世界过来的，记忆与本书世界有偏差；④反套路——主角故意不布局，想"自然活一次"。
- **消费绑定提示**：标注为「开篇钩子」+「长线伏笔」。消费场景：开篇即重生并完成第一次先知布局（如抢下某 IP/提前买房），作为"金手指契约"；同时埋下"哪些未来会因蝴蝶效应改变"的长线悬念。

### 商业帝国创业
- **资源需求**：可创业的行业（互联网/餐饮/制造/文娱）、初始资本来源、商业对手、时代风口（电商/短视频/AI）。
- **爽点类型**：事业养成 + 商战打脸 + 财力崛起。
- **消费时机**：第二卷起，主角从个人逆袭转向事业扩张。
- **变体**：①标准——主角从零创业一路做大；②反转——主角收购前世敌手公司；③极端——主角同时运营多个产业形成财团；④反套路——主角只做小生意享受生活，靠投资被动收入。
- **消费绑定提示**：标注为「阶段转折」+「高频爽点」。消费场景：每卷安排一次事业进阶（开店→连锁→上市→跨国），作为阶段转折点。

### 文抄公作品搬运
- **资源需求**：可被"搬运"的未来作品（歌曲/小说/剧本/综艺）、主角的"创作"身份（歌手/作家/编剧）、被搬运作品的原作者与版权纠纷风险。
- **爽点类型**：才华打脸 + 一夜爆红 + 文化资本积累。
- **消费时机**：第一卷中段至第二卷，主角快速积累名气与资本的手段。
- **变体**：①标准——主角"创作"未来爆款一夜成名；②反转——被搬运的原作者穿越过来追责；③极端——主角发现本书世界也有"另一个搬运者"；④反套路——主角只搬运冷门作品，反而凭审美眼光成名。
- **消费绑定提示**：标注为「高频爽点」。消费场景：每隔 20~30 章安排一次"新作发布"作为爽点节点，同时逐步累积主角的文化资本版图。

### 娱乐圈明星养成
- **资源需求**：娱乐圈生态（练习生/经纪/选秀/影视/代言）、人脉资源、CP/绯闻机制、对手艺人。
- **爽点类型**：名气飙升 + 舞台高光 + 圈内打脸。
- **消费时机**：第二至第四卷，主角或主角培养的人进入娱乐圈核心。
- **变体**：①标准——主角自己成为顶流；②反转——主角是经纪人，培养素人成顶流；③极端——主角建立娱乐帝国垄断行业；④反套路——主角主动退圈，回归幕后或普通人生活。
- **消费绑定提示**：标注为「高频爽点」+「阶段转折」。消费场景：每卷安排一次大型舞台/奖项/绯闻事件作为高潮，同时作为名气跃升的阶段转折。

### 重生复仇弥补遗憾
- **资源需求**：前世的伤害者（渣男/渣女/背叛者/仇家）、可被弥补的遗憾（至亲未死/错过的爱人/未完成的事）、复仇手段（信息差/布局/势力）。
- **爽点类型**：宿怨清算 + 情感救赎 + 命运补偿。
- **消费时机**：贯穿全书，常作为情感线主轴。
- **变体**：①标准——主角逐一报复前世仇人；②反转——仇人这一世是真心悔过的好人；③极端——主角发现前世悲剧是自己造成；④反套路——主角放弃复仇，专注弥补遗憾与新生。
- **消费绑定提示**：标注为「长线伏笔」+「高频爽点」。消费场景：每卷推进一条复仇/弥补线，前世遗憾清单作为贯穿全书的长线伏笔。

### 资本运作金融战
- **资源需求**：金融市场（股市/期货/并购）、资本势力（财团/庄家/外资）、主角的资本积累与操盘能力。
- **爽点类型**：财力碾压 + 智斗庄家 + 帝国级博弈。
- **消费时机**：中后段，主角从个人/小企业级跃升至资本级。
- **变体**：①标准——主角靠先知抄底暴富打脸庄家；②反转——主角的对手也是重生者；③极端——主角撬动国家资本参与国际金融战；④反套路——主角放弃金融投机，转向实业。
- **消费绑定提示**：标注为「阶段转折」。消费场景：中后段作为主角从"个人富豪"跃升至"资本玩家"的转折点。

### 听劝顶流与 CP 炒作
- **资源需求**：可互动的"网友/弹幕/观众"群体、CP 对象（死对头/偶像/隐婚对象）、舆论发酵机制、社交媒体生态。
- **爽点类型**：互动喜剧 + 反差萌 + 圈粉养成。
- **消费时机**：第二至第三卷，主角进入娱乐圈/公众视野后的节奏调剂。
- **变体**：①标准——主角听网友建议意外爆红；②反转——CP 对象是前世仇人/今生真爱；③极端——主角与 CP 对象私下是真伴侣，公开是炒作；④反套路——主角反向给网友出题，引发全民讨论。
- **消费绑定提示**：标注为「高频爽点」。消费场景：每隔 15~25 章安排一次舆论事件/CP 互动，作为节奏调剂与圈粉节点。

### 互联网风口投资布局
- **资源需求**：未来互联网巨头（BAT 级公司）的早期阶段、主角的初始资本、与创始团队的接洽契机、风投生态。
- **爽点类型**：先知暴富 + 站队顶级公司 + 资本版图扩张。
- **消费时机**：第二至第三卷，主角用先知完成资本原始积累后的进阶。
- **变体**：①标准——主角早期投资未来巨头获得巨额回报；②反转——主角成为某巨头幕后大股东影响走向；③极端——主角自创公司与未来巨头抗衡；④反套路——主角投资的"未来巨头"因蝴蝶效应倒闭，主角被迫亲自下场。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：中段作为主角资本版图扩张的阶段转折，同时埋下"与未来巨头关系"的长线伏笔。

### 重生弥补亲情遗憾
- **资源需求**：前世有遗憾的至亲（父母/兄弟姐妹/爱人）、可被改变的悲剧节点、亲情与事业的冲突。
- **爽点类型**：情感救赎 + 温情高光 + 价值取向反转（从追名逐利转向珍惜身边人）。
- **消费时机**：第一卷与贯穿全书，主角重生的情感动因。
- **变体**：①标准——主角救下前世死去的至亲；②反转——至亲这一世是另一重生者；③极端——主角发现救至亲需要牺牲事业或另一至亲；④反套路——主角放弃救至亲，尊重命运专注新生。
- **消费绑定提示**：标注为「开篇钩子」+「长线伏笔」。消费场景：开篇用"前世遗憾"作为重生的情感动因（钩子），贯穿全书作为主角价值取向的锚点。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：重生信息差的边界与失效
- **标准形态**：主角掌握未来信息，靠先知布局无往不利，信息差即金手指。
- **可变维度**：信息精度（精确事件/趋势/模糊）、信息失效原因（蝴蝶效应/平行世界/记忆偏差）、信息差的可分享性（独享/可传授/会被识破）。
- **衍生问题**：如果本书核心引擎是"蝴蝶效应"而不是"信息差碾压"，重生先知会从"全知全能"变成什么？如果 Strategy 让主角的重生记忆只覆盖前 3 年，后续主角该如何应对未知的未来？

### 母题 2：复仇与救赎的价值取向
- **标准形态**：主角重生后逐一报复前世仇人，同时弥补前世遗憾。
- **可变维度**：复仇强度（赶尽杀绝/适度惩罚/原谅）、救赎对象（至亲/爱人/自己）、复仇与救赎的优先级冲突。
- **衍生问题**：如果本书核心引擎是"成长与放下"而不是"复仇清算"，重生复仇会从"打脸"变成什么？主角是该执着于前世恩怨，还是该专注今生新生活？

### 母题 3：搬运与原创的版权伦理
- **标准形态**：主角把未来的爆款作品"搬运"到本书世界，快速积累名气与资本。
- **可变维度**：搬运对象（歌曲/小说/剧本/商业模式）、搬运的伦理处理（回避/合理化/反噬）、与"原作者"的关系（无/穿越过来/本书世界原生）。
- **衍生问题**：如果本书核心引擎是"原创价值"而不是"搬运套利"，文抄公会从"一夜爆红"变成什么？主角是该继续搬运，还是该在搬运中发展出真正的原创能力？

### 母题 4：个人逆袭与帝国扩张的节奏
- **标准形态**：主角从个人致富到创业再到资本运作，逐步建立商业帝国。
- **可变维度**：扩张速度（稳健/激进/跃进）、帝国的核心引擎（实业/金融/文化/科技）、帝国与主角个人生活的冲突。
- **衍生问题**：如果本书核心引擎是"小而美的生活"而不是"帝国扩张"，商业线会从"做大上市"变成什么？主角是该一路扩张，还是该在某个节点主动停下？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评的集中意见：

- **"文抄公"模式被批"既定框架写不下去"**：搜狐文章指出某文娱小说"后期质量有所下降，在既定框架下写不下去，戛然而止"——搬运式爆红的爽点耗尽后无以为继。规避方式：把搬运作为起点而非全部，中期让主角发展真正的原创能力或转向经营/资本线。
- **"投资 BAT"已成公式**：重生都市文几乎必写主角早期投资百度/阿里/腾讯暴富，同质化严重。规避方式：让主角投资的"未来巨头"因蝴蝶效应倒闭，或主角自创公司与未来巨头抗衡，制造不确定性。
- **复仇线脸谱化**：前世仇人全是"纯粹恶人"，打脸过程同质。规避方式：让仇人这一世是真心悔过的好人，或前世悲剧有主角自己的责任，制造道德灰度。
- **娱乐圈线与商业线割裂**：主角同时是顶流明星和商业巨头，两条线互不支撑。规避方式：让两条线深度交织（如用商业资源撬动娱乐圈、用娱乐圈影响力反哺商业）。
- **CP 炒作同质化**："死对头变恋人""隐婚甜文"已成标配。规避方式：让 CP 对象是前世仇人/今生真心，或主角与 CP 对象是真伴侣却被迫公开炒作，制造反差。
- **男频/女频套路分化僵化**：男频"女明星自由"、女频"影帝隐婚"已成刻板期待。规避方式：男频加入情感救赎深度，女频加入事业博弈硬度，模糊性别套路边界。

### 未覆盖子流派的推导路径

- **重生农村/乡土流**：从"商业帝国创业"反推——主角重生回农村，桥段改为"种田致富""乡村电商""乡土人情""反哺家乡"。
- **重生学生时代**：从"重生先知布局"反推——主角重生回中学/大学，桥段改为"学业逆袭""校园恋情""青春遗憾弥补""提前布局未来人脉"。
- **重生官场（参见 officialdom.md）**：从"资本运作金融战"反推——主角进入体制，桥段改为"派系站队""政绩工程""升迁博弈""民心工程"。
- **重生体育/电竞**：从"娱乐圈明星养成"反推——主角重生为运动员/电竞选手，桥段改为"提前训练""战术革新""大赛夺冠""伤病规避"。
- **重生乱世/末日预知**：从"重生先知布局"反推——主角预知末日/乱世降临，桥段改为"提前囤货""基地建设""求生布局""势力预置"。
- **平行世界/异界重生**：从"文抄公作品搬运"反推——主角重生到没有某作品/技术的平行世界，桥段改为"技术搬运""文化填补""世界观差异探索"。
- **重生配角/反派**：从"重生复仇弥补遗憾"反推——主角重生为某故事的配角/反派，桥段改为"避开主角光环""反向改写剧情""配角逆袭"。
