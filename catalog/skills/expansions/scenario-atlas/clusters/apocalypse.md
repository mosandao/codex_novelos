# 末世 / 废土（参考：《末日乐园》《全球进化》《末世之地下城》）

> **世界观支柱**：现代文明被天灾 / 病毒 / 异变 / 入侵瞬间摧毁，幸存者在丧尸、变异兽、极端环境与人性博弈中求生；以基地建设为核心重建秩序，最终追寻末世真相与净化 / 拯救之路。
> **典型消费节奏**：生存紧迫感（开篇钩子）+ 基地养成爽（高频）+ 人性博弈的戏剧张力（阶段转折）+ 净化真相的长线史诗（长线伏笔），读者期待"危机—建设—更大危机"的螺旋升级。

## 桥段清单

### 末世降临与文明崩塌
- **资源需求**：末世降临的具体形式（病毒 / 暴雪 / 外星入侵 / AI 异变 / 灵气异变）；降临的突然性与破坏力；现代文明的崩塌过程（通讯中断 / 物资抢夺 / 秩序瓦解）；主角的初始处境。
- **爽点类型**：灾难奇观 + 命运转折 + 末世紧迫感的强代入。
- **消费时机**：第一卷开篇必消费（开篇钩子），前 3 章完成降临。
- **变体**：①病毒爆发丧尸化；②极端天灾（暴雪 / 寒潮 / 旱灾 / 洪水）；③外星生物入侵；④AI 觉醒反叛；⑤灵气异变动植物异化。
- **消费绑定提示**：标注为**开篇钩子**。具体场景：第一卷第一章用一次"末世降临 + 主角目睹身边人遇险 / 死亡"完成世界观抛出与主角金手指激活，3 章内进入求生阶段。

### 异能觉醒与进化体系
- **资源需求**：末世触发的异能觉醒机制（病毒变异 / 灵气 / 系统 / 进化）；异能的分类与等级；进化的代价与瓶颈；异能者与非异能者的关系。
- **爽点类型**：金手指 + 养成 + 数值膨胀 + 跨等级碾压。
- **消费时机**：第一卷主角觉醒（开篇钩子）；每个阶段突破（阶段转折）。
- **变体**：①个人异能觉醒流；②全家觉醒流；③系统面板流（熟练度 / 属性）；④病毒感染者获得异能（丧尸流主角）；⑤异能进化到后期接近神级。
- **消费绑定提示**：标注为**开篇钩子 + 阶段转折**。具体场景：第一卷前 5 章让主角觉醒第一个异能，每卷末安排一次异能进化 + 跨等级碾压战作为卷末高潮。

### 避难所基地建设
- **资源需求**：可防御的据点（地下城 / 工厂 / 城堡 / 移动城市）；基地的基建系统（防御 / 农业 / 能源 / 医疗 / 武器）；基地的人口与人才；基地系统的辅助（系统流基地）。
- **爽点类型**：养成 + 文明重建 + 安全感 + 降维打击周边幸存者。
- **消费时机**：第一卷中段开始建设；贯穿全书作为底层节奏与高频爽点。
- **变体**：①地下城式固定基地；②移动城市式基地（车队 / 巨型载具）；③多基地联盟式；④基地系统流（系统辅助建设）；⑤天空 / 海上基地（极端环境）。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每 3~5 章交付一次"基地设施升级 + 周边幸存者震惊"的小高潮，作为养成节奏的核心节拍。

### 末世人性与幸存者博弈
- **资源需求**：多批幸存者群体（平民 / 暴徒 / 老弱 / 精英）；资源稀缺（食物 / 水 / 药品 / 弹药）；道德困境（救谁 / 弃谁 / 杀谁）；势力间的信任与背叛。
- **爽点类型**：人性戏剧张力 + 道德抉择 + 反杀背叛者 + 领袖魅力。
- **消费时机**：第一卷中后段开始接触外人；贯穿全书作为势力博弈主线。
- **变体**：①邻居借粮引发的冲突；②幸存者团体的内斗与清洗；③敌对基地的吞并；④老弱病残的去留道德困境；⑤主角的"救"与"不救"成为其领袖人设的分水岭。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第一卷末用一个"信任危机 + 反杀背叛者 + 主角领袖人设确立"事件，作为主角从"独狼"转向"领袖"的转折。

### 变异兽 / 丧尸潮攻城
- **资源需求**：丧尸 / 变异兽的等级与进化体系；尸潮 / 兽潮的成因（季节性 / 人为引发 / 高阶兽指挥）；基地的防御体系；守城战的代价。
- **爽点类型**：史诗战争 + 守护 + 主角力挽狂澜 + 基地威望跃升。
- **消费时机**：第二卷起每次基地升级后必有一次大规模攻城；卷末高潮必消费。
- **变体**：①丧尸潮围城；②变异兽潮攻城；③混合潮（丧尸 + 兽）；④空中变异生物攻城；⑤攻城背后有高阶智慧体指挥。
- **消费绑定提示**：标注为**阶段转折**。具体场景：每卷高潮安排一次"基地保卫战 + 主角力挽狂澜 + 战后基地威望跃升"事件，作为本卷的史诗顶点。

### 末世真相与净化拯救
- **资源需求**：末世降临的真相（病毒来源 / 外星目的 / 灵气真相 / 古代预言）；净化或拯救的途径（疫苗 / 净化装置 / 击败源头 / 完成仪式）；真相揭露的代价。
- **爽点类型**：真相揭露 + 史诗拯救 + 弱者逆袭拯救世界。
- **消费时机**：第三卷 / 全书后 1/3 主线，最终卷高潮。
- **变体**：①末世是外星文明的清洗；②末世是地球自我净化；③末世是某位存在的实验；④主角本身就是净化的关键；⑤净化失败的末日分支。
- **消费绑定提示**：标注为**长线伏笔**。具体场景：第一卷某条支线暗示末世真相（如发现古代预言 / 神秘组织），第三卷揭晓，作为全书高潮的引爆点。

### 末世囤货与物资搜集（新增）
- **资源需求**：现代物资的存量与分布（超市 / 仓库 / 工厂 / 军事基地）；物资搜集的危险（丧尸 / 暴徒 / 环境）；主角的储物金手指（空间 / 系统 / 仓库）；物资稀缺度的演进。
- **爽点类型**：收集爽 + 截胡 + 物资碾压（别人饿肚子主角吃香喝辣）。
- **消费时机**：第一卷主角金手指激活后必消费；贯穿全书的高频爽点。
- **变体**：①空间金手指囤货流；②系统仓库流；③现实仓库 + 搬空一座城；④物资交换经济线；⑤物资争夺引发的势力战。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每卷至少一次"大型物资搜集行动 + 截胡其他势力 + 主角基地物资跃升"事件，作为主角基地经济跃迁的节点。

### 废土势力与军阀割据（新增）
- **资源需求**：末世后的势力格局（军阀 / 教派 / 商队 / 流民团）；势力的领袖与人设；势力间的联盟与战争；主角势力的差异化定位。
- **爽点类型**：势力博弈 + 外交 + 兼并 + 主角势力的崛起。
- **消费时机**：第二卷起开始接触废土势力；中后段主角成为废土霸主。
- **变体**：①主角消灭军阀统一区域；②主角联盟多方制衡；③主角扶植傀儡；④主角的基地成为废土中心；⑤废土势力联合抵御更大威胁（兽潮 / 外星）。
- **消费绑定提示**：标注为**阶段转折**。具体场景：第二卷末用一个"击败 / 兼并一个区域级军阀"事件，让主角势力从"幸存者据点"跃升为"废土霸主"，作为本卷的势力转折。

### 末世重生 / 时间循环（新增）
- **资源需求**：重生的触发（死亡回归 / 时间循环 / 系统重置）；重生保留的信息（记忆 / 物品 / 能力）；重生的代价与次数限制；重生信息的利用（提前布局 / 规避死亡）。
- **爽点类型**：信息差爽 + 提前布局 + 反复试错的智斗。
- **消费时机**：第一卷开篇钩子（重生开局）；贯穿全书作为主角的核心金手指。
- **变体**：①一次性重生（回到末世前）；②多次时间循环（死亡回归）；③部分记忆保留（碎片式）；④可携带物品回归；⑤重生次数有限制造紧迫感。
- **消费绑定提示**：标注为**开篇钩子 + 高频爽点**。具体场景：第一卷第一章用一次重生开局抛出主角的信息差优势，每卷用 1~2 次"利用前世信息截胡 / 规避死亡"事件展示金手指价值。

### 异兽驯化与坐骑培养（新增）
- **资源需求**：可驯化的变异兽 / 丧尸体系；驯化机制（契约 / 喂养 / 进化）；变异兽的等级与进化路径；变异兽在基地 / 战斗中的作用。
- **爽点类型**：收集养成 + 兽宠战斗 + 跨物种羁绊 + 兽潮指挥。
- **消费时机**：第二卷起开始驯化；中后段主角拥有兽宠军团。
- **变体**：①主角驯化丧尸当劳工 / 战兵；②驯化变异兽当坐骑 / 战宠；③建立变异兽军团；④兽宠进化到高阶拥有智慧；⑤兽宠成为基地的守护神。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每 1~2 卷安排一次"驯化新兽宠 + 进化 + 战斗验证"事件，作为主角战力跃迁的节点。

### 末世商队与跨区域贸易（新增）
- **资源需求**：废土上的商队网络；商路的危险（丧尸 / 强盗 / 环境）；不同区域的资源差异（南方有食物、北方有矿产）；货币的演变（旧货币 / 物物交换 / 异能晶核）。
- **爽点类型**：贸易碾压 + 跨区域影响力 + 商业情报 + 商路保卫战。
- **消费时机**：第二卷起开始接触商队；中后段主角掌握商路主导权。
- **变体**：①主角组建自己的商队；②主角垄断关键商路；③商队贸易引发势力冲突；④商队其实是情报网络；⑤跨区域贸易让主角成为废土枢纽。
- **消费绑定提示**：标注为**高频爽点**。具体场景：每卷至少一次"商队贸易胜利 + 主角势力跨区域扩张"事件，作为主角影响力扩展的节点。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：基地建设的"安全感—扩张"循环
- **标准形态**：主角建立基地获得安全感，然后扩张引来更大威胁，威胁消除后继续扩张。
- **可变维度**：基地的形态（固定 / 移动 / 多点）；扩张的速度（稳扎稳打 vs 急速膨胀）；扩张引来的威胁类型（兽潮 / 军阀 / 官方残留 / 异界）；基地的内部矛盾（人口 / 资源 / 派系）。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"移动城市式基地"而非"固定基地"，这个桥段会变成什么形态？扩张逻辑如何重组？如果 <Strategy 阶段目标> 让主角主动放弃基地去追寻末世真相（非建设流），基地爽点如何让位于探险爽点？

### 母题 2：人性博弈的"救与不救"道德困境
- **标准形态**：主角在救人与自保之间反复抉择，每次抉择都塑造其领袖人设。
- **可变维度**：被救对象的性质（平民 / 亲友 / 潜在威胁）；救人的代价（物资 / 暴露 / 暂时削弱）；不救的后果（道德压力 / 报复 / 错过关键盟友）；主角的底线（救所有 / 救熟人 / 只救有用）。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"主角是冷酷的末世老油条"而非"善良的领袖"，这个桥段会变成什么形态？人性戏从何而来？如果 <Strategy 阶段目标> 让主角的底线在第二卷被彻底击碎（黑化），需要前置哪些世界事件？

### 母题 3：末世真相的"渐进揭露"曲线
- **标准形态**：末世真相从零星线索到全面揭露，最终主角找到净化 / 拯救途径。
- **可变维度**：真相的性质（自然 / 人为 / 神意 / 外星）；真相揭露的速度（一次性 vs 渐进）；真相是否可改变（可净化 vs 不可逆）；主角与真相的关系（旁观者 vs 关键变量）。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"末世不可逆转、只能适应"而非"可净化拯救"，这个桥段会变成什么形态？结局如何收束？如果 <Strategy 阶段目标> 让主角本身就是末世的源头或净化关键（黑化 / 救世分支），需要前置哪些伏笔？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评素材（晋江论坛吐槽帖、知乎套路总结、马良作家反套路分析）：

- **"入丧尸堆、囤货、基地建设"千篇一律**：晋江论坛读者集中吐槽末世文的雷同套路。规避：末世形式、囤货方式、基地形态至少有一项反常规（如天灾而非丧尸、共享仓库而非个人空间、移动城市而非固定基地）。
- **三大类型固化（丧尸 / 天灾 / 废土）缺乏创新**：Threads 讨论指出末世文被归纳为三种固定模式。规避：混合型末世（丧尸 + 天灾 + 外星）或反常规末世（AI 觉醒 / 维度入侵 / 古代诅咒）。
- **"让主角当丧尸"的反套路已被尝试**：番茄 9.4 分作品《你们别不信我真的是丧尸》用反向视角突破。规避：如果用反套路，必须有更深的差异化（如主角是丧尸但要伪装成人类基地领袖），而非简单换视角。
- **"灾难降临，金钱沦为废纸，秩序都是空谈，一切的保证只有力量"被反复套用**：这句话已成末世文的陈词滥调。规避：避免直接照搬此类套话，用具体场景代替抽象宣言。
- **重生开局泛滥**：末世重生已成为标准开局，读者审美疲劳。规避：重生的次数 / 保留物 / 代价必须有反常规设定（如只能重生 3 次 / 不能带记忆只能带物品 / 每次重生世界线微变）。
- **后期统一废土后乏味**：与领主流类似，末世文后期统一废土后缺乏张力。规避：在统一前引入更大威胁（异界入侵 / 末世真相激活 / 神级变异体）。

### 未覆盖子流派的推导路径

- **天灾流（非丧尸）**：聚焦极端天气，从"末世降临"推导出"暴雪 / 寒潮 / 旱灾"，从"避难所"推导出"冰屋 / 地下避难所 / 移动雪橇城"，强化生存维度弱化战斗。
- **丧尸流细分（病毒 / 寄生 / 智能）**：从"变异兽丧尸潮"推导出"丧尸进化树"，从"末世真相"推导出"病毒源头"，可衍生"智能丧尸文明"变体。
- **异兽流（废土 + 异兽）**：聚焦变异兽，从"异兽驯化"母题推导出"废土驯兽师"主线，从"废土势力"推导出"驯兽势力割据"。
