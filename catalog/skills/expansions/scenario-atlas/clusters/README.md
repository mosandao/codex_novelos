# 簇文件格式规范（clusters/README.md）

本目录下每个 `.md` 文件是一个题材簇的完整桥段清单。World Agent 通过父级 `prompt.md` 的索引定位到对应簇文件后，读本文件获取该题材的全部可复用桥段。

`<题材英文短名>.md`，全小写，连字符分隔。当前 26 个簇：

## 簇文件结构（强制）

每个簇文件必须按以下结构编写：

```markdown
# <题材中文名>（参考：<代表作 1><代表作 2>）

> **世界观支柱**：<一句话概括该题材的核心世界设定维度>
> **典型消费节奏**：<该题材读者期待的爽点密度与节奏>

## 桥段清单

### <桥段名>
- **资源需求**：这个世界需要哪些势力/规则/资源/地点来支撑此桥段。
- **爽点类型**：此桥段交付的爽感形态。
- **消费时机**：此桥段典型在哪一卷/哪一圈首次被消费。
- **变体**：同母题的不同执行形态，4 个起步，按本书差异选取。
- **消费绑定提示**：此桥段在世界契约中应被标注为哪一类消费时序（开篇钩子 / 阶段转折 / 高频爽点 / 长线伏笔），并指明至少一个具体的消费场景。

### <下一个桥段>
...（每个簇 8~11 个桥段）

## 消费时序表

| 桥段 | 消费时机 | 消费类型 |
|---|---|---|
| ... | 第一卷 | 开篇钩子 |
| ... | 中段 | 高频爽点 |

（每个簇必须提供此表，作为 world-contract 结构性消费约束的输入）

## 启发式推演提示（LLM 推演 hook）

本节是为 LLM 准备的"母题衍生指引"。World Agent 遇到本书差异与图集标准桥段不完全匹配时，按以下启发式问题自行推导新桥段，而不是硬套或跳过。

### 母题 1：<母题名>
- **标准形态**：<图集里的典型桥段长什么样>
- **可变维度**：<这个桥段的哪些维度可以按本书差异调整>
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是 X 而不是 Y，这个桥段会变成什么形态？如果 <Strategy 阶段目标> 把这个桥段从第一卷挪到第三卷，需要前置哪些世界资源？

### 母题 2：<母题名>
...

### 反套路与"烂大街"风险
<列出该题材被读者诟病的套路化问题，提示 World Agent 如何规避或反转。这部分来自 WebSearch 的读者批评素材。>

### 未覆盖子流派的推导路径
<如果本书属于该题材的冷门子流派（图集未直接覆盖），给出从已有母题推导到该子流派的路径。例：修仙→魔修流，可从"宗门考核"反推出"魔宗考核"的桥段变体。>
```

## 编写原则

1. **四字段是底线**：资源需求 / 爽点类型 / 消费时机 / 变体。消费绑定提示和消费时序表是 v0.3.0 新增的强制性消费约束输入。
2. **变体不少于 4 个**：覆盖"标准 / 反转 / 极端 / 反套路"四种执行形态。
3. **启发式推演不是补充桥段**：它是一组问题，引导 LLM 在本书差异下自行推导，而不是预先穷举。
4. **反套路与烂大街风险**必写：这是 WebSearch 读者批评素材的落地，帮助 World Agent 规避已被市场淘汰的执行。
5. **未覆盖子流派推导路径**必写：每个题材都有图集未直接覆盖的子流派（修仙的魔修流、玄幻的洪荒流、都市的兵王流等），给推导路径而不是穷举。
