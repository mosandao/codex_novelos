# 星际 / 太空歌剧（参考：《机动风暴》《吞噬星空》《星际机甲战将》《希灵帝国》）

> **世界观支柱**：以星际跃迁、机甲星战、多文明接触为支柱的太空歌剧，主角从星海一隅崛起至宇宙级强权。
> **典型消费节奏**：开篇星球内崛起钩子，中段跨星系扩张，后段宇宙级威胁。机甲/舰队战是大爽点节拍器。

## 桥段清单

### 星际跃迁文明接触
- **资源需求**：跃迁引擎/星门/虫洞技术、可接触的外星文明库、第一次接触外交协议、文明代差设定。
- **爽点类型**：文明级信息差碾压 + 第一次接触的奇观感 + 文明代差碾压或被碾压的反差。
- **消费时机**：第一卷末或第二卷的第一次出星系节点。
- **变体**：①高等文明降临主角母星（被碾压视角）；②主角文明首次跃迁接触低等文明（碾压视角）；③通过遗迹获得跃迁技术；④跃迁触发未知文明追猎（冲突）；⑤文明接触引发文明融合/同化。
- **消费绑定提示**：阶段转折。具体场景：作为第一卷到第二卷的过渡转折——主角或主角文明第一次完成星际跃迁/接触外星文明，决定下一阶段的星系格局。

### 机甲星战
- **资源需求**：机甲体系（量产/定制/传说级）、机甲驾驶员培养体系、太空战场/星域、舰队与机甲协同、机甲维修与改装。
- **爽点类型**：巨型机械战斗的视觉冲击 + 驾驶员个人武力碾压舰队 + 机甲改装的"硬核"爽点。
- **消费时机**：贯穿全书，每 1-2 卷一次大型机甲战作为高潮。
- **变体**：①单人神级机甲屠戮舰队；②量产机甲群战术碾压；③机甲竞速/武斗赛；④主角从残破机甲起步升级（养成线）；⑤机甲被更高维力量（虫族/古文明）击毁（反转）。
- **消费绑定提示**：高频爽点 + 阶段转折。具体场景：每 10-15 章安排一次机甲战作为稳定爽点供给；每卷安排一次大型星域级机甲/舰队决战作为该卷高潮。

### 星际殖民星球经营
- **资源需求**：可殖民星球/矿星、殖民船队、星球改造（ terraforming）技术、殖民地治理体系、本土生物/原住民。
- **爽点类型**：星球级种田养成 + 殖民扩张的帝国建设爽点。
- **消费时机**：中段（第二至四卷），文明站稳脚跟后的扩张线。
- **变体**：①改造荒星为宜居星；②矿星资源掠夺；③殖民星遇本土生物/原住民文明；④殖民引发星际领土争端（冲突）；⑤多星球殖民版图经营（养成线）。
- **消费绑定提示**：长线伏笔 + 高频爽点。具体场景：每殖民一颗新星作为阶段小高潮；殖民版图扩张作为长线伏笔，后段兑现为"星际帝国版图"。

### 星际势力星际公司博弈
- **资源需求**：星际公司/联邦/帝国势力库、星际贸易航线、政体博弈（公司 vs 联邦 vs 帝国）、情报与暗杀机制。
- **爽点类型**：势力博弈 + 纵横捭阖 + 资源/航线争夺的"权谋"爽点。
- **消费时机**：中段持续，配合殖民与军事线。
- **变体**：①公司垄断被主角打破；②联邦与帝国之间走钢丝；③星际财阀扶持傀儡；④势力博弈引发全面战争；⑤主角建立第三方势力制衡（养成线）。
- **消费绑定提示**：阶段转折 + 高频爽点。具体场景：每卷安排一次大型势力博弈（贸易战/暗杀/外交）作为该卷主线；主角势力从附庸到独立的跃升作为阶段转折。

### 宇宙级威胁远古文明
- **资源需求**：远古文明遗迹/沉睡的远古存在、宇宙级威胁（虫族潮/熵增/高维入侵）、远古科技/遗产、预言与遗迹线索。
- **爽点类型**：史诗级危机感 + 远古遗产获得 + 文明存亡的宏大叙事爽点。
- **消费时机**：后段（第四卷后）的大转折，全书最高潮铺垫。
- **变体**：①远古虫族苏醒吞噬星系；②高维文明入侵；③远古文明遗产引发争夺；④主角是远古文明后裔（血脉伏笔）；⑤宇宙级威胁实为误会/可沟通（反转）。
- **消费绑定提示**：长线伏笔 + 阶段转折。具体场景：前段（第二卷起）埋下"远古遗迹/预言"长线伏笔；后段兑现为"宇宙级威胁降临"大转折，标志全书从"扩张"转入"存亡之战"。

### 基因进化超凡觉醒
- **资源需求**：基因进化药剂/异能觉醒机制、超凡者等级体系、觉醒资源（异兽晶核/辐射/遗迹）、超凡与科技的关系。
- **爽点类型**：个人武力崛起 + 超凡碾压科技 + 进化节点突破。
- **消费时机**：贯穿全书作为主角成长线，与机甲/文明线交织。
- **变体**：①基因药剂觉醒异能；②异兽晶核吞噬进化；③远古基因血脉觉醒；④超凡与机甲融合（武道机甲）；⑤进化失控/异化（反转）。
- **消费绑定提示**：高频爽点 + 长线伏笔。具体场景：每个进化节点（每 1-2 卷）作为主角战力跃迁的阶段小高潮；超凡体系与宇宙级威胁的关联作为长线伏笔。

### 垃圾星底层崛起（新增）
- **资源需求**：垃圾星/废矿星/贫民窟、废品回收/拾荒经济、丛林法则生存环境、第一桶金机遇。
- **爽点类型**：底层逆袭 + 丛林法则求生 + 从废品中翻出金手指的开局爽点。
- **消费时机**：第一卷开篇钩子，主角的出身舞台。
- **变体**：①垃圾星少年捡到残破机甲；②贫民窟少年获得基因异能；③废品中翻出远古遗物；④被欺压后反杀崛起；⑤垃圾星被发现藏有稀有资源（转折）。
- **消费绑定提示**：开篇钩子。具体场景：第一卷前 3 章必须出现"垃圾星/贫民窟出身 + 翻出金手指"作为开篇钩子；world_contract 标注主角出身地为长线伏笔锚点。

### 星际虫族/异族入侵战争（新增）
- **资源需求**：虫族/异族生物体系、虫潮规模设定、人类防线/联邦军、生化武器/针对性科技、虫族母巢/母皇。
- **爽点类型**：人类存亡战争 + 大规模战役 + 屠虫爽点 + 英雄主义牺牲。
- **消费时机**：中后段大型战争线，配合宇宙级威胁母题。
- **变体**：①虫潮吞噬边境星域；②人类反攻虫族母星；③虫族进化适应人类武器（反转）；④与虫族母皇对话/沟通；⑤虫族实为更高等文明的生物兵器（伏笔）。
- **消费绑定提示**：阶段转折 + 长线伏笔。具体场景：每卷安排一次大型虫族战役作为该卷高潮；虫族背后的更高存在作为长线伏笔，结局卷揭晓。

### 星际学院/军校培养（新增）
- **资源需求**：星际军校/学院体系、师资/课程、同学圈子、学院资源（训练场/星舰/机甲）、升学与考核。
- **爽点类型**：校园日常 + 学院资源倾斜 + 同学羁绊的轻松爽点。
- **消费时机**：第一卷后半至第三卷，主角成长主线。
- **变体**：①军校入学考试碾压；②学院机甲/异能大赛；③导师偏爱收徒；④学院派系/世家子弟冲突；⑤毕业即入伍参战（转折）。
- **消费绑定提示**：阶段转折 + 高频爽点。具体场景：第一卷末以"入学军校"作为阶段转折；学院期间每卷安排一次"考核/大赛"作为该卷高潮。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：个人武力 vs 科技体系
- **标准形态**：主角凭基因进化/超凡觉醒/神级机甲，以个人武力碾压舰队与文明。
- **可变维度**：个人武力的来源（基因/异能/机甲/古修）、个人武力的上限（星系级 vs 宇宙级）、个人与集体（舰队/军团）的关系。
- **衍生问题**：如果本书的 Architecture 核心引擎是"舰队指挥"而非"个人武力"，机甲星战桥段会变成"星舰战术/舰队编队"的什么形态？个人高光桥段该如何重新设计为"关键时刻的旗舰决断"？

### 母题 2：文明代差
- **标准形态**：主角文明与外星文明存在技术/进化代差，碾压或被碾压。
- **可变维度**：代差的方向（主角高 vs 低）、代差的维度（科技/超凡/文化）、代差的弥合速度。
- **衍生问题**：如果本书的 Strategy 把主角文明从"高代差碾压方"改为"低代差被碾压方"，文明接触桥段会从"碾压爽点"变成"求生 + 逆向工程逆袭"的什么形态？需要前置哪些"偷师/考古"桥段？

### 母题 3：尺度膨胀
- **标准形态**：主角的活动尺度从星球→星系→宇宙逐级膨胀。
- **可变维度**：膨胀的速度、每级尺度的舞台复杂度、旧尺度舞台的去留（母星是否被抛弃）。
- **衍生问题**：如果本书的核心引擎是"深耕单星系"而非"无限膨胀"，宇宙级威胁桥段该如何改为"星系内的高密度博弈"？殖民桥段该如何缩减或改为"星系内行星开发"？

### 反套路与"烂大街"风险
来自 WebSearch 读者批评的提炼：
- **垃圾星少年捡机甲已成公式**：底层少年+残破机甲+丛林法则+离开垃圾星，套路高度同质化。建议让垃圾星本身成为长线伏笔（实为远古战场/藏有秘密），而非纯背景板。
- **机甲屠舰队数值化**：单人神级机甲屠戮整支舰队沦为数值碾压，缺乏战术深度。建议强化机甲改装的工程细节与舰队协同战术。
- **虫族/外星种族脸谱化**：虫族=无脑吞噬、外星种族=反派，缺乏文明深度。建议给异族文明设计独立的文化/动机，甚至可沟通可结盟。
- **远古文明=万能金手指仓库**：远古遗迹沦为"主角开挂提款机"。建议让远古遗产有代价/反噬，或远古文明本身仍是活跃威胁。
- **后期尺度失控**：星系→宇宙→多元宇宙层层膨胀，早期舞台与人物被抛弃，叙事失去锚点。建议保留母星/母校/初恋等"人性锚点"贯穿全书。

### 未覆盖子流派的推导路径
- **星际修仙/宇宙修真**：从"基因进化超凡觉醒"反推，把异能体系替换为修真体系（金丹/元婴/渡劫），星球=洞天，星系=修真界，桥段混血 xianxia.md。需新增"宇宙天劫/星际宗门"母题。
- **机甲武道/机甲修真**：从"机甲星战"反推，机甲与武道/修真融合（机甲即法宝、驾驶即御剑），桥段重心从"科技改装"变为"机甲修炼合一"。
- **太空歌剧宫廷流**：从"星际势力博弈"反推，强化帝国宫廷/皇室联姻/继承权斗争，弱化军事线，桥段重心从"星战"变为"星际宫廷权谋"，混血 officialdom.md。
- **星际商人/贸易流**：从"星际殖民"反推，主角是星际商人，桥段重心从"征服"变为"星际贸易/走私/航线垄断"，混血 isekai-build.md 的贸易垄断母题。
- **硬科幻/技术流**：从"星际跃迁"反推，强化技术细节的硬核推演（轨道力学/相对论/熵），弱化超凡线，桥段重心从"个人武力"变为"技术解题"。
- **星战同人/星际争霸同人**：从"星际虫族入侵"反推，套用既有游戏世界观（星际争霸/战锤/光环），桥段需对齐原作的种族与设定。
