# 游戏流 / 电竞（参考：《全职高手》《网游之近战法师》《虚拟入侵》《英雄联盟之传奇正盛》）

> **世界观支柱**：以网络游戏或电竞职业赛事为核心舞台，主角通过游戏内的实力碾压或电竞冠军成就爽点。
> **典型消费节奏**：开篇入服/复出钩子，之后高频"首杀/首通/比赛胜利"循环，电竞线按赛季推进。

## 桥段清单

### 副本首杀首通
- **资源需求**：高难度副本/Boss、首杀奖励机制（唯一称号/装备/全服公告）、竞速对手（其他公会/重生记忆里的前世路线）。
- **爽点类型**：信息差抢先 + 全服公告的"扬名"爽点 + 唯一奖励独占。
- **消费时机**：贯穿全书，每个新副本/资料片都是一次首杀机会。
- **变体**：①重生记忆抢先首杀；②隐藏职业碾压首通；③公会竞速抢首杀；④首杀被截胡后复仇（反转）；⑤首杀触发隐藏剧情（长线伏笔）。
- **消费绑定提示**：开篇钩子 + 高频爽点。具体场景：第一卷前 5 章必须有一次"首杀/首通"作为开篇钩子；之后每个新副本开放（每 10-15 章）安排一次首杀作为稳定爽点。

### 公会争霸
- **资源需求**：公会令/建会资格、公会成员库、攻城/领地战赛制、敌对公会库、公会资源（资金/领地/荣誉）。
- **爽点类型**：势力对抗 + 攻城掠地 + 公会排名跃升的集体荣誉爽点。
- **消费时机**：中段起持续，每 1-2 卷一次大型公会战。
- **变体**：①小公会逆袭大公会；②国战/跨服公会战；③公会内讧/叛徒（反转）；④公会联盟博弈；⑤从零建会到全服第一（养成线）。
- **消费绑定提示**：阶段转折 + 高频爽点。具体场景：第一卷末或第二卷以"建立公会"作为阶段转折；之后每卷安排一次大型公会战作为该卷高潮。

### 隐藏职业血脉觉醒
- **资源需求**：隐藏职业转职任务/触发条件、唯一性（全服唯一）、血脉/传承背景故事、与正统职业的差异化技能树。
- **爽点类型**：唯一性独占 + 隐藏内容揭晓的"天选"爽点 + 技能碾压。
- **消费时机**：第一卷开篇转职钩子，后续觉醒节点持续。
- **变体**：①开局觉醒唯一隐藏职业；②血脉觉醒解锁隐藏分支；③隐藏职业被削弱/曝光（反转）；④隐藏职业反噬（代价）；⑤多隐藏职业集于一身（极爽流）。
- **消费绑定提示**：开篇钩子 + 长线伏笔。具体场景：开篇转职即觉醒隐藏职业作为钩子；隐藏职业的来历/血脉作为长线伏笔，中后段揭晓其与游戏世界观/主线的关联。

### 全球总决赛电竞向
- **资源需求**：职业战队/俱乐部体系、赛季赛制（联赛/杯赛/世界赛）、赞助商/资本、对手战队库（韩国/欧美/东南亚）、直播与解说生态。
- **爽点类型**：为国争光 + 黑马逆袭 + 冠军加冕的极致荣誉爽点。
- **消费时机**：电竞线的最高潮，全书结尾或赛季大卷。
- **变体**：①退役老将复出夺冠；②草根战队逆袭豪门；③决赛击败宿敌韩国队；④决赛前主力受伤/换人（反转）；⑤卫冕王朝建立（连载线）。
- **消费绑定提示**：阶段转折 + 长线伏笔兑现。具体场景：作为电竞线最高潮，应安排在全书最后 1-2 卷；从第一卷起埋下"世界赛冠军"长线伏笔，每个赛季推进一次。

### 装备材料垄断
- **资源需求**：稀有材料产地/Boss 掉落、市场交易系统、制造专业（锻造/炼金/附魔）、资本积累。
- **爽点类型**：经济碾压 + 市场操控 + 财富积累的"商人"爽点。
- **消费时机**：中段持续，配合公会战/赛事。
- **变体**：①垄断稀有材料定价；②制造专业出产唯一装备；③囤货炒作市场；④垄断被打破/反垄断（反转）；⑤用经济手段瓦解敌对公会。
- **消费绑定提示**：高频爽点 + 长线伏笔。具体场景：每 10 章安排一次"材料垄断/装备竞拍"的小爽点；财富积累作为长线伏笔支撑后期的公会/战队建设。

### 版本更迭资料片
- **资源需求**：游戏版本更新机制、新地图/新职业/新系统、玩家适应期、版本强势流派。
- **爽点类型**：版本红利 + 信息差抢先适应 + 旧秩序洗牌的爽点。
- **消费时机**：每 2-3 卷一次大版本更新作为剧情转折。
- **变体**：①重生者抢先适应新版本；②版本削弱主角职业（反转）；③新资料片开放新大陆/新赛事；④版本更迭淘汰旧豪门；⑤版本彩蛋/隐藏内容。
- **消费绑定提示**：阶段转折。具体场景：每 2-3 卷安排一次大版本更新作为该阶段转折节点，重置格局、引入新爽点线。

### 游戏 VR 化现实入侵
- **资源需求**：游戏与现实交融机制（游戏舱/神经连接/异变）、现实能力/物品回流、政府/军方介入、现实危机。
- **爽点类型**：游戏能力现实化的"超能力"爽点 + 现实危机拯救。
- **消费时机**：中后段大转折，从纯游戏转入现实入侵线。
- **变体**：①游戏装备现实化；②游戏怪物入侵现实；③玩家现实获得游戏技能；④游戏成为异界通道（混血 infinite.md）；⑤现实入侵被掩盖/官方介入（阴谋型）。
- **消费绑定提示**：阶段转折 + 长线伏笔兑现。具体场景：前段埋下"游戏异常"长线伏笔，中后段兑现为"现实入侵"大转折，标志全书从"游戏爽文"转入"现实超凡"阶段。

### 重生复仇与前世记忆（新增）
- **资源需求**：前世被害/背叛背景、重生节点、前世记忆库（攻略/路线/隐藏内容）、前世仇人库。
- **爽点类型**：信息差碾压 + 复仇打脸 + 改写命运的爽点。
- **消费时机**：开篇背景钩子 + 贯穿全书的复仇线。
- **变体**：①前世被挚友/公会背叛重生；②重生回游戏开服抢先机；③逐步揭穿前世阴谋；④仇人前世今生实力对比反转；⑤与前世仇人合作（反转）。
- **消费绑定提示**：开篇钩子 + 长线伏笔。具体场景：开篇即用"前世被害重生"作为钩子；复仇线作为长线伏笔，每卷推进一次，高潮卷对决仇人。

### 主播/直播生态与粉丝经济（新增）
- **资源需求**：直播平台、观众/粉丝/弹幕生态、打赏/订阅机制、同行主播库、舆论/黑粉机制。
- **爽点类型**：扬名 + 粉丝增长 + 舆论碾压 + 技术流直播的认知优越。
- **消费时机**：第二卷起持续，与赛事/首杀线交织。
- **变体**：①技术主播爆红；②带妹/娱乐反差萌；③舆论危机公关；④黑粉/对线打脸；⑤直播引发职业战队关注。
- **消费绑定提示**：高频爽点。具体场景：每 10 章安排一次"直播间人气暴涨/弹幕反应"镜头作为稳定爽点供给；舆论危机作为阶段转折。

### 职业战队经营与转会博弈（新增）
- **资源需求**：俱乐部/资本/管理层、选手转会市场、教练/战术体系、赞助商、联赛规则。
- **爽点类型**：经营养成 + 转会博弈 + 战队从弱到强的集体荣誉。
- **消费时机**：电竞线中段，配合赛季推进。
- **变体**：①退役选手转型教练；②组建草根战队；③天价转会博弈；④战队内部矛盾/换血（反转）；⑤资本介入与电竞纯粹性的冲突。
- **消费绑定提示**：阶段转折 + 长线伏笔。具体场景：以"组建战队/重大转会"作为阶段转折；战队磨合作为长线伏笔，在世界赛前兑现为团队配合质变。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：信息差抢先
- **标准形态**：主角凭重生记忆/攻略/隐藏提示抢先首杀、抢先适应版本、抢先垄断。
- **可变维度**：信息差的来源（重生/系统/外服经验/数据挖掘）、信息差的衰减速度（其他玩家追赶）、信息差的边界（哪些内容无法抢先）。
- **衍生问题**：如果本书的 Architecture 核心引擎是"纯技术流"而非"信息差"，抢先桥段会从"知道攻略"变成"操作碾压"，需要前置哪些技术展示桥段？如果信息差会随版本衰减，后期如何维持爽点？

### 母题 2：唯一性独占
- **标准形态**：主角获得全服唯一的隐藏职业/称号/宠物/装备。
- **可变维度**：唯一性的形式（职业/装备/称号/坐骑）、唯一性的曝光时机、唯一性带来的追捧与觊觎。
- **衍生问题**：如果本书的 Strategy 把"唯一性曝光"从第一卷挪到第三卷，前期如何用"匿名小号"维持悬念？如果唯一性可以被复制/剥夺，桥段的紧张感会如何重构？

### 母题 3：集体 vs 个人
- **标准形态**：电竞/公会线强调集体荣誉，首杀/直播线强调个人英雄。
- **可变维度**：集体与个人的比重、个人能力对集体的带动、集体对个人的制约（战术/牺牲）。
- **衍生问题**：如果本书的核心引擎是"孤狼流"，公会/战队桥段该如何缩减或改为"主角单刷副本/单人带飞国家队"？如果核心是"团队养成"，首杀桥段该如何改为"五人配合首通"？

### 反套路与"烂大街"风险
来自 WebSearch 读者批评的提炼：
- **隐藏职业 + 首杀 + 重生三件套已成公式**：主角开局觉醒唯一隐藏职业、靠重生记忆抢首杀、然后一路碾压，套路高度同质化。建议让隐藏职业有代价/缺陷，或让重生记忆因蝴蝶效应失效。
- **BOSS 不堪一击**：读者批评很多网游文 Boss 沦为首杀工具人，缺乏挑战感。建议设计需要多次开荒、有机制深度的 Boss，让首杀本身有技术含量。
- **属性碾压代替战术**：稀有装备+宠物+技能堆数值，战斗沦为"一刀秒杀"。建议强化操作/战术/配合展示，而非纯数值碾压。
- **重生复仇线套路化**：前世被害→重生→打脸已成为网游文标配，复仇动机单一。可尝试"重生后发现自己前世才是反派"或"重生记忆是伪造的"等反转。
- **公会战/国战灌水**：后期陷入无尽的公会战国战模板。建议引入"游戏停服危机/电竞职业化"等元叙事作为差异化。

### 未覆盖子流派的推导路径
- **全息网游/VR 网游**：从"副本首杀"反推，沉浸式 VR 带来体感操作、痛觉反馈，桥段从"点击操作"变为"身体格斗"，需混血进 wuxia.md 或 xuanhuan.md 的战斗母题。
- **无限流网游（网游+副本世界）**：从"副本首杀"反推，副本本身是真实异界，死亡真实化，混血 infinite.md。
- **电竞言情/电竞日常**：从"职业战队经营"反推，弱化赛事爽点，强化选手日常/情感线，桥段重心从"夺冠"转向"人物成长与关系"。
- **游戏策划/开发者视角**：从"版本更迭"反推，主角是游戏策划/开发者，桥段从"适应版本"变为"设计版本/对抗玩家"，可衍生"策划与玩家的博弈"母题。
- **游戏降临/异界化为现实**：从"游戏 VR 化现实入侵"反推到极致，整个游戏世界取代现实，所有玩家被困游戏世界求生，混血 downturn.md 或 infinite.md。
