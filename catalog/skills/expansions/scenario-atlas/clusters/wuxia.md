# 武侠（参考：金庸《天龙八部》《射雕英雄传》、古龙《七种武器》、温瑞安《四大名捕》、《雪中悍刀行》）

> **世界观支柱**：以江湖（独立于朝堂的武人社会）、武功（招式/内功/轻功/暗器）、神兵、恩义为支柱，侠客在恩怨情仇与家国天下间抉择。
> **典型消费节奏**：以"恩怨—寻秘—对决"为循环，节奏中速，重人物与意境，高潮常落在武林大会、灭门复仇、盟主之争等集群事件。

## 桥段清单

### 江湖恩怨灭门复仇
- **资源需求**：被灭门的主角家族/师门、仇家势力（单一门派或联盟）、复仇所需的武功/情报/盟友、江湖道义与私仇的张力。
- **爽点类型**：宿怨清算 + 血债血偿 + 侠义悲歌。
- **消费时机**：第一卷开篇埋线，贯穿全书至末卷清算。
- **变体**：①标准——主角苦练后逐一复仇；②反转——仇人背后有更大阴谋或替罪羊；③极端——主角发现灭门是自家师门所为；④反套路——主角放弃复仇，转而化解恩怨止杀。
- **消费绑定提示**：标注为「开篇钩子」+「长线伏笔」。消费场景：开篇用灭门/血仇作为主角踏入江湖的动因，贯穿全书作为长线伏笔，末卷完成清算或反转。

### 武功秘籍争夺
- **资源需求**：稀缺武学秘籍（绝世武功/失传剑谱/内功心法）、多方觊觎的势力、秘籍的持有者与守护机制。
- **爽点类型**：机缘 + 实力质变 + 江湖博弈。
- **消费时机**：第二至第三卷，主角武学根基跃升的契机。
- **变体**：①标准——主角获得绝世秘籍练成神功；②反转——秘籍是陷阱/伪造/诅咒；③极端——秘籍需配特定体质/血脉才能练；④反套路——秘籍内容平平，主角靠自悟走出新路。
- **消费绑定提示**：标注为「阶段转折」。消费场景：中段用秘籍争夺作为主角武学进阶的阶段转折，同时牵出多方势力博弈。

### 武林大会英雄宴
- **资源需求**：跨门派的大型聚会（盟主选举/英雄帖/论剑/试剑大会）、各派高手阵容、聚会背后的阴谋或契机。
- **爽点类型**：群英荟萃 + 巅峰对决 + 江湖闻名。
- **消费时机**：中段，主角在江湖正式立万的舞台。
- **变体**：①标准——主角在大会上扬名立万；②反转——大会是阴谋陷阱（如《四大名捕》式诡异凶案）；③极端——大会中途被外敌/官府围剿；④反套路——主角是宴会暗中的操盘者，不出手却左右局势。
- **消费绑定提示**：标注为「高频爽点」+「阶段转折」。消费场景：中段每卷安排一次不同级别的大会（门派级→州级→武林级），作为稳定爽点与江湖地位跃升节点。

### 名剑神兵认主
- **资源需求**：神兵体系（名剑/神刀/奇门兵器）、神兵的来历与传说、认主机制（缘份/血脉/德行/武力）。
- **爽点类型**：机缘加身 + 独特性确立 + 兵器拟人化情感。
- **消费时机**：第二至第三卷，主角获得标志性武器的节点。
- **变体**：①标准——神兵主动认主角为主；②反转——神兵是诅咒，认主即招追杀；③极端——神兵有意识，与主角谈判共生；④反套路——主角拒绝神兵，靠木剑/徒手证道。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：中段作为主角"标志性武器"确立的阶段转折，同时埋下神兵来历之谜作为长线伏笔。

### 朝堂与江湖
- **资源需求**：朝廷势力（锦衣卫/六部/皇室）、江湖门派、朝野博弈的接口（案件/密令/通缉）、侠客与体制的张力。
- **爽点类型**：权谋博弈 + 侠义与忠义的冲突 + 双面身份。
- **消费时机**：中后段，主角从江湖游侠卷入朝堂大事。
- **变体**：①标准——主角助朝廷平乱或对抗朝廷；②反转——主角是朝廷密探潜伏江湖；③极端——主角同时在朝野两边任职；④反套路——主角主动斡旋，促成朝野和解。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：中后段作为主角从"江湖人"跃升至"影响天下格局者"的阶段转折，同时埋下朝堂主线伏笔。

### 武林盟主天下第一
- **资源需求**：武林盟主选举机制、天下高手排名（兵器谱/英雄榜）、争夺盟主的各方势力、盟主权力的实质。
- **爽点类型**：巅峰登顶 + 武林共尊 + 责任与孤独。
- **消费时机**：末卷或倒数第二卷，全书武学线的顶点。
- **变体**：①标准——主角击败所有竞争者登顶；②反转——盟主之位是烫手山芋/陷阱；③极端——主角登顶后发现更高境界（仙侠/出家）；④反套路——主角拒绝盟主之位，飘然远去。
- **消费绑定提示**：标注为「阶段转折」。消费场景：作为全书武学线的顶点高潮，标志主角在江湖的终极立万。

### 师徒门派恩义
- **资源需求**：可拜的名师/门派、师徒名分制度、同门关系（师兄妹/师兄弟）、师门恩怨与传承。
- **爽点类型**：传承获得 + 师徒情 + 同门羁绊（含反目）。
- **消费时机**：第一卷与贯穿全书，主角武学根基与情感纽带的建立。
- **变体**：①标准——主角拜入名门得真传；②反转——师父别有用心或师门有黑历史；③极端——主角同时承袭多家师门拼凑传承；④反套路——主角无师自通，反而指点名师。
- **消费绑定提示**：标注为「开篇钩子」+「长线伏笔」。消费场景：早期建立主角的师承与同门关系，作为情感纽带与长线伏笔（师门秘密/同门反目/传承之谜）。

### 秘籍残卷武学拼图
- **资源需求**：失传或分散的武学残卷（剑谱/心法/招式）、残卷分布线索、补全机制（印证/融合/悟道）。
- **爽点类型**：知识拼图 + 武学领悟 + 独门绝学成型。
- **消费时机**：贯穿全书的长线，常作为多卷暗线。
- **变体**：①标准——集齐残卷补全绝世武学；②反转——残卷是诱饵，每得一份引来追杀；③极端——残卷实为禁术，补全招反噬；④反套路——主角自创武学，残卷只是参照。
- **消费绑定提示**：标注为「长线伏笔」。消费场景：作为贯穿 3~5 卷的暗线，每卷推进一段，末卷合卷爆发。

### 武林阴谋江湖诡局
- **资源需求**：幕后黑手（邪教/朝廷/隐世高手/复仇者）、布局动机与执行链、可被串联的诡异事件（凶案/失踪/灭门）、揭局过程。
- **爽点类型**：悬疑解谜 + 智斗幕后 + 大反转。
- **消费时机**：中后段或末卷，全书最大反转之一。
- **变体**：①标准——主角揭穿阴谋清算幕后；②反转——主角自己也是局中棋子；③极端——幕后是主角至亲/师尊；④反套路——主角发现"阴谋"实为善意安排，主动配合。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：中段用一连串诡异事件埋伏笔（如《四大名捕》式十三凶徒连环案），末卷揭局作为全书最大反转。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：复仇与侠义的张力
- **标准形态**：主角背负灭门血仇踏入江湖，苦练武艺逐一复仇，过程中遭遇侠义与私仇的冲突。
- **可变维度**：复仇强度（赶尽杀绝/适度惩罚/化解）、侠义底色（儒家之侠/道家之侠/墨家之侠/反侠）、复仇与救赎的优先级。
- **衍生问题**：如果本书核心引擎是"侠之大者"而不是"私仇清算"，灭门复仇会从"血债血偿"变成什么？主角是该执着复仇，还是该为更大利害放下私仇？如果 Strategy 把复仇清算从末卷挪到第二卷，后续靠什么支撑读者耐心？

### 母题 2：武学传承与创新
- **标准形态**：主角拜师学艺获得传承，或抢夺秘籍练成神功，武学线沿"继承—精进—开宗"推进。
- **可变维度**：传承来源（师承/秘籍/奇遇/自悟）、传承与创新的比例、武学终极形态（开宗立派/超越前人/返璞归真）。
- **衍生问题**：如果本书核心引擎是"自创而非继承"，武学传承会从"集邮秘籍"变成什么？主角是该集齐残卷补全，还是该在残卷基础上破而后立？如果本书是"无武功的武侠"（靠智谋/权谋/兵器），武学线该如何重新定义？

### 母题 3：江湖与朝堂的双面博弈
- **标准形态**：主角在江湖自由与朝堂责任间抉择，或助朝廷平乱，或对抗朝廷庇护江湖。
- **可变维度**：朝野关系（对抗/合作/渗透/制衡）、主角立场（江湖人/朝廷人/双面/调停者）、家国天下的权重。
- **衍生问题**：如果本书核心引擎是"调停而非对抗"，朝堂与江湖会从"二选一"变成什么？主角是该选边站，还是该成为朝野之间的第三方力量？如果 Strategy 让主角从开篇就身在朝堂，江湖行的色彩会如何变化？

### 母题 4：神兵与主人的缘分
- **标准形态**：主角因缘际会获得名剑神兵，神兵认主，成为主角标志。
- **可变维度**：神兵主动性（死物/半意识/有意志）、认主机制（缘份/血脉/德行/武力）、神兵与主角的关系（工具/伙伴/诅咒）。
- **衍生问题**：如果本书核心引擎是"人剑合一"而不是"神器加身"，神兵会从"外挂"变成什么？主角是该依赖神兵，还是该在某个节点放下神兵证道？如果神兵是诅咒，认主的代价该如何铺陈？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评与武侠研究的集中意见：

- **"离奇与巧合"过度依赖**：中国作家网分析指出，武侠小说惯用"离奇与巧合"推进剧情（秘籍偶然获得、仇人偶然相遇、神兵偶然认主），金庸靠人物性格合理性来超越这一俗套，但后世模仿者常流于机械。规避方式：用人物性格与动机驱动而非巧合，让每次"偶遇"都有前因后果。
- **灭门复仇起点同质化**：几乎每本武侠都以"全家被杀"开局，复仇线千篇一律。规避方式：让灭门有更复杂真相（替罪羊/主角自家责任/误会），或主角主动放弃复仇转而化解恩怨。
- **武功秘籍"无敌化"**：绝世秘籍练成即天下无敌，缺乏武学张力。规避方式：让秘籍有局限（需配体质/有反噬/被克制），或主角的对手也练成同级武学形成对决。
- **武林大会脸谱化**：大会=比武=打脸，缺乏新意。规避方式：让大会成为阴谋舞台（如温瑞安《四大名捕》式的诡异凶案），或主角是操盘者而非参赛者。
- **名剑神兵过载**：兵器谱排名泛滥，神兵沦为道具。规避方式：限制神兵数量，让每件神兵有独立来历与情感线；或主角用木剑/徒手反衬神兵的虚妄。
- **朝堂线生硬**：江湖与朝堂切换突兀，主角"突然变成大官"。规避方式：在开篇就埋朝堂接口（如主角本是世家子/有官身），让朝堂线自然生长。
- **盟主结局空泛**：登顶盟主后故事戛然而止，"高处不胜寒"流于口号。规避方式：让盟主之位带来真实困境（责任/孤独/更高境界诱惑），给主角有意义的归宿。

### 未覆盖子流派的推导路径

- **武侠重生流**：从"江湖恩怨灭门复仇"反推——主角重生回悲剧前，桥段改为"提前布局避祸""逆转灭门""前世仇人今生盟友"。
- **武侠系统流**：从"武功秘籍争夺"反推——主角靠系统学武，桥段改为"武学面板""熟练度升级""签到神功"。
- **古龙式悬疑武侠**：从"武林阴谋江湖诡局"扩写——主角是侦探式侠客，桥段改为"案件推理""诡异凶案""七种武器式单元剧"。
- **温瑞安式群像武侠**：从"师徒门派恩义"反推——主角是团队一员（如四大名捕），桥段改为"群像协作""师门联动""连环凶案查办"。
- **高武/半仙侠**：从"武林盟主天下第一"反推——武学极致接近仙侠，桥段改为"破碎虚空""武道通神""一剑破万法"。
- **新派武侠/反武侠**：从"复仇与侠义张力"反推——主角质疑侠义本身，桥段改为"反英雄""解构江湖""侠之虚无"。
- **架空武侠/武侠基建**：从"朝堂与江湖"反推——主角以武力立国或 reform 体制，桥段改为"武林立国""江湖议会""武学普及"。
- **女性向武侠/闺阁武侠**：从"师徒门派恩义"反推——主角是女性侠客，桥段改为"女扮男装""闺阁武林""情感与侠义并重"。
