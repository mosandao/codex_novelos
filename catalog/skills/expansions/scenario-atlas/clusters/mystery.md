# 悬疑（参考：《心理罪》《长夜难明》《无证之罪》《坏小孩》）

> **世界观支柱**：以案件、线索、体制、心理侧写为核心，靠"凶案现场 + 嫌疑人矩阵 + 体制阻力 + 真相反转"支撑叙事。
> **典型消费节奏**：开篇以一桩反常规凶案钩住读者，中段以"线索拼图 + 嫌疑人对抗"维持高频推理爽点，后段以"体制对抗 + 真相反转"做长线与阶段转折。

## 桥段清单

### 案件侦破
- **资源需求**：一桩具有独特 signature（作案手法/现场特征/受害者画像）的凶案；一套可调用的侦查资源（法医、技侦、走访）；主角的破案专长。
- **爽点类型**：解谜 + 智商碾压 + 正义伸张。
- **消费时机**：第一卷开篇钩子，之后每个单元案的开头。
- **变体**：①传统刑侦走访破案；②技侦/法医硬核破案；③反套路"主角靠心理学/侧写破案"；④极端"案件本身就是主角设计的局"。
- **消费绑定提示**：开篇钩子 + 高频爽点。每个单元案的开头章节必消费；第一卷第一章的凶案应是全书最反常规的一桩，作为整体钩子。

### 线索拼图
- **资源需求**：散落在多个地点/人物/时间点的碎片线索；一个串联线索的"主线"（同一凶器/同一符号/同一时间）；主角的归纳能力。
- **爽点类型**：拼图完成感 + 智力优越感 + 真相逼近的紧张。
- **消费时机**：单元案中段，多次小拼图 + 卷尾一次大拼图。
- **变体**：①物证拼图（指纹/DNA/纤维）；②人证拼图（多人证词拼接）；③反套路"线索是凶手故意留下的导航"；④极端"拼图完成的形状指向主角自己"。
- **消费绑定提示**：高频爽点 + 长线伏笔。每个单元案的小拼图作为高频爽点；其中至少一条线索碎片应被标注为长线大案的伏笔（如"第三卷发现的纤维与第一卷受害者衣物吻合")。

### 嫌疑人对抗
- **资源需求**：一个有动机、有机会、有智商的嫌疑人矩阵（至少三人）；嫌疑人与主角的智力博弈；嫌疑人的反侦察手段。
- **爽点类型**：猫鼠游戏 + 智力对决 + 反转期待。
- **消费时机**：单元案中后段，每次审讯或对峙。
- **变体**：①嫌疑人主动挑衅；②嫌疑人伪装受害者；③反套路"最像凶手的其实是无辜的，最不像的反而是真凶"；④极端"嫌疑人矩阵本身就是凶手的多人格"。
- **消费绑定提示**：高频爽点。每单元案至少 2~3 次嫌疑人对抗章节，作为线索拼图的间奏。

### 真相反转
- **资源需求**：一个被读者和主角共同接受的"表面真相"；一个被埋伏笔的"真实真相"；一个揭穿节点。
- **爽点类型**：震撼 + 智力被碾压后的爽感 + 重新理解全书的快感。
- **消费时机**：每卷尾一次中等反转，终卷一次大反转。
- **变体**：①凶手身份反转；②动机反转（看似仇杀实为爱）；③反套路"没有反转，表面真相就是真相，但受害者视角反转"；④极端"反转之后再反转，直到读者怀疑叙述本身"。
- **消费绑定提示**：阶段转折 + 长线伏笔。每卷尾的反转作为本卷阶段转折；反转所需的伏笔应在前 80% 章节标注为长线伏笔。

### 体制对抗与孤勇者
- **资源需求**：一个不作为、错判、甚至腐败的体制（警队高层、检方、权力网络）；一个坚持追查的孤勇者主角；一个体制内少数盟友。
- **爽点类型**：悲壮 + 正义感 + 以弱胜强的爽感。
- **消费时机**：第二卷起，主角因案件触碰体制红线后。
- **变体**：①体制不作为主角单干；②体制主动阻挠主角；③反套路"体制内有更大的正义网络在暗中协助"；④极端"主角最终选择进入体制改造体制"。
- **消费绑定提示**：阶段转折 + 长线伏笔。第二卷某单元案牵出体制红线作为本卷阶段转折；孤勇者身份应贯穿全书作为长线。

### 心理画像与罪犯侧写
- **资源需求**：一套可解释、可展示的侧写方法论（犯罪心理、行为分析、地理画像）；主角的心理学/精神病学背景；一份侧写报告作为破案工具。
- **爽点类型**：专业感 + 神探光环 + "未抓人先识人"的装逼感。
- **消费时机**：每个单元案中段，作为缩小嫌疑人矩阵的关键手段。
- **变体**：①传统 FBI 式行为侧写；②反社会人格图谱分析；③反套路"侧写准确到可怕，但被侧写者其实是主角的镜像"；④极端"主角能与凶手的思维同步，但每次同步都侵蚀自己"。
- **消费绑定提示**：高频爽点。每单元案至少一次"侧写报告章节"，作为嫌疑人对抗的智力支撑。

### 连环凶案与作案签名（新增）
- **资源需求**：一个有固定 signature（仪式化手法/选受害者标准/留下标记）的连环凶手；多起可串联的旧案；一份连环案档案。
- **爽点类型**：恐惧升级 + 拼图快感 + "我们面对的不是一个人而是一种意志"。
- **消费时机**：第二卷起的跨单元大案，串联多个单元案。
- **变体**：①传统签名式连环凶手；②模仿犯复制旧案；③反套路"签名是凶手故意栽赃给已死的前辈"；④极端"多个凶手共享一个签名，因为他们被同一组织训练"。
- **消费绑定提示**：长线伏笔 + 阶段转折。第一卷起的某单元案细节应被标注为此桥段伏笔；第二卷揭穿"连环"性质时作为阶段转折。

### 旧案重查与陈年冤案（新增）
- **资源需求**：一桩发生在主角介入前多年、已被定案或冷案的旧案；旧案与主角或重要人物的私人关联；一份过时的卷宗。
- **爽点类型**：时空穿梭感的推理 + 平反冤屈的正义感 + "原来如此"的拼图完成。
- **消费时机**：第二卷或第三卷作为长线大案的主线。
- **变体**：①主角主动翻旧案；②旧案当事人找上门；③反套路"旧案的'真凶'其实也是冤枉的，真凶另有其人"；④极端"旧案从未发生，是集体记忆被篡改"。
- **消费绑定提示**：长线伏笔 + 终卷阶段转折。旧案应在第一卷以"主角的心结/家族往事"形式埋伏笔，终卷揭穿。

### 心理博弈与高智商对决（新增）
- **资源需求**：一个智商匹敌甚至超越主角的对手（高智商罪犯/咨询犯罪顾问/另一个天才侦探）；一个可博弈的封闭空间或长期通信渠道。
- **爽点类型**：棋逢对手 + 智力巅峰对决 + "你懂我我懂你"的暧昧张力。
- **消费时机**：第二卷起作为大反派线，贯穿全书。
- **变体**：①通信式博弈（信件/留言）；②当面审讯式博弈；③反套路"对手其实是主角分裂的人格"；④极端"主角与对手最终联手对抗更大的恶"。
- **消费绑定提示**：阶段转折 + 长线伏笔。第二卷引入对手时作为阶段转折；对手身份应作为长线伏笔至终卷揭穿。

### 小镇往事与群体沉默（新增）
- **资源需求**：一个所有人都知情但所有人都沉默的小镇/厂矿/村落；一桩被集体掩埋的往事；主角的"外来者"或"归来者"身份。
- **爽点类型**：压抑 + 窒息感 + 真相揭穿时的群体崩塌。
- **消费时机**：作为某个中长篇单元案（2~3 卷规模）的世界观底色。
- **变体**：①外来调查者破沉默；②归来者揭往事；③反套路"沉默不是共谋而是集体创伤后的失语"；④极端"小镇本身是虚构的，是某个实验的舞台"。
- **消费绑定提示**：阶段转折 + 长线伏笔。小镇的秘密应作为 2~3 卷的长线伏笔，揭穿章作为整段叙事的阶段转折。

### 叙述诡计与不可靠叙述（新增）
- **资源需求**：一个被有意误导的视角（主角/第一人称/日记体）；一个被隐藏的关键事实；一个揭穿后能重新解读前文的"钥匙"。
- **爽点类型**：智力碾压 + "被骗也爽"的快感 + 重读欲望。
- **消费时机**：终卷或全书最后一卷的揭穿章。
- **变体**：①第一人称主角隐瞒事实；②时间线错位误导；③反套路"叙述可靠但读者被文化偏见误导"；④极端"全文是主角的遗书/供词/妄想"。
- **消费绑定提示**：长线伏笔 + 终卷阶段转折。所有误导性细节应在前文标注为"伏笔/误导"，终卷揭穿章作为全书最终阶段转折。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：单元案与长线大案
- **标准形态**：每卷一个独立单元案，单元案的线索碎片串联出贯穿全书的长线大案。
- **可变维度**：单元案的规模（一章一案 vs 一卷一案）、长线大案的性质（连环/旧案/阴谋）、单元案与长线的耦合度。
- **衍生问题**：如果本书的 Architecture 核心引擎是"解谜"而不是"刑侦"，单元案要不要拉长到一卷一案？如果 Strategy 是单元剧为主，长线大案是否可以推迟到第三卷才浮现？

### 母题 2：反转的层次
- **标准形态**：每卷一次中等反转，终卷一次大反转。
- **可变维度**：反转的密度（每章小反转 vs 每卷大反转）、反转的性质（身份/动机/时间线/叙述本身）、反转所需的伏笔埋设量。
- **衍生问题**：如果本书定位是"轻松悬疑"，反转要不要降烈度？如果核心引擎是"恐怖"，反转是否可以从"凶手是谁"转向"这世界是什么"？

### 母题 3：体制与人
- **标准形态**：孤勇者主角对抗不作为/腐败体制，少数盟友协助。
- **可变维度**：体制的敌意程度、盟友的数量与位置、主角与体制的最终关系。
- **衍生问题**：如果本书是"体制内升迁"视角（参考 `officialdom.md`），孤勇者桥段要不要反过来写成"主角就是体制的修复者"？如果核心引擎是"博弈"，体制戏的比重是否可以超过案件戏？

### 母题 4：恐怖与推理的配比
- **标准形态**：前段靠凶案现场与罪犯侧写营造恐怖，后段靠推理与揭穿转爽。
- **可变维度**：恐怖的来源（凶案现场/罪犯心理/超自然暗示）、推理的硬核程度、配比随卷次的变化。
- **衍生问题**：如果本书是"悬疑 + 诡异流"混血，要不要把 `horror-rules.md` 的规则母题嫁接进来？如果核心引擎是"恐怖"，推理戏是否要让位于氛围营造？

### 反套路与"烂大街"风险
（综合 WebSearch 读者批评素材提炼，来源包括光明日报、新浪、三联生活周刊、界面新闻、澎湃新闻等）
- **套路化叙事"看开头知结尾"**：随着观众观剧量增加，对推理套路的识别能力增强，"旧案追凶、连环凶案、暗黑压抑风格"已成程式化窠臼。World Agent 应为每个单元案设计至少一处"反预期"的细节。
- **题材同质化与"小镇往事"扎堆**：2025 年上半年《沙尘暴》《棋士》《黄雀》《乌云之上》《借命而生》等接连上映但热度未达预期，"小镇 + 往事 + 群体沉默"设定被批评为扎堆。建议把群体沉默母题用到非小镇场景（厂矿/网络社区/跨国公司）。
- **人设套路化**：孤勇者主角 + 高智商罪犯 + 腐败高层的三角人设被反复使用。建议尝试"非孤勇者主角"或"无明确反派"的变体。
- **烂尾与叙事碎片化**：《隐秘的角落》之后多部作品被批评"结局乏力、叙事碎片化"。长线大案的伏笔回收应有明确规划，避免为反转而反转。
- **迷雾剧场式品牌透支**：批量同质化生产透支观众信任。World Agent 应在契约中明确"本书的差异点"，避免落入"暗黑小镇旧案"的默认模板。
- **女性角色刻板化**：被批评为"要么受害者要么工具人"（紫金陈在《长夜难明：双星》中尝试突破）。建议在嫌疑人矩阵与盟友中加入有主体性的女性角色。

### 未覆盖子流派的推导路径
- **本格推理流**：从"线索拼图 + 嫌疑人对抗"加强推导，弱化体制对抗与心理恐怖，可参考日系本格的"密室、不在场证明、凶器诡计"。
- **变格 / 诡异流**：把"真相反转"推向"这世界本身有问题"，嫁接 `horror-rules.md` 的规则母题，营造"细思恐极"氛围。
- **社会派**：把"体制对抗 + 小镇往事"权重提到最高，案件本身让位于社会结构批判，参考紫金陈、东野圭吾社会派作品。
- **法医 / 技侦硬核流**：把"心理侧写"替换为"法医解剖 + 技侦物证"，主角身份改为法医或痕检员，强调专业性。
- **悬疑 + 都市灵气**：嫁接 `urban-qi.md`，让"凶案"带有超自然成分，主角是异能侦探。
- **悬疑 + 系统流**：给主角叠加"破案系统"（线索提示/侧写加成/嫌疑人好感度），嫁接 `system.md`。
