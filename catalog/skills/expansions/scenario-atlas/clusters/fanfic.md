# 同人 / 综漫（参考：综漫同人 / 影视同人 / 四合院系列 / 综英美 / 忘羡向同人文）

> **世界观支柱**：以既有原著作品（动漫 / 影视 / 小说 / 游戏）的人物、关系、剧情节点、世界观为借用底座，主角（穿越者 / 原著配角 / 原著主角）在"已知剧情"的舞台上做不同选择、改写悲剧、发展 CP 或融合多原著世界。核心金手指是"原著知识差"与"原著情感既存"。
> **典型消费节奏**：开篇抛出"穿入哪个原著 + 占据哪个身份 + 知道多少剧情"的钩子，中段以"截胡原著机缘 / 偏离原著节点 / CP 推进"高频循环，后段以"改写原著终局 / 多原著融合真相"做长线收束。

## 桥段清单

### 穿入原著 / 综漫世界
- **资源需求**：一个明确的原著世界（动漫 / 影视 / 小说 / 游戏）、主角穿越后占据的身份（原著角色 / 原创角色 / 穿甲板）、主角对原著剧情的掌握程度（全知 / 半知 / 只看过同人）、与原著人物的初次接触契机。
- **爽点类型**：代入熟悉世界的亲切感 + "我知道接下来会发生什么"的优越感 + 身份错位的喜剧。
- **消费时机**：第一卷开篇 1~10 章，作为全书世界观奠基。
- **变体**：①穿成原著主角抢回主角光环；②穿成原著配角 / 炮灰翻盘；③穿成原著反派自救；④穿成原创角色旁观改写；⑤穿成原著物品 / 动物（极端反差）。
- **消费绑定提示**：开篇钩子 + 长线伏笔。具体场景：开篇即穿入并完成第一次"原著知识变现"（避开一次原著死亡点 / 截胡一个原著机缘），作为金手指契约；同时埋下"主角的穿越是否会被世界意识修正"的长线悬念。
- **跨簇说明**：本桥段聚焦"固定穿入一个原著世界"。若主角是被系统 / 主神驱动在多个位面 / 副本间循环穿梭，则属于快穿流 `quick-transmigration.md`（多位面循环）或无限流 `infinite.md`（主神副本机制），而非固定一个原著世界的同人。同人 = 固定单世界 + 原著借用；快穿 / 无限 = 多世界循环 + 系统驱动。按本书世界结构选用。

### 偏离原著（角色不死 / 不同选择）
- **资源需求**：一个原著中被默认会发生的关键节点（角色死亡 / 反派黑化 / 重要抉择）、可被改写的触发条件、改写后产生的蝴蝶效应、原著"世界意识 / 剧情修正力"对偏离的抵抗机制。
- **爽点类型**：逆天改命 + "我救下了那个该死的人"的情感补偿 + 改写遗憾的救赎感。
- **消费时机**：每个原著关键节点都是一次消费机会，贯穿全书。
- **变体**：①救下原著必死的角色；②阻止原著反派黑化；③让原著失败者走上不同道路；④改写后蝴蝶效应失控（反转）；⑤世界意识强行修正，被救的人换种方式死去（虐心型）。
- **消费绑定提示**：阶段转折 + 长线伏笔。具体场景：每个原著关键节点作为本卷阶段转折；"剧情修正力"的强弱作为长线伏笔，决定主角能否真正改写终局。

### 配角变主角（次要角色深挖）
- **资源需求**：一个原著中戏份不足但有人气的配角（反派 / 师尊 / 工具人 / 背景板）、该配角原著中未展开的背景与动机、可被补完的人物弧光、与原著主角的关系重塑。
- **爽点类型**：补完遗憾 + "原来他 / 她是这样的"的人物揭秘 + 边缘角色逆袭的爽感。
- **消费时机**：贯穿全书，作为人物塑造主线。
- **变体**：①给原著反派完整黑化动机洗白；②给原著工具人配角独立剧情线；③让原著背景板角色抢戏成为真主角；④配角与原著主角关系反转（敌变友 / 友变敌）；⑤配角其实是另一个穿越者（反转）。
- **消费绑定提示**：高频爽点 + 长线伏笔。具体场景：每个原著配角的高光节点作为高频爽点；配角的"真实身份 / 真实动机"作为长线伏笔，中后段揭秘。

### CP 感情线发展
- **资源需求**：一对或多对 CP 配对（原著向 / 跨原著 / 原创配原著）、CP 之间的情感障碍（立场 / 身份 / 原著结局）、CP 推进的节奏节点（相识 / 误解 / 表白 / 在一起）、原著粉丝对 CP 的接受度机制。
- **爽点类型**：嗑糖 + 情感养成 + "我喜欢的 CP 成真了"的愿望满足。
- **消费时机**：贯穿全书，作为情感主线。
- **变体**：①原著向 CP 推进到在一起；②原著悲剧 CP 改写为 HE；③跨原著 / 原创配原著的私设 CP；④CP 中一方是另一个穿越者（双向穿）；⑤原著主角被穿后 CP 崩塌（虐心反转）。
- **消费绑定提示**：高频爽点 + 阶段转折。具体场景：每 10~15 章安排一次"嗑糖 / 情感推进"小高潮；每个情感阶段（表白 / 在一起 / 公开）作为阶段转折。
- **跨簇说明**：本桥段的"攻略感情线"母题与快穿流 `quick-transmigration.md` 的"反派快穿与反派攻略"近似。区别：同人的 CP 是固定一个原著世界内的长期关系养成；快穿的攻略是多位面单元剧式攻略（每个位面一个攻略对象，常设定为同一灵魂）。按本书感情线结构选用。

### 综漫多原著世界融合
- **资源需求**：多个原著世界的融合机制（平行宇宙交汇 / 主神调度 / 共同位面）、各原著世界观的兼容性处理（力量体系差异 / 时间线对齐）、跨原著人物的互动逻辑、跨原著 CP 与冲突的可能。
- **爽点类型**：跨 IP 联动的猎奇爽 + "原来这两个角色会这样互动"的同人奇观 + 力量体系碰撞的碾压感。
- **消费时机**：第二卷起逐步引入第二个原著世界，后段多世界大融合。
- **变体**：①主角凭系统 / 主神调度穿越多个综漫世界；②多个原著世界因事件融合到一个位面；③跨原著 CP（如鸣人遇上路飞）；④跨原著力量体系碾压（修仙者进漫威）；⑤融合失控导致世界崩塌（反转）。
- **消费绑定提示**：阶段转折 + 长线伏笔。具体场景：每引入一个新原著世界作为阶段转折；多世界融合的"真相 / 主谋"作为长线伏笔，终卷揭秘。
- **跨簇说明**：本桥段聚焦"同人式多原著世界融合"。若多世界融合是由主神空间 / 轮回乐园驱动的副本机制（每个世界是一个任务副本、有积分结算与抹杀威胁），则属于无限流 `infinite.md`（主神空间副本），而非同人式综漫。综漫同人 = 借用原著世界做长期叙事；无限流 = 主神空间机制 + 副本任务。按本书核心驱动机制选用。

### 影视同人（四合院 / 谍战剧 / 年代剧）
- **资源需求**：一个热门影视剧原著（四合院系列 / 人民的名义 / 神探狄仁杰 / 父母爱情等）、该剧的时代背景与人物关系网、可被改写的剧情节点、与年代剧 / 权谋剧 / 家庭剧对应的世界规则。
- **爽点类型**：代入熟悉剧情的亲切感 + 改写"气人角色"命运的打脸爽 + 年代 / 体制内的逆袭。
- **消费时机**：第一卷开篇确立原著背景，后续按原著剧情节点推进。
- **变体**：①穿成"气人角色"（如四合院反派）洗白或更黑化；②穿成原著主角加速逆袭；③穿成原著配角（如年代剧女性）独立自强；④阻止原著悲剧（如谍战剧主角不死）；⑤原创角色介入原著搅动格局。
- **消费绑定提示**：开篇钩子 + 高频爽点。具体场景：开篇即穿入并完成第一次"原著剧情改写"（打脸一个气人角色 / 救下一个该死的人）；之后每 10~15 章安排一次原著节点改写。

### 原著人物 OOC（Out of Character）处理
- **资源需求**：原著人物的既有性格设定、偏离原著性格的合理化机制（穿越者占据 / 蝴蝶效应 / 平行世界 / 二创惯例）、原著粉丝对 OOC 的容忍度边界、OOC 服务于何种剧情目的（洗白 / 黑化 / CP 推进）。
- **爽点类型**：反差萌 + "他 / 她原来还有这一面"的人物新鲜感 + 服务于 CP / 洗白的剧情便利。
- **消费时机**：贯穿全书，是同人创作的核心手法之一。
- **变体**：①穿越者占据原著角色导致性格大变（合理化 OOC）；②原著角色因主角介入而改变成长轨迹；③平行世界设定解释性格差异；④原著反派被"洗白"引发争议（高风险）；⑤主角刻意伪装 OOC 隐藏穿越者身份。
- **消费绑定提示**：高频爽点 + 长线伏笔。具体场景：每个原著人物的"反差时刻"作为高频爽点；OOC 的"真实原因"（穿越者身份 / 平行世界）作为长线伏笔，中后段揭秘。
- **跨簇说明**：本桥段的"角色性格偏离"与快穿流 `quick-transmigration.md` 的"位面意识觉醒与 NPC 反叛"有表面相似（角色行为偏离既定），但同人的 OOC 是对既有 IP 人物的二创重塑（服务于粉丝情感），快穿的 NPC 反叛是位面机制失控（服务于剧情张力）。按本书偏离动机选用。

### 原著知识碾压（知道剧情走向）
- **资源需求**：主角对原著剧情的掌握库（关键事件 / 人物弱点 / 隐藏机缘 / 死亡点）、可被截胡的原著机缘（法宝 / 传承 / 配角 / 势力）、原著主角的"气运 / 主角光环"机制、知识差随剧情偏离而失效的边界。
- **爽点类型**：信息差碾压 + 截胡原著主角机缘 + "我比原著主角还懂这个世界"的优越感。
- **消费时机**：第一卷开篇即用，贯穿全书每个原著节点。
- **变体**：①截胡原著主角的金手指 / 法宝 / 配角；②提前避开原著死亡点 / 危机；③预知原著反派布局反杀；④知识差因剧情偏离而失效（蝴蝶效应反转）；⑤原著主角也是穿越者 / 重生者，知识差对冲（双穿反转）。
- **消费绑定提示**：开篇钩子 + 高频爽点。具体场景：开篇即用一次"原著知识变现"作为钩子；之后每个原著关键节点安排一次截胡 / 预知作为稳定爽点。
- **跨簇说明**：本桥段的"原著知识差"母题与无限流 `infinite.md` 的"副本世界的原著知识差"、快穿流 `quick-transmigration.md` 的"位面气运抢夺"近似。区别：同人的原著知识差固定针对一个 IP；无限的副本知识差是多个 IP 副本轮流；快穿的位面知识差服务于位面任务。按本书知识差的作用域选用。

### 改写原著悲剧结局
- **资源需求**：一个原著公认的悲剧结局（主角死亡 / CP 分离 / 世界毁灭 / 遗憾未了）、可被改写的因果链、改写所需的资源（实力 / 信息 / 牺牲权衡）、改写后新结局的合理性。
- **爽点类型**：救赎 + 情感补偿 + "我给了他们一个好结局"的造物主满足感。
- **消费时机**：全书高潮卷，作为长线主线的兑现。
- **变体**：①直接阻止悲剧发生；②改写悲剧但付出代价（牺牲自己 / 另一角色）；③悲剧换种形式重演（虐心反转）；④主角发现自己就是原著悲剧的根源（自指反转）；⑤改写后发现原著悲剧有其必然性，选择接受而非对抗（成熟向）。
- **消费绑定提示**：阶段转折 + 长线伏笔兑现。具体场景：作为全书高潮，安排在最后 1~2 卷；从第一卷起埋下"原著悲剧节点"长线伏笔，每个节点推进一次改写准备。

### 综英美 / 综武侠跨体系融合
- **资源需求**：跨文化 / 跨体系的多原著世界（漫威 + 哈利波特 / 金庸 + 漫威 / 美剧 + 日漫）、力量体系的兼容与碾压逻辑（修仙 vs 异能 / 武功 vs 科技）、跨文化人物的互动逻辑与 CP 可能、世界观融合的合理性框架。
- **爽点类型**：跨体系碾压 + "我的体系秒杀你的体系"的降维爽 + 跨文化 CP 的新奇感。
- **消费时机**：第二卷起引入第二体系，中后段多体系大碰撞。
- **变体**：①东方修仙进漫威碾压；②武侠高手进西方魔法世界；③科技流进玄幻世界；④多体系融合失控（反转）；⑤主角是唯一能跨体系的存在（天选型）。
- **消费绑定提示**：阶段转折 + 高频爽点。具体场景：每引入一个新体系作为阶段转折；跨体系碾压的实战展示每 15~20 章一次作为高频爽点。

### 原著粉丝的元叙事（打破第四面墙）
- **资源需求**：主角作为原著粉丝 / 读者的元身份、"知道这是虚构世界"的自觉、与原著作者 / 世界意识 / 读者的互动机制、元叙事服务的剧情目的（解构 / 致敬 / 反讽）。
- **爽点类型**：解构快感 + "我在和作者 / 原著对话"的元层优越感 + 同人文化的自我指涉。
- **消费时机**：中后段作为风格化转折，或贯穿全书的叙事基调。
- **变体**：①主角知道自己是同人角色，与"作者"对话；②原著角色觉醒"自己是虚构的"；③主角试图"回到现实世界"；④元叙事解构原著的既定套路；⑤元叙事沦为强行装逼（高风险，慎用）。
- **消费绑定提示**：长线伏笔 + 阶段转折。具体场景：中后段作为风格化转折引入元层；主角的"元身份"作为长线伏笔，终卷决定主角是否"回归现实"或"接受同人世界的真实"。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：原著知识差的边界与失效
- **标准形态**：主角凭对原著剧情的掌握截胡机缘、规避死亡点、预知反派布局。
- **可变维度**：知识精度（精确事件 / 模糊记忆 / 只看过同人）、知识失效原因（剧情偏离 / 平行世界 / 原著未完结）、知识的可分享性（独享 / 可透露给原著角色 / 一透露就失效）。
- **衍生问题**：如果本书的 <Architecture 核心引擎> 是"剧情修正力"而非"知识差碾压"，主角的截胡会从"百发百中"变成什么？如果 <Strategy 阶段目标> 让主角在第三卷遇到原著未完结 / 没看过的剧情，知识差失效后主角该如何靠真实实力应对？

### 母题 2：忠于原著 vs 偏离原著的张力
- **标准形态**：主角在"顺着原著走以保留知识差优势"与"偏离原著改写悲剧"之间拉扯。
- **可变维度**：偏离的动机（救角色 / 改 CP / 截机缘 / 纯粹不愿重复）、偏离的代价（知识差失效 / 世界意识反扑 / 蝴蝶效应失控）、原著粉丝对偏离的接受度。
- **衍生问题**：如果本书核心引擎是"必须忠于原著才能活"（剧情修正力极强），偏离桥段会从"随意改写"变成什么？主角是该冒险改写还是该顺从原著？如果核心是"彻底颠覆原著"，忠于原著的桥段要不要全部砍掉？

### 母题 3：CP 党争与粉丝接受度
- **标准形态**：同人 CP 常面临原著向 CP vs 跨原著 CP vs 原创配原著的党争，以及粉丝对"魔改 CP"的抵制。
- **可变维度**：CP 的性质（原著向 / 跨原著 / 原创配）、CP 的推进节奏（慢热 / 闪电）、CP 与原著结局的冲突、OOC 服务于 CP 的程度。
- **衍生问题**：如果本书核心引擎是"无 CP 事业流"，CP 桥段要不要砍掉或弱化为副线？如果核心是"极限嗑糖"，CP 推进节奏该如何加快？CP 党争如何在文本内体现而不引发读者骂战？

### 母题 4：多原著世界融合的兼容性
- **标准形态**：综漫 / 综英美把多个原著 IP 融合到一个叙事，需处理力量体系、时间线、人物关系的兼容。
- **可变维度**：融合机制（平行宇宙 / 主神调度 / 共同位面 / 单主角穿越多世界）、力量体系的碾压逻辑、跨 IP 人物的互动密度。
- **衍生问题**：如果本书是"单原著同人"而非"综漫多世界"，融合桥段要不要砍掉？如果核心引擎是"力量体系碰撞"，跨体系碾压该如何平衡才不会让某一体系粉丝觉得被贬低？多世界融合的"真相"要不要作为长线伏笔？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评（LOFTER / 半次元 / 知乎同人评论、综漫书评）的提炼：

- **OOC 崩人设**：为推进 CP 或洗白反派，把原著角色写成完全不同的人，被粉丝批"这不是我认识的他 / 她"。建议 OOC 必须有合理化机制（穿越者占据 / 蝴蝶效应成长），且保留原著角色的核心特质，而非彻底重写。
- **强行 CP**：原著无 CP 暗示或敌对关系的角色被强行凑一对，缺乏情感铺垫。建议 CP 推进必须有合理的情感发展弧线，而非"见面就在一起"。
- **玛丽苏 / 杰克苏**：主角（尤其原创角色）无所不能、所有原著角色都爱他 / 她、截胡所有机缘，被批为"作者自嗨"。建议给主角合理的局限与代价，让原著角色保持独立人格而非围着主角转。
- **私设过多导致"同人不像原著"**：大量私设（自定义力量体系 / 改写原著背景）让作品脱离原著韵味，沦为"借壳原创"。建议私设服务于原著韵味增强，而非替代。
- **综漫套路化**：综漫文常陷入"主角凭系统穿越各 IP 抢机缘收后宫"的流水线模板。建议每个 IP 世界的叙事有独立主题与情感，而非千篇一律的截胡。
- **原著知识差滥用**：主角靠"我看过原著"无脑碾压，原著角色的智慧被强行降智。建议让原著角色保持其原著智力水平，让知识差的优势建立在合理博弈上。
- **元叙事沦为装逼**：打破第四面墙的元叙事若处理不当，沦为"主角对原著角色装优越感"的尴尬桥段。建议元叙事服务于解构 / 致敬的深度，而非浅层炫技。
