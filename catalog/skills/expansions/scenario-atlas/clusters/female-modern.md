# 女频现言（参考：《你给我的喜欢》《慈悲城》《三分野》《掌中娇》）

> **世界观支柱**：以当代都市（豪门/职场/大院/娱乐圈/年代背景）的情感与阶层结构为底本，女主凭借重生/清醒/事业心/真情，在恋爱、婚姻、事业、原生家庭的张力中谋求被爱、自主与逆袭；核心爽感来自情感高光与打脸反转的交织。
> **典型消费节奏**：开篇用"重逢/误会/契约/重生"强钩子切入，前中段以"撒糖 + 打脸白月光/极品 + 误会虐心"高频交替供给，中段以"火葬场反转/带球跑/真相揭露"做阶段转折，后段以"破镜重圆/事业翻盘/虐恋和解"兑现长线承诺。

## 桥段清单

### 破镜重圆：重逢与旧情复燃
- **资源需求**：一段过去的关系（初恋/前夫/青梅竹马/暗恋）、当年分手的原因（误会/家庭/背叛/隐瞒）、重逢的契机（职场/同学会/共同朋友/意外）、重逢后双方的处境变化（一方功成名就/一方落魄/双方都已蜕变）。
- **爽点类型**：旧情苏醒的心动 + "兜兜转转还是你"的宿命感 + 误会解开的心痛与释然。
- **消费时机**：开篇钩子（若全书以重逢切入）或第一卷末的阶段转折。
- **变体**：①标准——分手多年重逢，误会解开旧情复燃；②反转——重逢时一方已有新欢/已婚，制造情感障碍；③极端——双方都不知道对方就是当年的那个人（失忆/改头换面/替身）；④反套路——重逢后确认"我们真的回不去了"，反而走向新的人。
- **消费绑定提示**：开篇钩子 + 长线伏笔。若全书以破镜重圆为主线，开篇即重逢并抛出"当年分手真相"的长线悬念；当年分手的原因应作为贯穿全书的伏笔，在终卷揭晓。

### 追妻火葬场：男主悔恨与苦追
- **资源需求**：男主前期对女主的伤害（冷落/误会/偏爱白月光/替身/背叛/休弃）、女主的离开（死心/带球跑/假死/远走）、男主的悔恨触发点（真相/失去/对比）、男主苦追的代价与障碍。
- **爽点类型**：男主卑微求复合的爽感 + 女主清醒拒绝的痛快 + 情感反转的高光。
- **消费时机**：中段阶段转折（前半段铺设伤害，中段反转进入火葬场）。
- **变体**：①标准——男主伤害女主后追悔莫及，卑微苦追求复合；②反转——女主在火葬场期间已有新欢/新生活，男主追而不得；③极端——男主追到女主才发现"她从未爱过我"，彻底绝望；④反套路——女主接受复合但"以牙还牙"，让男主也尝尝被冷落的滋味后才真正和解。
- **消费绑定提示**：阶段转折 + 高频爽点。中段必消费一次"女主离开 + 男主觉醒"的反转作为阶段转折；此后每隔一段安排一次"男主卑微追妻/女主清醒打脸"的高频爽点，直至终卷和解或决裂。

### 霸总/豪门总裁：阶层落差与宠爱
- **资源需求**：豪门/财阀/总裁的阶层设定（家族/集团/社会地位）、女主的普通身份（职员/落魄千金/素人/假千金）、阶层落差带来的冲突（家族反对/门第压力/舆论）、霸总的宠爱机制（砸钱/护短/宠溺/专一）。
- **爽点类型**：阶层跃迁的爽感 + 被偏爱的心动 + "他是我的"的专属感。
- **消费时机**：开篇钩子或第一卷主线。
- **变体**：①标准——普通女主被豪门总裁专一宠爱，阶层跃迁；②反转——女主其实是隐藏的真千金/落魄世家，身份揭穿后反转；③极端——女主比男主更厉害（隐藏大佬/双强），阶层落差是假象；④反套路——女主拒绝豪门，专注自己的事业与生活，男主必须"放下身段"才能靠近。
- **消费绑定提示**：开篇钩子 + 高频爽点。开篇用"阶层落差 + 第一次宠爱/护短"钩住读者；此后每隔一段安排一次"砸钱护短/打脸看不起女主的人"的高频爽点。

### 甜宠双向奔赴：无虐或轻虐撒糖
- **资源需求**：一对互相喜欢的主角、双向奔赴的情感基础（误会可解/无第三者/无恶意）、日常撒糖的场景（同居/约会/互动/撒狗粮）、轻虐的调剂（小误会/吃醋/短暂分离）。
- **爽点类型**：高密度撒糖的心动 + 双向奔赴的安心 + "甜到掉牙"的治愈感。
- **消费时机**：贯穿全书，作为节奏主线或虐恋线的调剂。
- **变体**：①标准——男女主互相喜欢，全程撒糖无大虐；②反转——表面甜宠实则一方有隐情（病/仇/任务），甜中带刀；③极端——甜宠是表象，结局反转（BE 或开放式）；④反套路——甜宠文里加入事业线/成长线，爱情只是生活的一部分而非全部。
- **消费绑定提示**：高频爽点。每隔 5~10 章安排一次撒糖节点（约会/告白/日常互动），作为读者粘性的核心来源；若全书非纯甜宠，则作为虐恋线的调剂穿插。

### 虐恋相爱相杀：误会重重与甜中带虐
- **资源需求**：相爱的男女主、横亘其间的障碍（误会/家族/身份/隐瞒/替身/白月光）、虐心的来源（冷待/伤害/错过/被迫分离）、虐后的和解或 BE。
- **爽点类型**：虐心的痛感 + "相爱却不能在一起"的张力 + 和解时的情感爆发。
- **消费时机**：中段主线，与甜宠线交替形成"甜虐"节奏。
- **变体**：①标准——相爱但因误会/家族相爱相杀，最终和解 HE；②反转——虐到极致后 BE，女主放手男主追悔（接入追妻火葬场）；③极端——双方互相伤害（双虐），最终一起毁灭或一起救赎；④反套路——所谓的"障碍"其实是可以解开的误会，前期虐后期甜。
- **消费绑定提示**：高频爽点（虐点）。中段每隔一段安排一次"误会加深/伤害/错过"的虐点，与甜宠线交替形成节奏；虐恋的根源应作为长线伏笔，在终卷揭晓与和解。

### 先婚后爱/契约婚姻
- **资源需求**：一段被迫或功利的婚姻（契约/联姻/闪婚/隐婚/利益交换）、男女主初期的关系（陌生/对立/利用）、婚后磨合的契机（同住/共事/危机）、感情升温的节点。
- **爽点类型**：婚后日久生情的心动 + "先婚后爱"的反转爽 + 日常撒糖。
- **消费时机**：开篇钩子（若以契约婚姻切入）或第一卷主线。
- **变体**：①标准——契约/闪婚后日久生情，弄假成真；②反转——契约背后有隐情（一方早暗恋/家族阴谋），感情升温时真相爆发；③极端——契约婚姻双方各自有真爱，最后反而爱上彼此；④反套路——契约到期女主坚决离婚，男主反而追妻火葬场。
- **消费绑定提示**：开篇钩子 + 高频爽点。开篇用"契约/闪婚"切入并抛出"为什么结婚"的悬念；婚后每一次磨合/危机作为撒糖或虐心的节点。

### 带球跑/萌宝：隐瞒孩子与重逢
- **资源需求**：女主怀孕带球跑的原因（误会/被逼/自保/男主不知情）、孩子成长的时间跨度、孩子与男主的相似/天赋、重逢与真相揭露的契机、男主发现孩子的反应。
- **爽点类型**：萌宝可爱 + "你的种我也要跑"的清醒 + 真相揭露的打脸 + 萌宝助攻。
- **消费时机**：中段阶段转折（带球跑作为前期转折）至后段（重逢真相揭露）。
- **变体**：①标准——女主带球跑数年后重逢，男主发现萌宝追妻；②反转——萌宝其实是天才/双胞胎/多胞胎，制造更多戏剧性；③极端——萌宝主动找爸爸或主动帮妈妈拒绝爸爸；④反套路——孩子并非男主亲生（领养/试管/前夫），真相揭露后反而更虐或更暖。
- **消费绑定提示**：阶段转折 + 高频爽点。带球跑作为中段阶段转折；重逢后每隔一段安排一次"萌宝助攻/真相逼近/男主试探"的高频爽点，直至真相揭露。

### 替身文学/白月光：错爱与真心
- **资源需求**：男主心中的"白月光"（初恋/亡妻/青梅/求而不得）、女主作为替身的处境（被利用/被冷待/被比较）、白月光的回归或真相、女主的清醒与离开、男主发现真心的转折。
- **爽点类型**：替身逆袭的打脸 + "我不是任何人的替身"的清醒 + 男主火葬场反转。
- **消费时机**：中段主线，常与追妻火葬场衔接。
- **变体**：①标准——女主被当替身，清醒离开后男主追妻；②反转——白月光其实是反派/已死/虚构，女主才是唯一的真心；③极端——女主和白月光长得一模一样（双胞胎/失忆），身份悬疑；④反套路——女主主动选择当替身（有自己的目的），利用完后全身而退。
- **消费绑定提示**：高频爽点 + 长线伏笔。中段每隔一段安排一次"被比较/被冷待"的虐点与"女主清醒反击"的爽点交替；白月光的真实身份应作为长线伏笔，在终卷揭晓。

### 年代文重生：50-80 年代的家庭与逆袭
- **资源需求**：具体的年代背景（50/60/70/80 年代）、年代特有的元素（票证/下乡/改革开放/大院/军婚/工厂/公社）、女主的落地身份（炮灰女配/极品亲戚的受害者/被退婚的知青/军嫂）、可被手撕的极品亲戚（重男轻女的公婆/贪小便宜的妯娌/白眼狼小叔子）、发家致富的路径（摆摊/倒卖/开店/承包/手艺）。
- **爽点类型**：手撕极品的痛快 + 发家致富的成就感 + 年代烟火气 + 军婚甜宠的治愈。
- **消费时机**：贯穿全书，作为年代文的核心循环（手撕极品 + 发家 + 撒糖交替）。
- **变体**：①标准——女主重生/穿书成年代炮灰，手撕极品亲戚发家致富；②反转——极品亲戚其实有苦衷/被冤枉，化解后变成助力；③极端——女主靠现代知识（医术/厨艺/美发/养殖）技能逆袭成为年代大佬；④反套路——女主不撕亲戚不发财，专注随军日常/夫妻恩爱的小日子。
- **消费绑定提示**：高频爽点 + 长线伏笔。每隔 10~20 章安排一次"手撕极品 + 发家进阶"的爽点循环；军婚/大院/工厂的人际网络应作为长线伏笔，在终卷以"家庭翻盘/邻里改观"收束。
- **跨簇说明**：本桥段聚焦"女频年代文"的家庭/大院/军婚/手撕极品视角（女频专属）。若重生年代戏服务于"男主创业/金融/文抄/仕途"（男频视角），则属于重生都市簇 `rebirth-urban.md` 的"重生先知提前布局""商业帝国创业""文抄公作品搬运"，请按主角性别与核心爽点选用对应母题。关键分野：女频年代文的第一战场是家庭与大院（手撕极品、随军日常、票证经营），男频重生都市的第一战场是创业与资本。

### 娱乐圈女频：女明星逆袭与 CP 炒作
- **资源需求**：娱乐圈生态（经纪/选秀/影视/代言/综艺/流量）、女明星的身份（被雪藏/被黑/过气/新人/替身/炮灰女配）、对手（绿茶女明星/打压前辈/黑粉/资本）、CP 炒作的对象（死对头/影帝/隐婚对象/真假难辨）、逆袭的路径（演技/综艺/作品/舆论反转）。
- **爽点类型**：女明星打脸黑粉 + 流量逆袭 + CP 撒糖 + 舞台高光。
- **消费时机**：第二卷起，女主进入娱乐圈后的主线。
- **变体**：①标准——被黑/过气女明星靠演技/作品翻红打脸；②反转——CP 对象是真伴侣，公开是炒作，私下是真甜；③极端——女主建立自己的娱乐帝国/工作室，从被资本操控到操控资本；④反套路——女主主动退圈回归普通人，或专注事业拒绝 CP。
- **消费绑定提示**：高频爽点 + 阶段转折。每隔 15~25 章安排一次"作品发布/综艺高光/舆论反转/CP 互动"的高频爽点；每次事业进阶（翻红/获奖/成立工作室）作为阶段转折。
- **跨簇说明**：本桥段聚焦"女明星视角"的娱乐圈逆袭（女频专属）。若娱乐圈戏服务于"男主成为顶流/文抄爆红/养成素人"（男频视角），则属于重生都市簇 `rebirth-urban.md` 的"娱乐圈明星养成""文抄公作品搬运""听劝顶流与 CP 炒作"，请按主角性别与爽点形态选用对应母题。关键分野：女频娱乐圈的核心爽点是"女明星打脸黑粉 + CP 撒糖"，男频娱乐圈的核心爽点是"男主爆红 + 圈内碾压"。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：虐与甜的节奏配比
- **标准形态**：现言以"甜虐交替"为核心节奏，虐点制造张力，甜点供给治愈，两者的高密度交替是读者粘性来源。
- **可变维度**：甜虐比例（纯甜/甜多虐少/虐多甜少/纯虐）、虐的来源（误会/家族/身份/替身/白月光）、虐的烈度（小别扭/冷待/伤害/生离死别）、和解的形态（HE/BE/开放式）。
- **衍生问题**：如果本书 Architecture 核心引擎是"甜宠治愈"而不是"虐恋张力"，虐点该如何被"小别扭"替代？如果 Strategy 让全书走"追妻火葬场"主线，前期的虐该铺设到什么烈度才能让中段反转够爽？如果市场趋势是"无 CP/专注自我强大"，感情线的甜虐配比是否可以被砍到最低？

### 母题 2：火葬场的反转力度
- **标准形态**：男主前期伤害女主，中段女主离开触发男主悔恨，男主卑微苦追求复合。
- **可变维度**：前期伤害的烈度（冷落/误会/偏爱白月光/替身/背叛）、女主离开的方式（死心/带球跑/假死/远走）、男主苦追的代价（尊严/地位/时间/真心的考验）、结局（和解/决裂/开放式）。
- **衍生问题**：如果本书核心引擎是"清醒女主不回头"而不是"男主苦追感动女主"，火葬场会从"追妻成功"变成什么？如果 Strategy 让女主在火葬场期间已有新欢，男主追而不得的结局该如何收束？如果前期伤害太重（如替身+背叛），男主的苦追是否还能合理化 HE？

### 母题 3：阶层落差与女主自主的张力
- **标准形态**：霸总/豪门文里，普通女主靠被宠爱实现阶层跃迁，爽点来自"他是我的"的专属感。
- **可变维度**：阶层落差的方向（男高女低/女高男低/双强）、女主的主动性（被动接受/主动利用/拒绝并自立）、阶层冲突的来源（家族反对/舆论/门第）、女主的自主程度（依附/平等/主导）。

## 反套路与"烂大街"风险

（素材来自 WebSearch 读者批评与 2025 短剧市场报告）

- **霸总甜宠虐恋审美疲劳**：2025 短剧市场报告明确指出，霸总甜宠虐恋已现审美疲劳，用户开始追求"无 CP/专注自我强大"的内容。**规避**：不要把"被霸总宠爱"作为唯一爽点，应让女主有独立的事业线/成长线（参考"职场女强/专注自我"的市场趋势）；或用"双强""女主比男主更厉害"反转阶层落差；或大胆走"女主拒绝豪门专注事业"的反套路。
- **追妻火葬场套路化**：男主前期伤害—女主离开—男主苦追—女主原谅已成公式，且前期伤害过重（替身+背叛+偏爱白月光）却强行 HE，读者抵触。**规避**：控制前期伤害的烈度，或让女主"以牙还牙"后再和解，或让男主追而不得走向 BE/开放式，制造意外感。
- **白月光/替身脸谱化**：白月光全是"完美初恋"，替身全是"卑微可怜"，缺乏新意。**规避**：让白月光其实是反派/已死/虚构/双胞胎，或让女主主动选择当替身（有自己的目的），制造身份悬疑。
- **误会推动剧情太低智**：靠"我不说你不问"的低智误会硬推虐恋，被读者诟病。**规避**：让障碍来自真实的结构性冲突（家族/身份/阶层/责任），而非一句话能说清的低智误会。
- **萌宝工具化**：萌宝全是"天才 + 助攻爸爸"的工具人，缺乏独立性。**规避**：让萌宝有自己的性格与成长线，或让萌宝主动帮妈妈拒绝爸爸，制造反差。
- **男主"工具人/背景板"或"全知全能"**：要么男主沦为撒糖道具，要么男主全能到女主无用武之地。**规避**：让男主有独立的事业线与弱点，与女主形成"双强"格局而非单方面扶持或碾压。
- **CP 炒作同质化**："死对头变恋人""隐婚甜文"已成标配。**规避**：让 CP 对象是前世仇人/今生真心，或主角与 CP 对象是真伴侣却被迫公开炒作，制造反差（参考 `rebirth-urban.md` 的"听劝顶流与 CP 炒作"反套路）。
