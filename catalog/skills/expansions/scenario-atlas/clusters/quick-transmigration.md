# 快穿流（参考：《快穿：攻略反派男神计划》《反派打脸系统》《快穿之 Boss 女配打脸攻略》）

> **世界观支柱**：以位面、系统、气运、反派为核心的"穿梭世界执行任务"叙事，靠"位面进入 + 系统任务 + 气运/世界意识 + 攻略对象"支撑单元剧与长线交织。
> **典型消费节奏**：开篇用绑定系统与首位面任务钩住读者，中段以"位面打脸循环 + 攻略感情线"高频供给爽点，后段以"位面串联 + 主世界真相"做长线收束。

## 桥段清单

### 位面进入与任务发布
- **资源需求**：一套可穿梭的位面体系（小说世界/影视剧/游戏/平行时空）；一个绑定主角的系统；每个位面的任务说明（攻略/逆袭/打脸/救赎）。
- **爽点类型**：新鲜感 + "我是上帝视角"的优越感 + 任务明确的方向感。
- **消费时机**：每个新位面的开篇钩子。
- **变体**：①系统直接派单；②主角自选位面；③反套路"任务说明是假的，真实任务隐含其中"；④极端"位面本身就是个陷阱，主角是被骗进去的"。
- **消费绑定提示**：开篇钩子 + 高频爽点。每个新位面的第一章必消费；任务说明的"隐藏条件"应作为本位面的长线伏笔。

### 位面打脸循环
- **资源需求**：一个欺负原主/主角的"渣男贱女"或"白莲花绿茶"矩阵；主角借系统/重生/穿越获得的碾压手段；打脸的"原主心愿"或"任务目标"。
- **爽点类型**：复仇爽感 + 打脸快感 + "看你怎么嚣张"的优越感。
- **消费时机**：每个位面的中段，反复高频消费。
- **变体**：①靠系统金手指打脸；②靠主角自身能力打脸；③反套路"打脸对象其实是被冤枉的"；④极端"主角打脸到最后发现自己才是真正的恶人"。
- **消费绑定提示**：高频爽点。每个位面至少 3~5 次打脸章节，作为本位面的爽点主体。

### 位面气运与世界意识
- **资源需求**：每个位面有自己的"气运之子/天命主角"（原书男女主）；位面有自我修复剧情的"世界意识"；主角行为与气运之子的冲突。
- **爽点类型**：逆天改命 + "我抢了你的气运"的爽感 + 与世界意志博弈的紧张。
- **消费时机**：每个位面的中后段，作为打脸循环的升级。
- **变体**：①正统抢气运；②与气运之子合作；③反套路"主角就是气运之子本人，只是失忆了"；④极端"世界意识觉醒后与主角成为对手/伙伴"。
- **消费绑定提示**：阶段转折 + 长线伏笔。每个位面的气运冲突高潮作为本位面阶段转折；"世界意识"的累积设定应作为终卷主世界真相的长线伏笔。

### 位面结算与下一世界
- **资源需求**：一套可量化的位面结算系统（积分/评分/奖励/属性）；一个可兑换的商城或属性面板；下一个位面的预览或随机机制。
- **爽点类型**：成就感 + 装备升级 + "下一站去哪"的期待感。
- **消费时机**：每个位面的结尾，作为过渡。
- **变体**：①标准结算 + 兑换；②结算失败惩罚；③反套路"结算分数是假的，真实目的是另一个"；④极端"结算后主角可以选择不进入下一世界，留下定居"。
- **消费绑定提示**：阶段转折。每次位面结算章作为本位面与下一位面的阶段转折点；结算奖励中应包含至少一件用于终卷主世界的长线伏笔道具。

### 主世界系统真相
- **资源需求**：一个绑定的系统背后的真相（神/外星/AI/高维存在/主角自己）；多个位面串联出的主线谜题；主世界的设定与主角的真实身份。
- **爽点类型**：世界观炸裂 + 真相揭穿 + "原来一切都被设计"的震撼。
- **消费时机**：终卷或最后两卷，作为长线收束。
- **变体**：①系统是善意的（帮助主角成长）；②系统是恶意的（利用主角）；③反套路"系统是另一个主角的分身"；④极端"主世界本身就是一个更大的位面"。
- **消费绑定提示**：长线伏笔全回收 + 终卷阶段转折。前期每个位面的"反常细节"都应被标注为此桥段的伏笔载体。

### 反派快穿与反派攻略
- **资源需求**：一个被攻略的反派对象（黑化/偏执/缺爱/反派 Boss）；反派的"黑化值/好感度"面板；主角降低黑化值或攻略反派的手段。
- **爽点类型**：救赎爽感 + 攻略成功 + "只有我能懂你"的专属感。
- **消费时机**：作为多数女频快穿的主线感情戏，贯穿每个位面。
- **变体**：①主角攻略反派走向相恋；②主角与反派联手打原主角；③反套路"反派其实也是快穿者"；④极端"反派是主世界的主角镜像，攻略他等于攻略自己"。
- **消费绑定提示**：高频爽点 + 长线伏笔。每个位面的感情线进展作为高频爽点；反派的"跨位面同一性"应作为终卷主世界真相的长线伏笔。

### 女配逆袭与炮灰翻盘（新增）
- **资源需求**：一个被原书边缘化的女配/炮灰身份；原主的心愿或怨念；主角借女配身份翻盘的剧本。
- **爽点类型**：以弱胜强 + 身份反转 + "原来女配才是真女主"的颠覆感。
- **消费时机**：作为部分位面的任务类型，与打脸循环交织。
- **变体**：①女配逆袭取代原女主；②女配独立不抢男主；③反套路"女配其实不想翻盘，只想躺平"；④极端"女配身份是主世界主角的真实身份"。
- **消费绑定提示**：高频爽点。每个女配位面的翻盘章作为本位面爽点高潮。

### 系统升级与金手指扩张（新增）
- **资源需求**：一套可升级的系统功能（商城/技能/属性/道具）；系统升级所需的资源（积分/任务/成就）；升级带来的新能力。
- **爽点类型**：养成 + 装备升级 + "我越来越强"的爽感。
- **消费时机**：每个位面结算后或重大成就时。
- **变体**：①标准线性升级；②分支选择升级；③反套路"系统升级其实是系统的进化，主角是被搭载的宿主"；④极端"系统升级到顶后觉醒自我意识"。
- **消费绑定提示**：阶段转折 + 长线伏笔。每次系统升级作为阶段转折；升级后获得的关键能力应作为终卷主世界的长线伏笔。

### 位面 bug 与系统漏洞（新增）
- **资源需求**：位面或系统中的漏洞/异常（卡 bug、跨位面道具、任务冲突）；主角发现并利用漏洞的能力；漏洞带来的后果。
- **爽点类型**：钻空子 + 智力碾压 + "我比系统还懂规则"的优越感。
- **消费时机**：中后段位面，作为打脸循环的变奏。
- **变体**：①利用漏洞刷积分；②跨位面带道具；③反套路"漏洞是系统故意留的钓鱼执法"；④极端"主角利用漏洞最终跳出系统"。
- **消费绑定提示**：高频爽点 + 长线伏笔。每次利用漏洞作为高频爽点；漏洞的累积应是终卷主世界真相的伏笔。

### 位面意识觉醒与 NPC 反叛（新增）
- **资源需求**：位面中 NPC/角色逐渐觉醒"自我意识"的设定；觉醒带来的剧情失控；主角应对觉醒 NPC 的策略。
- **爽点类型**：伦理冲击 + "他们不是数据是人"的震撼 + 与觉醒者的博弈。
- **消费时机**：中后段位面，作为长线伏笔的显现节点。
- **变体**：①单个 NPC 觉醒；②整个位面群体觉醒；③反套路"主角自己也是被觉醒的 NPC"；④极端"觉醒的 NPC 跨位面追杀主角到主世界"。
- **消费绑定提示**：长线伏笔 + 终卷阶段转折。前文位面的"NPC 反常细节"伏笔应在此桥段集中回收。

### 男频快穿与逆袭称霸（新增）
- **资源需求**：男频快穿的任务类型（称霸/收徒/建国/灭世）；男主的征服对象（势力/美女/世界）；男性向爽点的资源支撑。
- **爽点类型**：征服 + 后宫 + 称霸 + "我征服了一个又一个世界"的爽感。
- **消费时机**：作为男频快穿的每个位面主线。
- **变体**：①纯征服称霸；②收徒传承；③反套路"男主只想回家，称霸只是手段"；④极端"男主最终统一所有位面建立跨世界帝国"。
- **消费绑定提示**：高频爽点 + 阶段转折。每个位面的称霸高潮作为本位面阶段转折；跨位面的势力累积应作为终卷主世界的长线伏笔。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：位面单元剧
- **标准形态**：一个位面 = 一个 10~30 章的单元剧，包含进入、打脸、攻略、结算四段。
- **可变维度**：位面的规模（短篇 vs 长篇）、位面的题材（古言/现言/西幻/末世/星际）、单元剧之间的耦合度。
- **衍生问题**：如果本书的 Architecture 核心引擎是"感情线"而不是"任务"，位面单元剧要不要拉长到一卷一位面以深化感情？如果 Strategy 是"短篇爽文"，位面要不要压缩到 5~10 章？

### 母题 2：系统的性质
- **标准形态**：一个绑定主角、发布任务、结算奖励的系统，背后有真相。
- **可变维度**：系统的智能程度（机械 vs 拟人 vs 觉醒）、系统的善恶、系统的来源、主角与系统的关系。
- **衍生问题**：如果本书是"无系统快穿"（主角靠自身能力穿梭），系统真相桥段要不要砍掉？如果核心引擎是"博弈"，系统要不要成为主角的对手？

### 母题 3：攻略对象的同一性
- **标准形态**：每个位面的攻略对象都是"同一个灵魂"的不同化身。
- **可变维度**：同一性的明确度（明确暗示 vs 终卷揭穿）、同一性的性质（灵魂/主世界人物/系统投影）、主角是否知情。
- **衍生问题**：如果本书是"无 CP 快穿"，攻略对象同一性要不要砍掉？如果核心引擎是"打脸"，攻略线是否要让位于打脸线？

### 母题 4：主世界真相
- **标准形态**：多个位面串联出主世界的真相（系统来源/主角身份/更大阴谋）。
- **可变维度**：真相的性质（神/AI/高维/主角自己）、真相揭穿的时机、揭穿后是否还能继续穿梭。
- **衍生问题**：如果本书是"纯单元爽文"，主世界真相要不要砍掉？如果 Strategy 是"长线为主"，真相要不要提前到第二卷就开始浮现？

### 反套路与"烂大街"风险
（综合 WebSearch 读者批评素材提炼，来源包括知乎快穿书单、红袖书单、起点书单及多篇快穿评论）
- **打脸套路模板化**：原主被欺负→女主穿越→金手指碾压→渣男贱女跪地，这一循环被批为"流水线打脸"。World Agent 应为每个位面设计独有的打脸母题，避免每个位面都是"白莲花绿茶 + 渣男"。
- **反派攻略同质化**：黑化/偏执/缺爱的反派 Boss 被反复使用，"降黑化值"已成为公式。建议反派的黑化原因多样化，攻略方式不限于"给温暖"。
- **女配逆袭审美疲劳**：女配取代原女主的套路用滥后，读者批评"原女主被强行降智"。建议给原女主保留合理性，或让女配与原女主和解/合作。
- **系统金手指过强**：系统万能导致主角失去成长空间，读者批评"主角只是系统的傀儡"。建议给系统设限，或让主角在系统之外有所贡献。
- **位面之间缺乏关联**：纯单元剧的快穿被批为"流水账"，读者失去长线追读动力。建议至少埋一条贯穿多 位面的伏笔。
- **主世界真相套路化**：系统是神/AI/试验品已用滥。建议主世界真相有反预期设计，或与主角的身份/感情线深度绑定。
- **男频快穿过度征服化**：后宫 + 称霸的男频快穿被批为"扁平爽文"。建议增加称霸之外的情感/伦理维度。

### 未覆盖子流派的推导路径
- **男频快穿流**：从"打脸"替换为"称霸/征服/收徒"，攻略对象从反派改为势力/美女/世界，参考 `quick-transmigration.md` 男频母题。
- **虐文自救流**：主角穿越到虐文世界，从"被打脸"推导为"自救 + 反虐"，打脸对象是原作者/原剧情。
- **无 CP 事业流**：砍掉攻略感情线，把"打脸"替换为"事业成就"（经商/建国/学神），参考 `rebirth-urban.md` 与 `isekai-build.md`。
- **快穿 + 无限流**：嫁接 `infinite.md`，把"位面"替换为"副本"，任务从"攻略/打脸"改为"求生/通关"。
- **快穿 + 系统流**：深化系统设定，参考 `system.md`，把系统升级作为主线。
- **反派快穿 / 反派攻略流**：主角本身就是反派，从"打脸"推导为"反派逆袭"，攻略对象从反派改为原主角。
- **快穿直播流**：嫁接围观机制（参考 `horror-rules.md` 的直播母题），主角的位面任务被直播。
- **快穿 + 诡异流**：把"位面"替换为"规则怪谈副本"，嫁接 `horror-rules.md`。
