# 架空历史（参考：《回到明朝当王爷》《唐砖》《大宋的智慧》《赘婿》）

> **世界观支柱**：以一段真实或半真实的中国历史（唐/宋/明/清/乱世/架空王朝）为硬约束底本，主角凭借现代知识、先知信息或权谋手腕介入历史进程，在"蝴蝶效应"与"历史惯性"的张力中改变走向。
> **典型消费节奏**：开篇用"穿越落地 + 身份反差"钩住读者，前中段以"攀科技/改制度/积威望"高频供给经营获得感，中后段以"夺嫡/党争/平乱/称帝"做长线权谋收束，终卷以"新历史格局"兑现长线承诺。

## 桥段清单

### 穿越落地与身份确立
- **资源需求**：一段具体历史背景（朝代/年份/在位帝王）、主角的穿越身份（小兵/农夫/王爷/世家子/商贾/工匠）、落地后的第一生存危机、可借势的历史名人。
- **爽点类型**：身份反差 + 金手指降临 + 信息碾压。
- **消费时机**：开篇第一卷。
- **变体**：①标准——现代人穿越成底层，靠现代知识翻身；②反转——穿越成王侯将相，开局即高位但危机四伏；③极端——穿越成历史名人本人（李世民/朱元璋/康熙）；④反套路——穿越成"注定被主角踩"的反派/废柴，反向逆天改命。
- **消费绑定提示**：开篇钩子。第一卷开篇必消费，确立主角的"现代视角 + 历史身份"双重视角；身份反差应作为前 20 万字的高频爽点来源。

### 攀科技树与产业奠基
- **资源需求**：目标朝代的资源禀赋（宋代有煤铁可前置蒸汽机；明末有玉米番薯可救荒；战国缺铁需先点冶铁）、工匠体系、试验场、原材料渠道、可变现的产业（玻璃/肥皂/火药/印刷/造纸）。
- **爽点类型**：技术碾压 + 经营获得感 + 文明进步感。
- **消费时机**：第一二卷（立足期至扩张期）。
- **变体**：①标准——玻璃肥皂火药"老三样"起家；②反转——专攻冷门高附加值产业（印刷垄断/香料/瓷器）；③极端——直接攀蒸汽机/电报，开启工业革命；④反套路——科技树被本地势力反向利用，主角需应对自己造的怪胎。
- **消费绑定提示**：高频爽点 + 镶嵌式消费。每攀一个技术节点消费一次，必须与权谋线交织（如"火药配方被皇子觊觎"），避免变成纯种田流水账。

### 制度改革与思想启蒙
- **资源需求**：目标朝代的制度瓶颈（科举/军制/税制/农制/女权/奴婢）、改革的既得利益反对者、可借势的上位者、改革的社会基础。
- **爽点类型**：阳谋碾压 + 仁义凝聚 + 时代洪流。
- **消费时机**：中段（主角有一定话语权后）。
- **变体**：①标准——改革税制/军制得民心；②反转——以商促改，用经济倒逼制度；③极端——直接推翻旧王朝建立新制；④反套路——改革失败，主角学会"循序渐进"或被旧势力反噬。
- **消费绑定提示**：阶段转折。改革举措作为中段阶段转折；每项改革应标注其引发的政治反弹，作为下一段权谋线的输入。

### 历史名人互动与收服
- **资源需求**：目标朝代的名人（帝王/名臣/名将/文人/商人）、主角与名人的关系接口（同窗/上下级/联姻/敌对）、名人的历史宿命、收服或改变名人的途径。
- **爽点类型**：身份反转 + 阵营凝聚 + "原来你也在这里"的惊喜。
- **消费时机**：贯穿全程，每个重要名人登场节点。
- **变体**：①标准——收服历史名将为己用；②反转——与历史反派结盟，改变其宿命；③极端——主角取代历史名人本人；④反套路——历史名人看穿主角的穿越者身份，反向利用。
- **消费绑定提示**：高频爽点 + 长线伏笔。每位名人首次登场消费一次"互动爽点"；名人的历史宿命应作为长线伏笔，在对应历史节点回收。

### 夺嫡与皇位之争
- **资源需求**：皇位继承机制（嫡长子/立贤/密立）、夺嫡的皇子阵营、各方势力（外戚/宦官/世家/军头）、皇帝的态度、夺嫡的代价。
- **爽点类型**：智斗 + 阵营博弈 + 以弱胜强。
- **消费时机**：中后段（主角进入权力核心后）。
- **变体**：①标准——助某位皇子夺嫡，自己成为从龙之臣；②反转——主角自己就是皇子，亲自下场夺嫡；③极端——主角架空所有皇子，自己取而代之；④反套路——主角拒绝站队，反而成为各方拉拢的"关键少数"。
- **消费绑定提示**：阶段转折 + 长线伏笔。夺嫡爆发作为中后段阶段转折；每位皇子的弱点与野心应在前文作为伏笔埋下。

### 党争与朝堂博弈
- **资源需求**：朝堂派系结构（新党/旧党/清流/勋贵/阉党）、派系资源、党争的议题（变法/边防/储位）、党争的代价（贬谪/抄家/株连）。
- **爽点类型**：智斗 + 阵营博弈 + 孤勇者燃点。
- **消费时机**：中后段，与夺嫡线交织。
- **变体**：①标准——主角在党争中纵横捭阖，平衡各方；②反转——主角被卷入党争，从被动到反杀；③极端——主角主导党争，清洗异己；④反套路——主角主动瓦解党争机制，建立新政治生态。
- **消费绑定提示**：高频爽点。党争的每一次攻防（奏对/弹劾/廷推）作为高频爽点；党争的最终结局应与夺嫡线或改革线收束。

### 平乱与征战
- **资源需求**：动乱来源（藩镇/农民军/外族/叛乱/海盗）、军事体系（军制/粮草/将帅）、战略要地、平乱的代价、平乱后的封赏。
- **爽点类型**：军事碾压 + 战略智斗 + 以弱胜强。
- **消费时机**：中后段（主角掌军权后）或终卷。
- **变体**：①标准——主角以现代军事思想或火器碾压；②反转——主角"以战促和"，用最小代价平乱；③极端——主角借平乱架空中央，自己上位；④反套路——平乱后发现"敌军"是被中央逼反，主角面临道义抉择。
- **消费绑定提示**：阶段转折。平乱作为中后段或终卷阶段转折；平乱前应通过"情报/备战"桥段做长线铺垫，避免"天降大军"。

### 称帝/立国与历史走向改写
- **资源需求**：称帝/立国的合法性来源（功业/血统/禅让/民心）、旧王朝的覆灭条件、新王朝的国号/制度/都城、改写历史的代价。
- **爽点类型**：地位跃迁 + 长线爽感兑现 + 时代洪流。
- **消费时机**：终卷或全书高潮。
- **变体**：①标准——主角功高震主，黄袍加身或禅让登基；②反转——主角扶持傀儡，自己幕后掌权；③极端——主角不称帝，建立"虚君实相"的新政体；④反套路——主角称帝后发现"皇帝不好当"，反而怀念从前。
- **消费绑定提示**：长线伏笔全回收 + 终卷阶段转折。前文所有的功业积累、名臣收服、制度改革都应在此回收；新历史格局的形态应作为全书承诺的兑现。

### 蝴蝶效应与历史惯性对抗
- **资源需求**：主角改变历史后引发的连锁反应（提前出现的敌人/被改写的战役/扭曲的历史名人命运）、历史惯性的修正机制、主角对"蝴蝶效应"的预判与应对。
- **爽点类型**：长线伏笔回收 + 震撼 + 智斗。
- **消费时机**：贯穿中后段，每次主角重大干预后。
- **变体**：①标准——蝴蝶效应带来新敌人，主角临危应对；②反转——蝴蝶效应反而帮了主角（提前出现的意外盟友）；③极端——蝴蝶效应失控，历史走向完全不可预测；④反套路——主角主动制造蝴蝶效应，把历史当棋盘。
- **消费绑定提示**：长线伏笔。每次主角干预历史后，应在后续章节体现蝴蝶效应，作为"历史真实感"的伏笔回收机制。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：攀科技树的朝代适配
- **标准形态**：穿越到明末/宋代，造玻璃肥皂火药起家，逐步攀蒸汽机。
- **可变维度**：目标朝代的资源禀赋（铁矿/煤矿/水力/人口）、产业变现路径（军火/民用品/奢侈品）、科技树的"卡脖子节点"。
- **衍生问题**：如果本书穿越到战国（缺铁缺煤）而不是明末，攀科技树的起点和路径会如何变化？如果 Strategy 把"攀科技"从第一卷挪到第三卷（前期纯权谋），需要前置哪些世界资源（工匠/作坊/原材料渠道）？如果 Architecture 核心引擎是"思想启蒙"而非"科技碾压"，攀科技是否会退化为背景板？

### 母题 2：夺嫡的阵营复杂度
- **标准形态**：清穿九子夺嫡或唐穿玄武门，主角在皇子阵营中纵横捭阖。
- **可变维度**：皇子数量（一对一/多对多）、皇帝的态度（明君/昏君/猜忌）、外力干预（外戚/宦官/外族）、主角立场（臣子/皇子/调停者）。
- **衍生问题**：如果本书只有两位皇子（而非九龙夺嫡），夺嫡的张力会从"混战"变成什么？如果主角自己就是太子（被群起而攻之），桥段会从"辅佐者"变成"守擂者"，需要哪些前置？如果 Strategy 让夺嫡线在第二卷就爆发（而非中后段），主角的科技/势力积累是否足够支撑？

### 母题 3：历史名人的命运改写
- **标准形态**：收服历史名将（如收徐达/常遇春/岳飞），或改变历史名人的悲剧宿命（如救岳飞于风波亭）。
- **可变维度**：名人的历史宿命（善终/冤死/叛变）、主角的介入时机（成名前/鼎盛/末路）、介入方式（收服/对抗/平行）、改写宿命的蝴蝶效应。
- **衍生问题**：如果本书穿越到一个"历史名人已被杀"的时间点（如岳飞死后），主角该如何面对既成事实？如果 Architecture 核心引擎是"尊重历史惯性"而非"随意改写"，主角救名人的代价该如何设定（救一人，失一城）？

### 母题 4：历史真实与虚构的平衡
- **标准形态**：以真实历史为骨架，主角在关键节点干预，推动历史走向分叉。
- **可变维度**：历史真实度（纯架空王朝/半架空/严格遵循真实历史）、主角的干预强度（旁观/微调/大改/推翻）、读者的历史知识预期。
- **衍生问题**：如果本书是"纯架空王朝"（而非真实朝代），历史名人互动和蝴蝶效应桥段该如何调整？如果本书严格遵循真实历史（如明穿不能改变崇祯亡明），主角的爽点该如何兑现？如果 Architecture 要求"历史不可改变，只能顺应"，桥段会从"改写历史"变成"在历史夹缝中求生"。

## 反套路与"烂大街"风险

（素材来自 WebSearch 读者批评与中国作家网评论）

- **"老三样"攀科技树**：玻璃肥皂火药"老三样"已被读者诟病为"填空题式"创作，缺乏新意。**规避**：要么选冷门高附加值产业，要么把攀科技与权谋深度绑定（如"火药配方被觊觎"驱动剧情），而非纯种田流水账。
- **玄武门/夺嫡扎堆**：唐穿反复写玄武门之变、清穿反复写九子夺嫡，严重同质化。**规避**：选择冷门历史节点（如安史之乱后、靖难之役、明末南明），或在热门节点做反套路（《撼唐》给李世民来个玄武门之变）。
- **矮化世界**：为衬托主角而人为降低历史世界的难度（古人全是傻子、皇帝全是昏君）。**规避**：保留历史名人的智商与手腕，让主角的胜利来之不易；中国作家网评论指出"穿越小说的底色是个人情感投射"，但成熟作品应超越"疗伤"走向真正的历史思辨。
- **主线不清晰/偏平淡**：种田与权谋两条线割裂，缺乏真正的爆点。**规避**：每项科技/改革举措都必须驱动权谋剧情（如改革税制→得罪勋贵→引发党争），避免"种田 100 万字才进朝堂"。
- **双穿门模式雷同**：现代与古代反复穿梭，模式固化。**规避**：要么早期就关闭双向通道（专注古代线），要么让"现代"成为有限的资源补充而非无限外挂。

## 未覆盖子流派的推导路径

- **清穿宫斗/清穿言情**：从"夺嫡与皇位之争"反推——把阵营从"皇子"换成"后宫嫔妃"，把博弈工具从"军权/党争"换成"恩宠/子嗣/家族"，桥段改为"争宠/护子/家族联姻"。女频常见。
- **历史同人（穿越成历史名人本人）**：从"穿越落地与身份确立"的极端变体推导——主角就是李世民/朱元璋/康熙，需面对"历史宿命 vs 自主意志"的张力，桥段改为"既定命运对抗"。
- **乱世争霸/五代十国/春秋战国**：从"称帝/立国"反推——主角不是"从龙之臣"而是"逐鹿者"，桥段改为"乱世起兵/招贤纳士/兼并诸侯"，参考 `wuxia.md` 的江湖势力机制。
- **架空王朝（非真实历史）**：从"历史真实与虚构的平衡"推导——把真实朝代名替换为架空王朝，但保留"王朝兴衰"的历史规律；蝴蝶效应桥段可弱化，改为"架空王朝的内部规律"。
- **穿越救亡流**（穿越到民族危亡节点，如崖山之后/南明/抗战）：从"平乱与征战"推导——把"平乱"升级为"救亡图存"，桥段改为"挽狂澜于既倒/扶大厦之将倾"，爽点从"碾压"转为"悲壮燃点"。中国作家网专文讨论过此流派的演变。
- **历史研究范**（强调考据与历史真实感）：从"历史真实与虚构的平衡"推导——弱化爽文节奏，强化历史细节与制度考据，桥段改为"历史谜题破解/制度复原"，参考 `mystery.md` 的解谜机制。
