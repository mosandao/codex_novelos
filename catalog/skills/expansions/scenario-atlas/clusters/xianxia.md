# 修仙（参考：《凡人修仙传》《完美世界》《仙逆》《一念永恒》）

> **世界观支柱**：以境界突破（练气—筑基—金丹—元婴—化神…）为时间主轴，宗门、秘境、天劫、法宝构成资源与风险并行的修真世界。
> **典型消费节奏**：每个大境界突破即一次高潮，爽点沿"压抑—机缘—越级反杀"循环密集排布，平均 30~50 章一个大爽点。

## 桥段清单

### 宗门考核收徒
- **资源需求**：一个有名望的宗门（长老层、外门/内门/真传分级）、灵根/资质判定规则、入门试炼场地（幻阵、登仙梯、斗法台）。
- **爽点类型**：身份跃迁 + 打脸（被讥讽废柴者翻盘入真传）。
- **消费时机**：第一卷开篇到中段，主角踏入修真世界的第一道门槛。
- **变体**：①标准——主角靠隐藏灵根被高人破格收录；②反转——主角考核失败反而被魔修带走；③极端——主角是宗门隐藏的"镇宗炉鼎"被强留；④反套路——主角本是考核官，因变故沦为应试者。
- **消费绑定提示**：标注为「开篇钩子」。消费场景：第 1~10 章作为"踏入修真"的入场仪式，把宗门资源体系、境界划分、主角起点一次性铺给读者。

### 秘境探索夺宝
- **资源需求**：定期开启的上古秘境/遗迹、资源稀缺触发争夺、危机机关与上古遗存、各势力代表汇聚的契机。
- **爽点类型**：机缘 + 智斗 + 越级反杀（濒死突破是子母题）。
- **消费时机**：第二卷前后，主角脱离宗门庇护第一次独立博弈。
- **变体**：①标准——秘境争夺中获重宝；②反转——秘境实为陷阱/古魔封印；③极端——主角与同伴反目分赃；④反套路——秘境里只有一段残缺记忆没有宝物，但点醒主角大道。
- **消费绑定提示**：标注为「阶段转折」。消费场景：第一卷与第二卷的衔接段，用一次秘境事件让主角从"宗门新人"过渡到"独立修士"，顺带交付第一波大机缘。

### 飞升渡劫
- **资源需求**：境界体系顶层（渡劫期/飞升期设定）、天劫规则（雷劫、心魔劫、天人五衰）、飞升通道或仙界设定。
- **爽点类型**：宿命对抗 + 史诗感 + 世界观升维。
- **消费时机**：全书末卷或倒数第二卷的高潮，标志凡界篇终结。
- **变体**：①标准——渡过天劫飞升仙界；②反转——飞升通道被截断，主角坠入下界重来；③极端——主角主动散仙位重修；④反套路——天劫其实是上位者的选拔仪式，主角拒绝"飞升"选择留守凡间。
- **消费绑定提示**：标注为「阶段转折」+「长线伏笔」。消费场景：作为凡界篇的终结高潮，同时埋下仙界/上界的伏笔（如"飞升者再无归途"），为续篇留钩。

### 拍卖会
- **资源需求**：大型贸易城/仙城、拍卖行（如万象阁等级别）、各阶层修士与黑市势力、可被争抢的稀缺拍品（丹药、功法、地图残片）。
- **爽点类型**：财力打脸 + 资源博弈 + 信息差炫技。
- **消费时机**：第二至第三卷，主角已积累第一桶金后展示财力/情报。
- **变体**：①标准——主角财大气粗压价夺宝；②反转——拍品是诱饵，拍卖行设局剿杀买家；③极端——主角是匿名委托方，看着别人抢自己放出的东西；④反套路——主角一无所获，但通过观察竞拍者锁定仇家动向。
- **消费绑定提示**：标注为「高频爽点」。消费场景：中段每隔 50~80 章可插入一次拍卖会，作为资源与情报的交汇节点，顺便打脸挑衅者。

### 丹药法宝争夺
- **资源需求**：炼丹师/炼器师体系、稀缺灵药产地、可被多方觊觎的具体重宝（如九转还魂丹、先天灵宝）。
- **爽点类型**：资源争夺 + 杀人夺宝 + 越级保命。
- **消费时机**：贯穿中段，常作为秘境、拍卖会、宗门大比的子事件。
- **变体**：①标准——主角守宝击退群狼；②反转——主角是夺宝方，从老怪手中硬抢；③极端——宝物认主强行绑定主角引来追杀；④反套路——宝物是诅咒，谁拿谁死，主角被迫甩锅。
- **消费绑定提示**：标注为「高频爽点」。消费场景：作为中段任意卷的冲突引擎，每次新重宝出现即可触发一波争夺战。

### 收徒拜师
- **资源需求**：可拜的名师（隐世高人/宗门长老/上古大能残魂）、拜师契机（救命、传承、契约）、师徒名分制度。
- **爽点类型**：靠山加持 + 隐藏血脉/传承揭示 + 师徒情。
- **消费时机**：第一卷中后段或第二卷初，主角确立修真根基的关键节点。
- **变体**：①标准——隐世高人慧眼识珠收主角；②反转——师父别有用心，把主角当鼎炉/替死鬼；③极端——主角同时拜多位师父拼凑传承；④反套路——主角反向"收师"，用现代知识折服上古残魂。
- **消费绑定提示**：标注为「开篇钩子」+「长线伏笔」。消费场景：早期确立主角的传承来源，同时埋下"师父身份之谜"作为长线伏笔（如师尊真实身份是上界大能）。

### 宗门大比
- **资源需求**：跨宗门/跨州的大型比武、各宗门新一代弟子阵容、奖品（名额、灵脉、功法）、宿敌弟子。
- **爽点类型**：竞技打脸 + 同辈排名 + 宿敌对决。
- **消费时机**：第二至第三卷，主角在同辈中确立地位的舞台。
- **变体**：①标准——主角一路碾压夺魁；②反转——主角故意输给隐藏同门；③极端——大比中途被外敌入侵打断，化为混战；④反套路——主角是裁判/教练位，调教师弟妹上场。
- **消费绑定提示**：标注为「高频爽点」。消费场景：作为中段阶段性高潮，每 1~2 卷安排一次不同层级的比武（州级→大陆级），稳定输出竞技爽点。

### 灵脉洞府争夺
- **资源需求**：稀缺灵脉/福地、所有权归属规则、争夺的势力（世家、宗门、散修联盟）。
- **爽点类型**：地盘扩张 + 实力彰显 + 经营养成。
- **消费时机**：第三卷之后，主角从游侠转入立派/立宗阶段。
- **变体**：①标准——主角武力压服原主夺得灵脉；②反转——灵脉本是死局，主角改造后变废为宝；③极端——主角开辟多条洞府形成势力网；④反套路——主角放弃灵脉，因发现其下封印凶物。
- **消费绑定提示**：标注为「阶段转折」。消费场景：主角从"散修"转向"立宗/立势"的转折点，标志主角进入经营阶段。

### 功法残卷补全
- **资源需求**：上古功法体系、残卷分布线索（多份分散）、补全机制（融合、印证、悟道）。
- **爽点类型**：知识拼图 + 大道领悟 + 独门绝学成型。
- **消费时机**：贯穿全书的长线，常作为多卷的暗线。
- **变体**：①标准——集齐残卷补全逆天功法；②反转——残卷是诱饵，每补一卷引 来一批追杀；③极端——主角发现功法本是禁术，补全即招天劫；④反套路——主角自创功法，残卷只是参考反而走出新路。
- **消费绑定提示**：标注为「长线伏笔」。消费场景：作为贯穿 3~5 卷的暗线，每卷推进一段，最后在末卷合卷爆发。

### 金手指觉醒
- **资源需求**：可作金手指的设定（小瓶、残魂、铜镜、系统、至宝）、觉醒契机、金手指与修炼体系的接口。
- **爽点类型**：命运改写 + 独特性确立 + 长线优势获得。
- **消费时机**：第一卷开篇 1~5 章，主角区别于普通修士的根本来源。
- **变体**：①标准——意外获得至宝（如小瓶催熟灵药）；②反转——金手指是诅咒/契约，每用一次付出代价；③极端——金手指是上界大能的实验品；④反套路——主角的金手指是"看穿别人金手指"，专门反套路。
- **消费绑定提示**：标注为「开篇钩子」+「长线伏笔」。消费场景：开篇即交代金手指，作为全书的"独特性契约"向读者承诺爽点来源；同时埋下金手指来源之谜作为长线伏笔。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：境界瓶颈与越级突破
- **标准形态**：主角卡在某个境界瓶颈，靠秘境机缘/濒死顿悟/异宝灌顶完成越级突破，当场反杀围攻者。
- **可变维度**：瓶颈来源（资质/资源/心境/天劫）、突破代价（寿元/本源/情感）、突破后的反噬（心魔、追兵、暴露身份）。
- **衍生问题**：如果本书的 Architecture 核心引擎是"道心修证"而不是"资源堆叠"，越级突破会从"嗑药灌顶"变成什么形态？如果 Strategy 把"金丹期突破"从第二卷挪到第四卷，前期需要铺哪些"非境界成长"的爽点来填补？

### 母题 2：宗门庇护与独立出走
- **标准形态**：主角在宗门内被庇护又被压制，因某次大事件（被诬陷、长辈陨落、秘境事故）被迫出走，进入散修丛林。
- **可变维度**：出走原因（冤屈/野心/追杀/任务）、出走形态（单飞/带同门/叛宗）、宗门后续关系（复仇/回归/自立门户）。
- **衍生问题**：如果本书核心引擎是"经营立宗"而不是"个人飞升"，主角会不会从"出走者"变成"立宗者"？这时宗门大比该改成什么形态？

### 母题 3：天劫与天人对抗
- **标准形态**：修士到高境界必渡天劫，天劫既是门槛也是筛选，主角以逆天姿态硬抗天劫完成飞升。
- **可变维度**：天劫本质（天道规则/上位者筛选/世界自愈）、天劫形态（雷劫/心魔/天人五衰）、主角与天劫的关系（对抗/利用/超越）。
- **衍生问题**：如果本书核心引擎是"天道即反派"，天劫会从"自然现象"变成什么？如果 Strategy 把渡劫设为开篇钩子（主角上一世渡劫失败重生），后续每次境界突破的情绪色彩会如何变化？

### 母题 4：传承拼图与功法演化
- **标准形态**：主角获得残卷功法，跨多卷收集补全，最终形成独门大道。
- **可变维度**：残卷来源（上古宗门/异界/师承/敌手）、补全方式（融合/悟道/夺舍记忆）、功法终极形态（开宗立派/超越天道/反噬宿主）。
- **衍生问题**：如果本书核心引擎是"自创而非继承"，残卷补全会从"集邮"变成什么？主角是该补全残卷，还是该在残卷基础上"破而后立"？

### 反套路与"烂大街"风险

来自 WebSearch 读者批评的集中意见：

- **退婚流+废柴逆袭严重过载**：被讥为"填空题式"创作，"三十年河东三十年河西"已成梗。**注：退婚流由《斗破苍穹》开创，属于玄幻簇的权威桥段，其完整定义与反套路规避见 `xuanhuan.md` 的"退婚流开局"**；修仙族借用此桥段时，应聚焦于"灵根/资质觉醒"这一修仙专属的翻盘机制，而非复制玄幻的"血脉觉醒"套路，避免两个题材的开篇钩子雷同。
- **签到躺赢流丧失紧张感**：主角靠签到天降神器，缺乏人性转变与博弈张力，读者批评"太直白"。规避方式：签到奖励必须伴随使用代价或引来更强势的敌人。
- **越级反杀同质化**：濒死—血脉觉醒—燃烧本源—越级反杀被反复使用，知乎专栏已将其列为"典中典"。规避方式：让越级突破付出不可逆代价（寿元、至亲、本源），或主角靠智谋而非纯爆发获胜。
- **宗门设定脸谱化**：长老贪婪、师兄跋扈、师妹花痴已成刻板印象。规避方式：给宗门内部加入派系博弈、理念之争，让"打压主角"有制度性而非恶意性的理由。
- **渡劫期世界观割裂**：飞升后仙界篇常崩盘（凡界篇的积累在新体系下失效）。规避方式：在凡界阶段就预埋仙界规则的一致性接口。

> **力量代价的元法则**：本簇桥段涉及"越级反杀/境界突破/天劫渡劫"时，题材层的口头建议不足以约束。强制性的元法则（U-1 法则惰性、U-2 代价不可消除、U-4 力量上限）见 `universe-atlas/clusters/framework.md`；修仙世界的力量分级骨架（炼气→筑基→金丹…）与法则强度（LI）见 `universe-atlas/clusters/xianxia.md`。推导越级/渡劫桥段时必须同时参照 framework 的 U-* 元法则，确保越级付出不可逆代价。

### 未覆盖子流派的推导路径

- **魔修流**：从"宗门考核"反推——魔宗收徒不考灵根而考"魔性"，可衍生"血祭考核""噬主法宝""反噬心魔"等桥段；功法残卷补全改为"魔功反噬压制"。
- **佛修流/儒修流**：从"飞升渡劫"反推——渡劫不是雷劫而是"心魔劫/红尘劫"，桥段改为"渡化众生""立地成佛""言出法随"；宗门大比改为"辩经大会"。
- **体修流**：从"丹药法宝争夺"反推——主角不抢法宝只抢炼体材料，桥段改为"百炼成身""肉身渡劫""徒手碎法宝"。
- **妖修流**：从"血脉觉醒"反推——主角是妖修，渡劫化形面临被人类修士剖丹的宿命（学术论文《中國網路玄幻小說空間敘事》提到《万妖之祖》此桥段）。
- **剑修流**：从"功法残卷补全"反推——补的不是功法而是"剑意"，桥段改为"剑心通明""一剑破万法""剑冢选剑"。
- **修仙种田/经营流**：从"灵脉洞府争夺"扩写——主角以灵脉立宗，桥段重心从"争夺"转向"经营、收徒、扩宗、抵御外敌"。
