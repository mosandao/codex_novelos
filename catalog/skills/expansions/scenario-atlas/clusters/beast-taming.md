# 御兽 / 召唤（参考：《宠魅》《召唤万岁》《御兽修仙》《御兽从进化开始》）

> **世界观支柱**：人人可契约宠兽/眷灵的全民御兽世界，御兽师与宠兽通过羁绊共同进化升星。
> **典型消费节奏**：开篇契约第一只宠兽（钩子），之后高频"契约→培养→进化→对战"循环，每个进化节点是阶段性大爽点。

## 桥段清单

### 御兽契约捕捉
- **资源需求**：契约仪式/契约卷轴/契约兽蛋、可被契约的野生宠兽栖息地、御兽师天赋（精神力/契约位）、契约失败的反噬风险设定。
- **爽点类型**：契约成功瞬间的"获得感" + 捡漏式契约（别人看不上的垃圾宠实为隐藏血脉）。
- **消费时机**：第一卷开篇必有一次（首契约作为钩子），之后每个新宠兽加入都是一次小爽点。
- **变体**：①废柴开局捡漏垃圾宠；②被强大宠兽主动契约；③契约仪式失败反噬逆袭；④契约位稀缺只能精挑细选；⑤强制契约/血契带来的代价（反转）。
- **消费绑定提示**：开篇钩子 + 高频爽点。具体场景：第一卷前 5 章必须出现"首契约"作为开篇钩子；之后每 1-2 卷安排一次"新宠兽加入"的高频爽点；world_contract 需标注"契约位上限"作为消费约束。

### 御兽进化升星
- **资源需求**：进化材料/灵物/特定环境、进化路线图（隐藏 or 明示）、血脉觉醒触发条件、进化失败风险。
- **爽点类型**：形态升级的视觉冲击 + 战力质变的爽点 + 隐藏进化路线揭晓的"原来如此"感。
- **消费时机**：贯穿全书，每个宠兽的进化节点是阶段性大高潮。
- **变体**：①标准进化（小狼→疾风狼→地狱疾风狼）；②隐藏血脉觉醒（哈士奇→地狱疾风狼的逆向揭秘）；③多分支进化路线抉择；④进化失败/异化（反转）；⑤羁绊进化（需与主人情感达成条件）。
- **消费绑定提示**：阶段转折 + 长线伏笔兑现。具体场景：每卷至少一次进化作为卷尾阶段转折；开篇埋下的"这只宠兽真实血脉"伏笔应在第三卷前后兑现为首次大进化。

### 御兽对战擂台
- **资源需求**：竞技场/擂台赛制、排名体系、对手库（天才/世家/外校）、对战规则（一对一/轮换/团战）。
- **爽点类型**：碾压天才 + 排名跃升 + 宠兽配合的战术爽点。
- **消费时机**：高频，第二卷起每 1-2 卷一次大中型赛事。
- **变体**：①学院排位赛碾压天才；②跨区域联赛/大考；③赌兽/赌注赛；④规则限制赛（等级压制/属性克制）；⑤擂台败北触发进化（反转）。
- **消费绑定提示**：高频爽点。具体场景：每 10-15 章安排一场对战作为稳定爽点供给；每卷安排一次大型赛事（大考/联赛）作为该卷高潮锚点。

### 御兽图鉴收集
- **资源需求**：图鉴系统/真视之眼/鉴定术、稀有宠兽分布图、原产地探索路线、收集奖励机制。
- **爽点类型**：收集完成度 + 图鉴解锁的"全图鉴"强迫症爽点 + 稀有度展示。
- **消费时机**：贯穿全书作为暗线，关键收集节点触发支线。
- **变体**：①系统图鉴自动解锁；②真视之眼看穿隐藏属性；③图鉴收集兑换奖励；④图鉴反噬（看到不该看的）；⑤图鉴收集触发隐藏剧情（长线伏笔）。
- **消费绑定提示**：长线伏笔 + 高频爽点。具体场景：每契约/进化一只新宠兽都伴随图鉴更新（高频小爽点）；图鉴全收集作为全书长线伏笔，结局卷兑现为"图鉴完成度奖励"。

### 御兽秘境原产地
- **资源需求**：野生秘境/古遗迹/原始森林、稀有宠兽原产地、秘境开放周期/门票机制、秘境危险等级。
- **爽点类型**：探险 + 稀有宠兽捕获 + 秘境资源掠夺。
- **消费时机**：中段（第二至四卷），每 1-2 卷一次秘境副本。
- **变体**：①周期性开放公共秘境；②私人秘境/传承秘境；③秘境深处发现传说宠兽；④秘境异变（反转）；⑤与世家/敌对势力争夺秘境资源（冲突）。
- **消费绑定提示**：阶段转折 + 高频爽点。具体场景：每卷安排一次秘境副本作为该卷主线舞台；秘境深处的传说宠兽作为阶段转折节点。

### 人兽羁绊共生
- **资源需求**：羁绊值/灵力反哺机制、宠兽人格化/灵性、共同成长体系、羁绊断裂的代价设定。
- **爽点类型**：情感共鸣 + 宠兽为主角牺牲/守护的催泪爽点 + 进化反哺主人境界。
- **消费时机**：中后段情感高潮，常与进化节点绑定。
- **变体**：①宠兽进化反哺主人境界；②宠兽为主角挡致命一击；③羁绊过深导致主角共享宠兽痛觉；④宠兽主动选择离开（反转）；⑤人兽合体/附体战（高阶形态）。
- **消费绑定提示**：长线伏笔 + 阶段转折。具体场景：开篇建立羁绊伏笔，中段每次进化附带羁绊强化镜头；高潮卷安排"宠兽为主角牺牲"或"人兽合体"作为全书情感转折点。

### 御兽师学院培养（新增）
- **资源需求**：御兽学院/师资/课程体系、同学圈子、学院资源（图书馆/训练场/秘境）、升学考核。
- **爽点类型**：校园日常 + 学院资源倾斜 + 同学互动的轻松爽点。
- **消费时机**：第二卷起进入学院线，持续 2-3 卷。
- **变体**：①入学考试碾压；②学院资源倾斜引发嫉妒；③导师偏爱/收徒；④学院派系斗争；⑤退学/被开除逆袭（反转）。
- **消费绑定提示**：阶段转折 + 高频爽点。具体场景：第一卷末以"入学考试"作为进入学院线的阶段转折；学院期间每卷安排一次"考核/资源争夺"作为该卷高潮。

### 世家天才碾压与家族夺还（新增）
- **资源需求**：御兽世家/天赋血脉设定、被夺天赋的开局背景、对手天才库、家族资源/传承。
- **爽点类型**：废柴逆袭 + 打脸世家天才 + 夺回家族/天赋的复仇爽点。
- **消费时机**：开篇背景钩子 + 贯穿全书的复仇线。
- **变体**：①天赋被家族夺走后契约神宠逆袭；②被逐出家族后回归打脸；③世家天才一对一碾压；④揭穿家族阴谋；⑤与家族和解/合作（反转）。
- **消费绑定提示**：开篇钩子 + 长线伏笔。具体场景：开篇即用"天赋被夺/被逐出家族"作为钩子；复仇线作为长线伏笔贯穿，每卷一次打脸进度，高潮卷夺回家族。

### 全民御兽大考/选拔（新增）
- **资源需求**：全国/全州大考赛制、荒原/秘境考场、考官与监考机制、升学/晋级奖励。
- **爽点类型**：碾压同辈 + 大考黑马 + 排名公开的打脸爽点。
- **消费时机**：第一卷末或第二卷中的第一个大型公共舞台。
- **变体**：①荒原野外求生考；②对战淘汰赛；③秘境探索积分赛；④大考黑马引发世家关注；⑤大考舞弊/暗算（反转）。
- **消费绑定提示**：阶段转折。具体场景：作为第一卷到第二卷的过渡转折——主角在大考上一鸣惊人，决定下一阶段的学院/势力归属。

### 神级宠兽系统/进化模拟（新增）
- **资源需求**：系统面板/进化模拟天赋、模拟消耗（灵力/资源/寿命）、模拟结果的可信度。
- **爽点类型**：信息差碾压 + 模拟出最优进化路线的"作弊"爽点。
- **消费时机**：贯穿全书作为核心金手指，每次模拟是一次决策爽点。
- **变体**：①进化模拟（模拟出隐藏路线）；②战斗模拟（预演对战结果）；③人生模拟（模拟不同选择的人生）；④模拟失败/被干扰（反转）；⑤模拟结果被对手偷看（冲突）。
- **消费绑定提示**：高频爽点 + 长线伏笔。具体场景：每次面临进化/对战抉择时安排一次模拟（高频）；模拟系统本身的来历作为长线伏笔，后段揭晓。

## 启发式推演提示（LLM 推演 hook）

### 母题 1：垃圾宠隐藏血脉
- **标准形态**：主角契约一只所有人嫌弃的"垃圾宠"，实则隐藏传说血脉，后续进化逆袭。
- **可变维度**：垃圾宠的种类（动物/植物/元素/死灵/机械）、隐藏血脉的揭晓时机、揭晓方式（自然进化 vs 外部刺激）。
- **衍生问题**：如果本书的 Architecture 核心引擎是"科学培育"而不是"血脉觉醒"，隐藏血脉桥段会变成"基因优化/培育实验"的什么形态？血脉揭晓从被动变主动（主角刻意寻找基因样本）会如何重构爽点？

### 母题 2：契约位与多宠体系
- **标准形态**：主角契约位有限（3-6 只），每只宠兽承担不同战术定位。
- **可变维度**：契约位上限、契约位扩展机制、宠兽之间的配合/克制、退役/放生机制。
- **衍生问题**：如果本书的 Strategy 阶段目标把"契约位扩展"从第二卷挪到第四卷，前期如何用"单宠深度培养"替代"多宠战术"？如果契约位无限，桥段会变成"全图鉴收集流"，对战桥段该如何重新设计？

### 母题 3：进化路线分歧
- **标准形态**：每只宠兽在进化节点面临多分支选择（攻/防/敏/特殊）。
- **可变维度**：分支数量、分支解锁条件、分支不可逆性、分支之间的协同/冲突。
- **衍生问题**：如果本书的核心引擎是"羁绊决定进化"，进化分歧会从"资源驱动"变成"情感事件驱动"，需要前置哪些羁绊事件桥段？如果进化可逆/可重置，桥段的爽点会从"不可逆抉择的紧张感"变成什么？

### 反套路与"烂大街"风险
来自 WebSearch 读者批评的提炼：
- **宠兽种类高度雷同**：九尾炎狐、生命古树、雷云精灵、骷髅君主已成"标配"，几乎所有御兽文都有。建议跳出常见的"火狐/雷鸟/树精/骷髅"四件套，引入冷门物种（昆虫/海洋生物/微生物/古生物）或非生物宠（器灵/概念体）。
- **进化路线模板化**："小骷髅→骷髅兵→白骨将军→亡灵天灾"这种直线进化链已成公式。建议引入多分支进化、环境适应进化、甚至退化进化（高阶宠主动退回低阶以解锁新路线）。
- **后期套路灌水严重**："契约→培养→进化→碾压"循环反复，读者审美疲劳。建议在中后期引入"宠兽文明/宠兽世界内部政治"或"人兽身份反转（宠兽才是主角）"作为差异化。
- **金手指同质化**：真视之眼/进化模拟/图鉴系统已成标配。可尝试"反向金手指"（只能看到死亡结局/只能契约将死之兽）等变体。

### 未覆盖子流派的推导路径
- **精灵流/数码流**：从"御兽契约捕捉"反推，把宠兽替换为精灵/数码兽，契约机制变成"捕捉精灵球/数码扫描"，进化引入"分支进化+合体进化+装备进化"。
- **召唤流（区别于御兽）**：从"御兽契约"反推，召唤物来自异界/契约位面，不培养而是"召唤时长有限/召唤物有自主意识"，桥段重心从"养成"转向"契约谈判/召唤物博弈"。
- **器灵流/概念御兽**：从"图鉴收集"反推，被契约的是有灵性的器物（古董刀剑/书画/建筑）或抽象概念（季节/情绪/因果），进化路线从"血脉"变为"历史沉淀/概念升维"。
- **反派御兽师流**：从"世家天才碾压"反转，主角本身是反派/魔修御兽师，契约的是被正派唾弃的"凶兽/邪灵"，桥段重心从"碾压天才"变为"对抗正派围剿"。
- **宠兽视角流**：从"人兽羁绊共生"反推，主角就是被契约的宠兽，桥段重心从"御兽师培养宠兽"变为"宠兽培养废柴御兽师/宠兽选择主人"。
