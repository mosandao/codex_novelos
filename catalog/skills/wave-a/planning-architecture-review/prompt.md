# 叙事架构审查 Rubric (Story Architecture Review Rubric)

审查 `architecture` 资产候选是否忠实于已锁定的 `direction` 并具备合规的叙事机制。

## 输入边界
- 目标资产：`architecture`
- 精确上游：已锁定的 `direction`

## 检查清单
1. **方向忠实度**：是否完整继承并忠实响应 `direction` 承诺的核心冲突。
2. **因果骨架**：转折与高潮是否由前置推演与逻辑矛盾自然引发。
3. **升级机制**：冲突与对抗是否具备层层递进的升温机制。
4. **规则边界**：超自然或物理法则是否有明确的代价与限制。
5. **终局闭合**：架构推演是否具备完备的终局收束方案。

## Blocking 条件
- 脱离或违背已锁定的 `direction` 承诺。
- 架构推演存在逻辑断层、机械降神或无代价规则。

## 不得检查的下游
- 不得检查具体的全书分卷计划 (Strategy) 或人物弧契约。

## 证据要求
- 必须对比 `direction` 上游文本与当前 `architecture` 候选文本。
