# 全书战略审查 Rubric (Story Strategy Review Rubric)

审查 `strategy` 资产候选是否符合 `direction` 与 `architecture`。

## 输入边界
- 目标资产：`strategy`
- 精确上游：已锁定的 `direction` 与 `architecture`

## 检查清单
1. **阶段目标**：全书各阶段推进目标是否清晰合理。
2. **不可逆状态变化**：每个大阶段结束是否伴随不可逆的世界或角色状态变更。
3. **资源与压力升级**：对抗压力与危机规模是否按阶段升级。
4. **全书节奏**：高潮与间歇的分布是否符合长篇叙事节奏。

## Blocking 条件
- 违背 `direction` 或 `architecture` 约定的铁律。
- 阶段推进缺乏不可逆变化，导致情节原地打转。

## 不得检查的下游
- 不得检查单卷细化章纲或具体场景执行卡。

## 证据要求
- 引用战略阶段节点与上游架构规则进行对照说明。
