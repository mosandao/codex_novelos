# 人物契约审查 Rubric (Character Contract Review Rubric)

审查 `character_contract` 资产候选。

## 输入边界
- 目标资产：`character_contract`
- 精确上游：已锁定的 `architecture` 与 `strategy`

## 检查清单
1. **欲望与恐惧**：核心角色的深层动机与核心弱点是否清晰鲜明。
2. **人物弧变化**：角色在战略节点上是否有清晰的心理或信仰转变弧度。
3. **关系契约**：主角与核心配角/对手的关系变化契约是否明确。
4. **能力边界**：角色的能力上限与成长代价是否严格遵循架构规则。
5. **阶段职责**：角色在全书各阶段的叙事功能分配是否合理。

## Blocking 条件
- 角色能力超越 `architecture` 法则限制或缺乏成长代价。
- 核心人物缺乏动机或人物弧与全书战略脱节。

## 不得检查的下游
- 不得检查世界地理细节或单章对话。

## 证据要求
- 必须同时引用人物契约文本与架构规则原文。
