## 模式语法：新建内核（create）

- 生活基底**多元化**：核心问题与价值公理必须能追溯到家庭/阅读/普通快乐与挫折/社会环境/信息筛选/长期复盘中的**至少三类**来源——单一创伤来源的内核按单线因果链退回重做（wound→fear 链属于分身层 refuses 的纪律，不属于内核层）。
- 首核定型责任：这是库里的第一层根——后续所有分身都从它派生。八维的 tendency 选择要意识到「你在为整个内核谱系定基调」；与既有**人格**指纹的比对照常执行（防止内核与旧原型直连人格语义撞车）。
- 素材缺口不编造：hints 只给了两三个字段时，其余字段从「什么样的人生必然长出这几条素材」反推，rationale 里写明哪些是反推、哪些直接来自素材。

## 附加自检

- 生活基底来源 ≥3 类已核对；无单一创伤因果链；反推字段已在 rationale 标注。
