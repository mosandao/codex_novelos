## 库规模语法：小库（1-4 份）——豁免可用，但样样留痕

### 跨批次去重校验（强制）

生成前先扫描 `existing_persona_fingerprints`。小库全量比对。实际比对的份数与范围必须写入 cross_batch_check——未写明比对范围即该项检查未通过。

- 若烙印事件类型/年代与任意 1 份高度重合（如「体制转型期家道中落」已出现过），必须换一种冲击源，不因「不在同批」而豁免。
- 若标志性道具/仪式的**结构**（不只是名称）与任意 1 份雷同——即便物件名字不同，只要都是「创伤遗物 + 反复摩挲/把玩的私人仪式 + 印刷体金句」这套三段式——判定为撞车，须换用完全不同的立人方式（见主干 1.4 特质层纪律）。
- **叙事律令语义内核比对**（防价值观轴换皮存活）：`narrative_principles` 主原则（第 1 条）与 `forbidden_conveniences` 须与库中已有做**语义内核**比对——判据：抽掉题材词与措辞后剩下的是否同一条世界律令（如「一切力量兑付必有出处与利息」≈「没有白拿的神恩」，同为「力量必须可核算」轴）。**跨 parent 重合**（库中不同 parent 的人格也长出同轴）＝生成偏好泄漏，本次必须换主轴；**同 parent 重合**＝血缘继承合法，但须在 cross_batch_check 显式声明该轴来自 parent 原型签名，并说明本次表达角度如何从自己的 persona 长出——静默同轴视为未检查。
- **规则引用可溯源**：cross_batch_check 中引用的任何规则、阈值、条款必须是主干或本模块明文存在的——不得引用想象中的条款为自己的选择背书；引用前核对原文。
- 张力形态跨批轮换：生成前比对最近 3 份（库不足 3 份则全量）的张力形态，避开重复。
- 该校验结果写入 `parent_rationale` 的 `cross_batch_check` 小节：比对了哪些已有人格（份数与范围）、规避了什么重复、结论。

### 行业内生配额（小库豁免版）

从 `existing_persona_fingerprints` 的 career_track 逐份判定是否网文行业内生（判据：职业履历的**主要收入来源**在网文生态内——编辑/内容运营/数据岗/职业书评榜单玩家/同人创作社群资深成员；「读了多年书的老书虫但本职在别处」不算内生）。小库阶段豁免可用：本次 career_track 可以来自网文行业外，但须在 cross_batch_check 写明库内内生占比数字与豁免理由，供下次生成核对。

### theme_orientation 反默认引力（小库版，替代滚动比例）

样本无统计意义，不设比例触发——改为**逐个论证**：主题×兑现场域的组合不许机械贴频道默认（男频×agency／女频×communion×家族场域）。与默认组合重合必须论证为何默认组合对本书最优（「仅仅不顺手」不构成理由）；不重合时不需额外论证。

### 坏味道补充（出现即重做）

- 标志性道具名称不同但结构同为「创伤遗物+私人仪式+金句」三件套（跨人格判定，不止查同批）。
- 库中职业履历连续 3 份全部来自网文行业外的转行叙事，无一人有网文生态内生视角，且本次仍不补内生。

## 附加自检

- **跨批次撞车检查**：已全量比对 `existing_persona_fingerprints`，烙印事件类型、道具结构、张力形态、主原则与 forbidden_conveniences 的语义内核（跨 parent 无重合；同 parent 重合已声明血缘与表达角度）均未重复（或已上报理由），内生占比数字已算出，引用的规则条款均可溯源，校验结果已写入 `cross_batch_check`。
